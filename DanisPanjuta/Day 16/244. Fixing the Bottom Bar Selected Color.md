# Fixing the Bottom Bar Selected Color

---

## Overview

By default `BottomNavigationItem` colors are subtle. This lecture makes `selectedContentColor = Color.White` and `unselectedContentColor = Color.Black` (or `Color.Gray`) obvious, and ensures the `selected` param drives the highlight via `currentRoute`.

---

## The fix

`BottomBar.kt`:

```kotlin
BottomNavigationItem(
    icon = { Icon(painterResource(item.icon), null) },
    label = { Text(item.bTitle) },
    selectedContentColor = Color.White,
    unselectedContentColor = Color.Black,
    selected = currentRoute == item.bRoute, // was previously currentScreen.value == item
    onClick = { navController.navigate(item.bRoute) { launchSingleTop = true } }
)
```

| Before | After |
| :--- | :--- |
| `selected = currentScreen.value == item` (ViewModel state) | `selected = currentRoute == item.bRoute` (NavBackStack route) |
| Colors muted | `White` (selected) vs `Black` (unselected) pops |

The lecture notes `currentRoute` is the source of truth — `ViewModel.currentScreen` can drift if navigation is triggered from outside.

Also adds `launchSingleTop = true` to avoid stacking duplicate bottom destinations.

---

## Recap / cheat sheet

- **Colors:** `selectedContentColor=White`, `unselectedContentColor=Black`.
- **Selected:** `currentRoute == item.bRoute` via `currentBackStackEntryAsState()`.
