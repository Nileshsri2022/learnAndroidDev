# Adding Actions to our Scaffold

---

## Overview

The `Scaffold`'s `topBar` `MoreVert` (⋮) icon should open the `ModalBottomSheet` with actions like *Sort* or *Add Account*. This lecture wires that `IconButton` to `sheetState.show()` and adds `Snackbar` handling for the actions.

---

## Step 1 — actions

`HomeView` `TopAppBar`:

```kotlin
TopAppBar(
    title = { Text(viewModel.title) },
    navigationIcon = { IconButton({ scope.launch{ drawerState.open() } }) { Icon(Menu, null) } },
    actions = {
        IconButton(onClick = { scope.launch { sheetState.show() } }) {
            Icon(Icons.Default.MoreVert, null)
        }
    }
)
```

| Slot | Composable |
| :--- | :--- |
| `actions` | Row of `IconButton`s on the right of the bar |

---

## Step 2 — sheet actions

`sheetContent`:

```kotlin
Column {
    Row(Modifier.clickable{
        scope.launch{ sheetState.hide() }
        scaffoldState.snackbarHostState.showSnackbar("Sort clicked")
    }) { Icon(Sort, null); Text("Sort") }
    Row(Modifier.clickable{
        scope.launch{ sheetState.hide() }
        navController.navigate(Screen.Account.route)
    }) { Icon(Add, null); Text("Add Account") }
}
```

Each `Row` first `hide()`s the sheet, then performs the action (snackbar or navigation).

---

## Recap / cheat sheet

- **Actions:** `TopAppBar(actions={ IconButton(MoreVert){ scope.launch{ sheetState.show() } } })`.
- **Sheet items:** `Row(clickable{ scope.launch{ hide() }; action })`.
