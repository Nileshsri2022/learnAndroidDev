# Welcome to Day 16

---

## Overview

Day 16 completes the **Music App** started yesterday. The focus shifts from the **drawer** to the **`BottomBar`** (`BottomNavigation`), additional destinations (**Browse**, **Library**, **Home** with sticky text), `ModalBottomSheetLayout`, and keeping the `TopAppBar` title in sync. By the end the app has a production-like scaffold: top bar + drawer + bottom bar + bottom sheet + snackbars.

---

## What you will build

| Component | Role |
| :--- | :--- |
| `BottomBar` | `BottomNavigation` with 3 `BottomNavigationItem`s — Home, Browse, Library |
| `HomeView` (expanded) | `LazyColumn` with `StickyHeader` ("New Releases") + song rows |
| `BrowseScreen` | Challenge solution — grid of categories |
| `LibraryScreen` | User's library |
| `ModalBottomSheetLayout` | Bottom sheet that slides up with *Sort*, *Add Account* actions |
| Title sync | `MainViewModel` keeps `TopAppBar` title matching the selected bottom tab or drawer item |

## Recap / cheat sheet

- **BottomBar** = persistent navigation complementary to the drawer — both navigate but to different information architecture.
- **Bottom sheet** = contextual actions, not navigation.
