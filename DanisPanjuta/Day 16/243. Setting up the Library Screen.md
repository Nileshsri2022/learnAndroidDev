# Setting up the Library Screen

---

## Overview

`LibraryScreen` shows the user's library — playlists, artists, albums — as a `LazyColumn` with dividers and secondary text. It is a static placeholder, but it demonstrates `Divider` and conditional bottom-sheet actions.

---

## The screen

`LibraryView.kt`:

```kotlin
@Composable
fun Library() {
    LazyColumn(Modifier.fillMaxSize().padding(16.dp)) {
        items(libraries) { lib ->
            Row(Modifier.fillMaxWidth().padding(8.dp).clickable{ /* sheet or navigate */ }) {
                Icon(painterResource(lib.icon), null, Modifier.size(48.dp))
                Column(Modifier.padding(start=8.dp)) {
                    Text(lib.name, fontWeight=Bold)
                    Text(lib.iconText, color=Color.Gray)
                }
            }
            Divider(color=Color.LightGray)
        }
    }
}

data class Library(val name:String, val icon: Int, val iconText:String)
val libraries = listOf(
    Library("Playlist", R.drawable.ic_playlist, "103 songs"),
    Library("Artists", R.drawable.ic_microphone, "52 artists"),
    Library("Albums", R.drawable.ic_album, "20 albums")
)
```

| Element | Role |
| :--- | :--- |
| `Row` + `Icon` + `Column` | Classic list row |
| `Divider` | Hairline between rows |
| `clickable` | Would open `ModalBottomSheet` or navigate |

---

## Recap / cheat sheet

- **Library:** `LazyColumn { items(libraries) { Row(Icon+Column)+Divider } }`.
