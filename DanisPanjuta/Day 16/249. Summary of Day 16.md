## Theme

A production-grade **Scaffold** shell: top bar + drawer + bottom bar + bottom sheet + snackbars, with three bottom destinations and two drawer destinations, all synchronized via a `ViewModel` and `NavController`.

---

## Architectural flow

```text
MainActivity → Navigation()
      ├── NavHost(home_b)
      │     ├── composable(home_b) → HomeView(StickyHeader + SongItems + BottomSheet)
      │     ├── composable(browse) → Browse(LazyVerticalGrid)
      │     ├── composable(library) → Library(LazyColumn + Dividers)
      │     ├── composable(add_account) → AccountView
      │     └── composable(subscription) → SubscriptionView
      └── ModalBottomSheetLayout(sheetState)
            └── ModalDrawer(drawerState)
                  └── Scaffold(topBar=TopAppBar(title, Menu→open, MoreVert→showSheet), bottomBar=BottomBar)

BottomBar: BottomNavigation { Home,Browse,Library } → navigate(bRoute){launchSingleTop}
Drawer: ModalDrawer { DrawerItem } → close → viewModel.title → navigate(route)
TopAppBar: Text(viewModel.title) — synced via LaunchedEffect(currentRoute)
BottomSheet: MoreVert → scope.launch{ sheetState.show() } → Sort/Add actions
```

## Complete reference (bottom + sheet)

### BottomBar
```kotlin
@Composable fun BottomBar(navController:NavController, viewModel:MainViewModel){
    val currentRoute = navController.currentBackStackEntryAsState().value?.destination?.route
    BottomNavigation{ listOf(BottomScreen.Home, Browse, Library).forEach{
        BottomNavigationItem(icon={Icon(painterResource(it.icon),null)}, label={Text(it.bTitle)},
                             selected=currentRoute==it.bRoute, onClick={navController.navigate(it.bRoute){launchSingleTop=true}},
                             selectedContentColor=White, unselectedContentColor=Black)
    }}
}
```

### Sheet
```kotlin
val sheetState = rememberModalBottomSheetState(Hidden)
val scope = rememberCoroutineScope()
ModalBottomSheetLayout(sheetState, sheetContent={ Box{ Column{ Row(Sort){}; Row(Add){} } } }){
    Scaffold(topBar={TopAppBar(viewModel.title)}, bottomBar={BottomBar(...)}){ NavHost }
}
```
