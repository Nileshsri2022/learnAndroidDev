# Challenge Solution - Browse Screen

---

## Overview

The **Browse** destination is a `LazyVerticalGrid` of category cards (Podcasts, Live Events, Made For You, New Release). The lecture solves the challenge: a 2-column grid where each card has a `Card` + `Image` + `Text`.

---

## The screen

`BrowseScreen.kt`:

```kotlin
@Composable
fun BrowseScreen() {
    val categories = listOf("Podcasts", "Live Events", "Made For You", "New Release")
    LazyVerticalGrid(columns = GridCells.Fixed(2), contentPadding = PaddingValues(16.dp)) {
        items(categories) { cat ->
            Card(Modifier.padding(8.dp).fillMaxWidth().height(120.dp), elevation = 4.dp) {
                Column(Modifier.padding(16.dp)) {
                    Text(cat, fontWeight = Bold)
                    // optional Image
                }
            }
        }
    }
}
```

| Layout | Role |
| :--- | :--- |
| `LazyVerticalGrid(GridCells.Fixed(2))` | 2-column grid, lazy |
| `Card` | Elevated tile |
| `Text(cat)` | Category label |

Alternatively `LazyColumn` with `Row`s of two items — same visual result. The course picks `LazyVerticalGrid` for its built-in grid semantics.

---

## Recap / cheat sheet

- **Browse:** `LazyVerticalGrid(Fixed(2)) { items(categories) { Card { Text } } }`.
