# Setting up the BottomBar

---

## Overview

`BottomNavigation` is the row of 3-5 icons at the bottom of many apps (Spotify, YouTube). This lecture builds `BottomBar.kt` as a `BottomNavigation` that hosts `BottomNavigationItem`s.

---

## The composable

`BottomBar.kt`:

```kotlin
@Composable
fun BottomBar(navController: NavController, state: ModalBottomSheetState, viewModel: MainViewModel) {
    val screensInBottom = listOf(Screen.BottomScreen.Home, Screen.BottomScreen.Browse, Screen.BottomScreen.Library)
    val navBackStackEntry by navController.currentBackStackEntryAsState()
    val currentRoute = navBackStackEntry?.destination?.route
    val currentScreen = viewModel.currentScreen.value

    BottomNavigation(Modifier.background(Color.White)) {
        screensInBottom.forEach { item ->
            BottomNavigationItem(
                icon = { Icon(painter = painterResource(id = item.icon), contentDescription = item.bTitle) },
                label = { Text(item.bTitle) },
                selectedContentColor = Color.White,
                unselectedContentColor = Color.Black,
                selected = currentRoute == item.bRoute,
                onClick = { navController.navigate(item.bRoute) }
            )
        }
    }
}
```

| Prop | Value |
| :--- | :--- |
| `BottomNavigation` | Container, fixed height 56.dp, elevation |
| `BottomNavigationItem` | Each tab — `icon`, `label`, `selected`, `onClick` |
| `currentRoute == item.bRoute` | Determines selection |
| `navController.navigate(bRoute)` | Navigate to the bottom tab destination |

> `item.icon` is `@DrawableRes Int`, resolved via `painterResource`. Alternative uses `Icons.Filled.*`.

Scaffold placement:

```kotlin
Scaffold(bottomBar = { BottomBar(navController, sheetState, viewModel) }) { padding -> NavHost(Modifier.padding(padding)) }
```

---

## Recap / cheat sheet

- **BottomBar:** `BottomNavigation { screensInBottom.forEach { BottomNavigationItem(icon, label, selected, onClick) } }`.
- **Selection:** `currentRoute == item.bRoute`.
