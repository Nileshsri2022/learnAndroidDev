# Adding the Navigation Routes

---

## Overview

The three bottom tabs need routes distinct from drawer routes. This lecture extends the `Screen` sealed class to include `BottomScreen` objects and registers them in `NavHost`.

---

## Step 1 — Screen

`Screen.kt`:

```kotlin
sealed class Screen(val route: String) {
    object Home : Screen("home")
    object Account : Screen("add_account")
    object Subscription : Screen("subscription")
    sealed class BottomScreen(val bRoute: String, val bTitle: String, @DrawableRes val icon: Int) : Screen(bRoute) {
        object Home : BottomScreen("home_b", "Home", R.drawable.ic_home)
        object Browse : BottomScreen("browse", "Browse", R.drawable.ic_browse)
        object Library : BottomScreen("library", "Library", R.drawable.ic_library)
    }
}
```

| Screen | `bRoute` | Purpose |
| :--- | :--- |
| `BottomScreen.Home` | `"home_b"` | Song releases + sheet |
| `BottomScreen.Browse` | `"browse"` | Categories grid |
| `BottomScreen.Library` | `"library"` | User library |

Drawer routes and bottom routes coexist in one `NavHost`.

---

## Step 2 — NavHost

`Navigation.kt`:

```kotlin
NavHost(navController, startDestination = Screen.BottomScreen.Home.bRoute) {
    composable(Screen.BottomScreen.Home.bRoute) { HomeView(...) }
    composable(Screen.BottomScreen.Browse.bRoute) { BrowseView(...) }
    composable(Screen.BottomScreen.Library.bRoute) { LibraryView(...) }
    composable(Screen.Account.route) { AccountView(...) }
    composable(Screen.Subscription.route) { SubscriptionView(...) }
}
```

`MainViewModel.currentScreen: MutableState<Screen.BottomScreen>` tracks the selected bottom item for `BottomBar` highlighting.

---

## Recap / cheat sheet

- **Routes:** `sealed class Screen.BottomScreen(bRoute, bTitle, icon)` inside `Screen`.
- **NavHost:** `composable(BottomScreen.Home/Browse/Library.bRoute)` + drawer `Account`/`Subscription`.
