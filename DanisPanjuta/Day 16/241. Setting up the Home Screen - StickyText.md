# Setting up the Home Screen - StickyText

---

## Overview

`HomeView` now shows a **StickyHeader** ("New Releases") that pins at the top while scrolling, followed by song rows. This demonstrates `LazyColumn`'s `stickyHeader` (experimental) and a simple song model.

---

## The screen

`Home.kt` (or `HomeView`):

```kotlin
@OptIn(ExperimentalFoundationApi::class)
@Composable
fun HomeView() {
    LazyColumn {
        stickyHeader {
            Text("New Release", Modifier.fillMaxWidth().background(Color.LightGray).padding(16.dp))
        }
        items(songs) { song ->
            SongItem(song)
        }
    }
}

@Composable fun SongItem(song: Song) {
    Row(Modifier.fillMaxWidth().padding(8.dp)) {
        Image(painter = painterResource(song.image), contentDescription = null, Modifier.size(64.dp))
        Column(Modifier.padding(8.dp)) {
            Text(song.title, fontWeight = Bold)
            Text(song.subtitle, color = Color.Gray)
        }
    }
}
```

| API | Role |
| :--- | :--- |
| `@OptIn(ExperimentalFoundationApi::class)` | Required for `stickyHeader` in this Compose version |
| `stickyHeader { Text("New Release") }` | Pinned section header — stays visible until the next `stickyHeader` scrolls it off |
| `items(songs)` | Song rows with image + title + subtitle |

> The lecture's "StickyText" is just a `Text` inside `stickyHeader` with a background.

---

## Recap / cheat sheet

- **Sticky:** `@OptIn(ExperimentalFoundationApi::class) LazyColumn { stickyHeader { Text } items { } }`.
