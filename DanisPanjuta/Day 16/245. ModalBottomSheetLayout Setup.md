# ModalBottomSheetLayout Setup

---

## Overview

A **`ModalBottomSheetLayout`** slides a **bottom sheet** up from the bottom (over the content) for contextual actions like *Sort*, *Add Account*, *Settings*. Unlike the drawer, it is not navigation — it is a transient sheet that does not change the route.

---

## Step 1 — state

`HomeView`:

```kotlin
val sheetState = rememberModalBottomSheetState(
    initialValue = ModalBottomSheetValue.Hidden,
    confirmValueChange = { it != ModalBottomSheetValue.HalfExpanded } // skip Half
)
val scope = rememberCoroutineScope()
```

| State | Value | Role |
| :--- | :--- |
| `ModalBottomSheetState` | `Hidden` vs `Expanded` | Controls visibility |
| `confirmValueChange` | Skip `HalfExpanded` | Binary hidden/expanded |

---

## Step 2 — layout

```kotlin
ModalBottomSheetLayout(
    sheetState = sheetState,
    sheetContent = {
        Box(Modifier.fillMaxWidth().height(300.dp)) {
            Column(Modifier.padding(16.dp)) {
                Text("Sort by", fontWeight=Bold)
                // List options: Recently Added, Title, etc. — each calls scope.launch{ sheetState.hide() }
            }
        }
    }
) {
    Scaffold(
        topBar = { TopAppBar(...) },
        bottomBar = { BottomBar(...) }
    ) { padding ->
        // Home/Browse/Library NavHost content
    }
}
```

Showing the sheet:

```kotlin
IconButton(onClick = { scope.launch { sheetState.show() } }) {
    Icon(Icons.Default.MoreVert, null)
}
```

| Call | Effect |
| :--- | :--- |
| `scope.launch { sheetState.show() }` | `Hidden` → `Expanded`, scrim darkens |
| `scope.launch { sheetState.hide() }` | `Expanded` → `Hidden` |

---

## Recap / cheat sheet

- **Sheet:** `ModalBottomSheetLayout(sheetState, sheetContent={ Box+Column }) { Scaffold }`.
- **State:** `rememberModalBottomSheetState(Hidden)`.
- **Show/Hide:** `scope.launch{ sheetState.show()/hide() }`.
