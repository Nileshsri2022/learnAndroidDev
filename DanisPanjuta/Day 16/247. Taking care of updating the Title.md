# Taking care of updating the Title

---

## Overview

The `TopAppBar` title currently only updates via drawer clicks. Bottom-bar navigation and back-press must also keep it in sync. This lecture observes `currentBackStackEntry` and updates `viewModel.title` via `LaunchedEffect`.

---

## Step 1 — title source

`MainViewModel`:

```kotlin
var title by mutableStateOf("Home")
fun setTitle(newTitle: String){ title = newTitle }
```

---

## Step 2 — sync on navigation

`HomeView`:

```kotlin
val navBackStackEntry by navController.currentBackStackEntryAsState()
val currentRoute = navBackStackEntry?.destination?.route

LaunchedEffect(currentRoute) {
    when(currentRoute) {
        Screen.BottomScreen.Home.bRoute -> viewModel.setTitle("Home")
        Screen.BottomScreen.Browse.bRoute -> viewModel.setTitle("Browse")
        Screen.BottomScreen.Library.bRoute -> viewModel.setTitle("Library")
        Screen.Account.route -> viewModel.setTitle("Add Account")
        Screen.Subscription.route -> viewModel.setTitle("Subscription")
        else -> viewModel.setTitle("Home")
    }
}
```

| Mechanism | Role |
| :--- | :--- |
| `currentBackStackEntryAsState()` | State-backed current route — recomposes on navigate |
| `LaunchedEffect(currentRoute)` | Side-effect that runs when the route changes → updates `viewModel.title` |
| `viewModel.title` | Observed by `TopAppBar` — title animates |

> Alternative: each destination's `composable` calls `viewModel.setTitle` on entry — same effect, but `LaunchedEffect` centralizes it.

---

## Recap / cheat sheet

- **Sync:** `val currentRoute by navController.currentBackStackEntryAsState()` → `LaunchedEffect(currentRoute){ viewModel.setTitle(...) }`.
- **TopAppBar:** `Text(viewModel.title)` always reflects the current destination.
