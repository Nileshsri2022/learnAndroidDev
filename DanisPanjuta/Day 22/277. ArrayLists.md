# ArrayLists

---

## Overview

`ArrayList` is the workhorse collection of the XML track — RecyclerView adapters, quiz question lists, exercise lists and history lists all use it. It is a **dynamic array**: the size grows and shrinks as needed.

---

## Characteristics

- Size can **increase or decrease** as required.
- Provides **read and write** functionality.
- Keeps **insertion order**.
- **Not synchronized** (not thread-safe by default).
- **May contain duplicates**.

---

## Constructors

```kotlin
ArrayList<E>()                          // empty
ArrayList<E>(initialCapacity: Int)      // pre-sized capacity
ArrayList<E>(elements: Collection<E>)   // filled from another collection
```

---

## Important functions

| Function | Purpose |
| :--- | :--- |
| `add(element)` / `add(index, element)` | Append / insert |
| `clear()` | Remove all elements |
| `get(index)` / `[index]` | Read |
| `set(index, element)` / `[index] = ` | Replace |
| `remove(element)` / `removeAt(index)` | Delete |
| `indexOf(element)` | Position or `-1` |
| `size` | Element count |

---

## Examples

```kotlin
val arrayList = ArrayList<String>()
arrayList.add("One")
arrayList.add("Two")

println("...Print ArrayList...")
for (i in arrayList) println(i)

val arrayList2: ArrayList<String> = ArrayList(5)
val list: MutableList<String> = mutableListOf("One", "Two")
arrayList2.addAll(list)

// Iterator
val itr = arrayList2.iterator()
while (itr.hasNext()) println(itr.next())

println("Size of arrayList2 = ${arrayList2.size}")
println(arrayList2.get(1))     // Two
```

Shortcut builder: `val names = arrayListOf("Denis", "Anna")`.

---

## Recap / cheat sheet

- **Create:** `ArrayList<T>()`, `ArrayList<T>(capacity)`, `arrayListOf(...)`.
- **Use:** `add`, `addAll`, `get`, `set`, `remove`, `clear`, `size`, `iterator()`.
- **Dynamic, ordered, duplicates allowed.**
