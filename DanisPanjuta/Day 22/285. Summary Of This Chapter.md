## Overview

The Kotlin fundamentals block is complete — from here on the course builds real Android apps, learning further Kotlin features along the way.

---

## What was covered

| Topic | Key idea |
| :--- | :--- |
| **Collections** | `Array`, `List`, `Set`, `Map` — read-only vs. mutable |
| **ArrayList** | Dynamic, ordered, duplicates allowed — used heavily later |
| **Lambda expressions** | `{ a, b -> a + b }` — Android uses them for listeners and callbacks |
| **Visibility modifiers** | `public`, `private`, `protected`, `internal` (+ `open` for inheritance) |
| **Nested vs inner classes** | Inner classes can access the outer class's members |
| **Safe / unsafe casts** | `as?` returns `null`, `as` throws |
| **Exception handling** | `try` / `catch` / `finally` / `throw` keeps the app from crashing |

---

## Quick reference

```kotlin
val list = arrayListOf(1, 2, 3); list.add(4)
val sum: (Int, Int) -> Int = { a, b -> a + b }
private val secret = 42
class Outer { inner class Inner }
val s: String? = obj as? String
try { risky() } catch (e: Exception) { log(e) } finally { cleanup() }
```
