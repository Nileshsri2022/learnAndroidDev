# Exercise ArrayLists

---

## Overview

A short coding exercise (text/resource lecture — no video transcript) to practise `ArrayList`.

---

## Task

1. Create an `ArrayList<Double>` containing a few numbers, e.g. `1.73, 3.14, 2.51, 6.42`.
2. Loop through the list and **calculate the average** of all values.
3. Print the result to the console.

---

## Hints

- Keep a running `sum` variable of type `Double`.
- The average is `sum / list.size`.
- Use a `for (value in list)` loop — or try the built-in `list.average()` afterwards to verify.

---

## Recap / cheat sheet

- Practise: create `ArrayList`, iterate, aggregate values.
