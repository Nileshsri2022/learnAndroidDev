# Arrays

---

## Overview

An **array** stores a fixed number of elements of a type in one variable. This lecture shows the three equivalent ways to create an array, why `print(array)` prints garbage, and how to access, modify and loop over elements.

---

## Creating an array — three styles

```kotlin
// 1. Fully explicit
val numbers: IntArray = intArrayOf(1, 2, 3, 4, 5, 6)

// 2. Type inference from intArrayOf
val numbers = intArrayOf(1, 2, 3, 4, 5, 6)

// 3. Generic array — type inferred as Array<Int>
val numbers = arrayOf(1, 2, 3, 4, 5, 6)
```

All three are valid; the first is the most descriptive.

---

## Printing an array

```kotlin
print(numbers)                         // [I@7a81197d  ← memory address!
print(numbers.contentToString())       // [1, 2, 3, 4, 5, 6]
```

`print` on an array outputs the **reference / memory address**. Use `contentToString()` to see the elements.

---

## Looping

```kotlin
for (element in numbers) {
    print("${element + 2} ")   // 3 4 5 6 7 8
}
```

---

## Accessing and modifying by index

```kotlin
print(numbers[0])        // 1  — indices start at 0
numbers[0] = 6           // arrays are mutable in content…
numbers[1] = 5
print(numbers.contentToString())  // [6, 5, 3, 4, 5, 6]
```

- The **size is fixed** — you cannot add an 7th element to a 6-element array.
- Accessing an index ≥ size throws `ArrayIndexOutOfBoundsException`.

---

## Arrays of other types

```kotlin
val days = arrayOf("Mon", "Tue", "Wed")
val mixed = arrayOf("Hi", 42, true, 3.5)     // Array<Any>
val fruits = arrayOf(Fruit("Apple", 2.5), Fruit("Grape", 3.5))

data class Fruit(val name: String, val price: Double)

for (fruit in fruits) println(fruit.name)
for (index in fruits.indices) println("${fruits[index].name} is at $index")
```

---

## Recap / cheat sheet

- **Create:** `intArrayOf(...)`, `arrayOf(...)`.
- **Print:** `arr.contentToString()`.
- **Index:** `arr[i]`, `arr[i] = x`, `arr.indices`, `arr.size`.
- **Fixed size** — use a List/ArrayList when you need to grow.
