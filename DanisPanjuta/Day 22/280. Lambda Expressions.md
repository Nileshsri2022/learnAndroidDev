# Lambda Expressions

---

## Overview

A **lambda expression** is a function **without a name**, written as a literal and passed around as a value. Android uses them everywhere — `setOnClickListener { … }` is a lambda. (A lambda is related to, but not the same as, an *anonymous function*.)

---

## Syntax

```
{ parameter(s) -> body }
```

- Wrapped in **curly braces**.
- Parameters (optional) come before the **arrow `->`**.
- The **last expression** is the return value.

---

## Normal function vs. lambda

```kotlin
// Normal function
fun addNumber(a: Int, b: Int) {
    val add = a + b
    println(add)
}
addNumber(5, 10)          // 15

// Lambda
val myLambda: (Int) -> Unit = { s: Int -> println(s) }
addNumber(5, 10)

val sum: (Int, Int) -> Int = { a: Int, b: Int -> a + b }
println(sum(5, 10))       // 15

// Type inferred from the literal
val sum2 = { a: Int, b: Int -> println(a + b) }
sum2(5, 10)
```

The function type `(Int, Int) -> Int` reads "takes two Ints, returns an Int". `Unit` means "returns nothing".

---

## `it` — the implicit single parameter

```kotlin
val double: (Int) -> Int = { it * 2 }
```

When a lambda has exactly one parameter, you may omit it and use `it`.

---

## Trailing lambda syntax (used in Android)

```kotlin
button.setOnClickListener { view ->
    Toast.makeText(this, "Clicked", Toast.LENGTH_SHORT).show()
}
```

If the last parameter of a function is a function type, the lambda can go **outside the parentheses**.

---

## Recap / cheat sheet

- **Literal:** `{ a: Int, b: Int -> a + b }`.
- **Type:** `(Int, Int) -> Int`, `(String) -> Unit`.
- **Single param:** `it`.
- **Trailing lambda:** `foo(x) { … }`.
