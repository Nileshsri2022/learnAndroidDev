# Lists

---

## Overview

A **List** can hold single data types or custom objects and — in its mutable form — grows as elements are added. `listOf` is **read-only**; `mutableListOf` / `arrayListOf` are **read-write**.

---

## Read-only lists

```kotlin
val months = listOf("January", "February", "March")
val anyTypes = listOf(1, 2, 3, true, false, "String")   // List<Any>

println(anyTypes.size)     // 6
println(months[1])         // February

for (month in months) println(month)
```

Typing `months.` in the IDE shows dozens of helpers: `first()`, `last()`, `contains()`, `indexOf()`, `sorted()`, `filter {}`, `map {}`, …

Trying `months.add("April")` does **not compile** — a `List` has no `add`.

---

## Converting to a mutable list

```kotlin
val additionalMonths = months.toMutableList()
val newMonths = arrayOf("April", "May", "June")

additionalMonths.addAll(newMonths)
additionalMonths.add("July")
println(additionalMonths)   // [January, …, July]
```

---

## Creating a mutable list directly

```kotlin
val days = mutableListOf("Mon", "Tue", "Wed")
days.add("Thu")
days[2] = "Sunday"          // replace
days.removeAt(1)            // remove by index
days.remove("Mon")          // remove by value
val removeList = mutableListOf("Mon", "Wed")
days.removeAll(removeList)
days.removeAll(days)        // empties the list
println(days.isEmpty())     // true
```

---

## Recap / cheat sheet

- **Read-only:** `listOf(...)` — `size`, `[i]`, iterate.
- **Mutable:** `mutableListOf(...)` or `list.toMutableList()`.
- **Modify:** `add`, `addAll`, `set / [i] =`, `remove`, `removeAt`, `removeAll`.
