# Visibility Modifiers - public, private, internal, protected and open

---

## Overview

**Visibility modifiers** restrict where a class, function, property, constructor or interface can be accessed from. Kotlin has four: `public`, `private`, `protected`, `internal`. The keyword `open` is related — it controls **inheritance**, not visibility.

---

## Summary table

| Modifier | Visible… |
| :--- | :--- |
| **`public`** (default) | Everywhere in the project |
| **`private`** | Only inside the declaring class — or, for top-level declarations, only inside that **file** |
| **`protected`** | Inside the class **and its subclasses** (not available for top-level declarations) |
| **`internal`** | Everywhere inside the same **module** |

---

## public

```kotlin
public class Example { }          // same as: class Example { }
class Demo {
    public val x = 5              // public by default
    fun doSomething() { }         // public by default
}
```

If you write nothing, it's `public`.

---

## private

```kotlin
private class Example {
    private val x = 1
    private fun doSomething() { }
}
```

- `x` and `doSomething()` are only accessible inside `Example`.
- `private class Example` is only usable inside the file it's declared in.

---

## protected

```kotlin
open class Base {
    protected val i = 0
}

class Derived : Base() {
    fun getValue(): Int = i        // OK — subclass can see it
}
```

A protected member can be **overridden** in the subclass, and the override is protected too unless changed:

```kotlin
open class Base { open protected val i = 5 }
class Another : Base() {
    fun getValue(): Int = i
    override val i = 6
}
```

---

## internal

```kotlin
internal class Example {
    internal val x = 5
    internal fun getValue() { }
}
```

Visible anywhere in the same module (e.g. the `app` module), invisible to other modules/libraries.

---

## open

Kotlin classes and members are **final by default**. To inherit from a class or override a member, mark it `open`:

```kotlin
open class Vehicle { open fun drive() { } }
class Car : Vehicle() { override fun drive() { } }
```

---

## Recap / cheat sheet

- **Default:** `public`.
- **private:** class / file only.
- **protected:** class + subclasses.
- **internal:** same module.
- **open:** allows inheritance/override (classes are final by default).
