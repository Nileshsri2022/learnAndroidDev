# Sets and Maps

---

## Overview

A **Set** eliminates duplicates and is unordered. A **Map** stores **key → value** pairs. Both come in read-only and mutable variants.

---

## Sets

```kotlin
val fruits = setOf("Orange", "Apple", "Mango", "Grape", "Apple", "Orange")
println(fruits.size)            // 4 — duplicates ignored
println(fruits)                 // [Orange, Apple, Mango, Grape]
println(fruits.toSortedSet())   // [Apple, Grape, Mango, Orange]
```

Making it modifiable:

```kotlin
val newFruits = fruits.toMutableList()
newFruits.add("Water Melon")
newFruits.add("Pear")
println(newFruits.elementAt(4))   // Water Melon
```

| Type | Mutable? |
| :--- | :--- |
| `setOf` | No |
| `mutableSetOf`, `hashSetOf` | Yes |

---

## Maps

```kotlin
val daysOfTheWeek = mapOf(1 to "Monday", 2 to "Tuesday", 3 to "Wednesday")
println(daysOfTheWeek[2])                // Tuesday

for (key in daysOfTheWeek.keys) {
    println("$key is to ${daysOfTheWeek[key]}")
}
```

Values can be objects:

```kotlin
data class Fruit(val name: String, val price: Double)

val fruitsMap = mapOf("Favorite" to Fruit("Grape", 2.5), "Ok" to Fruit("Apple", 1.0))
```

Mutable map:

```kotlin
val newDaysOfWeek = daysOfTheWeek.toMutableMap()
newDaysOfWeek[4] = "Thursday"
newDaysOfWeek[5] = "Friday"
println(newDaysOfWeek.toSortedMap())
```

- Assigning to an **existing key** overwrites its value — keys are unique.

---

## Recap / cheat sheet

- **Set:** unique values → `setOf`, `mutableSetOf`, `toSortedSet()`, `elementAt(i)`.
- **Map:** `mapOf(k to v)`, `map[k]`, `map.keys`, `map.values`, `toMutableMap()`, `toSortedMap()`.
