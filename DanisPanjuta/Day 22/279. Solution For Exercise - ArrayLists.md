# Solution For Exercise - ArrayLists

---

## Overview

Reference solution for the ArrayList average exercise (text lecture — no video transcript).

---

## Solution

```kotlin
fun main() {
    val myArrayList: ArrayList<Double> = ArrayList()
    myArrayList.add(13.212312)
    myArrayList.add(23.151232)
    myArrayList.add(32.651553)
    myArrayList.add(16.223)
    myArrayList.add(66.1)

    var total = 0.0
    for (i in myArrayList) {
        total += i
    }
    val average = total / myArrayList.size
    println("Average is $average")

    // Built-in alternative
    println("Average (built-in) is ${myArrayList.average()}")
}
```

---

## Take-aways

- Initialize the accumulator as `0.0` so it is a `Double`, not an `Int`.
- Divide by `size` **after** the loop.
- Kotlin collections ship helpers like `sum()`, `average()`, `max()` — but knowing the manual loop matters.

---

## Recap / cheat sheet

- **Average:** `sum / size` or `list.average()`.
