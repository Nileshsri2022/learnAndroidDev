# Safe Cast and Unsafe Cast Operator

---

## Overview

Casting converts a value to another type. Kotlin has the **unsafe cast `as`** (throws on failure) and the **safe cast `as?`** (returns `null` on failure).

---

## Unsafe cast — `as`

```kotlin
val obj: Any? = null
val str: String = obj as String     // 💥 TypeCastException:
                                    // null cannot be cast to non-null type kotlin.String
println(str)
```

```kotlin
val obj: Any = 123
val str: String = obj as String     // 💥 ClassCastException:
                                    // Integer cannot be cast to String
```

`as` cannot *convert* an Int into a String — that needs `toString()` or parsing, not casting.

Working example — source and target types compatible:

```kotlin
val obj: Any? = "String unsafe cast"
val str: String? = obj as String?   // OK
println(str)
```

---

## Safe cast — `as?`

```kotlin
val location: Any = "Kotlin"
val safeString: String? = location as? String   // "Kotlin"
val safeInt: Int? = location as? Int            // null — no crash
println(safeString)
println(safeInt)
```

- Returns `null` if the cast is impossible.
- The target variable must be **nullable**.

---

## When you'll use it in Android

```kotlin
val model = intent.getSerializableExtra("EXTRA") as? HappyPlaceModel
val dialog = view as? TextView
```

---

## Recap / cheat sheet

- **`as`** — unsafe, throws `ClassCastException` / `TypeCastException`.
- **`as?`** — safe, returns `null`.
- Casting ≠ conversion: use `toString()`, `toInt()` to convert.
