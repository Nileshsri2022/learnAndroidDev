# Introduction to the Chapter - More Fundamentals of Kotlin

---

## Overview

Day 22 is **"Kotlin Fundamentals part three"** of the XML track. Before building real XML apps (Age in Minutes, Calculator, Quiz…), the course fills in the remaining language features that Android code uses constantly.

---

## Roadmap of the chapter

| # | Topic | Why it matters for Android |
| :--- | :--- | :--- |
| 1 | **Collections** — arrays, lists, sets, maps, `ArrayList` | Every list screen (RecyclerView, spinners, quiz questions) is backed by a collection |
| 2 | **Lambda expressions** | `setOnClickListener { … }`, callbacks, adapters |
| 3 | **Visibility modifiers** — `public`, `private`, `internal`, `protected`, `open` | Encapsulation of Activities, ViewModels, adapters |
| 4 | **Nested and inner classes** | ViewHolders inside Adapters, helper classes |
| 5 | **Safe (`as?`) and unsafe (`as`) cast** | Casting views, `Parcelable`/`Serializable` extras |
| 6 | **Exception handling** — `try` / `catch` / `finally` / `throw` | Network, file I/O, parsing without crashing |

---

## Why exception handling gets special attention

> A user may forgive an app that crashes once — they will not forgive it crashing repeatedly.

Many runtime errors can simply be **caught**: the app may not do exactly what was intended, but it keeps running and can show the user a meaningful message instead of an "App has stopped" dialog.
