# Adding Custom RadioGroups with Custom RadioButtons

---

## Overview

A pill-shaped, custom-styled **RadioGroup** toggles **METRIC UNITS** / **US UNITS**. Selected tab is filled with the accent colour and white text; the other is transparent with accent text — all via **selectors**.

---

## Drawables

`drawable/drawable_radio_group_tab_background.xml`:

```xml
<shape android:shape="rectangle">
    <solid android:color="@android:color/white" />
    <stroke android:width="1dp" android:color="@color/colorAccent" />
    <corners android:radius="20dp" />
</shape>
```

`drawable/drawable_units_tab_selector.xml`:

```xml
<selector xmlns:android="http://schemas.android.com/apk/res/android">
    <item android:drawable="@drawable/drawable_selected" android:state_checked="true" />
    <item android:drawable="@android:color/transparent" android:state_checked="false" />
</selector>
```

(`drawable_selected` = rounded rectangle filled with accent colour.)

`drawable/drawable_units_tab_text_color_selector.xml`:

```xml
<selector>
    <item android:color="@android:color/white" android:state_checked="true" />
    <item android:color="@color/colorAccent" />
</selector>
```

---

## Layout

```xml
<RadioGroup
    android:id="@+id/rgUnits"
    android:layout_width="match_parent"
    android:layout_height="35dp"
    android:layout_margin="10dp"
    android:background="@drawable/drawable_radio_group_tab_background"
    android:orientation="horizontal">

    <RadioButton
        android:id="@+id/rbMetricUnits"
        android:layout_width="0dp"
        android:layout_height="match_parent"
        android:layout_weight="1"
        android:background="@drawable/drawable_units_tab_selector"
        android:button="@null"
        android:checked="true"
        android:gravity="center"
        android:text="METRIC UNITS"
        android:textColor="@drawable/drawable_units_tab_text_color_selector"
        android:textSize="16sp"
        android:textStyle="bold" />

    <RadioButton
        android:id="@+id/rbUsUnits"
        … android:text="US UNITS" />
</RadioGroup>
```

- `android:button="@null"` removes the default radio circle.
- A **selector** picks a drawable/colour based on state (`state_checked`, `state_pressed`…).

---

## Recap / cheat sheet

- **Selector** drawables/colours for state-based styling.
- `button="@null"` + background selector = tab-like radio buttons.
