# Room Database Demo Part 1 - Introduction to Room Database

---

## Overview

A **Room Demo** app (name + email records) demonstrates **persistent storage**: data survives closing the app. Room is part of **Android Jetpack** and is the best-practice way to store structured data locally.

---

## What is Room?

> The Room persistence library provides an **abstraction layer over SQLite** to allow fluent database access while harnessing the full power of SQLite.

Benefits:

- **Compile-time verification** of SQL queries.
- **Convenience annotations** that minimise boilerplate.
- Streamlined **migration** paths.
- Integration with **coroutines** and **Flow**.

---

## Three main components

```
          ┌───────────────┐
          │  RoomDatabase │   @Database — holds the DB, provides DAOs
          └──────┬────────┘
                 │ getDao()
          ┌──────▼────────┐
          │      DAO      │   @Dao — functions for insert/query/update/delete
          └──────┬────────┘
                 │ returns / accepts
          ┌──────▼────────┐
          │    Entity     │   @Entity — data class = table row
          └───────────────┘
```

| Component | Annotation | Role |
| :--- | :--- | :--- |
| **Entity** | `@Entity` | Defines a table; each instance is a row |
| **DAO** | `@Dao` | Data Access Object — the queries |
| **Database** | `@Database` | Main access point, singleton |

## Gradle setup

```groovy
plugins {
    id 'kotlin-kapt'
}

dependencies {
    def roomVersion = "2.4.2"
    implementation "androidx.room:room-runtime:$roomVersion"
    kapt "androidx.room:room-compiler:$roomVersion"
    implementation "androidx.room:room-ktx:$roomVersion"          // coroutines + Flow
    implementation "androidx.lifecycle:lifecycle-runtime-ktx:2.4.1"
}
```

`kapt` runs Room's annotation processor that generates the implementation code (KSP is the modern alternative).

---

## Recap / cheat sheet

- **Room = SQLite + annotations + compile-time checks.**
- **Entity → DAO → Database.**
- Dependencies: runtime, compiler (kapt), ktx.
