# DEMO - Timers

---

## Overview

A demo of **`CountDownTimer`** — start, pause (cancel + remember remaining time), and resume — before using it in the workout app.

---

## CountDownTimer basics

```kotlin
object : CountDownTimer(millisInFuture, countDownInterval) {
    override fun onTick(millisUntilFinished: Long) { /* every interval */ }
    override fun onFinish() { /* when time is up */ }
}.start()
```

| Param | Meaning |
| :--- | :--- |
| `millisInFuture` | Total duration in ms |
| `countDownInterval` | How often `onTick` fires (ms) |

---

## Demo with pause/resume

```kotlin
private var countDownTimer: CountDownTimer? = null
private var timerDuration: Long = 60000        // 60 s
private var pauseOffset: Long = 0

binding.btnStart.setOnClickListener { startTimer(pauseOffset) }
binding.btnStop.setOnClickListener { pauseTimer() }
binding.btnReset.setOnClickListener { resetTimer() }

private fun startTimer(pauseOffsetL: Long) {
    countDownTimer = object : CountDownTimer(timerDuration - pauseOffsetL, 1000) {
        override fun onTick(millisUntilFinished: Long) {
            pauseOffset = timerDuration - millisUntilFinished
            binding.tvTimer.text = (millisUntilFinished / 1000).toString()
        }
        override fun onFinish() {
            Toast.makeText(this@MainActivity, "Timer is finished", Toast.LENGTH_LONG).show()
        }
    }.start()
}

private fun pauseTimer() {
    countDownTimer?.cancel()
}

private fun resetTimer() {
    countDownTimer?.cancel()
    binding.tvTimer.text = "${timerDuration / 1000}"
    countDownTimer = null
    pauseOffset = 0
}
```

- There is no built-in pause: **cancel** and later start a new timer with the **remaining** time (`pauseOffset`).
- `object : CountDownTimer(...)` = anonymous class implementing the abstract methods.

---

## Recap / cheat sheet

- `CountDownTimer(total, interval) { onTick; onFinish }.start()`.
- Pause = `cancel()` + store elapsed; resume = new timer with `total - elapsed`.
