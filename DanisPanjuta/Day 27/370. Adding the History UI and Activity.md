# Adding the History UI and Activity

---

## Overview

Adds a **HISTORY** circle button on the main screen that opens **`HistoryActivity`** — for now just a toolbar with a back arrow; the list comes after the Room demo.

---

## Main screen

```xml
<FrameLayout
    android:id="@+id/flHistory"
    android:layout_width="70dp"
    android:layout_height="70dp"
    android:background="@drawable/item_circular_color_accent_background" …>
    <ImageView android:layout_gravity="center" android:src="@drawable/ic_calendar" … />
</FrameLayout>
<TextView android:text="History" android:textColor="@color/colorAccent" … />
```

```kotlin
binding?.flHistory?.setOnClickListener {
    startActivity(Intent(this, HistoryActivity::class.java))
}
```

---

## HistoryActivity

```kotlin
class HistoryActivity : AppCompatActivity() {
    private var binding: ActivityHistoryBinding? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityHistoryBinding.inflate(layoutInflater)
        setContentView(binding?.root)

        setSupportActionBar(binding?.toolbarHistoryActivity)
        if (supportActionBar != null) {
            supportActionBar?.setDisplayHomeAsUpEnabled(true)
            supportActionBar?.title = "HISTORY"
        }
        binding?.toolbarHistoryActivity?.setNavigationOnClickListener { onBackPressed() }
    }

    override fun onDestroy() {
        super.onDestroy()
        binding = null
    }
}
```

The same toolbar pattern as Exercise, Finish and BMI activities — good practice to try alone.
