# Viewbinding with Recyclerviews

---

## Overview

How to use **View Binding** inside a RecyclerView **adapter/ViewHolder** — the approach Google recommends (Kotlin synthetics were deprecated; `findViewById` still works but is verbose).

---

## Item layout → binding class

`item_exercise_status.xml` → generated **`ItemExerciseStatusBinding`**.

---

## ViewHolder takes the binding

```kotlin
class ExerciseStatusAdapter(val items: ArrayList<ExerciseModel>) :
    RecyclerView.Adapter<ExerciseStatusAdapter.ViewHolder>() {

    class ViewHolder(binding: ItemExerciseStatusBinding) :
        RecyclerView.ViewHolder(binding.root) {
        val tvItem = binding.tvItem
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ViewHolder {
        return ViewHolder(
            ItemExerciseStatusBinding.inflate(
                LayoutInflater.from(parent.context), parent, false
            )
        )
    }
    …
}
```

| Piece | Meaning |
| :--- | :--- |
| `binding.root` | Passed to `RecyclerView.ViewHolder` — the row's root view |
| `inflate(inflater, parent, false)` | Inflate with correct layout params, but let RecyclerView attach it |
| `LayoutInflater.from(parent.context)` | Inflater from the RecyclerView's context |

---

## Recap / cheat sheet

- `ViewHolder(binding: ItemXBinding) : RecyclerView.ViewHolder(binding.root)`.
- `ItemXBinding.inflate(LayoutInflater.from(parent.context), parent, false)`.
