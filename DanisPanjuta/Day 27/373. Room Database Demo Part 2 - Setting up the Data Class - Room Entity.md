# Room Database Demo Part 2 - Setting up the Data Class - Room Entity

---

## Overview

Defines the **`EmployeeEntity`** — a data class annotated with `@Entity` that Room turns into a table `employee-table` with columns `id`, `name`, `email`.

---

## Code

```kotlin
@Entity(tableName = "employee-table")
data class EmployeeEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,
    val name: String = "",
    @ColumnInfo(name = "email-id")
    val email: String = ""
)
```

| Annotation | Meaning |
| :--- | :--- |
| `@Entity(tableName = …)` | This class is a table (default name = class name) |
| `@PrimaryKey(autoGenerate = true)` | Unique ID, auto-incremented by SQLite |
| `@ColumnInfo(name = …)` | Custom column name (default = property name) |

- Default values let you create an entity without an ID: `EmployeeEntity(name = "Denis", email = "d@x.com")` → Room assigns the ID on insert.
- Easy to extend with more columns later (requires a DB **version** bump/migration).

---

## Recap / cheat sheet

- `@Entity(tableName)`, `@PrimaryKey(autoGenerate = true)`, `@ColumnInfo(name)`.
- Data class = one row.
