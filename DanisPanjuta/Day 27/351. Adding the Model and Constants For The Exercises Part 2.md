# Adding the Model, Our Constants For The Exercises and Testing It Part 2

---

## Overview

Adds an **ImageView** for the exercise, loads the list in `ExerciseActivity`, tracks **`currentExercisePosition`**, and loops rest → exercise → rest until all exercises are done.

---

    app:layout_constraintTop_toBottomOf="@id/toolbarExercise"

## Code

```kotlin
private var exerciseList: ArrayList<ExerciseModel>? = null
private var currentExercisePosition = -1

override fun onCreate(savedInstanceState: Bundle?) {
    …
    exerciseList = Constants.defaultExerciseList()
    setupRestView()
}

// rest timer
override fun onFinish() {
    currentExercisePosition++
    setupExerciseView()
}

private fun setupExerciseView() {
    binding?.flRestView?.visibility = View.INVISIBLE
    binding?.tvTitle?.visibility = View.INVISIBLE
    binding?.tvExerciseName?.visibility = View.VISIBLE
    binding?.flExerciseView?.visibility = View.VISIBLE
    binding?.ivImage?.visibility = View.VISIBLE
    …
    binding?.ivImage?.setImageResource(exerciseList!![currentExercisePosition].getImage())
    binding?.tvExerciseName?.text = exerciseList!![currentExercisePosition].getName()
    setExerciseProgressBar()
}

// exercise timer
override fun onFinish() {
    if (currentExercisePosition < exerciseList?.size!! - 1) {
        setupRestView()
    } else {
        Toast.makeText(this@ExerciseActivity,
            "Congratulations! You have completed the 7 minutes workout.", Toast.LENGTH_SHORT).show()
    }
}
```

`setupRestView()` must make the rest views visible again and hide the exercise views.

Tip for testing: temporarily shorten timers (e.g. 1 s / 3 s) instead of waiting 7 minutes.

---

## Recap / cheat sheet

- Start at `currentExercisePosition = -1`; increment when rest ends.
- Exercise `onFinish` → next rest, or finish after the last one.
