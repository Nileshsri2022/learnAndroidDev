# Intro to 7 Minute Workout App

---

## Overview

Day 27 builds a **7 Minute Workout** app — a hugely popular app concept with many versions on the store. Twelve exercises of 30 s each, separated by 10 s rests, with a **timer**, **voice announcements**, a **sound**, a **progress indicator**, a **BMI calculator** and a **workout history** stored in a **Room** database.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **View Binding** | Replacing `findViewById` from now on |
| **Custom Toolbar** | Own toolbar with back navigation |
| **Custom circular progress** | Layer-list drawables, rotation for counter-clockwise tick |
| **CountDownTimer** | Rest and exercise timers |
| **TextToSpeech** | Announcing the next exercise |
| **MediaPlayer** | Playing a sound at exercise end |
| **RecyclerView** | Exercise status bar and history list |
| **Custom RadioGroup/RadioButton** | Metric vs US units in BMI screen |
| **Lambdas** in depth | Adapter click listeners |
| **Room database** | Entity, DAO, Database, Flow, coroutines |

## Screens

```
MainActivity (START, BMI, HISTORY)
  ├─► ExerciseActivity (rest 10s → exercise 30s × 12) ─► FinishActivity (saves date)
  ├─► BMIActivity (metric / US units)
  └─► HistoryActivity (RecyclerView of completed workouts)
```
