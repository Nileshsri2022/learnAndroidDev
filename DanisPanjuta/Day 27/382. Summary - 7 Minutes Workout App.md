# Summary - 7 Minutes Workout App

---

## Overview

Another app done — and one you can actually use to get fitter. This chapter introduced a lot of new functionality.

---

## What you learned

| Area | Details |
| :--- | :--- |
| **View Binding** | Type-safe view access, used from now on |
| **Custom UI** | Ripple circles, layer-list ring progress, selectors, custom radio tabs |
| **Toolbar** | `setSupportActionBar`, back navigation |
| **Timers** | `CountDownTimer`, cancelling in `onDestroy` |
| **Media** | `TextToSpeech`, `MediaPlayer` (`res/raw`) |
| **RecyclerView** | Adapter, ViewHolder with binding, `LayoutManager`, `notifyDataSetChanged` |
| **Dialogs** | Custom back-confirmation dialog |
| **BMI** | Metric and US formulas, `BigDecimal` rounding |
| **Lambdas** | Passing listeners into adapters |
| **Room** | Entity, DAO, Database singleton, Application class, `Flow` + `collect`, coroutines |
