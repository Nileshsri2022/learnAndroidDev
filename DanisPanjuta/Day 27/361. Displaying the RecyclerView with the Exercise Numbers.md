# Displaying the Recyclerview with the Exercise Numbers

---

## Overview

Connects the adapter to the RecyclerView with a **horizontal `LinearLayoutManager`**.

---

## Code — ExerciseActivity

```kotlin
private var exerciseAdapter: ExerciseStatusAdapter? = null

override fun onCreate(savedInstanceState: Bundle?) {
    …
    exerciseList = Constants.defaultExerciseList()
    setupRestView()
    setupExerciseStatusRecyclerView()
}

private fun setupExerciseStatusRecyclerView() {
    binding?.rvExerciseStatus?.layoutManager =
        LinearLayoutManager(this, LinearLayoutManager.HORIZONTAL, false)
    exerciseAdapter = ExerciseStatusAdapter(exerciseList!!)
    binding?.rvExerciseStatus?.adapter = exerciseAdapter
}
```

| `LinearLayoutManager(ctx, orientation, reverseLayout)` | |
| :--- | :--- |
| `HORIZONTAL` | Items side by side, scroll sideways |
| `false` | Normal order (1 → 12) |

Twelve 30 dp bubbles + margins fit most phone widths; otherwise the row scrolls.

---

## Recap / cheat sheet

- `layoutManager = LinearLayoutManager(this, HORIZONTAL, false)`.
- `adapter = ExerciseStatusAdapter(list)`.
