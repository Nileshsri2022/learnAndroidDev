# Adding a Media Player to play a sounds once an exercise is over

---

## Overview

Plays a short **sound** at the start of every rest period so the user knows the exercise is over — using **`MediaPlayer`** with a file in **`res/raw`**.

---

## Adding the sound

1. Right-click `res` → **New → Android Resource Directory** → type **raw**.
2. Copy `press_start.mp3` into `res/raw` (names: lowercase, underscores).

---

## Code

```kotlin
private var player: MediaPlayer? = null

private fun setupRestView() {
    try {
        val soundURI = Uri.parse(
            "android.resource://eu.tutorials.a7_minutesworkoutapp/" + R.raw.press_start)
        player = MediaPlayer.create(applicationContext, soundURI)
        player?.isLooping = false
        player?.start()
    } catch (e: Exception) {
        e.printStackTrace()
    }
    …
}

override fun onDestroy() {
    super.onDestroy()
    if (player != null) player!!.stop()
    …
}
```

Simpler alternative: `MediaPlayer.create(this, R.raw.press_start)`.

| Call | Meaning |
| :--- | :--- |
| `MediaPlayer.create(ctx, uri/resId)` | Creates & prepares the player |
| `isLooping = false` | Play once |
| `start()` / `stop()` / `release()` | Control & free resources |

Wrapped in `try / catch` — media loading can fail.

---

## Recap / cheat sheet

- Sounds live in `res/raw`.
- `MediaPlayer.create(...)`, `start()`, stop in `onDestroy`.
