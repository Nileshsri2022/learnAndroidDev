# Adding the Exercise Timer

---

## Overview

Challenge: when the rest timer hits 0, show a **30-second exercise timer** in the same activity (no extra activity). Solution: a second progress view, toggled with **visibility**.

---

## Layout additions

```xml
<TextView android:id="@+id/tvExerciseName" android:text="Exercise Name"
    android:visibility="invisible" android:textSize="22sp" android:textStyle="bold" … />

<FrameLayout
    android:id="@+id/flExerciseView"
    android:layout_width="100dp"
    android:layout_height="100dp"
    android:visibility="invisible" … >
    <ProgressBar
        android:id="@+id/progressBarExercise"
        style="?android:attr/progressBarStyleHorizontal"
        android:max="30"
        android:progress="300"
        android:progressDrawable="@drawable/circular_progress_bar"
        android:rotation="-90" … />
    <LinearLayout …>
        <TextView android:id="@+id/tvTimerExercise" android:text="30" … />
    </LinearLayout>
</FrameLayout>
```

---

## Code

```kotlin
private var exerciseTimer: CountDownTimer? = null
private var exerciseProgress = 0

private fun setupExerciseView() {
    binding?.flRestView?.visibility = View.INVISIBLE
    binding?.tvTitle?.visibility = View.INVISIBLE
    binding?.tvExerciseName?.visibility = View.VISIBLE
    binding?.flExerciseView?.visibility = View.VISIBLE

    if (exerciseTimer != null) {
        exerciseTimer?.cancel()
        exerciseProgress = 0
    }
    setExerciseProgressBar()
}

private fun setExerciseProgressBar() {
    binding?.progressBarExercise?.progress = exerciseProgress
    exerciseTimer = object : CountDownTimer(30000, 1000) {
        override fun onTick(millisUntilFinished: Long) {
            exerciseProgress++
            binding?.progressBarExercise?.progress = 30 - exerciseProgress
            binding?.tvTimerExercise?.text = (30 - exerciseProgress).toString()
        }
        override fun onFinish() {
            Toast.makeText(this@ExerciseActivity,
                "30 Seconds are over, lets go to the rest view", Toast.LENGTH_SHORT).show()
        }
    }.start()
}
```

Rest timer `onFinish()` → `setupExerciseView()`.

| Visibility | Space taken | Visible |
| :--- | :--- | :--- |
| `VISIBLE` | yes | yes |
| `INVISIBLE` | yes | no |
| `GONE` | no | no |

---

## Recap / cheat sheet

- Two timers, two views, swap with `visibility`.
- Rest `onFinish` → exercise; exercise `onFinish` → next rest.
