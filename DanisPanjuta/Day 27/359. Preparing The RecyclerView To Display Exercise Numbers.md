# Preparing The RecyclerView For The Bottom To Display Exercise Numbers

---

## Overview

A horizontal **RecyclerView** at the bottom of `ExerciseActivity` shows numbered circles (1–12) indicating progress — built **dynamically** so changing the exercise list needs no layout changes.

---

## Layout

```xml
<androidx.recyclerview.widget.RecyclerView
    android:id="@+id/rvExerciseStatus"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_margin="16dp"
    app:layout_constraintBottom_toBottomOf="parent"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintEnd_toEndOf="parent" />
```

---

## Item layout — `item_exercise_status.xml`

```xml
<LinearLayout
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="vertical">

    <TextView
        android:id="@+id/tvItem"
        android:layout_width="30dp"
        android:layout_height="30dp"
        android:layout_margin="5dp"
        android:background="@drawable/item_circular_color_gray_background"
        android:gravity="center"
        android:textColor="#212121"
        android:textSize="16sp"
        android:textStyle="bold"
        tools:text="1" />
</LinearLayout>
```

---

## Status drawables

| Drawable | Meaning |
| :--- | :--- |
| `item_circular_color_gray_background` | Not yet done (grey oval) |
| `item_circular_thin_color_accent_border` | Current exercise (white with accent border) |
| `item_circular_color_accent_background` | Completed (accent-filled oval) |

---

## Recap / cheat sheet

- Horizontal RecyclerView for status bubbles.
- Three oval drawables = pending / current / completed.
