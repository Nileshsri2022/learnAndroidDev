# Setting up the CustomDialog for the Backbutton

---

## Overview

Pressing Back mid-workout shouldn't silently discard progress. A **custom confirmation dialog** asks "Are you sure? This will stop the workout. You've come so far!" with **YES** (leave) and **NO** (keep going).

---

## Layout — `dialog_custom_back_confirmation.xml`

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:gravity="center"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView android:text="Are you sure?" android:textSize="22sp" android:textStyle="bold" … />
    <TextView android:text="This will stop the workout. You've come so far!" … />

    <LinearLayout android:orientation="horizontal" android:gravity="center" …>
        <Button android:id="@+id/btnYes" android:text="YES" … />
        <Button android:id="@+id/btnNo"  android:text="NO"  … />
    </LinearLayout>
</LinearLayout>
```

---

## Code

```kotlin
override fun onBackPressed() {
    customDialogForBackButton()
    // super.onBackPressed()  ← deliberately not called
}

private fun customDialogForBackButton() {
    val customDialog = Dialog(this)
    val dialogBinding = DialogCustomBackConfirmationBinding.inflate(layoutInflater)
    customDialog.setContentView(dialogBinding.root)
    customDialog.setCanceledOnTouchOutside(false)

    dialogBinding.btnYes.setOnClickListener {
        this@ExerciseActivity.finish()
        customDialog.dismiss()
    }
    dialogBinding.btnNo.setOnClickListener {
        customDialog.dismiss()
    }
    customDialog.show()
}
```

Toolbar navigation also calls `customDialogForBackButton()`.

(Modern equivalent: `onBackPressedDispatcher.addCallback(this) { customDialogForBackButton() }` — `onBackPressed()` is deprecated in API 33.)

---

## Recap / cheat sheet

- Override `onBackPressed()` → show dialog instead.
- Dialog with **View Binding**: `XBinding.inflate(layoutInflater)` → `setContentView(binding.root)`.
- `setCanceledOnTouchOutside(false)`.
