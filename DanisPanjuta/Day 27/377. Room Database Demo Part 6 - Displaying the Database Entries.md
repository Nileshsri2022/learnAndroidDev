# Room Database Demo Part 6 - Displaying the Database entries

---

## Overview

**Collects the `Flow`** of all employees and feeds each emission into the RecyclerView — the list updates automatically after every insert/update/delete.

---

## Collecting the Flow

```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    …
    val employeeDao = (application as EmployeeApp).db.employeeDao()
    binding?.btnAdd?.setOnClickListener { addRecord(employeeDao) }

    lifecycleScope.launch {
        employeeDao.fetchAllEmployees().collect {
            val list = ArrayList(it)
            setupListOfDataIntoRecyclerView(list, employeeDao)
        }
    }
}
```

- `collect {}` is a suspend call that **keeps running**, receiving a new list whenever the table changes.
- Convert `List` → `ArrayList` for the adapter.

---

## Populating the RecyclerView

```kotlin
private fun setupListOfDataIntoRecyclerView(
    employeesList: ArrayList<EmployeeEntity>,
    employeeDao: EmployeeDao
) {
    if (employeesList.isNotEmpty()) {
        val itemAdapter = ItemAdapter(employeesList,
            { updateId -> updateRecordDialog(updateId, employeeDao) },
            { deleteId -> deleteRecordAlertDialog(deleteId, employeeDao) }
        )
        binding?.rvItemsList?.layoutManager = LinearLayoutManager(this)
        binding?.rvItemsList?.adapter = itemAdapter
        binding?.rvItemsList?.visibility = View.VISIBLE
        binding?.tvNoRecordsAvailable?.visibility = View.GONE
    } else {
        binding?.rvItemsList?.visibility = View.GONE
        binding?.tvNoRecordsAvailable?.visibility = View.VISIBLE
    }
}
```

## Recap / cheat sheet

- `lifecycleScope.launch { dao.fetchAll().collect { list -> … } }`.
- Empty state: swap RecyclerView and "No records" TextView.
