# Creating the finish activity

---

## Overview

After the last exercise the user lands on **`FinishActivity`** — "END / Congratulations! You have completed the workout." with a FINISH button that returns to the main screen.

---

## Code

```kotlin
class FinishActivity : AppCompatActivity() {
    private var binding: ActivityFinishBinding? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityFinishBinding.inflate(layoutInflater)
        setContentView(binding?.root)

        setSupportActionBar(binding?.toolbarFinishActivity)
        if (supportActionBar != null) supportActionBar?.setDisplayHomeAsUpEnabled(true)
        binding?.toolbarFinishActivity?.setNavigationOnClickListener { onBackPressed() }

        binding?.btnFinish?.setOnClickListener { finish() }
    }
}
```

In `ExerciseActivity`, last exercise finished:

```kotlin
} else {
    finish()
    val intent = Intent(this@ExerciseActivity, FinishActivity::class.java)
    startActivity(intent)
}
```

`finish()` on `ExerciseActivity` removes it from the back stack → Back/FINISH lead to `MainActivity`.

---

## Recap / cheat sheet

- Last exercise → `finish()` + start `FinishActivity`.
- FINISH button → `finish()` back to main.
