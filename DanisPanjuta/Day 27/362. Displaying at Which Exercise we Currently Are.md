# Displaying at which exercise we currently are

---

## Overview

Updates the model flags as the workout progresses and calls **`notifyDataSetChanged()`** so the bubbles re-render: current = bordered, finished = filled.

---

## Rest timer finished → mark selected

```kotlin
override fun onFinish() {
    currentExercisePosition++
    exerciseList!![currentExercisePosition].setIsSelected(true)
    exerciseAdapter!!.notifyDataSetChanged()
    setupExerciseView()
}
```

---

## Exercise timer finished → mark completed

```kotlin
override fun onFinish() {
    exerciseList!![currentExercisePosition].setIsSelected(false)
    exerciseList!![currentExercisePosition].setIsCompleted(true)
    exerciseAdapter!!.notifyDataSetChanged()

    if (currentExercisePosition < exerciseList?.size!! - 1) {
        setupRestView()
    } else {
        // finish — next lecture
    }
}
```

`notifyDataSetChanged()` rebinds all items. More efficient: `notifyItemChanged(currentExercisePosition)`.

---

## Recap / cheat sheet

- Change model → `notifyDataSetChanged()` / `notifyItemChanged(pos)`.
- `isSelected` while doing, `isCompleted` after.
