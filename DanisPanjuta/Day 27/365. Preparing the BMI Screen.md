# Preparing the BMI Screen

---

## Overview

Adds a green **BMI** circle button (with "Calculator" label) to the main screen that opens a new **`BMIActivity`** with its own toolbar titled "CALCULATE BMI".

---

## Main screen addition

```xml
<LinearLayout
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="vertical" …>

    <FrameLayout
        android:id="@+id/flBMI"
        android:layout_width="70dp"
        android:layout_height="70dp"
        android:background="@drawable/item_circular_color_accent_background">
        <TextView android:layout_gravity="center" android:text="BMI"
            android:textColor="@color/white" android:textStyle="bold" … />
    </FrameLayout>

    <TextView android:text="Calculator" android:textColor="@color/colorAccent" … />
</LinearLayout>
```

```kotlin
binding?.flBMI?.setOnClickListener {
    startActivity(Intent(this, BMIActivity::class.java))
}
```

---

## BMIActivity toolbar

```kotlin
setSupportActionBar(binding?.toolbarBmiActivity)
if (supportActionBar != null) {
    supportActionBar?.setDisplayHomeAsUpEnabled(true)
    supportActionBar?.title = "CALCULATE BMI"
}
binding?.toolbarBmiActivity?.setNavigationOnClickListener { onBackPressed() }
```

---

## Recap / cheat sheet

- New activity + circular button entry point.
- `supportActionBar?.title = "…"` sets the toolbar title from code.
