# Finishing Day 9

---

## Overview

Day 9 is the course's densest feature day so far. The recipe app now fetches data from the internet, uses coroutines and a ViewModel to manage the request, converts JSON into Kotlin objects, and displays remote thumbnails in a lazy grid.

---

## What you practiced

- Reading JSON objects, arrays, and key/value pairs.
- Exploring a REST API and understanding HTTP request/response flow.
- Adding dependencies for ViewModel, Retrofit, JSON conversion, and Coil.
- Modeling the categories response with Kotlin data classes.
- Describing a GET endpoint with Retrofit and a suspend function.
- Launching asynchronous work with a coroutine and `viewModelScope`.
- Handling errors with `try`/`catch` and representing loading/error/content state.
- Building a Compose screen and two-column lazy grid.
- Declaring Internet permission and loading remote images.

---

## The main learning strategy

Some of these concepts may feel unfamiliar because several layers work together. Revisit the data-flow diagram and test the pieces individually: inspect the JSON, confirm the endpoint, verify model names, then trace state changes from the ViewModel into the UI. These patterns recur throughout Android development, so practice makes the flow more intuitive.

---

## Looking ahead

The category browser is a foundation rather than the finished recipe app. The course continues with navigation and more detailed screens, building on the network and UI patterns introduced today.
