# How Each Category Item Should Look Like

---

## Overview

The category screen receives a `List<Category>` and displays it in a scrollable, two-column `LazyVerticalGrid`. A separate item composable keeps the grid layout and the visual treatment of one category easy to understand.

---

## Grid and items

```kotlin
@Composable
fun CategoryScreen(categories: List<Category>) {
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),
        modifier = Modifier.fillMaxSize()
    ) {
        items(categories) { category ->
            CategoryItem(category = category)
        }
    }
}
```

`items(categories)` creates one grid item for every category in the list. The grid is lazy: it composes visible content as needed, which is useful for larger collections.

---

## One category item

```kotlin
@Composable
fun CategoryItem(category: Category) {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(8.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        AsyncImage(
            model = category.strCategoryThumb,
            contentDescription = "${category.strCategory} category",
            modifier = Modifier
                .fillMaxWidth()
                .aspectRatio(1f),
            contentScale = ContentScale.Crop
        )
        Text(
            text = category.strCategory,
            fontWeight = FontWeight.Bold,
            modifier = Modifier.padding(top = 8.dp)
        )
    }
}
```

The lecture uses Coil's Compose integration (`rememberAsyncImagePainter` with `Image`) to fetch the thumbnail URL asynchronously. `AsyncImage` is an equivalent concise Coil API in current usage. The item displays an image and the category name; the description and ID remain available for later features.

---

## Layout notes

- `GridCells.Fixed(2)` creates two columns.
- `Column` stacks the image above its label.
- Padding creates space around each tile.
- A square aspect ratio keeps thumbnails consistently shaped.
- An image content description supports accessibility; decorative images can use `null` where appropriate.

---

## Recap / cheat sheet

- Pass each item its own `Category` model.
- Use a lazy grid for a scrollable tiled collection.
- Use Coil to load the remote thumbnail from the URL field.
- Separate `CategoryItem` from `CategoryScreen` to keep each composable focused.
