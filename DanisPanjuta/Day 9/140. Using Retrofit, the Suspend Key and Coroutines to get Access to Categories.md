# Using Retrofit, the Suspend Key, and Coroutines to Get Access to Categories

---

## Overview

Retrofit turns an annotated Kotlin interface into an HTTP service. The category endpoint is a `GET` request; its JSON response is converted into `CategoriesResponse`. Because network work can take time, the call is declared `suspend` and invoked from a coroutine.

---

## Describe the endpoint

```kotlin
interface ApiService {
    @GET("categories.php")
    suspend fun getCategories(): CategoriesResponse
}
```

`@GET` supplies the endpoint path relative to a base URL. Retrofit generates the request and uses the configured converter to parse the body. The return type tells the converter which model to construct.

---

## Build Retrofit and create the service

```kotlin
private const val BASE_URL = "https://www.themealdb.com/api/json/v1/1/"

val retrofit = Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addConverterFactory(GsonConverterFactory.create())
    .build()

val apiService = retrofit.create(ApiService::class.java)
```

Use a valid HTTPS base URL ending in `/`; the `@GET` path is appended to it. The precise converter should match the dependency configured in the project. The API service is the reusable entry point for its endpoint methods.

---

## `suspend` and coroutines

A `suspend` function can pause without blocking the thread while waiting for work to complete. It must be called from another suspend function or from a coroutine. In Android, launch it from an appropriate lifecycle-aware scope (the following lecture uses `viewModelScope`). This keeps network work from freezing the main/UI thread and ties work to the ViewModel lifecycle.

> `suspend` alone does not automatically move arbitrary work to a background thread. Retrofit's suspend integration cooperates with coroutines for network calls; choose dispatchers appropriately for other blocking work.

---

## GET versus POST

This project reads category data, so it uses `GET`. Other HTTP methods, such as `POST`, are used for different operations such as submitting data, depending on the API contract.

---

## Recap / cheat sheet

- `@GET("path")` describes an HTTP GET endpoint.
- `baseUrl + endpoint path` forms the request URL.
- A converter maps the response body to the declared return type.
- `suspend` enables a non-blocking call from coroutine code.
- Retrofit generates the networking implementation from the interface.
