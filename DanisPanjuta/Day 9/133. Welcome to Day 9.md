# Welcome to Day 9

---

## Overview

Day 9 takes the app beyond local state: fetch data from a web service, convert its JSON response into Kotlin objects, and render the results in a Jetpack Compose interface. The running project is a recipe-category browser powered by TheMealDB.

---

## What you will build and learn

| Topic | Why it matters |
| :--- | :--- |
| Libraries and dependencies | Reuse tested functionality instead of writing networking and image-loading infrastructure yourself |
| JSON and REST APIs | Understand the data format and the request/response relationship used by web services |
| Retrofit | Describe HTTP endpoints as Kotlin interfaces and map responses to data classes |
| Coroutines and `suspend` | Perform potentially slow work without freezing the UI thread |
| ViewModel state and error handling | Keep the interface responsive while representing loading, success, and failure |
| Compose grids and remote images | Present API results in a scrollable two-column layout |

---

## Project goal

The first milestone is intentionally modest: request the recipe categories, show a loading indicator while the request is in progress, display an error if it fails, and otherwise show each category's image and name. Later course material expands the recipe app with navigation and individual recipe details.

---

## Day 9 roadmap

1. Learn the shape and purpose of JSON.
2. Inspect TheMealDB and choose the category endpoint.
3. Add ViewModel, Retrofit/JSON-converter, and Coil dependencies.
4. Define response data classes and a Retrofit service.
5. Fetch data from a ViewModel coroutine and expose UI state.
6. Build the recipe screen and category grid.
7. Add Internet permission, run the app, and trace the full data flow.

---

## Key idea

The UI should not know how an HTTP request is made. The service obtains typed data, the ViewModel turns it into observable screen state, and composables render that state.

---

## Cheat sheet

- **API:** a defined way for software systems to communicate.
- **JSON:** a lightweight text format for structured data.
- **Retrofit:** a library that turns annotated interfaces into HTTP clients.
- **Coroutine:** a lightweight unit of asynchronous work.
- **ViewModel:** owns screen-related state and survives common configuration changes.
- **Coil:** loads images, including remote images, for Compose.
