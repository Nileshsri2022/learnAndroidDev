# Adding Dependencies for ViewModel, Network Calls, and JSON

---

## Overview

Before writing the recipe client, add libraries that provide lifecycle-aware ViewModels, HTTP access and JSON conversion, plus remote image loading. Dependencies are declared in the app module's Gradle build file, then resolved by syncing the project.

---

## Libraries used in the project

| Library | Role |
| :--- | :--- |
| Lifecycle ViewModel Compose | Obtain a ViewModel from Compose and scope it to the UI lifecycle |
| Retrofit | Define and execute HTTP API calls from a Kotlin interface |
| Retrofit JSON converter | Deserialize JSON responses into Kotlin model objects |
| Coil Compose | Load and display remote images in Compose |

The lecture demonstrates adding dependencies under the **app module** dependencies—not the project-level Gradle file—and syncing after edits. Artifact coordinates and versions can change over time; use compatible versions from the course setup or the current project catalog.

```kotlin
dependencies {
    // Illustrative names only; use versions managed by your project.
    implementation("androidx.lifecycle:lifecycle-viewmodel-compose:<version>")
    implementation("com.squareup.retrofit2:retrofit:<version>")
    implementation("com.squareup.retrofit2:converter-gson:<version>")
    implementation("io.coil-kt:coil-compose:<version>")
}
```

> The exact JSON converter depends on the chosen converter library and model setup. Keep dependency versions aligned rather than copying an old version blindly.

---

## Why use libraries?

Networking, JSON parsing, and image caching involve much more work than the few lines that call them. A library packages that complexity behind a focused API. Retrofit handles HTTP requests and delegates conversion; Coil handles image fetching and rendering.

---

## Setup checklist

1. Open `build.gradle` / `build.gradle.kts` for the app module.
2. Add required dependencies in the existing `dependencies` block.
3. Sync Gradle and resolve any version or repository issues.
4. Confirm the imports resolve before building the service and composables.

---

## Recap / cheat sheet

- Gradle dependency → library becomes available to the module.
- Retrofit → HTTP client abstraction.
- Converter → JSON ↔ Kotlin model mapping.
- Lifecycle ViewModel Compose → ViewModel integration in Compose.
- Coil Compose → remote image loading for composables.
