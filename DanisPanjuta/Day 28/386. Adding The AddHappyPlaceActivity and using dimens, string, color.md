# Adding The Add HappyPlaceActivity and using dimens, string, color

---

## Overview

The FAB opens **`AddHappyPlaceActivity`** — a scrollable form with Title, Description, Date, Location, an image preview + "ADD IMAGE", and SAVE. All sizes, strings and colours are extracted to **resource files**.

---

## Navigation

```kotlin
fabAddHappyPlace.setOnClickListener {
    val intent = Intent(this, AddHappyPlaceActivity::class.java)
    startActivity(intent)
}
```

Toolbar with back arrow as in previous apps:

```kotlin
setSupportActionBar(toolbar_add_place)
supportActionBar?.setDisplayHomeAsUpEnabled(true)
toolbar_add_place.setNavigationOnClickListener { onBackPressed() }
```

## Resource files

| File | Example | Why |
| :--- | :--- | :--- |
| `values/dimens.xml` | `<dimen name="edit_text_text_size">16sp</dimen>` | One place to change sizes |
| `values/strings.xml` | `<string name="edit_text_hint_title">Title</string>` | Translations, no hard-coded text |
| `values/colors.xml` | `<color name="colorPrimary">#1E88E5</color>` | Consistent palette |

Studio's **Alt + Enter → Extract resource** converts hard-coded values.

## Recap / cheat sheet

- FAB → `AddHappyPlaceActivity` form.
- Extract **dimens / strings / colors** — no hard-coded values.
