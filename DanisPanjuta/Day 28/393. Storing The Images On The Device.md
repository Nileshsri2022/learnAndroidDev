# Storing The Images On The Device

---

## Overview

A gallery image could be **deleted by the user** at any time, so the app copies the bitmap into its **own private storage** and keeps the file path.

---

## saveImageToInternalStorage

```kotlin
companion object {
    private const val IMAGE_DIRECTORY = "HappyPlacesImages"
}

private fun saveImageToInternalStorage(bitmap: Bitmap): Uri {
    val wrapper = ContextWrapper(applicationContext)
    var file = wrapper.getDir(IMAGE_DIRECTORY, Context.MODE_PRIVATE)
    file = File(file, "${UUID.randomUUID()}.jpg")

    try {
        val stream: OutputStream = FileOutputStream(file)
        bitmap.compress(Bitmap.CompressFormat.JPEG, 100, stream)
        stream.flush()
        stream.close()
    } catch (e: IOException) {
        e.printStackTrace()
    }
    return Uri.parse(file.absolutePath)
}
```

| Piece | Meaning |
| :--- | :--- |
| `ContextWrapper.getDir(name, MODE_PRIVATE)` | App-private directory (`app_HappyPlacesImages`) |
| `UUID.randomUUID()` | Unique file name |
| `compress(JPEG, 100, stream)` | Write the bitmap |
| Return `Uri` | Saved later in the database |

---

## Using it

```kotlin
private var saveImageToInternalStorage: Uri? = null

// gallery & camera branches
saveImageToInternalStorage = saveImageToInternalStorage(selectedImageBitmap)
Log.e("Saved image: ", "Path :: $saveImageToInternalStorage")
```

Check via **Device File Explorer → data/data/<package>/app_HappyPlacesImages**. Private storage is removed when the app is uninstalled.

---

## Recap / cheat sheet

- Copy images into `getDir(..., MODE_PRIVATE)` with a UUID name.
- Store the returned path, not the gallery Uri.
