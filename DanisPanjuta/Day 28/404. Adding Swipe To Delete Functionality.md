# Adding Swipe To Delete Functionality

---

## Overview

A challenge: copy the swipe-to-edit callback into **`SwipeToDeleteCallback`** (direction **LEFT**, red background, delete icon) and delete the row from the database and the list.

---

## Database

```kotlin
fun deleteHappyPlace(happyPlace: HappyPlaceModel): Int {
    val db = this.writableDatabase
    val success = db.delete(TABLE_HAPPY_PLACE, KEY_ID + "=" + happyPlace.id, null)
    db.close()
    return success
}
```

---

## Adapter

```kotlin
fun removeAt(position: Int) {
    val dbHandler = DatabaseHandler(context)
    val isDeleted = dbHandler.deleteHappyPlace(list[position])
    if (isDeleted > 0) {
        list.removeAt(position)
        notifyItemRemoved(position)
    }
}
```

---

## Callback + attach

```kotlin
abstract class SwipeToDeleteCallback(context: Context) :
    ItemTouchHelper.SimpleCallback(0, ItemTouchHelper.LEFT) {
    // same as edit, but red (#f44336) background drawn on the right
    // and ic_delete_white_24dp icon
}

val deleteSwipeHandler = object : SwipeToDeleteCallback(this) {
    override fun onSwiped(viewHolder: RecyclerView.ViewHolder, direction: Int) {
        val adapter = rv_happy_places_list.adapter as HappyPlacesAdapter
        adapter.removeAt(viewHolder.adapterPosition)
        getHappyPlacesListFromLocalDB()      // update empty state
    }
}
ItemTouchHelper(deleteSwipeHandler).attachToRecyclerView(rv_happy_places_list)
```

`notifyItemRemoved` animates the removal smoothly.

---

## Recap / cheat sheet

- LEFT swipe → `db.delete` + `list.removeAt` + `notifyItemRemoved`.
- Two `ItemTouchHelper`s can be attached to one RecyclerView.
