# Steps to integrate AdMob in your Android App in Kotlin

---

## Overview

Resource lecture (no video transcript): how to monetise an app with **Google AdMob** banner ads.

---

## 1. Create an AdMob account & app

- Sign up at **admob.google.com**, add your app, create an **ad unit** (e.g. Banner).
- Note the **App ID** (`ca-app-pub-XXXX~YYYY`) and **Ad unit ID** (`ca-app-pub-XXXX/ZZZZ`).

---

## 2. Dependency

```groovy
implementation 'com.google.android.gms:play-services-ads:21.0.0'
```

---

## 3. Manifest

```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-3940256099942544~3347511713" />   <!-- test App ID -->
```

---

## 4. Initialise

```kotlin
MobileAds.initialize(this) {}
```

---

## 5. Banner in XML

```xml
<com.google.android.gms.ads.AdView
    xmlns:ads="http://schemas.android.com/apk/res-auto"
    android:id="@+id/adView"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:layout_gravity="center_horizontal|bottom"
    ads:adSize="BANNER"
    ads:adUnitId="ca-app-pub-3940256099942544/6300978111" />   <!-- test unit -->
```

```kotlin
val adRequest = AdRequest.Builder().build()
binding.adView.loadAd(adRequest)
```

---

## ⚠️ Rules

- **Always use test ad unit IDs** during development — clicking your own live ads can get the account banned.
- Replace with real IDs only for release.
- Other formats: Interstitial, Rewarded, Native.

---

## Recap / cheat sheet

- Dependency + App ID meta-data + `MobileAds.initialize` + `AdView.loadAd(AdRequest)`.
- Test IDs while developing.
