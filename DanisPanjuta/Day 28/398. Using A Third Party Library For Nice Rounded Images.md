# Using A Third Party Library For Nice Rounded Images

---

## Overview

Replaces the square list image with a **circular** one using **CircleImageView** by hdodenhof — much quicker than building it yourself.

---

## Dependency

```groovy
implementation 'de.hdodenhof:circleimageview:3.0.1'
```

---

## Usage

```xml
<de.hdodenhof.circleimageview.CircleImageView
    android:id="@+id/iv_place_image"
    android:layout_width="60dp"
    android:layout_height="60dp"
    android:src="@mipmap/ic_launcher_round"
    app:civ_border_color="@color/circular_image_border_color"
    app:civ_border_width="2dp" />
```

| Attribute | Effect |
| :--- | :--- |
| `civ_border_width` | Ring thickness |
| `civ_border_color` | Ring colour |
| `civ_circle_background_color` | Fill behind transparent images |

Works like an `ImageView` in code (`setImageURI`, `setImageBitmap`). Note: it always uses `centerCrop`.

Alternative without a library: Material's `ShapeableImageView` with `app:shapeAppearanceOverlay` (50% corner radius).

---

## Recap / cheat sheet

- `de.hdodenhof.circleimageview.CircleImageView` + `civ_border_*` attributes.
