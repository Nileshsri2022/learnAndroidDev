# Using The Third Party Library DEXTER For Permission Handling

---

## Overview

**Dexter** (github.com/Karumi/Dexter) simplifies runtime permissions. Clicking **ADD IMAGE** shows a small dialog — "Select photo from Gallery" / "Capture photo from camera" — and requesting storage permission uses Dexter.

---

## Dependency

```groovy
implementation 'com.karumi:dexter:6.2.3'
```

---

## Picture dialog

```kotlin
R.id.tv_add_image -> {
    val pictureDialog = AlertDialog.Builder(this)
    pictureDialog.setTitle("Select Action")
    val pictureDialogItems = arrayOf("Select photo from Gallery", "Capture photo from camera")
    pictureDialog.setItems(pictureDialogItems) { _, which ->
        when (which) {
            0 -> choosePhotoFromGallery()
            1 -> takePhotoFromCamera()
        }
    }
    pictureDialog.show()
}
```

`setItems` shows a list inside an `AlertDialog`; `which` is the tapped index.

## Dexter multi-permission request

```kotlin
private fun choosePhotoFromGallery() {
    Dexter.withContext(this)
        .withPermissions(
            Manifest.permission.READ_EXTERNAL_STORAGE,
            Manifest.permission.WRITE_EXTERNAL_STORAGE
        )
        .withListener(object : MultiplePermissionsListener {
            override fun onPermissionsChecked(report: MultiplePermissionsReport?) {
                if (report!!.areAllPermissionsGranted()) {
                    Toast.makeText(this@AddHappyPlaceActivity,
                        "Storage READ/WRITE permission are granted. Now you can select an image from GALLERY",
                        Toast.LENGTH_SHORT).show()
                }
            }
            override fun onPermissionRationaleShouldBeShown(
                permissions: MutableList<PermissionRequest>?, token: PermissionToken?) {
                showRationalDialogForPermissions()
            }
        }).onSameThread().check()
}
```

## Rationale → open app settings

```kotlin
private fun showRationalDialogForPermissions() {
    AlertDialog.Builder(this)
        .setMessage("It looks like you have turned off permissions required for this feature. It can be enabled under Application Settings")
        .setPositiveButton("GO TO SETTINGS") { _, _ ->
            try {
                val intent = Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS)
                val uri = Uri.fromParts("package", packageName, null)
                intent.data = uri
                startActivity(intent)
            } catch (e: ActivityNotFoundException) {
                e.printStackTrace()
            }
        }
        .setNegativeButton("Cancel") { dialog, _ -> dialog.dismiss() }
        .show()
}
```

Declare both permissions in the manifest.

---

## Recap / cheat sheet

- `Dexter.withContext(ctx).withPermissions(...).withListener(MultiplePermissionsListener).check()`.
- `report.areAllPermissionsGranted()`.
- Denied permanently → deep-link to **app settings**.
