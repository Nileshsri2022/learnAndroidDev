# Adding ActivityForResult In Order To Update The List Dynamically

---

## Overview

After adding a place and returning, the list didn't refresh. Fix: start `AddHappyPlaceActivity` **for a result**; on `RESULT_OK` reload the list.

---

## MainActivity

```kotlin
companion object {
    var ADD_PLACE_ACTIVITY_REQUEST_CODE = 1
}

fabAddHappyPlace.setOnClickListener {
    val intent = Intent(this@MainActivity, AddHappyPlaceActivity::class.java)
    startActivityForResult(intent, ADD_PLACE_ACTIVITY_REQUEST_CODE)
}

override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    if (requestCode == ADD_PLACE_ACTIVITY_REQUEST_CODE) {
        if (resultCode == Activity.RESULT_OK) {
            getHappyPlacesListFromLocalDB()
        } else {
            Log.e("Activity", "Cancelled or Back Pressed")
        }
    }
}
```

---

## AddHappyPlaceActivity — after saving

```kotlin
if (addHappyPlace > 0) {
    setResult(Activity.RESULT_OK)
    finish()
}
```

Back button without saving → `RESULT_CANCELED` → no reload.

(Modern replacement: `registerForActivityResult(StartActivityForResult())`.)

---

## Recap / cheat sheet

- Caller: `startActivityForResult(intent, CODE)` + `onActivityResult`.
- Callee: `setResult(RESULT_OK); finish()`.
