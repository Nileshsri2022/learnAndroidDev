# Passing Whole Objects from One Activity To Another - Serializable vs Parcelable

---

## Overview

The detail screen needs the whole `HappyPlaceModel`. Intents can carry objects if they are **`Serializable`** or **`Parcelable`**. This lecture compares both.

---

## Serializable (simple)

```kotlin
data class HappyPlaceModel(
    val id: Int, val title: String?, val image: String?, val description: String?,
    val date: String?, val location: String?, val latitude: Double, val longitude: Double
) : Serializable
```

```kotlin
// MainActivity
intent.putExtra(EXTRA_PLACE_DETAILS, model)

// HappyPlaceDetailActivity
var happyPlaceDetailModel: HappyPlaceModel? = null
if (intent.hasExtra(MainActivity.EXTRA_PLACE_DETAILS)) {
    happyPlaceDetailModel =
        intent.getSerializableExtra(MainActivity.EXTRA_PLACE_DETAILS) as HappyPlaceModel
}
if (happyPlaceDetailModel != null) {
    setSupportActionBar(toolbar_happy_place_detail)
    supportActionBar?.setDisplayHomeAsUpEnabled(true)
    supportActionBar?.title = happyPlaceDetailModel.title
    iv_place_image.setImageURI(Uri.parse(happyPlaceDetailModel.image))
    tv_description.text = happyPlaceDetailModel.description
    tv_location.text = happyPlaceDetailModel.location
}
```

`companion object { var EXTRA_PLACE_DETAILS = "extra_place_details" }`

---

## Parcelable (faster)

```kotlin
data class HappyPlaceModel(…) : Parcelable {
    constructor(parcel: Parcel) : this(
        parcel.readInt(), parcel.readString(), parcel.readString(), parcel.readString(),
        parcel.readString(), parcel.readString(), parcel.readDouble(), parcel.readDouble())

    override fun writeToParcel(parcel: Parcel, flags: Int) {
        parcel.writeInt(id); parcel.writeString(title); …
    }
    override fun describeContents(): Int = 0

    companion object CREATOR : Parcelable.Creator<HappyPlaceModel> {
        override fun createFromParcel(parcel: Parcel) = HappyPlaceModel(parcel)
        override fun newArray(size: Int): Array<HappyPlaceModel?> = arrayOfNulls(size)
    }
}
```

Or with the **`kotlin-parcelize`** plugin: `@Parcelize data class HappyPlaceModel(…) : Parcelable` — no boilerplate. Read with `getParcelableExtra`.

---

## Comparison

| | Serializable | Parcelable |
| :--- | :--- | :--- |
| Origin | Java standard | Android-specific |
| Implementation | Marker interface — zero code | Manual (or `@Parcelize`) |
| Mechanism | Reflection — creates many temp objects | Explicit write/read |
| Speed | Slower | **Much faster** |
| Recommended on Android | Small/simple cases | ✅ Yes |

---

## Recap / cheat sheet

- `putExtra(KEY, obj)` requires `Serializable` or `Parcelable`.
- Prefer **Parcelable** (`@Parcelize`) on Android.
