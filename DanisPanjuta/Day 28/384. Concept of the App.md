# Concept of the App

---

## Overview

A walkthrough of the finished Happy Places app and its screens.

---

## Screens

```
MainActivity
 ├─ RecyclerView of happy places (circle image, title, description)
 ├─ "No happy places added yet" when empty
 ├─ FAB (+) ──► AddHappyPlaceActivity
 ├─ swipe right ──► edit (AddHappyPlaceActivity pre-filled)
 ├─ swipe left  ──► delete
 └─ tap item ──► HappyPlaceDetailActivity
                   ├─ big image, description, location
                   └─ VIEW ON MAP ──► MapActivity (marker + zoom animation)

AddHappyPlaceActivity
 ├─ Title, Description
 ├─ Date (DatePickerDialog)
 ├─ Location (Google Places autocomplete) + SELECT CURRENT LOCATION (GPS)
 ├─ Image preview + ADD IMAGE → Select photo from Gallery / Capture photo from camera
 └─ SAVE → SQLite
```

---

## Data stored per place

| Field | Type |
| :--- | :--- |
| id | Int (primary key) |
| title, description | String |
| image | String (file path in app storage) |
| date | String |
| location | String (address) |
| latitude, longitude | Double |

Data is stored **permanently** and loaded on app start.
