# Adding Camera Picking Functionality

---

## Overview

Implements **`takePhotoFromCamera()`** — same structure as the gallery function, but requests the **CAMERA** permission too and launches the camera intent.

---

## Code

```kotlin
private fun takePhotoFromCamera() {
    Dexter.withContext(this)
        .withPermissions(
            Manifest.permission.READ_EXTERNAL_STORAGE,
            Manifest.permission.WRITE_EXTERNAL_STORAGE,
            Manifest.permission.CAMERA
        )
        .withListener(object : MultiplePermissionsListener {
            override fun onPermissionsChecked(report: MultiplePermissionsReport?) {
                if (report!!.areAllPermissionsGranted()) {
                    val intent = Intent(MediaStore.ACTION_IMAGE_CAPTURE)
                    startActivityForResult(intent, CAMERA)
                }
            }
            override fun onPermissionRationaleShouldBeShown(
                permissions: MutableList<PermissionRequest>?, token: PermissionToken?) {
                showRationalDialogForPermissions()
            }
        }).onSameThread().check()
}
```

Result handling:

```kotlin
} else if (requestCode == CAMERA) {
    val thumbnail: Bitmap = data!!.extras!!.get("data") as Bitmap
```

On the emulator the camera shows a virtual 3D room — good enough for testing.

---

## Recap / cheat sheet

- Add `CAMERA` to the Dexter permission list.
- `ACTION_IMAGE_CAPTURE` → thumbnail bitmap.
