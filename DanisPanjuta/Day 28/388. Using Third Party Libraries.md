# Using Third Party Libraries

---

## Overview

Why and how to use **third-party libraries**. Depending on the feature, building it yourself may take far too much code — often a well-maintained open-source library already solves it.

---

## When to use a library

| Use a library when… | Build it yourself when… |
| :--- | :--- |
| The feature is generic (permissions, image loading, networking) | It's your app's unique core logic |
| A popular, maintained library exists | Libraries are abandoned or bloated |
| It saves significant time and bugs | It's only a few lines of code |

---

## How to add one

1. Find it (GitHub, Maven Central, Android Arsenal).
2. Read the **README** — the dependency line and usage examples.
3. Add to `app/build.gradle`:

```groovy
dependencies {
    implementation 'com.karumi:dexter:6.2.3'
    implementation 'de.hdodenhof:circleimageview:3.1.0'
}
```

4. Make sure the repository (`mavenCentral()`, `google()`, sometimes `jitpack.io`) is in `settings.gradle` / project `build.gradle`.
5. **Sync Now**.

---

## Evaluate before adding

- ⭐ Stars, recent commits, open issues.
- License (MIT, Apache 2.0).
- Size / number of transitive dependencies.

## Recap / cheat sheet

- Add via `implementation 'group:artifact:version'` + Gradle sync.
- Check maintenance, license, size.
