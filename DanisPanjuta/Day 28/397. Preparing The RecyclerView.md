# Preparing The RecyclerView

---

## Overview

Adds a **RecyclerView** to `activity_main.xml`, an item layout (**CardView** with image, title, description), and the **`HappyPlacesAdapter`**. Visibility toggles between the list and the "no records" text.

---

## Main layout

```xml
<androidx.recyclerview.widget.RecyclerView
    android:id="@+id/rv_happy_places_list"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:visibility="gone"
    app:layout_behavior="@string/appbar_scrolling_view_behavior" />
```

---

## Item layout — `item_happy_place.xml`

```xml
<androidx.cardview.widget.CardView
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_margin="5dp"
    app:cardCornerRadius="5dp"
    app:cardElevation="5dp"
    android:foreground="?attr/selectableItemBackground">

    <LinearLayout android:orientation="horizontal" android:padding="10dp" …>
        <ImageView android:id="@+id/iv_place_image" android:layout_width="60dp"
            android:layout_height="60dp" … />
        <LinearLayout android:orientation="vertical" android:layout_marginStart="10dp" …>
            <TextView android:id="@+id/tvTitle" android:textStyle="bold" android:textSize="16sp" … />
            <TextView android:id="@+id/tvDescription" android:textColor="#8A8A8A" … />
        </LinearLayout>
    </LinearLayout>
</androidx.cardview.widget.CardView>
```

`selectableItemBackground` → ripple when tapped.

## Adapter

```kotlin
open class HappyPlacesAdapter(
    private val context: Context,
    private var list: ArrayList<HappyPlaceModel>
) : RecyclerView.Adapter<RecyclerView.ViewHolder>() {

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): RecyclerView.ViewHolder =
        MyViewHolder(LayoutInflater.from(context).inflate(R.layout.item_happy_place, parent, false))

    override fun onBindViewHolder(holder: RecyclerView.ViewHolder, position: Int) {
        val model = list[position]
        if (holder is MyViewHolder) {
            holder.itemView.iv_place_image.setImageURI(Uri.parse(model.image))
            holder.itemView.tvTitle.text = model.title
            holder.itemView.tvDescription.text = model.description
        }
    }

    override fun getItemCount(): Int = list.size

    private class MyViewHolder(view: View) : RecyclerView.ViewHolder(view)
}
```

## MainActivity

```kotlin
private fun setupHappyPlacesRecyclerView(happyPlaceList: ArrayList<HappyPlaceModel>) {
    rv_happy_places_list.layoutManager = LinearLayoutManager(this)
    rv_happy_places_list.setHasFixedSize(true)
    val placesAdapter = HappyPlacesAdapter(this, happyPlaceList)
    rv_happy_places_list.adapter = placesAdapter
}

private fun getHappyPlacesListFromLocalDB() {
    val list = DatabaseHandler(this).getHappyPlacesList()
    if (list.size > 0) {
        rv_happy_places_list.visibility = View.VISIBLE
        tv_no_records_available.visibility = View.GONE
        setupHappyPlacesRecyclerView(list)
    } else {
        rv_happy_places_list.visibility = View.GONE
        tv_no_records_available.visibility = View.VISIBLE
    }
}
```

(This Android 10 chapter uses Kotlin synthetics `holder.itemView.tvTitle`; with View Binding use an `ItemHappyPlaceBinding` ViewHolder instead.)
