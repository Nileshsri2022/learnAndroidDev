# Using The Google Places API

---

## Overview

Tapping the **Location** field opens Google's **Places Autocomplete** overlay where the user searches a place or full address; the result fills the field and stores latitude/longitude. Requires a Google Cloud project and **API key**.

---

## Google Cloud setup

1. Go to **console.developers.google.com** (Google Cloud Console), create/select a project.
2. **APIs & Services → Library** → enable **Places API** and **Maps SDK for Android**.
3. **Credentials → Create credentials → API key**. Restrict it to your package + SHA-1 later.
4. Billing account required (free monthly credit).

Store the key in `strings.xml`:

```xml
<string name="google_maps_api_key">YOUR_API_KEY</string>
```

(Never commit real keys publicly — use `local.properties`/Secrets Gradle plugin in real projects.)

## Dependency

```groovy
implementation 'com.google.android.libraries.places:places:2.5.0'
```

## Initialise & launch autocomplete

```kotlin
companion object {
    private const val PLACE_AUTOCOMPLETE_REQUEST_CODE = 3
}

override fun onCreate(savedInstanceState: Bundle?) {
    …
    if (!Places.isInitialized()) {
        Places.initialize(this@AddHappyPlaceActivity,
            resources.getString(R.string.google_maps_api_key))
    }
    et_location.setOnClickListener(this)
}

R.id.et_location -> {
    try {
        val fields = listOf(Place.Field.ID, Place.Field.NAME,
            Place.Field.LAT_LNG, Place.Field.ADDRESS)
        val intent = Autocomplete.IntentBuilder(AutocompleteActivityMode.FULLSCREEN, fields)
            .build(this@AddHappyPlaceActivity)
        startActivityForResult(intent, PLACE_AUTOCOMPLETE_REQUEST_CODE)
    } catch (e: Exception) {
        e.printStackTrace()
    }
}
```

## Result

```kotlin
} else if (requestCode == PLACE_AUTOCOMPLETE_REQUEST_CODE) {
    val place: Place = Autocomplete.getPlaceFromIntent(data!!)
    et_location.setText(place.address)
    mLatitude = place.latLng!!.latitude
    mLongitude = place.latLng!!.longitude
}
```

Make `et_location` non-focusable like the date field.

---

## Recap / cheat sheet

- Enable **Places API**, create API key.
- `Places.initialize(ctx, key)` → `Autocomplete.IntentBuilder(FULLSCREEN, fields)`.
- `Autocomplete.getPlaceFromIntent(data)` → address + `latLng`.
