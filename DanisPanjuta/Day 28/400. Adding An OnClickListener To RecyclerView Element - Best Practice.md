# Adding An OnClickListener To RecyclerView Element - Best Practice

---

## Overview

Tapping a list item should open **`HappyPlaceDetailActivity`**. The best-practice approach: the adapter exposes an **`OnClickListener` interface**; the activity supplies the implementation.

---

## Adapter

```kotlin
open class HappyPlacesAdapter(
    private val context: Context,
    private var list: ArrayList<HappyPlaceModel>
) : RecyclerView.Adapter<RecyclerView.ViewHolder>() {

    private var onClickListener: OnClickListener? = null

    fun setOnClickListener(onClickListener: OnClickListener) {
        this.onClickListener = onClickListener
    }

    override fun onBindViewHolder(holder: RecyclerView.ViewHolder, position: Int) {
        val model = list[position]
        if (holder is MyViewHolder) {
            …
            holder.itemView.setOnClickListener {
                if (onClickListener != null) {
                    onClickListener!!.onClick(position, model)
                }
            }
        }
    }

    interface OnClickListener {
        fun onClick(position: Int, model: HappyPlaceModel)
    }
}
```

---

## Activity

```kotlin
placesAdapter.setOnClickListener(object : HappyPlacesAdapter.OnClickListener {
    override fun onClick(position: Int, model: HappyPlaceModel) {
        val intent = Intent(this@MainActivity, HappyPlaceDetailActivity::class.java)
        startActivity(intent)
    }
})
```

- `object : Interface { … }` = anonymous implementation.
- The adapter stays reusable — it doesn't know about activities or navigation.

Create `HappyPlaceDetailActivity` with a toolbar (back arrow), large `ImageView`, description and location TextViews, and a VIEW ON MAP button.

---

## Recap / cheat sheet

- Adapter: `interface OnClickListener { fun onClick(pos, model) }` + setter.
- Activity: `adapter.setOnClickListener(object : … { })`.
