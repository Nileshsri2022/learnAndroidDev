# Introduction to the Chapter - Happy Places App

---

## Overview

Day 28 builds **Happy Places** — an app to store your favourite places with a **title, description, date, image and location**. It combines many features learned so far and adds several new ones: GPS location, Google Places search, Google Maps, the device camera, SQLite, and third-party libraries.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **RecyclerView** (again) | List of happy places, click handling best practice |
| **Swipe gestures** | `ItemTouchHelper` — swipe to edit / delete |
| **Camera & gallery** | Take a photo or pick one, store it in app storage |
| **Third-party libraries** | **Dexter** (permissions), **CircleImageView** (rounded images) |
| **SQLite** | `SQLiteOpenHelper` database handler (CRUD) |
| **Passing objects** | `Serializable` vs `Parcelable` |
| **Google Places API** | Autocomplete search for a location |
| **Google Maps** | `SupportMapFragment`, markers, camera animation |
| **Location** | `FusedLocationProviderClient`, `Geocoder` for addresses |
| **AdMob** | Bonus: integrating ads |

---
