# Summary - Happy Places

---

## Overview

The Happy Places app is complete — a full-featured app with local storage, media, maps and location.

---

## What you learned

| Area | Details |
| :--- | :--- |
| **Google Maps** | `SupportMapFragment`, markers, animated camera |
| **Google Places** | Autocomplete search with an API key |
| **Location** | `FusedLocationProviderClient`, `LocationManager`, `Geocoder` |
| **RecyclerView** | Click listener interface (best practice), swipe with `ItemTouchHelper` |
| **Dexter** | Easier permission handling |
| **Camera / Gallery** | Implicit intents, bitmaps, storing images in private storage |
| **CircleImageView** | Rounded images via a third-party library |
| **SQLite** | `SQLiteOpenHelper`, `ContentValues`, `Cursor`, CRUD |
| **Objects between activities** | `Serializable` vs `Parcelable` |
| **Results** | `startActivityForResult` / `setResult` to refresh lists |
| **AdMob** | Monetisation basics |
