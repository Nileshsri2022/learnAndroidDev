# Adding The Select Current Location Button And Permissions

---

## Overview

Adds a **SELECT CURRENT LOCATION** button under the location field. It first checks that **location services are enabled**, then requests **fine/coarse location** permissions with Dexter.

---

## Layout

```xml

    android:id="@+id/tv_select_current_location"
```

## Manifest

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

---

## Is location enabled?

```kotlin
private fun isLocationEnabled(): Boolean {
    val locationManager: LocationManager =
        getSystemService(Context.LOCATION_SERVICE) as LocationManager
    return locationManager.isProviderEnabled(LocationManager.GPS_PROVIDER) ||
           locationManager.isProviderEnabled(LocationManager.NETWORK_PROVIDER)
}
```

---

## Click handler

```kotlin
R.id.tv_select_current_location -> {
    if (!isLocationEnabled()) {
        Toast.makeText(this, "Your location provider is turned off. Please turn it on.",
            Toast.LENGTH_SHORT).show()
        val intent = Intent(Settings.ACTION_LOCATION_SOURCE_SETTINGS)
        startActivity(intent)
    } else {
        Dexter.withActivity(this)
            .withPermissions(
                Manifest.permission.ACCESS_FINE_LOCATION,
                Manifest.permission.ACCESS_COARSE_LOCATION
            )
            .withListener(object : MultiplePermissionsListener {
                override fun onPermissionsChecked(report: MultiplePermissionsReport?) {
                    if (report!!.areAllPermissionsGranted()) {
                        Toast.makeText(this@AddHappyPlaceActivity,
                            "Location permission is granted. Now you can request for a current location.",
                            Toast.LENGTH_SHORT).show()
                    }
                }
                override fun onPermissionRationaleShouldBeShown(
                    permissions: MutableList<PermissionRequest>?, token: PermissionToken?) {
                    showRationalDialogForPermissions()
                }
            }).onSameThread().check()
    }
}
```

## Recap / cheat sheet

- `LocationManager.isProviderEnabled(GPS/NETWORK)`.
- Location off → `Settings.ACTION_LOCATION_SOURCE_SETTINGS`.
- Dexter for FINE + COARSE permissions.
