# Adding the Missing Operations and Finalizing the App

---

## Overview

Copies the subtraction branch for **`+`, `*`, `/`**, and adds **`removeZeroAfterDot`** so results like `98.0` display as `98`.

---

## Full onEqual

```kotlin
fun onEqual(view: View) {
    if (lastNumeric) {
        var tvValue = tvInput?.text.toString()
        var prefix = ""
        try {
            if (tvValue.startsWith("-")) {
                prefix = "-"
                tvValue = tvValue.substring(1)
            }
            if (tvValue.contains("-")) {
                val (one, two) = split(tvValue, "-", prefix)
                tvInput?.text = removeZeroAfterDot((one.toDouble() - two.toDouble()).toString())
            } else if (tvValue.contains("+")) {
                val (one, two) = split(tvValue, "+", prefix)
                tvInput?.text = removeZeroAfterDot((one.toDouble() + two.toDouble()).toString())
            } else if (tvValue.contains("/")) {
                val (one, two) = split(tvValue, "/", prefix)
                tvInput?.text = removeZeroAfterDot((one.toDouble() / two.toDouble()).toString())
            } else if (tvValue.contains("*")) {
                val (one, two) = split(tvValue, "*", prefix)
                tvInput?.text = removeZeroAfterDot((one.toDouble() * two.toDouble()).toString())
            }
        } catch (e: ArithmeticException) {
            e.printStackTrace()
        }
    }
}

private fun split(value: String, op: String, prefix: String): Pair<String, String> {
    val parts = value.split(op)
    return Pair(prefix + parts[0], parts[1])
}
```

(The lecture writes each branch out in full; the `split` helper above is a tidier equivalent.)

## removeZeroAfterDot

```kotlin
private fun removeZeroAfterDot(result: String): String {
    var value = result
    if (result.contains(".0")) {
        value = result.substring(0, result.length - 2)
    }
    return value
}
```

`"98.0"` → `"98"`. (Note: `endsWith(".0")` is safer — `contains(".0")` would also match `"1.05"`.)

## Test cases

| Input | Output |
| :--- | :--- |
| `99*99` | `9801` |
| `66/6` | `11` |
| `10/4` | `2.5` |
| `-5+3` | `-2` |

Dividing a `Double` by `0` gives `Infinity` rather than throwing.

---

## Recap / cheat sheet

- One `if / else if` branch per operator.
- **Tidy result:** strip trailing `.0`.
- `Double` math avoids integer-division surprises.
