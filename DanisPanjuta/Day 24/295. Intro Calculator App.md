# Intro Calculator App

---

## Overview

Day 24 builds a **Calculator App**. The instructor admits it's "probably the most boring app" of the course — but it's a classic (and a common university assignment) that teaches a lot about building a UI that positions everything exactly as intended.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **LinearLayouts** in depth | Nesting, `orientation`, **`layout_weight`** |
| **`android:onClick`** | Wiring XML buttons to Activity functions |
| **String manipulation** | `append`, `contains`, `startsWith`, `split`, `substring`, `endsWith` |
| **Math operations** | `+ − × ÷` on `Double` values |
| **State flags** | Tracking last input (`lastNumeric`, `lastDot`) |

---

## Recap / cheat sheet

- **Focus:** complex, evenly-spaced UI + string handling.
- These patterns are reused in every following XML app.
