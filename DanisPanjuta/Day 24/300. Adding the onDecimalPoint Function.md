# Adding the onDecimalPoint Function

---

## Overview

Adds a **`.`** button (bottom-left, next to `0`) so the calculator can work with decimals, and makes sure a dot can only be added **after a digit** and **once per number**.

---

## XML

```xml
<Button
    android:id="@+id/btnDot"
    android:layout_width="0dp"
    android:layout_height="match_parent"
    android:layout_weight="1"
    android:layout_margin="2dp"
    android:onClick="onDecimalPoint"
    android:text="." />
```

Both `.` and `0` keep `layout_weight="1"` so the row stays balanced.

---

## Kotlin

```kotlin
fun onDecimalPoint(view: View) {
    if (lastNumeric && !lastDot) {
        tvInput?.append(".")
        lastNumeric = false
        lastDot = true
    }
}
```

| State | Dot allowed? |
| :--- | :--- |
| Display empty | ❌ `lastNumeric = false` |
| `12` | ✅ → `12.` |
| `12.` | ❌ last input wasn't numeric |
| `12.5` | ❌ `lastDot = true` |

`onClear` should also reset `lastNumeric = false` and `lastDot = false`.

---

## Recap / cheat sheet

- **Guard:** `if (lastNumeric && !lastDot)`.
- After adding the dot: `lastNumeric = false; lastDot = true`.
