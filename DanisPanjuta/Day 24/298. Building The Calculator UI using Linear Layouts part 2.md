# Building The Calculator UI using Linear Layouts part 2

---

## Overview

Finishes the UI mostly by **copy-pasting** the first row, then changing button labels. Adds the **CLR** button and the `onDigit` click handler stub.

---

## Duplicating rows

With `layout_weight="1"` on each row `LinearLayout`, duplicating it three times yields four equally-tall rows automatically:

| Row | Buttons |
| :--- | :--- |
| 1 | `7 8 9 /` |
| 2 | `4 5 6 *` |
| 3 | `1 2 3 -` |
| 4 | `0 = +` (dot added next lecture) |
| 5 | `CLR` (full width) |

Tip: extract repeated attributes into a **style** or use string resources to avoid hard-coded text warnings.

---

## android:onClick

Instead of `setOnClickListener` for 16 buttons, each `Button` declares:

```xml
android:onClick="onDigit"
```

and the Activity provides a **public** function with a `View` parameter:

```kotlin
fun onDigit(view: View) {
    Toast.makeText(this, "Button clicked", Toast.LENGTH_SHORT).show()
}
```

- The signature **must** be `fun name(view: View)` — otherwise the app crashes on click.
- `view` is the button that was pressed → cast to `Button` to read its text.

---

## CLR button

```xml
<Button
    android:id="@+id/btnClear"
    android:layout_width="match_parent"
    android:layout_height="0dp"
    android:layout_weight="1"
    android:onClick="onClear"
    android:text="CLR" />
```

---

## Recap / cheat sheet

- **Copy-paste rows** — weights keep them equal.
- **XML click:** `android:onClick="fnName"` ↔ `fun fnName(view: View)`.
