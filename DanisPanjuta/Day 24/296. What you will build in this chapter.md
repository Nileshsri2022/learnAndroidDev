# What you will build in this chapter

---

## Overview

A demo of the finished calculator — its features **and its limitations** — plus a challenge to try building the UI yourself before watching the solution.

---

## Features

- Large **display** `TextView` at the top (right-aligned, grey background).
- **4×4 grid** of equally-sized buttons with equal spacing:

```
 7   8   9   /
 4   5   6   *
 1   2   3   -
 .   0   =   +
            CLR
```

- **CLR** clears the display.
- Decimal point support (only one dot per number).
- One operation at a time: `99-1 = 98`, `6*9 = 54`.
- Negative first numbers supported: `-5+3 = -2`.
- Results like `98.0` are cleaned to `98`.

---

## Limitations (by design)

- No chained expressions (`1+2+3` evaluates only one operator).
- No operator precedence, brackets or history.
- Operators can only be added after a digit.

---

## Challenge

Pause and build the UI using **LinearLayouts** only — the key is making all buttons the same size with the same distances.

---

## Recap / cheat sheet

- **Goal:** complex yet uniform UI; string-based single-operation calculator.
