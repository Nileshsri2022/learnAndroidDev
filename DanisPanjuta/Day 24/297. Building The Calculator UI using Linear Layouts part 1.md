# Building The Calculator UI using Linear Layouts part 1

---

## Overview

Creates the `MyCalculator` project (min SDK 21) and starts the layout: a vertical root `LinearLayout`, the display `TextView`, and the first row of buttons inside a horizontal `LinearLayout`.

---

## Why LinearLayout instead of ConstraintLayout?

Google recommends `ConstraintLayout`, but for grids of equal elements a **LinearLayout with weights** is much quicker — rows can be copy-pasted and weights keep everything evenly spaced.

---

## Root and display

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    tools:context=".MainActivity">

    <TextView
        android:id="@+id/tvInput"
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="2"
        android:background="#EFEFEF"
        android:gravity="bottom|end"
        android:padding="10dp"
        android:maxLength="12"
        android:text=""
        android:textSize="48sp" />
```

- `gravity="bottom|end"` → text sits in the bottom-right corner like a real calculator.
- `maxLength` limits the characters displayed.

---

## The first button row

```xml
    <LinearLayout
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="1"
        android:orientation="horizontal">

        <Button
            android:layout_width="0dp"
            android:layout_height="match_parent"
            android:layout_weight="1"
            android:layout_margin="2dp"
            android:onClick="onDigit"
            android:text="7" />
        <!-- 8, 9 … -->
        <Button
            android:layout_width="0dp"
            android:layout_height="match_parent"
            android:layout_weight="1"
            android:layout_margin="2dp"
            android:onClick="onOperator"
            android:text="/" />
    </LinearLayout>
```

---

## layout_weight explained

- Set the dimension along the orientation to **`0dp`** and give each child a **`layout_weight`**.
- Remaining space is shared **proportionally**: four buttons with weight `1` → 25 % each.
- Display weight `2` vs. rows weight `1` → display is twice as tall as a row.

---

## Recap / cheat sheet

- **Equal widths:** `layout_width="0dp"` + `layout_weight="1"`.
- **Nesting:** vertical root → horizontal rows.
- **Display:** `gravity="bottom|end"`, large `textSize`.
