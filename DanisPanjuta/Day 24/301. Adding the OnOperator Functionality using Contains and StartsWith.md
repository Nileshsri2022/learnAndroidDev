# Adding the OnOperator Functionality using Contains and StartsWith on Strings

---

## Overview

Operators (`+ - * /`) may only be added **after a digit** and **only once**. The logic uses the String methods **`contains`** and **`startsWith`**.

---

## String helpers — demo

```kotlin
val sentence = "Denis is a coder"
sentence.contains("Denis")     // true
sentence.startsWith("Denis")   // true
sentence.startsWith("coder")   // false
```

Hover a method in the IDE to see what it returns (`Boolean` here).

---

## onOperator

```kotlin
fun onOperator(view: View) {
    tvInput?.text?.let {
        if (lastNumeric && !isOperatorAdded(it.toString())) {
            tvInput?.append((view as Button).text)
            lastNumeric = false
            lastDot = false
        }
    }
}
```

- `tvInput?.text?.let { }` — run only if the text exists; `it` is the `CharSequence`.
- `lastDot = false` because the next number may get its own dot.

---

## isOperatorAdded

```kotlin
private fun isOperatorAdded(value: String): Boolean {
    return if (value.startsWith("-")) {
        false
    } else {
        value.contains("/")
            || value.contains("*")
            || value.contains("+")
            || value.contains("-")
    }
}
```

A leading `-` is a **negative number**, not an operator — so `-5` still allows adding an operator.

(For the leading minus to be enterable, `onOperator` can also allow `-` when the display is empty.)

---

## Recap / cheat sheet

- **contains / startsWith** return `Boolean`.
- Only one operator per calculation; leading `-` = sign.
- Use `?.let { }` to work on nullable text.
