# Using OnClick and Implementing the CLR Functionality

---

## Overview

Digits are now **appended** to the display `TextView`, and **CLR** empties it. Introduces the nullable class-level `tvInput` reference.

---

## Getting the display

```kotlin
class MainActivity : AppCompatActivity() {
    private var tvInput: TextView? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        tvInput = findViewById(R.id.tvInput)
    }
```

---

## onDigit — append the button's text

```kotlin
    fun onDigit(view: View) {
        tvInput?.append((view as Button).text)
    }
```

- `view as Button` → cast so we can read `.text` (the digit on the button).
- `append` adds to the existing text instead of replacing it.

---

## onClear

```kotlin
    fun onClear(view: View) {
        tvInput?.text = ""
    }
}
```

---

## Flags for later logic

```kotlin
var lastNumeric: Boolean = false   // was the last input a digit?
var lastDot: Boolean = false       // has the current number a dot?

fun onDigit(view: View) {
    tvInput?.append((view as Button).text)
    lastNumeric = true
    lastDot = false
}

fun onClear(view: View) {
    tvInput?.text = ""
}
```

---

## Recap / cheat sheet

- **Append:** `tvInput?.append((view as Button).text)`.
- **Clear:** `tvInput?.text = ""`.
- **Flags:** `lastNumeric`, `lastDot` guard later input.
