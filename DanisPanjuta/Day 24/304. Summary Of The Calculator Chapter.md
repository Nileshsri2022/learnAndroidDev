## What you learned

| Area | Details |
| :--- | :--- |
| **Complex UI** | Nested `LinearLayout`s, `layout_weight`, `0dp` trick, `gravity` |
| **Click handling** | `android:onClick="fn"` + `fun fn(view: View)` |
| **Casting** | `view as Button` to read text |
| **Strings** | `append`, `contains`, `startsWith`, `split`, `substring` |
| **State flags** | `lastNumeric`, `lastDot` |
| **Math** | `toDouble()` and the four operators |
| **Robustness** | `try / catch` around parsing/math |

---

## Function map

```
onDigit()        → append digit, lastNumeric = true
onDecimalPoint() → append ".", only once per number
onOperator()     → append op, only after digit & once
onClear()        → reset display and flags
onEqual()        → split at op, compute, removeZeroAfterDot()
```
