# If Statements as Expressions

---

## Overview

Deep-dive on **`if` as expression** — assigning the result directly and using it in string templates.

---

## Examples

```kotlin
val age = 20
val group = if (age < 13) "Child" else if (age < 20) "Teen" else "Adult"
val greeting = "You are a $group"

val textColor = if (group == "Adult") Color.Black else Color.Gray
```

Works because every branch returns the same type.

---

## Recap / cheat sheet

- **Expression:** every `if` branch must_return same type.
- **Usage:** `val x = if (...) ... else ...`.
