## If statements

```kotlin
val x = 5
if (x > 10) println("Greater")
else if (x == 5) println("Five")
else println("Other")

val result = if (x > 0) "Positive" else "Non-positive" // if is an expression
val max = if (a > b) a else b
```

`if` returns a value — no ternary needed.

---

## Recap / cheat sheet

- **If:** `if (cond) { } else if { } else { }`.
- **Expression:** `val y = if (c) a else b`.
