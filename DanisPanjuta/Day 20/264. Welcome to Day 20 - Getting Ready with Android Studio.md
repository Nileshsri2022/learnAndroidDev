# Welcome to Day 20 - Getting Ready with Android Studio

---

## Overview

**Getting Ready with Android Studio** (XML track) repeats the Day 1 setup but for the **legacy XML UI toolkit**: creating a project with **Empty Views Activity**, changing `TextView` size, and running on an emulator/device.

---

## Roadmap

1. Empty Views Activity → `activity_main.xml` (ConstraintLayout + TextView).
2. `Hello World` and string resources.
3. People Counter app (button + TextView counter).
4. Testing on a physical phone (USB debugging).

---

## Recap / cheat sheet

- **Views Activity** = XML layout, not Compose.
- **TextView:** `android:textSize="24sp"` in XML.
