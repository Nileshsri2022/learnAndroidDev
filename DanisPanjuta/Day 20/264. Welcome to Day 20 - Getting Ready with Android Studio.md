## 📝 Summary

Day 20 marks the beginning of the **XML & View-based development track** in the course. While Days 5–18 focused on modern Jetpack Compose, an enormous portion of production Android software in industry still relies on Android's classic View hierarchy and XML layouts. 

In Day 20, students revisit the Android Studio setup from the perspective of View-based development: creating an **Empty Views Activity**, configuring projects, exploring the XML Design and Blueprint editors, creating an Android Virtual Device (AVD), writing their first interactive XML app (**People Counter**), and testing apps on both emulators and physical hardware.

## 📒 Detailed Notes

### Why Learn the XML Track?
- **Legacy Industry Codebases:** Thousands of mature enterprise applications (banking, healthcare, logistics, e-commerce) were built with XML layouts over the past decade.
- **Career Flexibility:** Professional Android developers frequently maintain, refactor, and migrate existing XML codebases to modern architectures.
- **Deep Framework Understanding:** Learning how Android's underlying View system, Activities, and resource layouts operate provides foundational knowledge that enhances your understanding of modern toolkits.

### Day 20 Roadmap
1. **Project Creation & IDE UI:** Setting up an Empty Views Activity, configuring package names, minSDK, and customizing editor typography.
2. **Emulator Configuration:** Selecting device hardware profiles, downloading system images, and configuring RAM, heap, and CPU allocations.
3. **Hello World & XML Attributes:** Editing `activity_main.xml`, understanding `ConstraintLayout`, and mastering `sp` text sizing.
4. **The People Counter App:** Building a complete interactive app with buttons, text views, counter variables, and Toast alerts.
5. **On-Device Testing:** Unlocking developer mode on physical hardware for high-performance testing.

## 📌 Important Terms

| Term | Definition |
| :--- | :--- |
| **Empty Views Activity** | Android Studio template that sets up an Activity linked to an XML layout file using `setContentView`. |
| **ConstraintLayout** | A flexible ViewGroup that allows positioning and sizing widgets relative to siblings and parent boundaries. |
| **AVD (Android Virtual Device)** | Software emulator simulating an Android device on your desktop development machine. |
| **USB Debugging** | Developer bridge setting allowing Android Studio to push, execute, and debug code directly on physical hardware. |
