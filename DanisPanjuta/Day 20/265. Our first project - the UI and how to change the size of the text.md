## 🧠 Key Concepts & Decisions

| # | Concept | Explanation & Best Practice |
|---|---|---|
| 1 | **Template Selection** | Select **Empty Views Activity** (or **Empty Activity** in older Studio versions). Avoid templates with pre-generated navigation or buttons so you learn core mechanics from scratch. |
| 2 | **Package Naming** | Inverted domain convention (e.g., `com.company.appname` or `eu.tutorials.myfirstapp`). Must be globally unique across the entire Google Play Store. |
| 3 | **Kotlin vs. Java** | Kotlin is Google's first-class, official language for Android development. It provides null safety, concise syntax, and modern functional features. |
| 4 | **Minimum SDK (minSDK)** | Specifies the lowest Android version capable of running the app. Selecting **API 21 (Android 5.0 Lollipop)** supports over 94% of active devices worldwide. |
| 5 | **AppCompat Library** | A foundational AndroidX support library that backports modern Android features and styling to older Android OS versions. |
| 6 | **IDE vs. Editor Font** | **Appearance Settings** scale the Android Studio UI menus and tabs; **Editor Font Settings** scale the actual code lines inside editor panes. |

## 📒 Detailed Notes

### 1. The Project Wizard Tour
- **Device Categories:** Android Studio supports Phones & Tablets, Wear OS (smartwatches), Android TV, and Automotive. We focus primarily on Phones and Tablets.
- **Available Templates:**
  - *Bottom Navigation Activity:* Generates pre-wired navigation fragments.
  - *Basic Activity:* Generates a floating action button (FAB) and menu bar.
  - *Empty Views Activity:* A clean slate with one Activity and one blank layout XML file. **Always start here as a beginner** to understand every line of code.

### 2. Configuring Project Settings
- **Name:** The human-facing app title (e.g., `My First App`).
- **Package Name:** Inverted web domain format:
  ```
  eu.tutorials.myfirstapp
  └── Domain: tutorials.eu  ──> inverted: eu.tutorials
  └── App identifier: myfirstapp
  ```
  *Crucial Rule:* Once published to Google Play, the package name can never be changed. It is the permanent unique ID of your application.
- **Save Location:** A clean local path without unusual characters or spaces.
- **Language:** Select **Kotlin**.
- **Minimum SDK (API Level):**
  - An **SDK (Software Development Kit)** includes tools, compilers, debuggers, and libraries for developing for a specific operating system.
  - Setting minSDK to the latest version (e.g. Android 12 / API 31) means only ~1% to 8% of users with newest devices can install your app.
  - Setting minSDK to **API 21 (Android 5.0)** covers ~94.1%+ of the global Android ecosystem. Thanks to Google's **AppCompat**, you can still use modern UI features on these older devices.

### 3. Understanding the Project Structure
Switch the left tool window dropdown from **Project** to **Android** view for the cleanest organization:
```
app/
├── java/
│   └── eu.tutorials.myfirstapp/
│       └── MainActivity.kt      <-- Kotlin logic & lifecycle entry point
└── res/                         <-- Resources folder
    ├── drawable/                <-- Images, icons, and vector XML files
    ├── layout/
    │   └── activity_main.xml    <-- XML layout definition
    └── values/
        ├── colors.xml           <-- Color definitions
        ├── strings.xml          <-- Text localization resources
        └── themes.xml           <-- Style themes
```

### 4. Customizing Android Studio Font Scaling
- **IDE Interface Size:** Press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> (or <kbd>Cmd</kbd>+<kbd>,</kbd> on macOS) → **Appearance & Behavior → Appearance** → Check *Use custom font* → Set size to `16` or `18`.
- **Editor Code Size:** In Settings, navigate to **Editor → Font** → Set size to `18` or `20` for comfortable code reading.

## 💻 Code: How Kotlin Binds to XML

In `MainActivity.kt`:
```kotlin
package eu.tutorials.myfirstapp

import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        // Binds this Activity to the layout resource res/layout/activity_main.xml
        setContentView(R.layout.activity_main)
    }
}
```

## 📌 Important Terms

| Term | Definition |
| :--- | :--- |
| **Activity** | A single focused screen that a user can interact with in an Android application. |
| **`setContentView`** | Method that inflates the specified XML layout file and attaches it to the Activity window. |
| **`R` Class** | An auto-generated Kotlin/Java class mapping all project resources (`res/`) to static integer IDs. |
| **minSDK** | Minimum Android API level required to install and run the application. |
| **AppCompatActivity** | Base class for Activities that provide backward-compatible Material design and action bar support. |

## ❓ Q&A

**Q: Why does Android Studio show a Gradle build bar when first creating a project?**  
A: Gradle is Android's build automation tool. On initial creation, it downloads required compiler plugins, libraries, and dependencies, and verifies that the project environment is valid.

**Q: What is the difference between the "Project" view and the "Android" view in the sidebar?**  
A: The "Project" view mirrors the exact physical directory layout on your hard drive (including Gradle caches and build outputs). The "Android" view flattens this into a practical, logical view highlighting only source code, manifests, and resources.

## ✅ Key Takeaways

1. 🏗️ **Start clean:** Always use Empty Views Activity when learning the View system to master fundamental connections.
2. 🌐 **Package names are permanent:** Choose a unique reverse-domain identifier for every new Android app.
3. 📱 **Optimize minSDK:** Balance modern API features with maximum device reach (API 21 reaches ~94%+ of users).
4. 🔗 **`setContentView` is the bridge:** It connects your Kotlin `MainActivity` class to its XML design file `activity_main.xml`.
