# Our first project - the UI and how to change the size of the text

---

## Overview

Create **Empty Views Activity** → open `res/layout/activity_main.xml` → `TextView` with `Hello World` → adjust size via **Attributes** panel or XML `android:textSize="48sp"`.

---

## XML

```xml
<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Hello World"
    android:textSize="48sp"
    app:layout_constraintTop_toTopOf="parent"
    app:layout_constraintStart_toStartOf="parent" />
```

`sp` for text, `dp` for layout.

---

## Recap / cheat sheet

- **Text size:** Attributes → `textSize` or XML `android:textSize`.
