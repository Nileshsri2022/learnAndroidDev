## 📒 Detailed Notes

### 1. Dissecting `MainActivity.kt`
```kotlin
package eu.tutorials.myfirstapp

import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}
```
- **Peeking Behind the Curtain:** If you hold <kbd>Ctrl</kbd> (or <kbd>Cmd</kbd> on macOS) and click on `AppCompatActivity`, Android Studio decompiles and opens `AppCompatActivity.java`. You will see hundreds of lines of foundational Android platform code managing window tokens, action bars, menu delegates, and back navigation.
- **Activity Definition:** In traditional Android development, **one Activity equals one screen**. If an app has a Login screen, a Feed screen, and a Settings screen, it historically used three separate Activities (or one Activity hosting multiple Fragments).

### 2. Exploring `activity_main.xml`
Android Studio provides three modes via the top-right toggle buttons:
1. **Design Mode:** Visual drag-and-drop surface with Component Tree and Attributes panel.
2. **Split Mode (Recommended):** Code editor on the left, live rendered preview on the right.
3. **Code Mode:** Pure XML text editor.

You can instantly jump from `R.layout.activity_main` in Kotlin straight into the XML file by holding <kbd>Ctrl</kbd> and clicking on `activity_main`.

### 3. Understanding Units: Why `sp` for Text?
When customizing text size in the Attributes panel or XML code:
- **`px` (Raw Pixels):** **Never use!** A 24px text looks readable on a 160 DPI screen, but appears microscopically tiny on a modern 560 DPI smartphone.
- **`dp` (Density-independent Pixels):** Scales based on physical screen density ($1 \text{ dp} = 1 \text{ pixel at } 160 \text{ DPI}$). Great for buttons, margins, widths, and padding.
- **`sp` (Scale-independent Pixels):** Scales like `dp`, **plus** respects the user's accessibility font size preference configured in their phone's system settings. **Always use `sp` for text!**

### 4. Customizing Text Appearance in XML
```xml
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout 
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context=".MainActivity">

    <TextView
        android:id="@+id/tvGreeting"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello, Denis!"
        android:textColor="#FF0000"
        android:textSize="28sp"
        android:textStyle="bold"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toTopOf="parent" />

</androidx.constraintlayout.widget.ConstraintLayout>
```

- **Hardcoded String Warning:** Android Studio displays a subtle yellow lint warning on `android:text="Hello, Denis!"`. This is because production apps should extract display strings into `res/values/strings.xml` for multi-language localization.

## 📌 Important Terms

| Term | Definition |
| :--- | :--- |
| **Layout Inflation** | The process where Android parses an XML file and instantiates real `View` objects in memory. |
| **`TextView`** | Android's primary View widget for rendering text onto the screen. |
| **Scale-independent Pixels (`sp`)** | Unit of measurement for typography that scales with both screen density and user accessibility settings. |
| **DPI (Dots Per Inch)** | The pixel density of a physical display screen. |
| **Lint** | A static code analysis tool in Android Studio that flags anti-patterns, missing constraints, and unlocalized strings. |

## ❓ Q&A

**Q: What happens if I accidentally delete the `import androidx.appcompat.app.AppCompatActivity` line?**  
A: Android Studio will highlight `AppCompatActivity` in red and refuse to build. You can place your cursor on the unresolved red word and press <kbd>Alt</kbd>+<kbd>Enter</kbd> (or <kbd>Option</kbd>+<kbd>Return</kbd>) to automatically re-import the missing class.

**Q: Why does the TextView have four `app:layout_constraint...` attributes?**  
A: In a `ConstraintLayout`, every child widget must have at least one horizontal and one vertical constraint anchor. By constraining all four sides to `parent`, the TextView is perfectly centered on the screen.

## ✅ Key Takeaways

1. 🏛️ **The Activity is your canvas:** `MainActivity` controls screen lifecycle, while `activity_main.xml` defines visual structure.
2. 🔤 **Always use `sp` for text:** Scale-independent pixels guarantee readable typography across all device densities and accessibility configurations.
3. 🗺️ **The `R` class is the resource map:** It bridges XML resources in `res/` with runtime Kotlin logic.
4. ⚡ **Master Split View:** Working in Split mode gives you real-time visual feedback while editing raw XML markup.
