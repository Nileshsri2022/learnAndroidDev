# People Counter App

---

## Overview

A button increments a `TextView` counter — the **state** predecessor in Views (`var count = 0; button.setOnClickListener { count++; textView.text = count.toString() }`).

---

## Code

```kotlin
class MainActivity : AppCompatActivity() {
    var count = 0
    override fun onCreate(b: Bundle?) {
        super.onCreate(b)
        setContentView(R.layout.activity_main)
        val tvCount = findViewById<TextView>(R.id.tvCount)
        val btn = findViewById<Button>(R.id.btnAdd)
        btn.setOnClickListener { count++; tvCount.text = count.toString() }
    }
}
```

---

## Recap / cheat sheet

- **Counter:** `findViewById` + `setOnClickListener` + `var count`.
