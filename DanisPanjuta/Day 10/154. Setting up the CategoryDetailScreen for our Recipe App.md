# Setting up the CategoryDetailScreen for our Recipe App

---

## Overview

Back in the recipe app, tapping a category should open a detail screen showing:

1. The category title at the top.
2. The category image.
3. A long description underneath that **scrolls on its own**, while the title and image stay put.

A new Kotlin file `CategoryDetailScreen.kt` holds the composable.

---

## The detail screen

```kotlin
@Composable
fun CategoryDetailScreen(category: Category) {
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = category.strCategory,
            textAlign = TextAlign.Center,
            fontWeight = FontWeight.Bold,
            fontSize = 24.sp
        )

        Spacer(modifier = Modifier.height(16.dp))

        Image(
            painter = rememberAsyncImagePainter(category.strCategoryThumb),
            contentDescription = "${category.strCategory} category",
            modifier = Modifier.wrapContentSize()
        )

        Spacer(modifier = Modifier.height(16.dp))

        Text(
            text = category.strCategoryDescription,
            textAlign = TextAlign.Justify,
            modifier = Modifier.verticalScroll(rememberScrollState())
        )
    }
}
```

The composable **requires** a `Category`. Without it there is nothing to render, which is why the
navigation lectures focus on delivering that object.

---

## Element by element

| Element | Detail |
| :--- | :--- |
| `Column` + `fillMaxSize()` + `padding(16.dp)` | Full-screen vertical layout with outer spacing |
| `horizontalAlignment = Alignment.CenterHorizontally` | Centres the title, image, and text |
| `Text` title | Shows `strCategory`; `TextAlign.Center` centres multi-line titles |
| `Image` with `rememberAsyncImagePainter` | Coil loads the thumbnail from `strCategoryThumb` |
| `contentDescription` | Describes the image for screen readers, e.g. `"Beef category"` |
| `Modifier.wrapContentSize()` | The image takes only the space it needs |
| `TextAlign.Justify` | Stretches lines ending in a soft break to fill the container width |
| `Modifier.verticalScroll(rememberScrollState())` | Makes only the description scrollable |

---

## Scrolling just the description

`Modifier.verticalScroll(...)` is applied to a single `Text`, not to the `Column`. The result:

```text
┌──────────────────────────────┐
│  Beef                        │  ← stays visible
│  ┌────────────────────────┐  │
│  │      image             │  │  ← stays visible
│  └────────────────────────┘  │
│  Beef is a type of meat …    │  ← scrolls inside its own box
│  … more text …               │
└──────────────────────────────┘
```

`rememberScrollState()` is state because the UI has to remember the scroll position across
recompositions — the same reason text input uses `remember`.

---

## Text alignment options

| Value | Effect |
| :--- | :--- |
| `TextAlign.Center` | Centres each line; used for the title |
| `TextAlign.Justify` | Stretches soft-broken lines to fill the width; used for the description |
| `TextAlign.Start` / `End` | Aligns to the reading start or end edge |

Worth experimenting with: the right choice depends on how much text and how wide the container is.

---

## Recap / cheat sheet

- Give the detail screen the model it needs: `CategoryDetailScreen(category: Category)`.
- Coil's `rememberAsyncImagePainter` (or `AsyncImage`) loads remote thumbnails from a URL.
- Always provide a meaningful `contentDescription` for accessibility.
- `Modifier.verticalScroll(rememberScrollState())` scrolls one child instead of the whole screen.
- `TextAlign.Justify` produces an even, newspaper-style text block.
