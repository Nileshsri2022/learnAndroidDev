## What was covered

* **Interfaces** — a class can implement several of them, learning skills from more than one source
* **`override`** — replacing an inherited function in a child class
* **`super`** — still executing the parent's version of that function
* **Inheritance** — `open class`, `class Child : Parent()`, and the fact that a child can call
  functions it never declared itself

Several things you had already *seen* in `MainActivity` now finally make sense — for example why
`onCreate` can be overridden and why `super.onCreate` is called.

* **ViewModels** — and how to restructure an app to comply with them
* **Models and repositories** — the data layer and the clean API in front of it
