# Functions That Didn't Exist and Could Be Called — Inheritance

---

## The story

In the noble house of **Base Class** there are ancestral traits and traditions. Over time the
younger generations — the **subclasses** — inherited those traits but also added their own
characteristics.

* **Lady Primary**, the matriarch, owns the **House of Base Class**.
* Her two children: **Sir Secondary** (great at archery) and **Lady Tertiary** (a melodious voice).

Both inherit the core values of the house. Each brings their own flair on top.

---

## The code

New project → **No Activity** → `InheritanceApp`. Pure Kotlin, no UI.

**`Start.kt`** — the entry point:

```kotlin
fun main() {
    // ...
}
```

**`BaseClass.kt`** — the parent:

```kotlin
open class BaseClass {

    fun coreValues() {
        println("Core values of House Base Class")
    }
}
```

**`Secondary.kt`** — the child:

```kotlin
class Secondary : BaseClass()
```

---

## The `open` keyword

A class cannot inherit from just anything. It must be **`open`**:

```kotlin
open class BaseClass      // ✅ can be inherited from
class BaseClass           // ❌ cannot
```

Without `open`, `class Secondary : BaseClass()` is a compile error. Kotlin makes classes *closed*
by default so nobody can extend your class without you allowing it.

The syntax is: **colon + class name + parentheses**.

---

## The magic: a function that "didn't exist"

```kotlin
fun main() {
    val objectOne = BaseClass()
    objectOne.coreValues()        // Core values of House Base Class

    val objectTwo = Secondary()
    objectTwo.coreValues()        // Core values of House Base Class  ← ?!
}
```

`Secondary` is **empty**. It has no functions. Yet `coreValues()` can be called on it — and it
prints the Base Class message.

That is inheritance: `Secondary` did not *copy* the function, it *is* a `BaseClass`, so it has
everything `BaseClass` has. Every function and property created in the parent now also exists in
the child.

You get the output twice:

```
Core values of House Base Class
Core values of House Base Class
```

First from `objectOne` (a real `BaseClass`), second from `objectTwo` (a `Secondary` acting as one).

## Where you have already seen this

```kotlin
class MainActivity : ComponentActivity() {
```

`MainActivity` inherits from `ComponentActivity`. That is why it can `override fun onCreate` and
call `super.onCreate` — it *is* a `ComponentActivity`, so it already has all of that machinery.

---

## Takeaway

| Keyword | Meaning |
| :--- | :--- |
| `open class X` | X may be inherited from |
| `class Y : X()` | Y inherits everything X has |
| (nothing else) | Y can already call X's functions and read X's properties |
