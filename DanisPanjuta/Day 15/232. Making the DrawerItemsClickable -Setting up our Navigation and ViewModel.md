# Making the DrawerItemsClickable -Setting up our Navigation and ViewModel

---

## Overview

The drawer is visible but not yet navigable. This lecture makes each `DrawerItem` **clickable**, closes the drawer, updates the `ViewModel`'s title, and navigates via `NavHost`.

---

## Step 1 — DrawerItem row

`DrawerItem.kt` composable:

```kotlin
@Composable
fun DrawerContent(items: List<DrawerItem>, onItemClick: (DrawerItem) -> Unit) {
    Column {
        DrawerHeader() // e.g. Box with app logo
        items.forEach { item ->
            Row(
                modifier = Modifier
                    .fillMaxWidth()
                    .clickable { onItemClick(item) }
                    .padding(16.dp)
            ) {
                Icon(painter = painterResource(id = item.icon), contentDescription = null)
                Spacer(Modifier.width(16.dp))
                Text(text = item.title)
            }
        }
    }
}
```

---

## Step 2 — ViewModel title

`MainViewModel.kt` (or `MusicViewModel`):

```kotlin
class MainViewModel : ViewModel() {
    var title by mutableStateOf("Home")
        private set

    fun setTitle(newTitle: String) { title = newTitle }
}
```

| Member | Role |
| :--- | :--- |
| `title` `by mutableStateOf("Home")` | Observed by `TopAppBar` — recomposes on change |
| `setTitle` | Called from drawer click before `navigate` |

---

## Step 3 — Navigation

`Navigation.kt`:

```kotlin
NavHost(navController, startDestination = "home") {
    composable("home") { HomeView(...) }
    composable("add_account") { AccountView(viewModel) }
    composable("subscription") { SubscriptionView(viewModel) }
}
```

Drawer `onItemClick`:

```kotlin
DrawerContent(drawerItems) { item ->
    scope.launch { drawerState.close() }
    viewModel.setTitle(item.title)
    navController.navigate(item.route)
}
```

Now selecting **Subscription** closes the drawer, sets `TopAppBar` to *Subscription*, and shows `SubscriptionView`.

---

## Recap / cheat sheet

- **Row:** `Row(clickable{ onItemClick(item) }) { Icon(painterResource)+Text }`.
- **Title:** `viewModel.title by mutableStateOf` → `setTitle` on click.
- **Nav:** `navController.navigate(item.route)` after `drawerState.close()`.
