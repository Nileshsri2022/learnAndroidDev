# Subscription View

---

## Overview

`SubscriptionView` is the second drawer destination — a placeholder for subscription management. Structurally identical to `AccountView` but with a `Card` layout that demonstrates a subscription tier (Free/Premium) and a **progress indicator**.

---

## The screen

`SubscriptionView.kt`:

```kotlin
@Composable
fun SubscriptionView() {
    Column(Modifier.fillMaxSize().padding(16.dp)) {
        Card(Modifier.fillMaxWidth(), elevation = 4.dp) {
            Column(Modifier.padding(16.dp)) {
                Text("My Music", style = MaterialTheme.typography.h6)
                Spacer(Modifier.height(8.dp))
                Text("Subscription: Premium")
                LinearProgressIndicator(modifier = Modifier.fillMaxWidth())
                Spacer(Modifier.height(8.dp))
                Text("Renewal: Dec 2025")
            }
        }
    }
}
```

| Element | Role |
| :--- | :--- |
| `Card` | Elevated container |
| `LinearProgressIndicator` | Demo of subscription progress (30 days left, etc.) |
| Static text | Placeholder — later could be driven by `ViewModel` subscription `State` |

Navigation: `drawer → Subscription` → `SubscriptionView` with `viewModel.title = "Subscription"` set before `navigate`.

---

## Recap / cheat sheet

- **SubscriptionView:** `Column → Card → Text + LinearProgressIndicator`.
- **Drawer:** `SubscriptionView` is a `composable("subscription")` in `NavHost`.
