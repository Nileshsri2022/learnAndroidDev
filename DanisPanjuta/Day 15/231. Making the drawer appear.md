# Making the drawer appear

---

## Overview

With `TopAppBar` and `DrawerItem`s ready, this lecture makes the drawer actually **slide** by wrapping the `Scaffold` in a `ModalDrawer`/`ModalNavigationDrawer` and opening it from the hamburger click via `DrawerState` and a `CoroutineScope`.

---

## Step 1 — state

`HomeView`:

```kotlin
val drawerState = rememberDrawerState(DrawerValue.Closed)
val scope = rememberCoroutineScope()
```

| State | Factory | Role |
| :--- | :--- |
| `drawerState` | `rememberDrawerState(Closed)` | Holds `isOpen`, `isClosed`, `open()`, `close()` are `suspend` |
| `scope` | `rememberCoroutineScope()` | `launch` the suspend `open()`/`close()` |

---

## Step 2 — drawer

```kotlin
ModalDrawer(
    drawerState = drawerState,
    drawerContent = {
        Column {
            // optional Drawer header (Box with logo)
            DrawerContent(drawerItems) { item ->
                scope.launch { drawerState.close() }
                navController.navigate(item.route)
                viewModel.title = item.title
            }
        }
    }
) {
    Scaffold(
        topBar = { TopAppBar(title = viewModel.title) { scope.launch { drawerState.open() } } }
    ) { padding -> /* NavHost content */ }
}
```

| Slot | Composable | Notes |
| :--- | :--- | :--- |
| `drawerState` | `DrawerState` | Drives open/closed animation |
| `drawerContent` | `Column` + `DrawerItem` rows | Each `Icon(painterResource) + Text` |
| `open()`/`close()` | `suspend` | Must be called from `scope.launch` |

> In M3 the equivalent is `ModalNavigationDrawer(drawerState, drawerContent={ ModalDrawerSheet{ ... } })` — shift is mechanical; the `scope.launch` pattern remains.

---

## Recap / cheat sheet

- **State:** `rememberDrawerState(Closed)` + `rememberCoroutineScope()`.
- **Open:** `IconButton { scope.launch { drawerState.open() } }`.
- **Close:** `scope.launch { drawerState.close() }` before `navigate`.
- **Content:** `ModalDrawer(drawerState, drawerContent={ DrawerContent }) { Scaffold(...) }`.
