# AccountView

---

## Overview

`AccountView` is a destination reached from the drawer (`Add Account` row). It shows the created accounts and exposes the **Add** button that opens `AddAccountDialog`. The lecture builds its `Scaffold`-less content and wires it to a simple list in the `ViewModel`.

---

## The screen

`AccountView.kt`:

```kotlin
@Composable
fun AccountView(viewModel: MainViewModel) {
    val accounts = viewModel.accounts // State<List<String>> or Flow

    Column(Modifier.fillMaxSize().padding(16.dp)) {
        Text("Accounts", style = MaterialTheme.typography.h5)
        Spacer(Modifier.height(16.dp))

        LazyColumn {
            items(accounts) { account ->
                Card(Modifier.fillMaxWidth().padding(4.dp), elevation=4.dp) {
                    Text(account, Modifier.padding(16.dp))
                }
            }
        }

        var showDialog by remember { mutableStateOf(false) }
        Button(onClick = { showDialog = true }) { Text("Add Account") }

        if (showDialog) AddAccountDialog(
            onDismiss = { showDialog = false },
            onAdd = { viewModel.addAccount(it); showDialog = false }
        )
    }
}
```

| Piece | Role |
| :--- | :--- |
| `LazyColumn` | Renders `accounts` |
| `Button Add Account` | Opens the dialog |
| `AddAccountDialog` | Returns a `String` → `viewModel.addAccount` |

`MainViewModel` holds `accounts by mutableStateOf(listOf<String>())` and `fun addAccount(name: String){ accounts = accounts + name }`.

---

## Recap / cheat sheet

- **AccountView:** `Column → Text + LazyColumn(accounts) + Button Add Account + AddAccountDialog`.
- **ViewModel:** `accounts` as `mutableStateOf(list)` + `addAccount`.
