# Adding Resource Icons and Prepping our DrawerItem for the Drawer

---

## Overview

A drawer shows a list of entries, each with an **icon + title + route**. This lecture adds **drawable resources** for those icons and models each row as `DrawerItem`.

---

## Step 1 — drawables

Download icons (via *File → New → Vector Asset* or downloaded drawables) into `res/drawable`:

| Drawable | Drawer entry |
| :--- | :--- |
| `ic_account.xml` | Add Account |
| `ic_subscription.xml` | Subscription |
| `ic_add_account.xml` | Add Account (alt) |

Alternatively use `Icons.Default.AccountBox`, `Subscriptions`, etc., but the course uses **resource IDs** to demonstrate `painterResource`.

---

## Step 2 — DrawerItem model

`DrawerItem.kt`:

```kotlin
data class DrawerItem(
    val id: String,
    val title: String,
    @DrawableRes val icon: Int,
    val route: String
)

val drawerItems = listOf(
    DrawerItem("1", "Add Account", R.drawable.ic_add_account, "add_account"),
    DrawerItem("2", "Subscription", R.drawable.ic_subscription, "subscription"),
    DrawerItem("3", "Add Account (Music)", R.drawable.ic_account, "add_account_music")
)
```

| Field | Type | Role |
| :--- | :--- | :--- |
| `id` | `String` | Stable key for `LazyColumn` |
| `title` | `String` | Drawer row label |
| `icon` | `@DrawableRes Int` | `painterResource(icon)` |
| `route` | `String` | `navController.navigate(route)` |

> Annotate `icon` with `@DrawableRes` so lint warns if a non-drawable int is passed.

---

## Recap / cheat sheet

- **Icons:** add vector drawables to `res/drawable` or use `Icons.Default.*`.
- **Model:** `data class DrawerItem(id, title, @DrawableRes icon, route)`.
- **List:** `val drawerItems = listOf(DrawerItem(...))`.
