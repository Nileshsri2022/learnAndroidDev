# Add Account Dialog

---

## Overview

The **Add Account** entry should open a modal dialog to create a new account, not a full screen. This lecture builds `AccountDialog` as an `AlertDialog` with a `TextField`, **Add**/**Dismiss** buttons, and a callback that feeds the entered string back to the caller.

---

## The composable

`AccountDialog.kt`:

```kotlin
@Composable
fun AddAccountDialog(
    onDismiss: () -> Unit,
    onAdd: (String) -> Unit
) {
    var accountName by remember { mutableStateOf("") }

    AlertDialog(
        onDismissRequest = onDismiss,
        title = { Text("Add Account") },
        text = {
            Column {
                OutlinedTextField(
                    value = accountName,
                    onValueChange = { accountName = it },
                    label = { Text("Account name") },
                    modifier = Modifier.fillMaxWidth()
                )
            }
        },
        confirmButton = {
            TextButton(onClick = {
                if (accountName.isNotEmpty()) onAdd(accountName)
                onDismiss()
            }) { Text("Add") }
        },
        dismissButton = {
            TextButton(onClick = { onDismiss() }) { Text("Dismiss") }
        }
    )
}
```

| Part | Role |
| :--- | :--- |
| `AlertDialog(onDismissRequest)` | Modal that dims the scrim and captures back press |
| `OutlinedTextField` | Single-line input for the new account name |
| `confirmButton` (`Add`) | Validates non-empty, calls `onAdd(accountName)`, then `onDismiss()` |
| `dismissButton` | Plain `onDismiss()` |
| `onAdd: (String) -> Unit` | Hoisted — caller adds to list/database |

Shown from the drawer or `HomeView` via:

```kotlin
var showAddAccountDialog by remember { mutableStateOf(false) }
if (showAddAccountDialog) AddAccountDialog(onDismiss={showAddAccountDialog=false}, onAdd={ /* save */ })
```

---

## Recap / cheat sheet

- **Dialog:** `AlertDialog(title={Text}, text={OutlinedTextField}, confirmButton={TextButton Add}, dismissButton={TextButton Dismiss})`.
- **State:** `accountName by remember{mutableStateOf("")}` inside the dialog.
- **Hoist:** `onAdd:(String)->Unit` + `onDismiss:()->Unit`.
