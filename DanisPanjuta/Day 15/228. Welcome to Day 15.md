# Welcome to Day 15

---

## Overview

Day 15 starts the **Music App** — a Spotify-like shell that practices large-scale **Material scaffold** patterns: `TopAppBar`, `Drawer` (modal navigation drawer), `ViewModel` for title and drawer state, and dialogs. It is the penultimate Compose project before the Firebase chat app.

No data source yet — focus is purely on **navigation, scaffolding, and drawer mechanics**.

---

## What the app will look like

| Component | Behaviour |
| :--- | :--- |
| `TopAppBar` | Shows current screen title, `NavigationIcon` (hamburger) opens drawer |
| `ModalDrawer` / `ModalNavigationDrawer` | Slides from start edge, lists `DrawerItem`s (*Add Account*, *Subscription*, etc.) |
| `AccountDialog` | `AlertDialog` for new account creation |
| `AccountView`, `SubscriptionView` | Two additional destinations reached via drawer navigation |
| `ViewModel` (`MainViewModel`/`MusicViewModel`) | Holds `currentScreen`, `drawerShouldBeOpened` |

---

## Day 15 roadmap

1. Add `TopAppBar` with title and `onNavigationIconClick`.
2. Create `DrawerItem` model + add resource icons (drawables).
3. Make the drawer appear (`ModalDrawer`/`DrawerState` + `rememberDrawerState`, `rememberCoroutineScope`).
4. Make drawer items clickable — hoist `onDrawerItemSelected` → navigation + ViewModel title update.
5. `Add Account Dialog` (`AlertDialog` with `TextField`).
6. Build `AccountView` and `SubscriptionView` composables.

---

## Recap / cheat sheet

- **Music App** = scaffold exercise before Firebase.
- **Drawer** = `ModalDrawer` + `DrawerState` + `ViewModel` + `Scaffold`.
- **Navigation** = drawer items drive `NavHost` destinations; `ViewModel` keeps the `TopAppBar` title in sync.
