# Summary of Day 15

---

The course's **Summary of Day 15** lecture has no transcript. This recap consolidates the Music App drawer phase.

---

## Theme

Build the **navigation shell** of a music app: a `Scaffold` with `TopAppBar` + `ModalDrawer` that navigates to `AccountView` and `SubscriptionView` and captures new accounts via an `AlertDialog`.

---

## Architectural flow

```text
MainActivity → Navigation()
      ├── NavHost("home")
      │     ├── composable("home") → HomeView(Scaffold(TopAppBar, ModalDrawer) → LazyColumn)
      │     ├── composable("add_account") → AccountView(LazyColumn + AddAccountDialog)
      │     └── composable("subscription") → SubscriptionView(Card)
      └── MainViewModel(title by mutableStateOf, accounts: List<String>)
            └── DrawerItem(id, title, @DrawableRes icon, route) + drawerItems

ModalDrawer(drawerState=rememberDrawerState, drawerContent=DrawerContent)
      └── IconButton(Menu) → scope.launch{ drawerState.open() }
          DrawerItem click → scope.launch{ drawerState.close() } → viewModel.title=item.title → navController.navigate(route)
```

## Complete reference (drawer portion)

### Screen
```kotlin
sealed class Screen(val route:String){ object Home:Screen("home"); object Account:Screen("add_account"); object Subscription:Screen("subscription") }
```

### ViewModel
```kotlin
class MainViewModel: ViewModel(){ var title by mutableStateOf("Home"); fun setTitle(t:String){title=t} }
```

### Drawer
```kotlin
data class DrawerItem(val id:String, val title:String, @DrawableRes val icon:Int, val route:String)
val drawerState = rememberDrawerState(DrawerValue.Closed)
val scope = rememberCoroutineScope()
ModalDrawer(drawerState, drawerContent={ DrawerContent(drawerItems){ scope.launch{drawerState.close()}; viewModel.setTitle(it.title); navController.navigate(it.route) } }){
    Scaffold(topBar={ TopAppBar(title=viewModel.title){ scope.launch{drawerState.open()} } }){ /* NavHost */ }
}
```
