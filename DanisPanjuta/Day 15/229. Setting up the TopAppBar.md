# Setting up the TopAppBar

---

## Overview

The first visual is the **TopAppBar**. It shows the current screen title and a **hamburger `NavigationIcon`** that will open the drawer. This lecture extracts it into `TopAppBar.kt`.

---

## Step 1 — create the composable

`TopAppBar.kt`:

```kotlin
@Composable
fun TopAppBar(
    title: String,
    onNavigationIconClick: () -> Unit
) {
    androidx.compose.material.TopAppBar(
        title = { Text(title) },
        backgroundColor = Color.White,
        navigationIcon = {
            IconButton(onClick = { onNavigationIconClick() }) {
                Icon(Icons.Filled.Menu, contentDescription = "Drawer")
            }
        }
    )
}
```

| Param | Role |
| :--- | :--- |
| `title` | From `viewModel.title` — *Home*, *Account*, *Subscription* |
| `onNavigationIconClick` | Hoisted — `HomeView`'s drawer should open, not the bar itself |
| `Icons.Filled.Menu` | Hamburger; import `material.icons.filled.Menu` |
| `backgroundColor = White` | Matches the Wishlist's monochrome bar theme |

Called in `HomeView`'s `Scaffold(topBar = { TopAppBar(title, { scope.launch{ drawerState.open() } }) })`.

---

## Recap / cheat sheet

- **TopAppBar:** `TopAppBar(title={Text(title)}, navigationIcon={IconButton{Icon(Menu)}})`.
- **Hoist:** `onNavigationIconClick: () -> Unit`.
