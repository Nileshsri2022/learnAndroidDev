# Adding A NavigationIcon to our AppBar

---

## Overview

A top bar without a back arrow cannot navigate. This lecture adds `Icons.Filled.ArrowBack` as the `navigationIcon` of `TopAppBar`, wrapped in an `IconButton` that calls the hoisted `onBackNavClicked`.

---

## The code

Inside `AppBarView`, add to `TopAppBar`:

```kotlin
TopAppBar(
    title = { Text(title, color = colorResource(id = R.color.white)) },
    backgroundColor = colorResource(id = R.color.app_bar_color),
    navigationIcon = {
        IconButton(onClick = { onBackNavClicked() }) {
            Icon(
                imageVector = Icons.Filled.ArrowBack,
                contentDescription = null,
                tint = Color.White
            )
        }
    }
)
```

| Property | Value | Meaning |
| :--- | :--- | :--- |
| `navigationIcon` | `@Composable () -> Unit` | Composable slot on the left of the bar |
| `IconButton` | `onClick = { onBackNavClicked() }` | Clickable wrapper — required for ripple + accessibility |
| `Icons.Filled.ArrowBack` | Material filled icon | The canonical *Up* arrow |
| `contentDescription = null` | Decorative when paired with visible title; real app would be `"Back"` |

Import: `androidx.compose.material.icons.filled.ArrowBack` (or `androidx.compose.material.icons.Icons` + `Filled`).

---

## Behaviour at this point

The icon appears on **every** screen, including `HomeView`, where it should not. The next lecture makes it **conditional** — only on the add/edit screen — by checking the current navigation route.

---

## Recap / cheat sheet

- **Slot:** `TopAppBar(navigationIcon = { IconButton { Icon(ArrowBack) } })`.
- **Hoist:** `onClick = { onBackNavClicked() }` — bar does not own `NavController`.
- **Icon:** `Icons.Filled.ArrowBack`, tint `Color.White` on teal bar.
