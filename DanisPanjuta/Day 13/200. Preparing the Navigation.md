# Preparing the Navigation

---

## Overview

Day 10 introduced navigation with two screens; this lecture applies the same **sealed-class routes** + `NavHost` + `rememberNavController` pattern to the Wishlist, wiring `HomeView` and the still-empty `AddEditDetailView`.

---

## Step 1 — routes

`Screen.kt`:

```kotlin
sealed class Screen(val route: String) {
    object HomeScreen : Screen("home_screen")
    object AddScreen : Screen("add_screen")
}
```

Routes are bare strings (`"home_screen"`, `"add_screen"`) plus an `id` argument for the detail screen.

---

## Step 2 — Navigation composable

`Navigation.kt`:

```kotlin
@Composable
fun Navigation(
    viewModel: WishViewModel = viewModel(),
    navController: NavHostController = rememberNavController()
) {
    NavHost(navController = navController, startDestination = Screen.HomeScreen.route) {
        composable(Screen.HomeScreen.route) {
            HomeView(navController = navController, viewModel = viewModel)
        }
        composable(
            Screen.AddScreen.route + "/{id}",
            arguments = listOf(navArgument("id") {
                type = NavType.LongType
                defaultValue = 0L
                nullable = false
            })
        ) { entry ->
            val id = if (entry.arguments != null) entry.arguments!!.getLong("id") else 0L
            AddEditDetailView(id = id, viewModel = viewModel, navController = navController)
        }
    }
}
```

| Piece | Role |
| :--- | :--- |
| `rememberNavController()` | Owns the back stack |
| `NavHost(startDestination = HomeScreen)` | Graph container |
| `composable(HomeScreen)` | Renders `HomeView` |
| `composable(AddScreen/{id}, navArgument("id"))` | Parses `id: Long`; `0L` = add, `>0` = edit |
| `entry.arguments!!.getLong("id")` | Extracts the passed id |

Wire it in `MainActivity`:

```kotlin
setContent { WishlistAppTheme { Surface(...) { Navigation() } } }
```

---

## At this point

- `HomeView` renders the dummy list.
- Tapping a `WishItem` or the **FAB** navigates to `AddEditDetailView` (blank for now).
- Back press returns to the list (system back; the bar's `navigateUp` is next).

---

## Recap / cheat sheet

- **Screen:** `sealed class Screen(route)` → `HomeScreen`, `AddScreen`.
- **Graph:** `NavHost → composable(HomeScreen) + composable(AddScreen/{id}, navArgument("id", LongType, 0L))`.
- **Nav:** `navController.navigate(Screen.AddScreen.route + "/${wish.id}")`; `navigateUp()` to return.
- **MainActivity:** hosts only `Navigation()`.
