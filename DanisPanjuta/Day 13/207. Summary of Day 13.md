## Theme

Assemble a two-screen list app whose structure will be persisted tomorrow: a `Scaffold` with conditional `TopAppBar` + `FloatingActionButton`, a `LazyColumn` of `WishItem` cards, and a `NavHost` that navigates between `HomeView` (list) and `AddEditDetailView` (form).

---

## Architectural flow

```text
MainActivity.setContent → Navigation()
      ├── NavHost(start = HomeScreen)
      │     ├── composable(HomeScreen) → HomeView(navController, viewModel)
      │     │        ├── Scaffold
      │     │        │     ├── TopAppBar(AppBarView, showBackIcon=false)
      │     │        │     ├── FloatingActionButton(+): navigate(AddScreen/0L)
      │     │        │     └── LazyColumn → WishItem(DummyWish) → navigate(AddScreen/id)
      │     │        └── AppBarView, FAB, DummyWish
      │     └── composable(AddScreen/{id}) → AddEditDetailView(id, viewModel, navController)
      │              ├── Scaffold(TopAppBar, showBackIcon=true, onBackNavClicked=navigateUp)
      │              ├── WishTextField (×2) → WishViewModel state
      │              └── Button: addWish/updateWish → navigateUp
      └── WishViewModel → Flow<List<Wish>> (dummy today, Room tomorrow)
```

## Complete reference implementation (in-memory portion)

### 1. `Wish.kt`
```kotlin
data class Wish(val id: Long = 0L, val title: String = "", val description: String = "")
object DummyWish { val wishlist = listOf(Wish(...), ...) }
```

### 2. `WishItem.kt`
```kotlin
@Composable fun WishItem(wish: Wish, onClick: () -> Unit) {
    Card(Modifier.fillMaxWidth().padding(8.dp).clickable{onClick()}, elevation=10.dp, backgroundColor=Color.White){
        Column(Modifier.padding(16.dp)){
            Text(wish.title, fontWeight=ExtraBold)
            Text(wish.description)
        }
    }
}
```

### 3. `AppBarView.kt`
```kotlin
@Composable fun AppBarView(title: String, showBackIcon: Boolean=true, onBackNavClicked:()->Unit={}) {
    TopAppBar(title={Text(title,color=colorResource(R.color.white))},
              backgroundColor=colorResource(R.color.app_bar_color),
              navigationIcon={
                  if(showBackIcon) IconButton({onBackNavClicked()}){
                      Icon(Icons.Filled.ArrowBack,null,tint=Color.White)
                  }
              })
}
```

### 4. `Screen.kt` + `Navigation.kt`
```kotlin
sealed class Screen(val route:String){ object HomeScreen:Screen("home_screen"); object AddScreen:Screen("add_screen") }
@Composable fun Navigation(viewModel:WishViewModel=viewModel(), navController:NavHostController=rememberNavController()){
    NavHost(navController, startDestination=Screen.HomeScreen.route){
        composable(Screen.HomeScreen.route){ HomeView(navController, viewModel) }
        composable(Screen.AddScreen.route+"/{id}", arguments=listOf(navArgument("id"){type=NavType.LongType;defaultValue=0L})){
            AddEditDetailView(id=it.arguments?.getLong("id")?:0L, viewModel=viewModel, navController=navController)
        }
    }
}
```
