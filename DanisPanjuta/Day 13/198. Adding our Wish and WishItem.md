# Adding our Wish and WishItem

---

## Overview

Before any database exists, the list needs a model (`Wish`) and a row (`WishItem`). `Wish` is a `data class` with `id`, `title`, `description`; `WishItem` is a `Card`/`Column` that renders a `Wish` and exposes `onClick`.

---

## Step 1 — the model

`Wish.kt`:

```kotlin
data class Wish(
    val id: Long = 0L,
    val title: String = "",
    val description: String = ""
)
```

| Field | Type | Default | Meaning |
| :--- | :--- | :--- | :--- |
| `id` | `Long` | `0L` | Primary key, auto-generated by Room later |
| `title` | `String` | `""` | Wish headline |
| `description` | `String` | `""` | Details |

Tomorrow adds `@Entity(tableName = "wishlist")`, `@PrimaryKey(autoGenerate = true)`, `@ColumnInfo`.

---

## Step 2 — the row

`WishItem.kt`:

```kotlin
@Composable
fun WishItem(wish: Wish, onClick: () -> Unit) {
    Card(
        modifier = Modifier
            .fillMaxWidth()
            .padding(top = 8.dp, start = 8.dp, end = 8.dp)
            .clickable { onClick() },
        elevation = 10.dp,
        backgroundColor = Color.White
    ) {
        Column(modifier = Modifier.padding(16.dp)) {
            Text(text = wish.title, fontWeight = FontWeight.ExtraBold)
            Text(text = wish.description)
        }
    }
}
```

| Element | Modifier/Prop | Role |
| :--- | :--- | :--- |
| `Card` | `fillMaxWidth()`, `elevation=10.dp` | Elevated container with shadow |
| `clickable { onClick() }` | On the `Card` modifier | Tapping the row opens `AddEditDetailView` with that `id` |
| `Column` | `padding(16.dp)` | Stacks title (bold) above description |

---

## Recap / cheat sheet

- **Model:** `data class Wish(id: Long=0L, title: String="", description: String="")`.
- **Row:** `Card(clickable) → Column → Text(title, ExtraBold) + Text(description)`.
- **Click:** hoisted `onClick: () -> Unit` → `navController.navigate(AddScreen/${wish.id})`.
