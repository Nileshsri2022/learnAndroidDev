# Displaying Dummy Data

---

## Overview

No database yet — but the `LazyColumn` can still be proven with **hard-coded wishes**. This lecture creates a `DummyWish` object that holds a `List<Wish>` and renders it to confirm layout, colors, and click handling before any `Flow` or `Dao` is involved.

---

## Step 1 — dummy source

`DummyWish.kt`:

```kotlin
object DummyWish {
    val wishlist = listOf(
        Wish(title = "Google Watch 2", description = "An Android Watch"),
        Wish(title = "Oculus Quest 2", description = "A VR headset for playing games"),
        Wish(title = "A Sci-fi Book", description = "A science fiction novel by Isaac Asimov"),
        Wish(title = "Bean bag", description = "A comfy bean bag to substitute for a chair"),
        Wish(title = "New keyboard", description = "Mechanical, 65%"),
        Wish(title = "100K job", description = "Getting a job that pays >100K/year")
    )
}
```

`object` gives a singleton — accessible as `DummyWish.wishlist` without instantiation.

---

## Step 2 — render in HomeView

```kotlin
@Composable
fun HomeView(navController: NavController, viewModel: WishViewModel) {
    Scaffold(...) { paddingValues ->
        LazyColumn(modifier = Modifier
            .fillMaxSize()
            .padding(paddingValues)
            .background(Color.LightGray)) {

            items(DummyWish.wishlist, key = { wish -> wish.id }) { wish ->
                WishItem(wish = wish) {
                    navController.navigate(Screen.AddScreen.route + "/${wish.id}")
                }
            }
        }
    }
}
```

| Piece | Why |
| :--- | :--- |
| `items(list, key = { wish.id })` | Stable keys prevent swipe/delete glitches later |
| `DummyWish.wishlist` | In-memory source, replaced tomorrow by `wishViewModel.getAllWishes` `Flow` |
| `navController.navigate(.../${wish.id})` | Passes the tapped wish's id to the detail screen (edit mode) |

---

## Verification

Run the app: six cards appear, each with bold title and description, tappable. The teal `TopAppBar` and black **FAB** hover above the light-gray `LazyColumn`. The list proves the `Scaffold` + `Card` + `LazyColumn` stack works before any Room code is added.

## Recap / cheat sheet

- **DummyWish:** `object DummyWish { val wishlist = listOf(Wish(...)) }`.
- **HomeView:** `LazyColumn { items(DummyWish.wishlist, key={id}) { WishItem(it) } }`.
- **Tomorrow:** replace `DummyWish.wishlist` with `viewModel.getAllWishes.collectAsState(initial = emptyList()).value`.
