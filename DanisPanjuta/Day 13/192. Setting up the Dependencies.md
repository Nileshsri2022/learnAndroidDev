# Setting up the Dependencies

---

## Overview

All libraries needed for the next two days are added at once: **Navigation Compose**, **Room**, and the **Kotlin KAPT** plugin that Room's annotation processor requires.

---

## Step 1 — create the project

In Android Studio: **New Project → Empty Activity → Name: *My Wishlist App* → Finish**.

Choose **Empty Activity (Jetpack Compose)**, not *Basic Views Activity* (which generates XML) — the course builds the scaffold from scratch so its parts are understood.

Wait for the initial Gradle sync to finish.

---

## Step 2 — add the dependency versions

At the top of `app/build.gradle.kts` (outside `dependencies`), define version variables (lecture uses these exact values):

```kotlin
plugins {
    id("com.android.application")
    id("org.jetbrains.kotlin.android")
    id("kotlin-kapt") // ← required for Room
}

ext {
    set("navVersion", "2.7.5")
    set("composeVersion", "1.6.0-alpha08")
    set("roomVersion", "2.6.0")
}
```

> In newer templates the versions may be declared as `val navVersion = "2.7.5"` inside a `buildscript` or `gradle/libs.versions.toml`. The effect is the same — centralize version numbers.

Then inside `dependencies`:

```kotlin
dependencies {
    implementation("androidx.core:core-ktx:1.12.0")
    implementation("androidx.compose.ui:ui:${project.properties["composeVersion"]}")
    implementation("androidx.compose.material3:material3")
    implementation("androidx.lifecycle:lifecycle-viewmodel-compose:2.7.0")

    // Navigation
    implementation("androidx.navigation:navigation-compose:${project.properties["navVersion"]}")

    // Room
    implementation("androidx.room:room-runtime:${project.properties["roomVersion"]}")
    implementation("androidx.room:room-ktx:${project.properties["roomVersion"]}") // coroutines + Flow
    kapt("androidx.room:room-compiler:${project.properties["roomVersion"]}")

    // Alternative without version vars:
    // implementation("androidx.navigation:navigation-compose:2.7.5")
    // implementation("androidx.room:room-runtime:2.6.0")
}
```

| Artifact | Role |
| :--- | :--- |
| `navigation-compose` | `NavHost`, `composable`, `rememberNavController` |
| `room-runtime` + `room-ktx` | `@Entity`, `@Dao`, `@Database`, `Flow` |
| `room-compiler` (`kapt`) | Generates the `WishDatabase_Impl` at compile time |
| `kotlin-kapt` plugin | Enables the `kapt` configuration |

---

## Step 3 — why KAPT?

Room is annotation-processed: `@Entity`, `@Dao`, `@Database` are read by the compiler to generate `_Impl` classes. Without `id("kotlin-kapt")` the build fails with *"kapt not found"* or *"unresolved reference: room-compiler"*.

Sync now: **Sync Now** banner → errors disappear, `WishDatabase_Impl` becomes generatable.

---

## Step 4 — sync and verify

After **Sync Now** succeeds:

- `import androidx.room.Entity` resolves.
- `import androidx.navigation.compose.NavHost` resolves.
- `WishDatabase` (next day) will compile.

If `core-ktx` already exists with a newer version, keep the newer one — do not downgrade.

---

## Recap / cheat sheet

- **Plugin:** `id("kotlin-kapt")` at top.
- **Vars:** `navVersion=2.7.5`, `composeVersion=1.6.0-alpha`, `roomVersion=2.6.0`.
- **Deps:** `navigation-compose`, `room-runtime` + `room-ktx`, `kapt room-compiler`.
- **Sync Now** — KAPT errors vanish only after sync.
