# HomeView and Scaffold

---

## Overview

`Scaffold` is the Material **skeleton** that gives an app its canonical structure: a top bar, a content area, a floating action button, an optional bottom bar, and a `SnackbarHost`. This lecture creates `HomeView` around `Scaffold` and extracts the top bar into a reusable `AppBarView`.

---

## Step 1 — create `HomeView`

New file: `HomeView.kt`

```kotlin
@Composable
fun HomeView() {
    Scaffold(
        topBar = { AppBarView(title = "Wishlist") },
        floatingActionButton = { /* FAB next video */ }
    ) { paddingValues ->
        // LazyColumn with wishes + dummy data
        LazyColumn(modifier = Modifier.padding(paddingValues)) { }
    }
}
```

| Slot | Composable | Purpose |
| :--- | :--- | :--- |
| `topBar` | `AppBarView` | Title + back icon |
| `floatingActionButton` | `FloatingActionButton` | Add new wish |
| `content` (`{ padding -> }`) | `LazyColumn` | The list itself; `padding` prevents overlap with top bar |

`Scaffold` already handles `scaffoldState` and `backgroundColor` internally in M3, but the lecture uses the older `scaffoldState = rememberScaffoldState()` variant — functionally identical.

---

## Step 2 — extract `AppBarView`

New file: `AppBarView.kt`

```kotlin
@Composable
fun AppBarView(
    title: String,
    onBackNavClicked: () -> Unit = {}
) {
    TopAppBar(
        title = {
            Text(
                text = title,
                color = colorResource(id = R.color.white),
                modifier = Modifier.padding(start = 4.dp),
                fontWeight = FontWeight.Bold
            )
        },
        backgroundColor = colorResource(id = R.color.app_bar_color),
        elevation = 3.dp,
        navigationIcon = { /* added next */ }
    )
}
```

| Parameter | Type | Default | Role |
| :--- | :--- | :--- | :--- |
| `title` | `String` | — | What the bar displays (*Wishlist*, *Add a Wish*) |
| `onBackNavClicked` | `() -> Unit` | `{}` | Hoisted callback — the bar does not navigate itself, it calls the lambda |

> Colors come from `res/values/colors.xml` (`#FFFFFF`, `#018786`). The lecture uses `colorResource(id = R.color.white)` rather than `Color.White` to show resource-driven theming.

Call site in `MainActivity`:

```kotlin
setContent { WishlistAppTheme { HomeView() } }
```

The bar appears with white bold title on the teal app bar color.

---

## Recap / cheat sheet

- **Scaffold:** `Scaffold(topBar = { ... }, floatingActionButton = { ... }) { padding -> content }`.
- **AppBarView:** `TopAppBar(title = { Text(title) }, backgroundColor = colorResource(...))`.
- **Hoisting:** `onBackNavClicked: () -> Unit = {}` — bar invokes, parent decides (navController).
- **Padding:** always apply `Modifier.padding(paddingValues)` to the scaffold's content.
