# Understanding HEX and Colors in Depth

---

## Overview

Compose colors are often hard-coded as `Color(0xFF018786)`, but real apps keep them in `res/values/colors.xml` as **HEX**. This short lecture explains HEX — the base-16 number system behind `#RRGGBB` — and how Compose resolves `colorResource` to a `Color`.

---

## HEX fundamentals

| Concept | Decimal (base-10) | HEX (base-16) |
| :--- | :--- | :--- |
| Digits | 0-9 | 0-9 + A-F (10-15) |
| Example | `255` | `FF` |
| Max per byte | `255` | `FF` |

A color is four bytes: `AARRGGBB` (Alpha, Red, Green, Blue).

```text
#018786
  01 87 86
  R  G  B    (alpha implicitly FF = opaque)
0xFF018786 = Color(0xFF018786)
```

- `FF` = `255` = fully opaque.
- `00` = `0` = fully transparent.
- Lower hex values = darker channel; higher = brighter.

Android Studio's color gutter (the square next to `#018786`) shows the swatch and a picker — click it to adjust visually.

---

## Where colors live

`res/values/colors.xml`:

```xml
<resources>
    <color name="white">#FFFFFF</color>
    <color name="black">#000000</color>
    <color name="app_bar_color">#018786</color>
    <color name="wish_item_bg">#E8E8E8</color>
</resources>
```

Resolved in Compose via:

```kotlin
colorResource(id = R.color.white) // → Color(0xFFFFFFFF)
colorResource(id = R.color.app_bar_color) // → Color(0xFF018786)
```

Or inline (no resource):

```kotlin
Color(0xFF018786)
Color.White
```

The lecture recommends `colorResource` for theming: a single XML change recolors the whole app.

---

## Recap / cheat sheet

- **HEX:** base-16, `A-F` = 10-15, `#RRGGBB` = red/green/blue, `AARRGGBB` with alpha.
- **`colors.xml`:** centralize `<color name="...">#RRGGBB</color>`.
- **Compose:** `colorResource(id = R.color.name)` or `Color(0xFF...)`.
