# Starting with the AddEditDetailView

---

## Overview

`AddEditDetailView` is the second screen — a form with two text fields (title, description) and a submit button. This lecture builds its **Scaffold** and the blank state that `WishViewModel`/`Navigation` will soon populate.

---

## The composable skeleton

`AddEditDetailView.kt`:

```kotlin
@Composable
fun AddEditDetailView(
    id: Long,
    viewModel: WishViewModel,
    navController: NavController
) {
    var title by remember { mutableStateOf("") }
    var description by remember { mutableStateOf("") }

    Scaffold(
        topBar = {
            AppBarView(
                title = if (id != 0L) "Update Wish" else "Add Wish",
                onBackNavClicked = { navController.navigateUp() }
            )
        }
    ) { paddingValues ->
        Column(
            modifier = Modifier
                .padding(paddingValues)
                .wrapContentSize()
                .padding(10.dp)
        ) {
            // WishTextField for title, description, and Button Add/Update
        }
    }
}
```

| Element | Role |
| :--- | :--- |
| `id: Long` | Navigation argument — `0L` = add, `>0` = edit |
| `Scaffold.topBar` | `AppBarView` with dynamic title |
| `Column` with `paddingValues` | Form content, avoids overlap with bar |
| `WishTextField` | Custom text field (next video) |

The form starts empty; the next two videos fill it with `OutlinedTextField` and bind it to the `ViewModel`.

---

## Recap / cheat sheet

- **Screen:** `AddEditDetailView(id: Long, viewModel, navController)` — `Scaffold(topBar=AppBarView(title, onBackNavClicked)) { Column }`.
- **Title:** `if (id != 0L) "Update Wish" else "Add Wish"`.
- **Back:** `onBackNavClicked = { navController.navigateUp() }`.
