# Understanding Singleton and our Graph Object

---

## Overview

A **`Singleton`** is a class with **one instance per process**. `Graph` is the Wishlist's manual DI container implemented as a Kotlin `object` — a process-wide singleton that holds the `WishDatabase` and `WishRepository`. This lecture builds `Graph`.

---

## The object

`Graph.kt`:

```kotlin
object Graph {
    lateinit var database: WishDatabase
        private set

    val wishRepository by lazy {
        WishRepository(wishDao = database.wishDao())
    }

    fun provide(context: Context) {
        database = Room.databaseBuilder(
            context,
            WishDatabase::class.java,
            "wishlist.db"
        ).build()
    }
}
```

| Member | Modifier | Role |
| :--- | :--- | :--- |
| `object Graph` | `object` | Kotlin's built-in singleton — one instance, thread-safe |
| `lateinit var database: WishDatabase` | `lateinit` + `private set` | Set once in `provide`, read-only elsewhere; `lateinit` crashes loudly if accessed before `provide` |
| `wishRepository by lazy { ... }` | `lazy` | Instantiated on first access, after `database` is set; `database.wishDao()` is cheap but must happen after `database` exists |
| `fun provide(context: Context)` | `fun` | Called once from `Application.onCreate` with the `Application` context |

---

## Why `lazy` for the repository?

| Declaration | Init timing |
| :--- | :--- |
| `val wishRepository = WishRepository(database.wishDao())` | At object construction — `database` is still `lateinit`, would crash |
| `val wishRepository by lazy { WishRepository(database.wishDao()) }` | On first *use* — by then `provide` has been called, so safe |

---

## Lifecycle

```text
Process start → Application.onCreate → Graph.provide(this)
                                        → database = Room.databaseBuilder(...).build()
                                        → (lazy) wishRepository created on first ViewModel construction
              → Activity → ViewModel(Graph.wishRepository) → uses repository
```

---

## Recap / cheat sheet

- **Graph:** `object Graph { lateinit var database:WishDatabase; val wishRepository by lazy{ WishRepository(database.wishDao()) }; fun provide(context) }`.
- **object** = singleton; **lateinit** = must be initialized once; **lazy** = init on first access after initialization.
