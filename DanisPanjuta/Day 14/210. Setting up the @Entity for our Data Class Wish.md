# Setting up the @Entity for our Data Class Wish

---

## Overview

An `@Entity` tells Room that a data class is a **table**. Each property is a **column**; each instance is a **row**; one column is the **primary key** that uniquely identifies a row. This lecture annotates `Wish` for Room.

---

## Step 1 — annotate the class

`Wish.kt`:

```kotlin
import androidx.room.ColumnInfo
import androidx.room.Entity
import androidx.room.PrimaryKey

@Entity(tableName = "wishlist")
data class Wish(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0L,

    @ColumnInfo(name = "wish-title")
    val title: String = "",

    @ColumnInfo(name = "wish-desc")
    val description: String = ""
)
```

| Annotation | Meaning |
| :--- | :--- |
| `@Entity(tableName = "wishlist")` | Maps class `Wish` → SQLite table `wishlist` |
| `@PrimaryKey(autoGenerate = true)` | `id` is the PK; Room increments it (`1,2,3...`) automatically. Never use `title` as PK — titles can duplicate |
| `@ColumnInfo(name = "wish-title")` | Column name in the table → `wish-title` (lecture uses hyphenated names to show custom naming) |
| Defaults `0L`, `""` | Required so Room can instantiate via no-arg constructor |

> If `Wish` lived elsewhere, the table name and column names can be anything; the lecture picks `wishlist`, `wish-title`, `wish-desc` explicitly.

---

## Table mental model

```text
Database (WishDatabase)
  └── Table `wishlist`
        ├── Column `id` (PK, auto)  │ 1  │ 2  │ 3  │
        ├── Column `wish-title`     │ "Google Watch 2" │ "Oculus Quest 2" │ ...
        └── Column `wish-desc`      │ "An Android Watch" │ "VR headset" │ ...
        Each Wish = one row
```

---

## Why `id` must be PK, not title

If `title` were PK, two wishes titled *"100K job"* would collide — Room would reject the second or overwrite the first. An auto-incrementing `Long` is globally unique, simple, and cheap to index.

---

## Recap / cheat sheet

- **Entity:** `@Entity(tableName = "wishlist") data class Wish(@PrimaryKey(autoGenerate=true) val id: Long, @ColumnInfo(name="wish-title") val title, @ColumnInfo(name="wish-desc") val description)`.
- **PK:** `id` with `autoGenerate = true`; never a user-editable field.
- **Columns:** `@ColumnInfo(name=...)` optional — omit to use property name as column name.
