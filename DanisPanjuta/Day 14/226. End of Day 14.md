## What you built and learned

- **Storage theory**: `SharedPreferences` vs files vs SQLite/Room.
- **Entity**: `@Entity(tableName="wishlist")` with `@PrimaryKey(autoGenerate)` and `@ColumnInfo`.
- **Dao**: `@Insert`/`@Query`/`@Update`/`@Delete` with `suspend` writes + `Flow` reads.
- **Database**: `abstract class WishDatabase: RoomDatabase()` with `@Database(entities, version, exportSchema)`.
- **Repository**: `WishRepository(wishDao)` as indirection between `Dao` and `ViewModel`.
- **ViewModel**: `WishViewModel(Graph.wishRepository)` with `lateinit var getAllWishes: Flow<List<Wish>>` + `Dispatchers.IO` writes.
- **Graph**: `object Graph { lateinit var database; wishRepository by lazy{...}; provide(context) }`.
- **Application**: `WishlistApp : Application() { Graph.provide(this) }` + manifest `android:name`.
- **DI**: `WishViewModel(Graph.wishRepository)` default → testability.
- **UI**: `HomeView` `collectAsState`, `AddEditDetailView` `getWishById` prefill, button branching `add` vs `update`, snackbars.
- **Swipe-to-delete**: `SwipeToDismiss` with `rememberDismissState`, `key={wish.id}`, `background` (`animateColorAsState`, `Box` + `Delete` icon), direction and threshold tuning.
