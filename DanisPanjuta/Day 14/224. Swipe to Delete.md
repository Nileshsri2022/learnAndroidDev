# Swipe to Delete

---

## Overview

Deleting via a button is possible, but modern lists use **swipe-to-dismiss**. This lecture makes each `WishItem` dismissible by wrapping it in `SwipeToDismiss` and calling `viewModel.deleteWish` when the swipe thresholds are crossed.

---

## Step 1 — state

`HomeView` defines per-item dismiss state:

```kotlin
val wishlist by viewModel.getAllWishes.collectAsState(initial = emptyList())

LazyColumn {
    items(wishlist, key = { wish -> wish.id }) { wish ->
        val dismissState = rememberDismissState(
            confirmStateChange = {
                if (it == DismissValue.DismissedToEnd || it == DismissValue.DismissedToStart) {
                    viewModel.deleteWish(wish)
                }
                true
            }
        )

        SwipeToDismiss(
            state = dismissState,
            directions = setOf(DismissDirection.EndToStart, DismissDirection.StartToEnd),
            dismissThresholds = { FractionalThreshold(0.5f) },
            dismissContent = { WishItem(wish) { navController.navigate(...) } }
            // background → next video
        )
    }
}
```

| Param | Value | Meaning |
| :--- | :--- | :--- |
| `rememberDismissState(confirmStateChange)` | Lambda returns `true` to allow dismissal | Calls `deleteWish` when fully dismissed |
| `directions` | `EndToStart` + `StartToEnd` | Both swipes accepted (lecture later narrows to `EndToStart` only) |
| `FractionalThreshold(0.5f)` | 50% of width | How far the user must swipe before `Dismissed*` is reached |
| `dismissContent` | `WishItem` | The row that slides away |
| `key = { wish.id }` | On `items` | **Critical** — without stable keys, Compose reuses slots and the wrong wish disappears. Lecture demonstrates the bug: deleting wish #4 without `key` removed #5 |

## Step 2 — call chain

`WishViewModel.deleteWish` → `wishRepository.deleteWish` → `wishDao.deleteWish` → Room `DELETE`.

---

## Verification

Add 5 wishes, swipe #4 halfway → it snaps back; swipe past 50% → it animates off-screen and `wishlist` shrinks; `collectAsState` recomposes; tapping remaining items still navigates to the correct detail.

---

## Recap / cheat sheet

- **Swipe:** `SwipeToDismiss(state=rememberDismissState{ deleteWish }, directions, FractionalThreshold(0.5f), dismissContent={WishItem})`.
- **Key:** `items(wishlist, key={wish.id})` — mandatory for correct dismissal.
- **Delete:** `viewModel.deleteWish(wish)` → `Dispatchers.IO` → `DELETE`.
