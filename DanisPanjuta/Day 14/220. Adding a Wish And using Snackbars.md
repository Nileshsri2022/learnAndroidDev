# Adding a Wish And using Snackbars

---

## Overview

Create actually writes. This lecture makes the **Add Wish** button in `AddEditDetailView` call `viewModel.addWish` and shows **Snackbars** for validation and undo.

---

## Step 1 — the button logic

`AddEditDetailView.kt`:

```kotlin
Button(onClick = {
    if (wishTitleState.isNotEmpty() && wishDescriptionState.isNotEmpty()) {
        viewModel.addWish(
            Wish(title = wishTitleState.trim(), description = wishDescriptionState.trim())
        )
        // or viewModel.updateWish if id != 0L
        navController.navigateUp()
    } else {
        scope.launch {
            scaffoldState.snackbarHostState.showSnackbar("Please enter fields to create a wish")
        }
    }
}) {
    Text(if (id != 0L) "Update Wish" else "Add Wish")
}
```

| Guard | Behaviour |
| :--- | :--- |
| `title.isNotEmpty() && description.isNotEmpty()` | Both fields required — otherwise `Snackbar` |
| `id != 0L` | Edit mode → `updateWish`; `0L` → `addWish` |
| `viewModel.addWish(Wish(...))` | `viewModelScope.launch(Dispatchers.IO)` inside the ViewModel → Room insert |
| `navController.navigateUp()` | Return to list after successful write |

---

## Step 2 — Snackbar

`HomeView` owns the `Scaffold`:

```kotlin
val scaffoldState = rememberScaffoldState()
val scope = rememberCoroutineScope()

Scaffold(
    scaffoldState = scaffoldState,
    topBar = { AppBarView(...) },
    snackbarHost = { scaffoldState.snackbarHostState }
) { padding ->
    LazyColumn(Modifier.padding(padding)) { /* wishes */ }
}
```

| API | Role |
| :--- | :--- |
| `rememberScaffoldState()` | Holds `snackbarHostState` |
| `rememberCoroutineScope()` | Scope to `launch` the `suspend fun showSnackbar` |
| `scaffoldState.snackbarHostState.showSnackbar("...")` | Suspends until dismissed; must be called from coroutine |

Lecture shows the **empty-field** mistake (tap Add with blank inputs) producing *"Please enter fields to create a wish"* as a `Snackbar` rather than a `Toast`.

---

## Recap / cheat sheet

- **Button:** `if (fields non-empty) addWish/updateWish → navigateUp() else scope.launch{ snackbarHostState.showSnackbar("Please enter fields...") }`.
- **Scaffold:** `rememberScaffoldState()` + `snackbarHost = { scaffoldState.snackbarHostState }`.
- **AddWish:** `Wish(title= wishTitleState.trim(), description=...)` — `id` defaults to `0L` → autoGenerate.
