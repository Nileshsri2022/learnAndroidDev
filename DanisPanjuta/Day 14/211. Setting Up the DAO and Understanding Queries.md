# Setting Up the DAO and Understanding Queries

---

## Overview

**DAO = Data Access Object**. It declares **how** the app talks to the table — every CRUD operation and every query is a method on an `interface` that Room implements. This lecture creates `WishDao`.

---

## Step 1 — create the interface

`WishDao.kt`:

```kotlin
import androidx.room.*

@Dao
interface WishDao {

    @Insert(onConflict = OnConflictStrategy.IGNORE)
    suspend fun addWish(wishEntity: Wish)

    @Query("SELECT * FROM `wishlist`")
    fun getAllWishes(): Flow<List<Wish>>

    @Update
    suspend fun updateWish(wishEntity: Wish)

    @Delete
    suspend fun deleteWish(wishEntity: Wish)

    @Query("SELECT * FROM `wishlist` WHERE id=:id")
    fun getWishById(id: Long): Flow<Wish>
}
```

| Member | Annotation | Why |
| :--- | :--- | :--- |
| `@Dao` | On interface | Marks it as a DAO for Room processor |
| `@Insert(onConflict = IGNORE)` + `suspend` | Insert a row; `IGNORE` = skip duplicate PK (should not happen with autoGenerate) |
| `@Query("SELECT * FROM wishlist")` → `Flow<List<Wish>>` | **Read** all rows; `Flow` = emits on every table change → UI recomposes |
| `@Update` + `suspend` | Update by PK |
| `@Delete` + `suspend` | Delete by PK |
| `@Query("SELECT * FROM wishlist WHERE id=:id")` → `Flow<Wish>` | Read single row by PK; `:id` is a bound parameter |

> The backticks around `` `wishlist` `` are needed because the table name contains a hyphen-like string in some editors; plain `wishlist` also works if the table name has no special chars.

---

## Suspend vs Flow

| Signature | Thread | Usage |
| :--- | :--- | :--- |
| `suspend fun addWish` | Must be called from coroutine (`Dispatchers.IO`) | One-shot write |
| `fun getAllWishes(): Flow<List<Wish>>` | Cold flow, Room emits on each change | Collected as `collectAsState` in Compose |

`@Insert`/`@Update`/`@Delete` are `suspend` because they touch disk.

---

## Recap / cheat sheet

- **DAO:** `@Dao interface WishDao { @Insert suspend add, @Query Flow getAll, @Update suspend update, @Delete suspend delete, @Query Flow getById }`.
- **Query:** `SELECT * FROM wishlist` and `SELECT * FROM wishlist WHERE id=:id`.
- **Flow** for reads, `suspend` for writes.
