# Swipe to Delete Background

---

## Overview

A bare `SwipeToDismiss` slides the row off without visual feedback. This lecture adds a **red `Box` with a `Delete` `Icon`** that is revealed as the row is dragged, plus an `animateColorAsState` that fades from `Transparent` to `Red` based on swipe direction, and limits the allowed direction to `EndToStart`.

---

## The background composable

Inside `SwipeToDismiss`:

```kotlin
val dismissState = rememberDismissState(...)

val color by animateColorAsState(
    targetValue = if (dismissState.dismissDirection == DismissDirection.EndToStart) Color.Red else Color.Transparent,
    label = "swipe color"
)
val alignment = Alignment.CenterEnd

SwipeToDismiss(
    state = dismissState,
    directions = setOf(DismissDirection.EndToStart), // only right-to-left now
    dismissThresholds = { FractionalThreshold(1f) }, // experiment: must swipe 100% in lecture demo
    background = {
        Box(
            modifier = Modifier
                .fillMaxSize()
                .background(color)
                .padding(horizontal = 20.dp),
            contentAlignment = alignment
        ) {
            Icon(Icons.Default.Delete, contentDescription = null, tint = Color.White)
        }
    },
    dismissContent = { WishItem(...) }
)
```

| Element | Role |
| :--- | :--- |
| `animateColorAsState` | Animates `Color` when `dismissDirection` changes — smooth fade |
| `Box(fillMaxSize, background(color), padding(20.dp), CenterEnd)` | Full-row background revealed under the sliding content |
| `Icon(Delete, White)` | Affordance that the gesture means *delete* |
| `FractionalThreshold(1f)` vs `0.5f` | Lecture experiments: `1f` requires full width; `0.5f` is more ergonomic — keep `0.5f` for production |
| `directions = EndToStart` only | Prevents accidental right-swipe deletion; only right-to-left works — left icon is hidden but `background` still handles it |

---

## Verification

Add wishes → swipe from **right to left** → red `Box` + white `Delete` icon appears underneath → release past threshold → row gone from DB. Swipe from **left to right** now does nothing (after narrowing to `EndToStart`).

---

## Recap / cheat sheet

- **Background:** `Box(animateColorAsState(direction→Red/Transparent), alignment=CenterEnd, Icon(Delete, White))`.
- **Directions:** `setOf(DismissDirection.EndToStart)` for right-to-left only.
- **Threshold:** `FractionalThreshold(0.5f)` (or `1f` for demo) — how far to trigger.
