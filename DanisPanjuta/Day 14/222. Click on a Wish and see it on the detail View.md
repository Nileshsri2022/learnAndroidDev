# Click on a Wish and see it on the detail View

---

## Overview

A list without detail is read-only. This lecture makes tapping a `WishItem` open `AddEditDetailView` in **edit mode**: it reads the `id` from the route, loads the `Wish` as `Flow<Wish>`, and pre-fills the two `WishTextField`s.

---

## Step 1 — pass id

`HomeView`:

```kotlin
WishItem(wish = wish) {
    navController.navigate(Screen.AddScreen.route + "/${wish.id}")
}
```

`Navigation`:

```kotlin
composable(Screen.AddScreen.route + "/{id}",
           arguments = listOf(navArgument("id"){type=NavType.LongType; defaultValue=0L})){
    val id = it.arguments?.getLong("id") ?: 0L
    AddEditDetailView(id = id, viewModel = viewModel, navController = navController)
}
```

---

## Step 2 — load and prefill

`AddEditDetailView.kt`:

```kotlin
@Composable
fun AddEditDetailView(id: Long, viewModel: WishViewModel, navController: NavController) {
    val scaffoldState = rememberScaffoldState()

    val wishToEdit = if (id != 0L) {
        viewModel.getWishById(id).collectAsState(initial = Wish(0L, "", "")).value
    } else {
        Wish(0L, "", "")
    }

    var title by remember { mutableStateOf(wishToEdit.title) }
    var description by remember { mutableStateOf(wishToEdit.description) }

    // when Flow emits after load, LaunchedEffect syncs state?
    // Lecture uses immediate mutableStateOf(wishToEdit...) + relies on recomposition

    Scaffold(
        topBar = { AppBarView(title = if (id != 0L) "Update Wish" else "Add Wish") { navController.navigateUp() } }
    ) { padding ->
        Column(Modifier.padding(padding)) {
            WishTextField(label="Title", value=title, onValueChanged={title=it})
            WishTextField(label="Description", value=description, onValueChanged={description=it})
            Button(onClick = {
                if (title.isNotEmpty() && description.isNotEmpty()) {
                    if (id != 0L) viewModel.updateWish(Wish(id=id, title=title, description=description))
                    else viewModel.addWish(Wish(title=title, description=description))
                    navController.navigateUp()
                } else {
                    // snackbar
                }
            }) { Text(if (id != 0L) "Update Wish" else "Add Wish") }
        }
    }
}
```

| Step | Code | Role |
| :--- | :--- |
| `getWishById(id).collectAsState(Wish(0L,"",""))` | Loads the single `Wish` as `State<Wish>` |
| `remember { mutableStateOf(wishToEdit.title) }` | Prefills the form fields |
| `Button` branch | `updateWish` when `id != 0L`, `addWish` when `0L` |

> The lecture notes the subtlety that `collectAsState` emits asynchronously — the form's `remember` runs before the DB emits, but the next recomposition corrects `wishToEdit`. A `LaunchedEffect(wishToEdit)` sync would be more robust.

---

## Recap / cheat sheet

- **Tap:** `navigate(AddScreen/${wish.id})` → detail.
- **Load:** `viewModel.getWishById(id).collectAsState(Wish(0L,"","")).value`.
- **Prefill:** `mutableStateOf(wishToEdit.title/description)`.
- **Save:** branch `updateWish` vs `addWish` by `id`.
