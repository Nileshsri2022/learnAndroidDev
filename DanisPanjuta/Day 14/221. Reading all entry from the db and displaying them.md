# Reading all entry from the db and displaying them

---

## Overview

Writes work, but the list still shows `DummyWish`. This lecture replaces the dummy source with the **real `Flow<List<Wish>>` from Room**, collected as Compose `State` so the list recomposes on every insert/update/delete.

---

## Step 1 — collect in HomeView

`HomeView.kt`:

```kotlin
@Composable
fun HomeView(viewModel: WishViewModel, navController: NavController) {
    val wishlist by viewModel.getAllWishes.collectAsState(initial = emptyList())

    Scaffold(...) { paddingValues ->
        LazyColumn(Modifier.padding(paddingValues)) {
            items(wishlist, key = { wish -> wish.id }) { wish ->
                WishItem(wish = wish) {
                    navController.navigate(Screen.AddScreen.route + "/${wish.id}")
                }
            }
        }
    }
}
```

| Call | Meaning |
| :--- | :--- |
| `collectAsState(initial = emptyList())` | Collects `Flow<List<Wish>>` as `State<List<Wish>>`; `initial` is rendered until the first DB emission |
| `by` delegate | `State<List<Wish>>` → `List<Wish>` via `getValue()` — `wishlist` is a plain list |
| `key = { wish.id }` | Stable keys prevent swipe-delete duplication bug (seen later) |

---

## Step 2 — fix the ViewModel Flow init

`WishViewModel` already has:

```kotlin
lateinit var getAllWishes: Flow<List<Wish>>
init { viewModelScope.launch { getAllWishes = wishRepository.getWishes() } }
```

The lecture changes `lateinit` to immediate `wishRepository.getWishes()` in some commits — both work as long as `Graph` is initialized first. The *lazy* `getAllWishes` pattern guarantees `Graph.provide` has been called.

---

## Verification

1. Add a wish (*"100K job"*) → **Snackbar** confirms, list now shows it.
2. Kill the app → reopen → wish is still there (proof it is persisted, not `DummyWish`).
3. Delete app data → list is empty again.

`DummyWish` can now be **deleted**.

## Recap / cheat sheet

- **HomeView:** `val wishlist by viewModel.getAllWishes.collectAsState(initial=emptyList())`.
- **LazyColumn:** `items(wishlist, key={wish.id}) { WishItem(...) }`.
- **DummyWish** → replaced; delete the file.
