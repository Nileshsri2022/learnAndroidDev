# Adding an undo button and functionality

---

## Overview

Adds an **undo** `ImageButton` that removes the **last stroke**. Removed paths are kept in a second list (so a *redo* could be added later).

---

## DrawingView

```kotlin
private val mUndoPaths = ArrayList<CustomPath>()

fun onClickUndo() {
    if (mPaths.size > 0) {
        mUndoPaths.add(mPaths.removeAt(mPaths.size - 1))
        invalidate()
    }
}
```

- `removeAt(lastIndex)` returns the removed element → stored in `mUndoPaths`.
- `invalidate()` triggers `onDraw`, which redraws the remaining paths.

Redo (optional challenge):

```kotlin
fun onClickRedo() {
    if (mUndoPaths.size > 0) {
        mPaths.add(mUndoPaths.removeAt(mUndoPaths.size - 1))
        invalidate()
    }
}
```

## UI + wiring

```xml
<ImageButton
    android:id="@+id/ib_undo"
    android:layout_width="50dp"
    android:layout_height="50dp"
    android:layout_margin="5dp"
    android:scaleType="fitXY"
    android:src="@drawable/ic_undo" />
```

```kotlin
val ibUndo: ImageButton = findViewById(R.id.ib_undo)
ibUndo.setOnClickListener { drawingView?.onClickUndo() }
```

## Recap / cheat sheet

- **Undo:** `mUndoPaths.add(mPaths.removeAt(mPaths.lastIndex)); invalidate()`.
- Guard with `if (mPaths.size > 0)`.
