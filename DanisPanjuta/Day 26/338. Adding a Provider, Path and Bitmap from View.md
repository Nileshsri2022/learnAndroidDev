# Adding a provider - path and a image sandwich maker to our app

---

## Overview

Prepares **saving**: adds a **save** button, the **write** permission, a **`FileProvider`** for sharing later, and **`getBitmapFromView`** — the "image sandwich maker" that merges the background image and the drawing into one `Bitmap`.

---

## Save button + permission

```xml
<ImageButton android:id="@+id/ib_save" android:src="@drawable/ic_save" … />
```

```xml
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
```

Request it together with the read permission:

```kotlin
requestPermission.launch(arrayOf(
    Manifest.permission.READ_EXTERNAL_STORAGE,
    Manifest.permission.WRITE_EXTERNAL_STORAGE
))
```

## FileProvider

`AndroidManifest.xml` (inside `<application>`):

```xml
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="eu.tutorials.kidsdrawingapp.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/path" />
</provider>
```

`res/xml/path.xml`:

```xml
<paths>
    <external-path name="captured" path="Android/data/eu.tutorials.kidsdrawingapp/files" />
</paths>
```

A `FileProvider` exposes files through **`content://`** URIs so other apps can read them securely (raw `file://` URIs are blocked since Android 7).

## The image sandwich — getBitmapFromView

```kotlin
private fun getBitmapFromView(view: View): Bitmap {
    val returnedBitmap = Bitmap.createBitmap(view.width, view.height, Bitmap.Config.ARGB_8888)
    val canvas = Canvas(returnedBitmap)
    val bgDrawable = view.background
    if (bgDrawable != null) {
        bgDrawable.draw(canvas)        // bottom slice: background
    } else {
        canvas.drawColor(Color.WHITE)
    }
    view.draw(canvas)                  // top slice: the view + its children
    return returnedBitmap
}
```

Passing the **FrameLayout** (`fl_drawing_view_container`) captures both the background `ImageView` and the `DrawingView`.

---

## Recap / cheat sheet

- **FileProvider** + `xml/path.xml` for shareable `content://` URIs.
- **View → Bitmap:** create bitmap, `Canvas(bitmap)`, draw background, `view.draw(canvas)`.
