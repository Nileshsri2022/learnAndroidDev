# Displaying The Custom Progress Dialog and Hiding it When done

---

## Overview

Saving can take a while, so the **custom progress dialog** from the demo is shown before saving starts and dismissed when it finishes.

---

## Helpers in MainActivity

```kotlin
var customProgressDialog: Dialog? = null

private fun showProgressDialog() {
    customProgressDialog = Dialog(this@MainActivity)
    customProgressDialog?.setContentView(R.layout.dialog_custom_progress)
    customProgressDialog?.show()
}

private fun cancelProgressDialog() {
    if (customProgressDialog != null) {
        customProgressDialog?.dismiss()
        customProgressDialog = null
    }
}
```

---

## Wiring into save

```kotlin
ibSave.setOnClickListener {
    if (isReadStorageAllowed()) {
        showProgressDialog()
        lifecycleScope.launch {
            val flDrawingView: FrameLayout = findViewById(R.id.fl_drawing_view_container)
            saveBitmapFile(getBitmapFromView(flDrawingView))
        }
    }
}
```

Inside `saveBitmapFile` → `runOnUiThread { cancelProgressDialog(); … toast … }`.

Order matters: show **on the main thread** before launching, dismiss **on the main thread** after the I/O completes.

---

## Recap / cheat sheet

- `showProgressDialog()` → background work → `cancelProgressDialog()` in `runOnUiThread`.
