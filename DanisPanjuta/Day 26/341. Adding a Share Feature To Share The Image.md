# Adding a Share Feature To Share The Image Via Email, WhatsApp etc.

---

## Overview

After saving, the image is offered to other apps via the Android **share sheet** (Gmail, WhatsApp, Bluetooth…). Uses **`MediaScannerConnection`** to register the file, and **`FileProvider`** for a secure URI.

---

## shareImage

```kotlin
private fun shareImage(result: String) {
    MediaScannerConnection.scanFile(this, arrayOf(result), null) { path, uri ->
        val shareIntent = Intent()
        shareIntent.action = Intent.ACTION_SEND
        shareIntent.putExtra(Intent.EXTRA_STREAM, uri)
        shareIntent.type = "image/png"
        startActivity(Intent.createChooser(shareIntent, "Share"))
    }
}
```

| Piece | Role |
| :--- | :--- |
| `MediaScannerConnection.scanFile` | Adds the file to the media database and returns a content `Uri` |
| `Intent.ACTION_SEND` | Implicit "share" intent |
| `EXTRA_STREAM` | The content to share |
| `type = "image/png"` | MIME type — filters compatible apps |
| `Intent.createChooser` | Always shows the app picker |

Alternative with the FileProvider:

```kotlin
val uri = FileProvider.getUriForFile(this,
    "eu.tutorials.kidsdrawingapp.fileprovider", File(result))
shareIntent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
```

---

## Calling it after saving

```kotlin
runOnUiThread {
    cancelProgressDialog()
    if (result.isNotEmpty()) {
        Toast.makeText(this@MainActivity, "File saved successfully :$result", Toast.LENGTH_SHORT).show()
        shareImage(result)
    } else { … }
}
```

`shareImage` is self-contained — copy it into any app that needs sharing.
