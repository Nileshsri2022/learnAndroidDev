# Preparing the BrushSizeSelector and How To Use DisplayMetrics

---

## Overview

Adds a public **`setSizeForBrush`** function to `DrawingView`. To look the same on every device, the size is converted from **dp to pixels** using **`TypedValue.applyDimension`** with the screen's **`DisplayMetrics`**.

---

## Code

```kotlin
fun setSizeForBrush(newSize: Float) {
    mBrushSize = TypedValue.applyDimension(
        TypedValue.COMPLEX_UNIT_DIP,
        newSize,
        resources.displayMetrics
    )
    mDrawPaint!!.strokeWidth = mBrushSize
}
```

| Part | Meaning |
| :--- | :--- |
| `COMPLEX_UNIT_DIP` | Interpret `newSize` as **dp** |
| `resources.displayMetrics` | Screen density info of the current device |
| Return value | Size in **pixels** for this device |

Without conversion, `20f` px is thick on a low-density screen and thin on a high-density one.

---

## Using it

In `setUpDrawing()` remove the hard-coded `mBrushSize = 20f`, and in `MainActivity`:

```kotlin
private var drawingView: DrawingView? = null

override fun onCreate(savedInstanceState: Bundle?) {
    …
    drawingView = findViewById(R.id.drawing_view)
    drawingView?.setSizeForBrush(20.toFloat())
}
```

The function is **public** (no `private`) so the activity can call it.

---

## Recap / cheat sheet

- **dp → px:** `TypedValue.applyDimension(COMPLEX_UNIT_DIP, value, resources.displayMetrics)`.
- `setSizeForBrush()` is the API the activity uses.
