# Do something in the Background using Coroutines

---

## Overview

Long tasks (saving files, network, database) **block the UI thread** — the app freezes, and if it doesn't respond for ~**5 seconds** Android shows an **ANR** ("Application Not Responding"). **Coroutines** move such work to a background thread.

---

## The problem — blocking demo

```kotlin
btnExecute.setOnClickListener {
    execute("Task executed successfully")
}

private fun execute(result: String) {
    for (i in 1..100000) {
        Log.e("delay: ", "" + i)     // long loop on the main thread → UI frozen
    }
    runOnUiThread {
        Toast.makeText(this, result, Toast.LENGTH_SHORT).show()
    }
}
```

## The solution — `suspend`, `lifecycleScope`, `withContext`

```kotlin
btnExecute.setOnClickListener {
    showProgressDialog()
    lifecycleScope.launch {
        execute("Task executed successfully")
    }
}

private suspend fun execute(result: String) {
    withContext(Dispatchers.IO) {
        for (i in 1..100000) {
            Log.e("delay: ", "" + i)
        }
        runOnUiThread {
            cancelProgressDialog()
            Toast.makeText(this@MainActivity, result, Toast.LENGTH_SHORT).show()
        }
    }
}
```

| Piece | Meaning |
| :--- | :--- |
| `suspend fun` | Can pause without blocking; only callable from a coroutine |
| `lifecycleScope.launch {}` | Starts a coroutine tied to the Activity lifecycle (auto-cancelled on destroy) |
| `withContext(Dispatchers.IO)` | Switch to a background thread pool for I/O |
| `runOnUiThread {}` | Back to the main thread to touch the UI |

**Dispatchers:** `Main` (UI), `IO` (disk/network), `Default` (CPU-heavy).

---

## Recap / cheat sheet

- **Never block the main thread** (ANR after ~5 s).
- `lifecycleScope.launch { suspendFn() }` → `withContext(Dispatchers.IO) { … }`.
- UI updates only on the main thread.
