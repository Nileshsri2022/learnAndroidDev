# Adding the color pallet using custom drawables that we created

---

## Overview

Builds the **colour palette** — a horizontal `LinearLayout` of `ImageButton`s, each showing a colour via its `background` and a common **pallet drawable** on top. Functionality comes next lecture.

---

## Pallet drawables

`drawable/pallet_normal.xml`:

```xml
<shape android:shape="rectangle">
    <stroke android:width="2dp" android:color="#FF9AA2AF" />
    <solid android:color="#00000000" />
</shape>
```

`drawable/pallet_pressed.xml`:

```xml
<shape android:shape="rectangle">
    <stroke android:width="3dp" android:color="#FF666666" />
    <solid android:color="#00000000" />
</shape>
```

Transparent fill → the button's **background colour** shows through; only the border differs.

---

## Colour resources — `values/colors.xml`

```xml
<color name="skin">#FFD8B0</color>
<color name="black">#000000</color>
<color name="red">#FF0000</color>
<color name="green">#00FF00</color>
<color name="blue">#0000FF</color>
<color name="yellow">#FFEB3B</color>
<color name="lollipop">#FF9800</color>
<color name="random">#9C27B0</color>
<color name="white">#FFFFFF</color>
```

---

## Palette layout

```xml
<LinearLayout
    android:id="@+id/ll_paint_colors"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="horizontal"
    app:layout_constraintBottom_toTopOf="@id/ll_action_buttons" … >

    <ImageButton
        android:layout_width="25dp"
        android:layout_height="25dp"
        android:layout_margin="2dp"
        android:background="@color/skin"
        android:onClick="paintClicked"
        android:src="@drawable/pallet_normal"
        android:tag="@color/skin" />
    <!-- black, red, green, blue, yellow, lollipop, random, white -->
</LinearLayout>
```

- **`android:tag`** stores the colour on the view — read later to know which colour was clicked.

---

## Recap / cheat sheet

- **Swatch:** `ImageButton` with `background=@color/x`, `src=@drawable/pallet_normal`, `tag=@color/x`.
- `pallet_pressed` marks the selected swatch.
