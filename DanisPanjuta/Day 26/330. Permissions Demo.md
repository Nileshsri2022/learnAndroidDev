# Permissions Demo

---

## Overview

A standalone demo of **runtime permissions** using the **Activity Result API**: requesting **one** permission (camera) and **multiple** permissions at once (camera + fine/coarse location), plus showing a **rationale** dialog when the user denied before.

---

## Permission levels

| Type | Example | Granted |
| :--- | :--- | :--- |
| **Normal** | `INTERNET` | Automatically at install |
| **Dangerous** | `CAMERA`, `ACCESS_FINE_LOCATION`, `READ_EXTERNAL_STORAGE` | User must allow at **runtime** |

Every permission must also be declared in the manifest:

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

---

## Single permission

```kotlin
private val cameraResultLauncher: ActivityResultLauncher<String> =
    registerForActivityResult(ActivityResultContracts.RequestPermission()) { isGranted ->
        if (isGranted) {
            Toast.makeText(this, "Permission granted for camera", Toast.LENGTH_LONG).show()
        } else {
            Toast.makeText(this, "Permission denied for camera", Toast.LENGTH_LONG).show()
        }
    }

btnCameraPermission.setOnClickListener {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M &&
        shouldShowRequestPermissionRationale(Manifest.permission.CAMERA)) {
        showRationaleDialog("Permission Demo requires camera access",
            "Camera cannot be used because Camera access is denied")
    } else {
        cameraResultLauncher.launch(Manifest.permission.CAMERA)
    }
}
```

## Multiple permissions

```kotlin
private val cameraAndLocationResultLauncher: ActivityResultLauncher<Array<String>> =
    registerForActivityResult(ActivityResultContracts.RequestMultiplePermissions()) { permissions ->
        permissions.entries.forEach {
            val permissionName = it.key
            val isGranted = it.value
            if (isGranted) {
                when (permissionName) {
                    Manifest.permission.ACCESS_FINE_LOCATION ->
                        Toast.makeText(this, "Fine location granted", Toast.LENGTH_SHORT).show()
                    Manifest.permission.ACCESS_COARSE_LOCATION ->
                        Toast.makeText(this, "Coarse location granted", Toast.LENGTH_SHORT).show()
                    else -> Toast.makeText(this, "Camera granted", Toast.LENGTH_SHORT).show()
                }
            } else { /* denied handling */ }
        }
    }

cameraAndLocationResultLauncher.launch(arrayOf(
    Manifest.permission.CAMERA,
    Manifest.permission.ACCESS_FINE_LOCATION,
    Manifest.permission.ACCESS_COARSE_LOCATION
))
```

Android 12 lets the user choose **precise** or **approximate** location.

## Rationale dialog

```kotlin
private fun showRationaleDialog(title: String, message: String) {
    val builder = AlertDialog.Builder(this)
    builder.setTitle(title)
        .setMessage(message)
        .setPositiveButton("Cancel") { dialog, _ -> dialog.dismiss() }
    builder.create().show()
}
```

`shouldShowRequestPermissionRationale` returns `true` when the user **denied once** — explain *why* before asking again. After "Don't ask again", the system dialog no longer appears; the user must enable it in Settings.

---

## Recap / cheat sheet

- **Declare** in manifest + **request** at runtime.
- `RequestPermission()` → `Boolean`; `RequestMultiplePermissions()` → `Map<String, Boolean>`.
- `shouldShowRequestPermissionRationale()` → explain first.
