# Custom Progress Bar Dialogs

---

## Overview

The old `ProgressDialog` is **deprecated**, so the workaround is a **custom dialog containing a `ProgressBar`**. It's shown while a background task runs so the user knows something is happening (and can't interact meanwhile).

---

## Layout — `dialog_custom_progress.xml`

```xml
<LinearLayout
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:gravity="center_vertical"
    android:orientation="horizontal"
    android:padding="16dp">

    <ProgressBar
        android:layout_width="wrap_content"
        android:layout_height="wrap_content" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginStart="16dp"
        android:text="Please wait..."
        android:textSize="18sp" />
</LinearLayout>
```

A `ProgressBar` without a style is **indeterminate** — a spinning circle.

---

## Code

```kotlin
private fun customProgressDialogFunction() {
    val customProgressDialog = Dialog(this)
    customProgressDialog.setContentView(R.layout.dialog_custom_progress)
    customProgressDialog.show()
}
```

In the real app, keep a reference so it can be dismissed when the work finishes:

```kotlin
private var customProgressDialog: Dialog? = null

private fun showProgressDialog() {
    customProgressDialog = Dialog(this)
    customProgressDialog?.setContentView(R.layout.dialog_custom_progress)
    customProgressDialog?.setCancelable(false)
    customProgressDialog?.show()
}

private fun cancelProgressDialog() {
    customProgressDialog?.dismiss()
    customProgressDialog = null
}
```

---

## Recap / cheat sheet

- **ProgressDialog is deprecated** → `Dialog` + `ProgressBar` layout.
- `show…()` before work, `cancel…()` after.
