# Adding The Gallery ImageButton To The UI

---

## Overview

Adds a **gallery** button next to the brush button in a horizontal `LinearLayout` of action buttons. Clicking it will later ask for storage permission and open the gallery.

---

## Action buttons row

```xml
<LinearLayout
    android:id="@+id/ll_action_buttons"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="horizontal"
    app:layout_constraintBottom_toBottomOf="parent"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintEnd_toEndOf="parent">

    <ImageButton
        android:id="@+id/ib_gallery"
        android:layout_width="50dp"
        android:layout_height="50dp"
        android:layout_margin="5dp"
        android:scaleType="fitXY"
        android:src="@drawable/ic_gallery" />

    <ImageButton
        android:id="@+id/ib_brush"
        android:layout_width="50dp"
        android:layout_height="50dp"
        android:layout_margin="5dp"
        android:scaleType="fitXY"
        android:src="@drawable/ic_brush" />
</LinearLayout>
```

The palette `LinearLayout` is now constrained **above** this row.

---

## Recap / cheat sheet

- Group tool buttons in a horizontal `LinearLayout`.
- `scaleType="fitXY"` stretches the icon to the button size.
