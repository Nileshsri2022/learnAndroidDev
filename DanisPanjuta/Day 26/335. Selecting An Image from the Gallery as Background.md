# Selecting An Image from the gallery using it as a background

---

## Overview

Once permission is granted, an **Intent** opens the device gallery. The chosen image's **URI** is set on the background `ImageView`.

---

## Gallery result launcher

```kotlin
val openGalleryLauncher: ActivityResultLauncher<Intent> =
    registerForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
        if (result.resultCode == RESULT_OK && result.data != null) {
            val imageBackground: ImageView = findViewById(R.id.iv_background)
            imageBackground.setImageURI(result.data?.data)
        }
    }
```

- `result.data` — the returned `Intent`.
- `result.data?.data` — the **`Uri`** of the selected image.

---

## Launching the gallery after permission

```kotlin
if (isGranted) {
    Toast.makeText(this@MainActivity, "Permission granted…", Toast.LENGTH_LONG).show()
    val pickIntent = Intent(Intent.ACTION_PICK, MediaStore.Images.Media.EXTERNAL_CONTENT_URI)
    openGalleryLauncher.launch(pickIntent)
}
```

| Part | Meaning |
| :--- | :--- |
| `Intent.ACTION_PICK` | Implicit intent — "let the user pick something" |
| `MediaStore.Images.Media.EXTERNAL_CONTENT_URI` | …from the device's image collection |

Intents aren't only for moving between your own activities — **implicit intents** ask *other* apps (gallery, camera, browser) to do something.

Test on the emulator by first dragging a few images into it or taking a photo with the emulated camera.

---

## Recap / cheat sheet

- **Pick image:** `Intent(ACTION_PICK, MediaStore.Images.Media.EXTERNAL_CONTENT_URI)`.
- **Result:** `StartActivityForResult()` → `result.data?.data` (Uri) → `setImageURI`.
