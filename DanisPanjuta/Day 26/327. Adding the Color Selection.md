# Adding the Color selection

---

## Overview

Implements `setColor` in `DrawingView` and the `paintClicked` handler in `MainActivity`, highlighting the selected swatch with the **pressed** drawable.

---

## DrawingView.setColor

```kotlin
fun setColor(newColor: String) {
    color = Color.parseColor(newColor)
    mDrawPaint!!.color = color
}
```

`Color.parseColor("#FF0000")` converts a hex string into an `Int` colour.

---

## MainActivity

```kotlin
private var mImageButtonCurrentPaint: ImageButton? = null

override fun onCreate(savedInstanceState: Bundle?) {
    …
    val linearLayoutPaintColors = findViewById<LinearLayout>(R.id.ll_paint_colors)
    mImageButtonCurrentPaint = linearLayoutPaintColors[1] as ImageButton   // black
    mImageButtonCurrentPaint!!.setImageDrawable(
        ContextCompat.getDrawable(this, R.drawable.pallet_pressed)
    )
}

fun paintClicked(view: View) {
    if (view !== mImageButtonCurrentPaint) {
        val imageButton = view as ImageButton
        val colorTag = imageButton.tag.toString()
        drawingView?.setColor(colorTag)

        imageButton.setImageDrawable(
            ContextCompat.getDrawable(this, R.drawable.pallet_pressed))
        mImageButtonCurrentPaint?.setImageDrawable(
            ContextCompat.getDrawable(this, R.drawable.pallet_normal))
        mImageButtonCurrentPaint = view
    }
}
```

| Step | Purpose |
| :--- | :--- |
| `linearLayout[1]` | Access a child by index (androidx `ViewGroup.get` extension) |
| `view !== current` | Ignore taps on the already-selected colour (referential inequality) |
| `tag.toString()` | Hex string stored in XML |
| Swap drawables | New swatch → pressed, previous → normal |

---

## Recap / cheat sheet

- **Colour from tag:** `Color.parseColor(view.tag.toString())`.
- Track the selected swatch in `mImageButtonCurrentPaint`.
