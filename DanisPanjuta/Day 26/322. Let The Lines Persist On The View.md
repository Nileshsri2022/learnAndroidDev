# Let The Lines Persist On The View

---

## Overview

Stores every finished stroke in an **`ArrayList<CustomPath>`** and redraws all of them in `onDraw`, so lines stay on screen for the lifetime of the activity.

---

## The list of paths

```kotlin
private val mPaths = ArrayList<CustomPath>()
```

`val` — the list reference can't be replaced, but its contents can change.

---

## Save a stroke when the finger lifts

```kotlin
MotionEvent.ACTION_UP -> {
    mPaths.add(mDrawPath!!)
    mDrawPath = CustomPath(color, mBrushSize)
}
```

---

## Draw all saved strokes

```kotlin
override fun onDraw(canvas: Canvas) {
    super.onDraw(canvas)
    canvas.drawBitmap(mCanvasBitmap!!, 0f, 0f, mCanvasPaint)

    for (path in mPaths) {
        mDrawPaint!!.strokeWidth = path.brushThickness
        mDrawPaint!!.color = path.color
        canvas.drawPath(path, mDrawPaint!!)
    }

    if (!mDrawPath!!.isEmpty) {
        mDrawPaint!!.strokeWidth = mDrawPath!!.brushThickness
        mDrawPaint!!.color = mDrawPath!!.color
        canvas.drawPath(mDrawPath!!, mDrawPaint!!)
    }
}
```

Because each `CustomPath` remembers its own **colour and thickness**, changing brush settings later doesn't affect old strokes.

---

## Recap / cheat sheet

- **Persist:** `mPaths.add(path)` on `ACTION_UP`.
- **Redraw all:** loop `mPaths` in `onDraw`, applying each path's style.
