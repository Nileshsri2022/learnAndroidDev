# CustomDialogs Demo Part 2

---

## Overview

A **custom dialog** has a UI you design yourself in an XML layout — any text, buttons, colours, images. Part 2 builds and wires one up.

---

## Layout — `dialog_custom.xml`

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Custom Dialog Title"
        android:textSize="20sp"
        android:textStyle="bold" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_marginTop="10dp"
        android:text="This is a custom dialog, the UI is fully defined by us." />

    <LinearLayout
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:gravity="end"
        android:orientation="horizontal">
        <TextView android:id="@+id/tv_submit" android:text="SUBMIT" android:padding="10dp" … />
        <TextView android:id="@+id/tv_cancel" android:text="CANCEL" android:padding="10dp" … />
    </LinearLayout>
</LinearLayout>
```

---

## Code

```kotlin
private fun customDialogFunction() {
    val customDialog = Dialog(this)
    customDialog.setContentView(R.layout.dialog_custom)

    customDialog.findViewById<TextView>(R.id.tv_submit).setOnClickListener {
        Toast.makeText(applicationContext, "clicked submit", Toast.LENGTH_LONG).show()
        customDialog.dismiss()
    }
    customDialog.findViewById<TextView>(R.id.tv_cancel).setOnClickListener {
        Toast.makeText(applicationContext, "clicked cancel", Toast.LENGTH_LONG).show()
        customDialog.dismiss()
    }
    customDialog.show()
}
```

With **View Binding** (used later in the course):

```kotlin
val binding = DialogCustomBinding.inflate(layoutInflater)
customDialog.setContentView(binding.root)
binding.tvSubmit.setOnClickListener { … }
```

---

## Recap / cheat sheet

- `Dialog(this)` + `setContentView(layout)` + `findViewById` on the dialog.
- Always `dismiss()` in button handlers.
