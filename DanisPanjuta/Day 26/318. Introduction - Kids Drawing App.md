# Introduction - Kids Drawing App

---

## Overview

Day 26 builds the **Kids Drawing App** — an advanced project where the **`View`** class itself is extended and drawn on. Until now views were only *used* (a `Button` is a view); now we **manipulate** a view with a `Canvas`, `Paint` and `Path`.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **Custom views** | Subclassing `View`, `onDraw`, `onTouchEvent`, `onSizeChanged` |
| **Canvas drawing** | `Canvas`, `Bitmap`, `Paint`, `Path` |
| **Highly customized UI** | Custom drawables, colour palette, custom dialogs |
| **Importing images** | Pick an image from the gallery as a background |
| **Exporting images** | Save the drawing as PNG to the device |
| **Permissions** | Runtime permissions with the Activity Result API |
| **Dialogs** | Snackbar, AlertDialog, custom dialog, custom progress dialog |
| **Coroutines** | Doing heavy work in the background |
| **Sharing** | Share the image via email, WhatsApp, etc. |

---

## Recap / cheat sheet

- **Core:** custom `DrawingView : View` + Canvas.
- **Extras:** gallery import, save, share, undo, brush size, colours.
