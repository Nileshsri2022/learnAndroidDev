# Saving an Image on The Phone using Coroutines and OutPutStreams

---

## Overview

Writes the merged `Bitmap` to a **PNG file** in the background with a **suspend function**, **`ByteArrayOutputStream`** and **`FileOutputStream`**, then reports the file path.

---

## saveBitmapFile

```kotlin
private suspend fun saveBitmapFile(mBitmap: Bitmap?): String {
    var result = ""
    withContext(Dispatchers.IO) {
        if (mBitmap != null) {
            try {
                val bytes = ByteArrayOutputStream()
                mBitmap.compress(Bitmap.CompressFormat.PNG, 90, bytes)

                val f = File(externalCacheDir?.absoluteFile.toString()
                        + File.separator + "KidDrawingApp_"
                        + System.currentTimeMillis() / 1000 + ".png")

                val fo = FileOutputStream(f)
                fo.write(bytes.toByteArray())
                fo.close()

                result = f.absolutePath

                runOnUiThread {
                    if (result.isNotEmpty()) {
                        Toast.makeText(this@MainActivity,
                            "File saved successfully :$result", Toast.LENGTH_SHORT).show()
                    } else {
                        Toast.makeText(this@MainActivity,
                            "Something went wrong while saving the file.", Toast.LENGTH_SHORT).show()
                    }
                }
            } catch (e: Exception) {
                result = ""
                e.printStackTrace()
            }
        }
    }
    return result
}
```

| Step | Purpose |
| :--- | :--- |
| `compress(PNG, 90, bytes)` | Encode bitmap into bytes (quality ignored for PNG) |
| `externalCacheDir` | App-specific external storage folder |
| `System.currentTimeMillis()/1000` | Unique file name |
| `FileOutputStream.write` | Write bytes to disk |
| `try / catch` | I/O can fail — don't crash |

## Calling it

```kotlin
ibSave.setOnClickListener {
    if (isReadStorageAllowed()) {
        lifecycleScope.launch {
            val flDrawingView: FrameLayout = findViewById(R.id.fl_drawing_view_container)
            saveBitmapFile(getBitmapFromView(flDrawingView))
        }
    }
}

private fun isReadStorageAllowed(): Boolean {
    val result = ContextCompat.checkSelfPermission(this,
        Manifest.permission.READ_EXTERNAL_STORAGE)
    return result == PackageManager.PERMISSION_GRANTED
}
```

---

## Recap / cheat sheet

- **Bitmap → PNG bytes:** `compress(PNG, 90, ByteArrayOutputStream())`.
- **Write:** `FileOutputStream(file).write(bytes)`.
- Run in `withContext(Dispatchers.IO)`; toast via `runOnUiThread`.
