## Features

```
┌──────────────────────────────┐
│   [background image]         │
│      ✏️ drawing canvas       │  ← FrameLayout: ImageView + DrawingView
│                              │
├──────────────────────────────┤
│ ● ● ● ● ● ● ● ●              │  ← colour palette (ImageButtons)
│ [🖼 gallery] [↶ undo] [🖌 brush] [💾 save] │
└──────────────────────────────┘
```

| Feature | How it works |
| :--- | :--- |
| Draw with a finger | Custom view reacts to touch events |
| Change **colour** | Tap a palette swatch |
| Change **brush size** | Dialog with small / medium / large |
| **Background image** | Pick from the gallery (permission required) |
| **Undo** | Removes the last stroke |
| **Save** | Exports the canvas + background to a PNG (with progress dialog) |
| **Share** | Share sheet → Gmail, WhatsApp, Bluetooth… |

---

## Recap / cheat sheet

- **Simple UI, advanced internals** — no splash screen, just a big canvas and a toolbar.
