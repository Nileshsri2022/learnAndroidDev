## Pipeline you should be able to draw from memory

```
UI (Composable)
   │  user types / taps
   ▼
Event (onClick, onValueChange, onDismissRequest)
   │  you assign a new value
   ▼
State (remember { mutableStateOf(...) }  or  by remember { ... })
   │  Compose notices the change
   ▼
Recomposition (only the composables that read that state re-run)
   │
   ▼
Updated UI
```

## API cheat sheet

```kotlin
// Observable + survives recomposition
var inputValue by remember { mutableStateOf("") }

// Same thing without `by` — you must use .value
val conversionFactor = remember { mutableStateOf(1.00) }
conversionFactor.value = 0.01

// Safe number parse
val n = inputValue.toDoubleOrNull() ?: 0.0

// Convert through meters, 2 decimal places
val result =
    (n * conversionFactor.value * 100.0 / oConversionFactor.value)
        .roundToInt() / 100.0

// Open / close a menu
iExpanded = true            // button
iExpanded = false           // onDismissRequest or item onClick
DropdownMenu(expanded = iExpanded, onDismissRequest = { iExpanded = false }) { }

// Text styles
Text("Title", style = MaterialTheme.typography.headlineLarge)
Text("Result", style = MaterialTheme.typography.headlineMedium)
```

## State variables in the finished app

| Variable | Role |
| :--- | :--- |
| `inputValue` | String in the text field |
| `outputValue` | Calculated result (String, for `Text`) |
| `inputUnit` / `outputUnit` | Labels on the two buttons |
| `iExpanded` / `oExpanded` | Whether each menu is open |
| `conversionFactor` | Input unit → meters |
| `oConversionFactor` | Output unit → meters |

Factors: cm `0.01`, m `1.00`, ft `0.3048`, mm `0.001`.
