# Implementing `iExpanded` — Open and Close the Dropdown Menus

---

## Overview

In the previous lecture, state variables were declared (`iExpanded`, `oExpanded`, `inputUnit`, `conversionFactor`, …) but the dropdowns still did nothing useful.

This lecture wires **open / close** to those booleans, then starts handling a menu-item click.

The big idea: **you never animate the menu yourself**. You only change a boolean. Compose shows or hides the menu from that boolean.

---

## 1. Make the layout easier to read

The instructor labels the two boxes so it is obvious which side is which:

- Left `Box` → **input** (what you convert *from*)
- Right `Box` → **output** (what you convert *to*)

Comments like `// Input Box` / `// Output Box` (and `// Input Button` / `// Output Button`) help when both menus look identical.

## 2. Opening a menu = set expanded to `true`

The input button should open the input menu:

```kotlin
Button(onClick = { iExpanded = true }) {
    Text("Select")
    Icon(
        imageVector = Icons.Default.ArrowDropDown,
        contentDescription = "Arrow Down"
    )
}

DropdownMenu(
    expanded = iExpanded,          // was hardcoded true/false
    onDismissRequest = { /* next */ }
) { /* items */ }
```

Same idea for the output side, with `oExpanded`:

```kotlin
Button(onClick = { oExpanded = true }) { /* ... */ }

DropdownMenu(
    expanded = oExpanded,
    onDismissRequest = { /* next */ }
) { /* items */ }
```

`DropdownMenu(expanded = …)` **reads** the state. The button **writes** it. That is unidirectional data flow in one line.

---

## 3. Closing a menu = set expanded to `false`

### A. Tap outside the menu — `onDismissRequest`

`onDismissRequest` runs when the user taps **outside** the menu (or presses back). That is the natural “please close” event:

```kotlin
DropdownMenu(
    expanded = iExpanded,
    onDismissRequest = { iExpanded = false }
) { /* ... */ }

DropdownMenu(
    expanded = oExpanded,
    onDismissRequest = { oExpanded = false }
) { /* ... */ }
```

After this, you can open a menu and close it by tapping anywhere else. Selecting an item still does nothing — that is the next step.

### B. Tap a menu item — close it in `onClick`

Choosing “Centimeters” should also hide the menu. Do that in the item’s `onClick`:

```kotlin
DropdownMenuItem(
    text = { Text("Centimeters") },
    onClick = {
        iExpanded = false
        inputUnit = "Centimeters"
        conversionFactor.value = 0.01
    }
)
```

Three jobs on one click:

| Action | Why |
| :--- | :--- |
| `iExpanded = false` | Collapse the menu |
| `inputUnit = "Centimeters"` | Remember what was chosen (button label comes later) |
| `conversionFactor.value = 0.01` | 1 cm = 0.01 m — store the multiplier |

`conversionFactor` was declared with `=` (a `MutableState<Double>`), so you assign **`.value`**, not the variable itself.

At this point only the **Centimeters** item on the **input** menu is fully wired. Meters / Feet / Millimeters still do nothing if you tap them — that is the next lecture.

---

## 4. Why this feels easier than XML

In XML you often had to:

- find the view
- show / hide it
- attach click listeners
- keep the visible UI and the data in sync yourself

Here the UI is a function of state:

```
iExpanded == true  → menu is on screen
iExpanded == false → menu is gone
```

No extra “please redraw” call. Recomposition does that.

## 5. Conversion factors (preview)

The app treats **meters** as the base unit. Factors convert *into meters*:

| Unit | Factor (to meters) |
| :--- | :--- |
| Centimeters | `0.01` |
| Meters | `1.00` |
| Feet | `0.3048` |
| Millimeters | `0.001` |

Only centimeters is assigned in this video. The rest, plus a `convertUnits()` helper, come next.

## Summary

* **Open:** button sets `iExpanded` / `oExpanded` to `true`
* **Close outside:** `onDismissRequest` sets them back to `false`
* **Close on item click:** do the same inside `onClick`, and also store the unit + factor
* The menu itself is dumb — it only *displays* the boolean

Next: a `convertUnits()` function, then the same `onClick` pattern on every input item.
