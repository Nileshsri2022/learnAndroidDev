# Register For Activity Result Demo

---

## Overview

A resource/demo lecture (no video transcript) about getting a **result back** from another Activity. The old `startActivityForResult` / `onActivityResult` pair is **deprecated**; the modern replacement is the **Activity Result API** — `registerForActivityResult`.

---

## Old way (deprecated)

```kotlin
startActivityForResult(intent, REQUEST_CODE)

override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    if (requestCode == REQUEST_CODE && resultCode == RESULT_OK) { … }
}
```

---

## New way — registerForActivityResult

```kotlin
class MainActivity : AppCompatActivity() {

    private val openSecondActivity =
        registerForActivityResult(ActivityResultContracts.StartActivityForResult()) { result ->
            if (result.resultCode == Activity.RESULT_OK) {
                val value = result.data?.getStringExtra("KEY")
                Toast.makeText(this, "Got: $value", Toast.LENGTH_SHORT).show()
            }
        }

    fun launch() {
        openSecondActivity.launch(Intent(this, SecondActivity::class.java))
    }
}
```

Second activity returns data:

```kotlin
val data = Intent().putExtra("KEY", "Hello from Second")
setResult(Activity.RESULT_OK, data)
finish()
```

---

## Built-in contracts

| Contract | Use |
| :--- | :--- |
| `StartActivityForResult()` | Generic Intent → `ActivityResult` |
| `RequestPermission()` / `RequestMultiplePermissions()` | Runtime permissions |
| `GetContent()` | Pick a file/image |
| `TakePicture()` | Camera to a Uri |

Must be registered **before** the Activity is started (as a property or in `onCreate`).

---

## Recap / cheat sheet

- `registerForActivityResult(contract) { result -> }` then `.launch(input)`.
- Callee: `setResult(RESULT_OK, intent); finish()`.
