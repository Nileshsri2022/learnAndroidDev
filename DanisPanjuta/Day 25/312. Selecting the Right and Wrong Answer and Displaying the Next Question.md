# Selecting the Right and Wrong Answer and Displaying the Next Question

---

## Overview

Implements **SUBMIT**: the wrong choice turns red, the correct answer turns green, the button changes to **GO TO NEXT QUESTION** (or **FINISH** on the last one), and the next question is loaded.

---

## New drawables

- `correct_option_border_bg.xml` — `<solid android:color="@android:color/holo_green_light" />`
- `wrong_option_border_bg.xml` — `<solid android:color="@android:color/holo_red_light" />`

---

## answerView helper

```kotlin
private fun answerView(answer: Int, drawableView: Int) {
    when (answer) {
        1 -> tvOptionOne?.background   = ContextCompat.getDrawable(this, drawableView)
        2 -> tvOptionTwo?.background   = ContextCompat.getDrawable(this, drawableView)
        3 -> tvOptionThree?.background = ContextCompat.getDrawable(this, drawableView)
        4 -> tvOptionFour?.background  = ContextCompat.getDrawable(this, drawableView)
    }
}
```

## Submit logic

```kotlin
private var mCorrectAnswers: Int = 0

R.id.btn_submit -> {
    if (mSelectedOptionPosition == 0) {
        // Nothing selected → the button acts as "next"
        mCurrentPosition++
        when {
            mCurrentPosition <= mQuestionsList!!.size -> setQuestion()
            else -> { /* go to ResultActivity — later lecture */ }
        }
    } else {
        val question = mQuestionsList?.get(mCurrentPosition - 1)
        if (question!!.correctAnswer != mSelectedOptionPosition) {
            answerView(mSelectedOptionPosition, R.drawable.wrong_option_border_bg)
        } else {
            mCorrectAnswers++
        }
        answerView(question.correctAnswer, R.drawable.correct_option_border_bg)

        if (mCurrentPosition == mQuestionsList!!.size) {
            btnSubmit?.text = "FINISH"
        } else {
            btnSubmit?.text = "GO TO NEXT QUESTION"
        }
        mSelectedOptionPosition = 0
    }
}
```

And in `setQuestion()`:

```kotlin
defaultOptionsView()
if (mCurrentPosition == mQuestionsList!!.size) btnSubmit?.text = "FINISH"
else btnSubmit?.text = "SUBMIT"
```

---

## State machine

| `mSelectedOptionPosition` | Button press does… |
| :--- | :--- |
| `1..4` | Evaluate, colour answers, change button text, reset to `0` |
| `0` | Advance to next question (or finish) |

---

## Recap / cheat sheet

- **Colour feedback** via `answerView(position, drawable)`.
- **Score:** `mCorrectAnswers++`.
- Reset `mSelectedOptionPosition = 0` so the next press advances.
