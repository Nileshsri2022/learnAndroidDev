# Setting up The Questions UI and Connecting the UI to the Model Part 2

---

## Overview

Adds the four **option TextViews** (styled like buttons with a custom border drawable) and the **SUBMIT** button, and fills the options from the current question.

---

## Default border drawable — `res/drawable/default_option_border_bg.xml`

```xml
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <stroke android:width="1dp" android:color="#E8E8E8" />
    <solid android:color="@android:color/white" />
    <corners android:radius="5dp" />
</shape>
```

| Tag | Effect |
| :--- | :--- |
| `<stroke>` | Border width + colour |
| `<solid>` | Fill colour |
| `<corners>` | Rounded corners |

---

## Option TextViews

```xml
<TextView
    android:id="@+id/tv_option_one"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_margin="10dp"
    android:background="@drawable/default_option_border_bg"
    android:gravity="center"
    android:padding="15dp"
    android:text="Apple"
    android:textColor="#7A8089"
    android:textSize="18sp" />
<!-- tv_option_two, tv_option_three, tv_option_four -->

<Button
    android:id="@+id/btn_submit"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_marginTop="16dp"
    android:text="SUBMIT"
    android:textSize="18sp" />
```

TextViews are used instead of Buttons for full control of their look (buttons come with Material tint/shadow).

---

## Filling the options — `setQuestion()`

```kotlin
private var mCurrentPosition: Int = 1
private var mQuestionsList: ArrayList<Question>? = null

private fun setQuestion() {
    val question: Question = mQuestionsList!![mCurrentPosition - 1]
    ivImage?.setImageResource(question.image)
    progressBar?.progress = mCurrentPosition
    tvProgress?.text = "$mCurrentPosition/${progressBar?.max}"
    tvQuestion?.text = question.question
    tvOptionOne?.text = question.optionOne
    tvOptionTwo?.text = question.optionTwo
    tvOptionThree?.text = question.optionThree
    tvOptionFour?.text = question.optionFour
}
```

Called from `onCreate` after `mQuestionsList = Constants.getQuestions()`.

---

## Recap / cheat sheet

- **Shape drawable:** `stroke`, `solid`, `corners`.
- **TextView-as-button** via `background` drawable.
- **`setQuestion()`** renders the question at `mCurrentPosition`.
