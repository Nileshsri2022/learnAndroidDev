# Preparing The Projects Style and Manifest

---

## Overview

Creates `MyQuizApp` (Empty Activity) and removes the **action bar** by changing the theme — learning what the **`AndroidManifest.xml`** is for along the way.

---

## The manifest

`app/manifests/AndroidManifest.xml` declares:

- Every **activity** of the app.
- Which activity is the **launcher** (first screen) via an intent-filter.
- The app **theme**, icon, label, and permissions.

```xml
<application
    android:allowBackup="true"
    android:icon="@mipmap/ic_launcher"
    android:label="@string/app_name"
    android:theme="@style/Theme.MyQuizApp">

    <activity android:name=".MainActivity" android:exported="true">
        <intent-filter>
            <action android:name="android.intent.action.MAIN" />
            <category android:name="android.intent.category.LAUNCHER" />
        </intent-filter>
    </activity>
</application>
```

---

## Removing the action bar

In `res/values/themes.xml` switch the parent theme to a **NoActionBar** variant:

```xml
<style name="Theme.MyQuizApp" parent="Theme.MaterialComponents.DayNight.NoActionBar">
    <item name="colorPrimary">@color/purple_500</item>
    …
</style>
```

Alternatively set `android:theme="@style/Theme.MaterialComponents.Light.NoActionBar"` on a single activity in the manifest.

Also check `themes.xml (night)` — dark mode uses its own file.

---

## Recap / cheat sheet

- **Manifest:** activities, launcher, theme, permissions.
- **No action bar:** parent `…NoActionBar` theme.
- Remember the **night** theme variant.
