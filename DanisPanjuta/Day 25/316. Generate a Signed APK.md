# Generate a Signed APK

---

## Overview

Resource lecture (no video transcript) explaining how to produce a **signed release build** so the app can be installed outside Android Studio or uploaded to the Play Store.

---

## APK vs AAB

| Format | Use |
| :--- | :--- |
| **APK** | Directly installable file — share / sideload |
| **AAB** (Android App Bundle) | Required by Google Play for new apps; Play generates optimized APKs per device |

---

## Steps

1. **Build → Generate Signed Bundle / APK…**
2. Choose **APK** (or Android App Bundle).
3. **Key store path → Create new…**
   - Location for the `.jks` file.
   - Key store password, key alias, key password.
   - Validity (e.g. 25+ years), name/organization fields.
4. Select the **release** build variant.
5. Finish — output lands in `app/release/app-release.apk`.

---

## ⚠️ Keep your keystore safe

- Every update of a Play Store app must be signed with the **same key** (or via Play App Signing).
- Back the `.jks` file and passwords up; never commit them to a public repository.

---

## Recap / cheat sheet

- **Build → Generate Signed Bundle / APK**, create keystore, release variant.
- **AAB** for Play Store, **APK** for sideloading.
