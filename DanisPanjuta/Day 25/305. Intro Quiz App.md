# Intro Quiz App

---

## Overview

Day 25 builds a **Flag Quiz App**. The user enters their name, answers ten "What country does this flag belong to?" questions, and sees a result screen with their score. It introduces concepts important for *any* software, not only apps: **models**, **multiple screens**, and **passing data** between them.

---

## App flow

```
MainActivity (enter name, START)
      │  Intent + putExtra(name)
      ▼
QuizQuestionsActivity
  • question text + flag ImageView
  • ProgressBar "3/10"
  • 4 option TextViews (selectable)
  • SUBMIT → green/red feedback → GO TO NEXT QUESTION
      │  Intent + putExtra(name, correct, total)
      ▼
ResultActivity (trophy, "Congratulations Denis", "Your score is 8 out of 10", FINISH)
```

---

## New concepts

| Concept | Purpose |
| :--- | :--- |
| `AndroidManifest.xml` | Registering activities, launcher, themes |
| `CardView` | Elevated rounded container |
| **Data class model** `Question` | Holds question, image, options, answer |
| `Constants` object | Question list + Intent keys |
| Custom **drawables** (shape XML) | Option borders: default / selected / correct / wrong |
| `ScrollView`, `ProgressBar` | Scrollable content, progress |
| **Intents** + `putExtra` | Navigate & pass data |
| Signed **APK** | Preparing for release |

---

## Recap / cheat sheet

- **3 activities:** Main → QuizQuestions → Result.
- Model + constants + intents are the core lessons.
