# Introduction To OpenWeatherMap And General Overview

---

## Overview

**OpenWeatherMap** (openweathermap.org) offers a free weather API — ideal for practice. The same skills apply to any API (e.g. football-data.org for a football app).

---

## Getting started

1. Sign up at openweathermap.org.
2. **API keys** tab → copy your key (activation can take a little while).
3. Docs: **API → Current Weather Data**.

---

## The endpoint

```
https://api.openweathermap.org/data/2.5/weather?lat=35&lon=139&units=metric&appid=YOUR_KEY
```

| Param | Meaning |
| :--- | :--- |
| `lat`, `lon` | Coordinates |
| `units` | `metric` (°C) / `imperial` (°F) / default Kelvin |
| `appid` | Your API key |

---

## Response (abridged)

```json
{
  "coord": { "lon": 139, "lat": 35 },
  "weather": [ { "id": 800, "main": "Clear", "description": "clear sky", "icon": "01d" } ],
  "main": { "temp": 21.3, "feels_like": 20.8, "temp_min": 20, "temp_max": 23,
            "pressure": 1012, "humidity": 60 },
  "wind": { "speed": 3.1, "deg": 350 },
  "clouds": { "all": 0 },
  "dt": 1650000000,
  "sys": { "country": "JP", "sunrise": 1649965000, "sunset": 1650012000 },
  "name": "Shuzenji"
}
```

Paste into a JSON viewer to explore the nested structure.

---

## Recap / cheat sheet

- Endpoint `/data/2.5/weather?lat&lon&units&appid`.
- Response → weather[], main, wind, sys, name.
