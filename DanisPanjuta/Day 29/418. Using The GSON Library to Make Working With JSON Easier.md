# Using The GSON Library to Make Working With JSON Easier

---

## Overview

**GSON** (by Google) converts JSON into Kotlin/Java objects (**deserialization**) and back (**serialization**) automatically — no more manual `optString` chains.

---

## Dependency

```groovy
implementation 'com.google.code.gson:gson:2.9.0'
```

---

## Model classes mirroring the JSON

```kotlin
data class ResponseData(
    val message: String,
    val user_id: Int,
    val name: String,
    val email: String,
    val mobile: Long,
    val profile_details: ProfileDetails,
    val data_list: List<DataListItem>
)

data class ProfileDetails(val is_profile_completed: Boolean, val rating: Double)
data class DataListItem(val id: Int, val value: String)
```

Property names must match JSON keys — or use `@SerializedName("user_id") val userId: Int`.

---

## Parsing

```kotlin
val responseData = Gson().fromJson(result, ResponseData::class.java)

Log.i("Message", responseData.message)
Log.i("Is Profile Completed", "${responseData.profile_details.is_profile_completed}")
for (item in responseData.data_list) {
    Log.i("Value", item.value)
}
```

Serialization: `Gson().toJson(responseData)` → JSON String.

---

## Recap / cheat sheet

- `Gson().fromJson(json, X::class.java)` / `Gson().toJson(obj)`.
- Models mirror JSON structure; `@SerializedName` for custom names.
