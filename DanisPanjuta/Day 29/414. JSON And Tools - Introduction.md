# JSON And Tools - Introduction

---

## Overview

Web data (weather, sports results…) is usually delivered as **JSON** (or XML). This lecture explains JSON's structure and introduces **Mocky** (mocky.io) to create custom HTTP responses containing JSON for practice.

---

## JSON syntax

```json
{
  "message": "Hello",
  "user_id": 1,
  "name": "Denis",
  "email": "denis@example.com",
  "mobile": 123456789,
  "profile_details": {
    "is_profile_completed": false,
    "rating": 4.5
  },
  "data_list": [
    { "id": 1, "value": "Item 1" },
    { "id": 2, "value": "Item 2" }
  ]
}
```

| Element | Syntax |
| :--- | :--- |
| **Object** | `{ "key": value, … }` |
| **Array** | `[ value, value ]` |
| Values | string `"…"`, number, `true/false`, `null`, object, array |

Keys are always strings in double quotes.

---

## Tools

| Tool | Use |
| :--- | :--- |
| **mocky.io** | Paste JSON → get a URL returning it (fake backend) |
| **JSON viewer / formatter** (e.g. jsonformatter.org, jsonviewer.stack.hu) | Pretty-print and inspect structure |
| **Postman** | Send requests and inspect responses |
| **JSON to Kotlin Class plugin** | Generate data classes from JSON |

---

## Recap / cheat sheet

- JSON = objects `{}` + arrays `[]` of key/value data.
- Mocky for fake endpoints while learning.
