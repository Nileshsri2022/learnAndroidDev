# Summary - Weather App

---

## Overview

The Weather App is finished. Applications can now pull live data from the internet — a hugely important capability for real-world apps.

---

## What you learned

| Area | Details |
| :--- | :--- |
| **HTTP** | `HttpURLConnection`, GET vs POST, background threads |
| **JSON** | Structure, `JSONObject`/`JSONArray`, Mocky for fake APIs |
| **GSON** | `fromJson` / `toJson` with data classes |
| **Retrofit** | Service interface, `@GET`, `@Query`, `enqueue` callbacks |
| **OpenWeatherMap** | API keys, query params, units |
| **Connectivity** | `ConnectivityManager`, `NetworkCapabilities` |
| **Location** | Dexter + FusedLocationProviderClient |
| **UI** | CardView grid, dynamic icons, Unix time formatting |
| **Menus** | Toolbar refresh action |
| **SharedPreferences** | Caching the last response |

---

## Data flow

```
Location ──► Retrofit (OpenWeatherMap) ──► WeatherResponse ──► SharedPreferences (JSON)

                                                          setupUI() ◄┘
```
