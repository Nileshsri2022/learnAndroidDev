# DEMO - Downloading A Website And Its Text in Android

---

## Overview

Low-level demo: open an **`HttpURLConnection`** to a Mocky URL in the **background**, read the response stream into a String, and log it. Understanding this makes libraries like Retrofit (and Firebase) less magical.

---

## Manifest

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

---

## Background task

```kotlin
private inner class CallAPILoginAsyncTask : AsyncTask<Any, Void, String>() {

    private lateinit var customProgressDialog: Dialog

    override fun onPreExecute() {
        super.onPreExecute()
        showProgressDialog()
    }

    override fun doInBackground(vararg params: Any?): String {
        var result: String
        var connection: HttpURLConnection? = null
        try {
            val url = URL("https://run.mocky.io/v3/<your-id>")
            connection = url.openConnection() as HttpURLConnection
            connection.doInput = true
            connection.doOutput = true

            val httpResult: Int = connection.responseCode
            if (httpResult == HttpURLConnection.HTTP_OK) {
                val inputStream = connection.inputStream
                val reader = BufferedReader(InputStreamReader(inputStream))
                val stringBuilder = StringBuilder()
                var line: String?
                try {
                    while (reader.readLine().also { line = it } != null) {
                        stringBuilder.append(line + "\n")
                    }
                } catch (e: IOException) {
                    e.printStackTrace()
                } finally {
                    inputStream.close()
                }
                result = stringBuilder.toString()
            } else {
                result = connection.responseMessage
            }
        } catch (e: SocketTimeoutException) {
            result = "Connection Timeout"
        } catch (e: Exception) {
            result = "Error : " + e.message
        } finally {
            connection?.disconnect()
        }
        return result
    }

    override fun onPostExecute(result: String?) {
        super.onPostExecute(result)
        cancelProgressDialog()
        Log.i("JSON RESPONSE RESULT", result!!)
    }
}

// start
CallAPILoginAsyncTask().execute()
```

| AsyncTask step | Thread |
| :--- | :--- |
| `onPreExecute` | Main — show progress |
| `doInBackground` | Background — network |
| `onPostExecute` | Main — handle result |

Network on the main thread throws `NetworkOnMainThreadException`. (`AsyncTask` is deprecated — prefer coroutines.)

---

## Recap / cheat sheet

- `URL(...).openConnection() as HttpURLConnection` → `responseCode` → read `inputStream`.
- Always background thread + `INTERNET` permission.
