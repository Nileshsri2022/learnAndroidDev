# Introduction - Weather App

---

## Overview

Day 29 builds a **Weather App** that shows the current weather for the user's location. Getting data from the internet is something almost every client project needs — the instructor has used exactly these techniques in paid contracts.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **HTTP basics** | Downloading a website's text, GET vs POST |
| **JSON** | Reading `JSONObject` / `JSONArray` manually |
| **Mocky** | Creating fake API responses for testing |
| **GSON** | Converting JSON ↔ Kotlin objects automatically |
| **OpenWeatherMap API** | A free real-world REST API with an API key |
| **Retrofit** | Type-safe HTTP client |
| **Location + permissions** | Dexter, FusedLocationProvider (reused) |
| **Custom progress dialog** | While the network call runs |
| **Menus** | Refresh button in the toolbar |
| **SharedPreferences** | Caching the last response for offline display |

---

## Recap / cheat sheet

- Internet data → JSON → models → UI; cached with SharedPreferences.
