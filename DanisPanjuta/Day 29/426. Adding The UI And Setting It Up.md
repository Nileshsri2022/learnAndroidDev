# Adding The UI And Setting It Up

---

## Overview

Builds the weather UI — a grid of **CardViews** with icons: weather main/description, temperature (°C), humidity, min/max, wind speed, location name/country, sunrise and sunset — and fills them with **`setupUI()`**.

---

## Layout idea

```
┌──────────────┬──────────────┐
│ ☀ Clear      │ 🌡 21.3°C    │
│ clear sky    │ 60 per cent  │
├──────────────┼──────────────┤
│ ⬇ 20 min     │ 💨 3.1       │
│ ⬆ 23 max     │ miles/hour   │
├──────────────┴──────────────┤
│ 📍 Shuzenji        JP        │
├──────────────┬──────────────┤
│ 🌅 06:12      │ 🌇 19:28     │
└──────────────┴──────────────┘
```

Each tile: `CardView` → horizontal `LinearLayout` → `ImageView` + vertical TextViews (`tv_main`, `tv_main_description`, `tv_temp`, `tv_humidity`, `tv_min`, `tv_max`, `tv_speed`, `tv_name`, `tv_country`, `tv_sunrise_time`, `tv_sunset_time`). Icons come from the course resources.

---

## setupUI

```kotlin
private fun setupUI(weatherList: WeatherResponse) {
    for (i in weatherList.weather.indices) {
        tv_main.text = weatherList.weather[i].main
        tv_main_description.text = weatherList.weather[i].description

        tv_temp.text = weatherList.main.temp.toString() +
            getUnit(application.resources.configuration.locales.toString())
        tv_humidity.text = weatherList.main.humidity.toString() + " per cent"
        tv_min.text = weatherList.main.temp_min.toString() + " min"
        tv_max.text = weatherList.main.temp_max.toString() + " max"
        tv_speed.text = weatherList.wind.speed.toString()
        tv_name.text = weatherList.name
        tv_country.text = weatherList.sys.country
    }
}

private fun getUnit(value: String): String {
    var unit = "°C"
    if ("US" == value || "LR" == value || "MM" == value) unit = "°F"
    return unit
}
```

The US, Liberia and Myanmar use Fahrenheit.

Call `setupUI(weatherList)` in `onResponse` when successful.

---

## Recap / cheat sheet

- CardView tiles + `setupUI(response)` mapping model → TextViews.
- Unit by locale (°C / °F).
