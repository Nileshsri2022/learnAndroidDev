# Storing The Data Via SharedPreferences And Preloading It

---

## Overview

Caches the last weather response in **SharedPreferences** (as a JSON string via GSON) so the app shows something immediately on start — even offline — while it reloads.

---

## SharedPreferences

Key-value storage for **small, simple** data (strings, ints, booleans, floats). Stored as an XML file in the app's private folder.

```kotlin
// Constants
const val PREFERENCE_NAME = "WeatherAppPreference"
const val WEATHER_RESPONSE_DATA = "weather_response_data"

private lateinit var mSharedPreferences: SharedPreferences

override fun onCreate(savedInstanceState: Bundle?) {
    …
    mSharedPreferences = getSharedPreferences(Constants.PREFERENCE_NAME, Context.MODE_PRIVATE)
    setupUI()          // show cached data immediately
    …
}
```

---

## Saving the response

```kotlin
override fun onResponse(call: Call<WeatherResponse>, response: Response<WeatherResponse>) {
    if (response.isSuccessful) {
        hideProgressDialog()
        val weatherList: WeatherResponse? = response.body()

        val weatherResponseJsonString = Gson().toJson(weatherList)
        val editor = mSharedPreferences.edit()
        editor.putString(Constants.WEATHER_RESPONSE_DATA, weatherResponseJsonString)
        editor.apply()

        setupUI()
    }
}
```

`apply()` writes asynchronously; `commit()` synchronously returns a Boolean.

---

## Loading it

```kotlin
private fun setupUI() {
    val weatherResponseJsonString = mSharedPreferences.getString(Constants.WEATHER_RESPONSE_DATA, "")
    if (!weatherResponseJsonString.isNullOrEmpty()) {
        val weatherList = Gson().fromJson(weatherResponseJsonString, WeatherResponse::class.java)
        // … same UI code as before …
    }
}
```

---

## Recap / cheat sheet

- `getSharedPreferences(name, MODE_PRIVATE)`.
- Save: `edit().putString(key, Gson().toJson(obj)).apply()`.
- Load: `getString(key, "")` → `Gson().fromJson(...)`.
