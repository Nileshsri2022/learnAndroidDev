# Adding The Sunrise And Sunset Time

---

## Overview

`sunrise` and `sunset` come as **Unix timestamps** (seconds since 1970). A helper converts them to a readable **`HH:mm`** string.

---

## Code

```kotlin
private fun unixTime(timex: Long): String? {
    val date = Date(timex * 1000L)                     // seconds → milliseconds
    val sdf = SimpleDateFormat("HH:mm", Locale.UK)
    sdf.timeZone = TimeZone.getDefault()
    return sdf.format(date)
}

// in setupUI
tv_sunrise_time.text = unixTime(weatherList.sys.sunrise)
tv_sunset_time.text = unixTime(weatherList.sys.sunset)
```

| Pattern | Meaning |
| :--- | :--- |
| `HH` | 24-hour clock |
| `hh` + `a` | 12-hour with AM/PM |
| `mm` | Minutes |

- Changed `sunrise`/`sunset` in the `Sys` model from `Int` to **`Long`**.
- `TimeZone.getDefault()` → device's local time.

---

## Recap / cheat sheet

- Unix seconds × 1000 → `Date` → `SimpleDateFormat("HH:mm")`.
