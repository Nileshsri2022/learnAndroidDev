# Adding A Refresh Button In The Menu

---

## Overview

Adds a **refresh** icon to the action bar via an **options menu**, so the user can reload the weather without restarting the app.

---

## Menu resource — `res/menu/menu_main.xml`

```xml
<menu xmlns:android="http://schemas.android.com/apk/res/android"
      xmlns:app="http://schemas.android.com/apk/res-auto">
    <item
        android:id="@+id/action_refresh"
        android:icon="@drawable/ic_refresh"
        android:orderInCategory="100"
        android:title="Refresh"
        app:showAsAction="always" />
</menu>
```

`showAsAction`: `always` (icon in bar), `ifRoom`, `never` (overflow ⋮).

---

## Activity

```kotlin
override fun onCreateOptionsMenu(menu: Menu?): Boolean {
    menuInflater.inflate(R.menu.menu_main, menu)
    return super.onCreateOptionsMenu(menu)
}

override fun onOptionsItemSelected(item: MenuItem): Boolean {
    return when (item.itemId) {
        R.id.action_refresh -> {
            requestLocationData()
            true
        }
        else -> super.onOptionsItemSelected(item)
    }
}
```

Returning `true` = event handled.

---

## Recap / cheat sheet

- `res/menu/*.xml` + `onCreateOptionsMenu` (inflate) + `onOptionsItemSelected` (handle).
