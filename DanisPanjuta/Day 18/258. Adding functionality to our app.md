## 📝 Summary

This lecture builds the user-facing interface for the room directory: the **`ChatRoomListScreen`**. Students combine Jetpack Compose layout primitives—`Scaffold`, `LazyColumn`, `Card`, and `AlertDialog`—with reactive `RoomViewModel` state to present a beautiful, interactive room browser.

Denis demonstrates how to trigger an `AlertDialog` allowing users to type a channel name, dispatch the creation request to `roomViewModel.createRoom()`, render live room items in an optimized scrollable list, and handle navigation clicks passing the selected room's ID and title to the chat screen.

## 🧠 UI State & Interaction Flow

```
User Clicks "Create Room" Button
       │
       ▼
showDialog = true ──> Compose renders AlertDialog
       │
       ▼
User enters room name ("Compose Enthusiasts") ──> Clicks "Add"
       │
       ▼
roomViewModel.createRoom("Compose Enthusiasts") ──> showDialog = false
       │
       ▼
Room added in Firestore ──> ViewModel reloads ──> LazyColumn recomposes!
       │
       ▼
User taps "Join" on Room Card ──> Navigates to ChatScreen(roomId, roomName)
```

## 💻 Detailed Compose Implementation (`chatrooms.kt`)

```kotlin
package eu.tutorials.chatroomapp.screen

import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.runtime.livedata.observeAsState
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import androidx.lifecycle.viewmodel.compose.viewModel
import eu.tutorials.chatroomapp.data.Room
import eu.tutorials.chatroomapp.viewmodel.RoomViewModel

@Composable
fun ChatRoomListScreen(
    roomViewModel: RoomViewModel = viewModel(),
    onJoinClicked: (Room) -> Unit
) {
    var showDialog by remember { mutableStateOf(false) }
    var name by remember { mutableStateOf("") }
    val rooms by roomViewModel.rooms.observeAsState(emptyList())

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        // Top Header
        Text(
            text = "Chat Rooms",
            fontSize = 24.sp,
            fontWeight = FontWeight.Bold
        )

        Spacer(modifier = Modifier.height(16.dp))

        // Scrollable list of active rooms
        LazyColumn(
            modifier = Modifier.weight(1f),
            verticalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            items(rooms) { room ->
                RoomItem(room = room, onJoinClicked = { onJoinClicked(room) })
            }
        }

        Spacer(modifier = Modifier.height(16.dp))

        // Create Room Button
        Button(
            onClick = { showDialog = true },
            modifier = Modifier.fillMaxWidth()
        ) {
            Text("Create Room")
        }

        // Modal Dialog for Room Creation
        if (showDialog) {
            AlertDialog(
                onDismissRequest = { showDialog = false },
                title = { Text("Create a new room") },
                text = {
                    OutlinedTextField(
                        value = name,
                        onValueChange = { name = it },
                        singleLine = true,
                        label = { Text("Room Name") },
                        modifier = Modifier.fillMaxWidth()
                    )
                },
                confirmButton = {
                    Button(
                        onClick = {
                            if (name.isNotBlank()) {
                                roomViewModel.createRoom(name)
                                name = ""
                                showDialog = false
                            }
                        }
                    ) {
                        Text("Add")
                    }
                },
                dismissButton = {
                    TextButton(onClick = { showDialog = false }) {
                        Text("Cancel")
                    }
                }
            )
        }
    }
}

@Composable
fun RoomItem(room: Room, onJoinClicked: () -> Unit) {
    Card(
        modifier = Modifier.fillMaxWidth(),
        elevation = CardDefaults.cardElevation(defaultElevation = 2.dp)
    ) {
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .padding(16.dp),
            horizontalArrangement = Arrangement.SpaceBetween,
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text(
                text = room.name,
                fontSize = 18.sp,
                fontWeight = FontWeight.SemiBold
            )
            OutlinedButton(onClick = onJoinClicked) {
                Text("Join")
            }
        }
    }
}
```

## 📌 Important Terms

| Term | Definition |
| :--- | :--- |
| **`LazyColumn`** | High-performance scrolling list in Jetpack Compose that only composes items currently visible on screen. |
| **`items(rooms)`** | DSL extension function feeding a list of domain objects directly into a lazy list container. |
| **`AlertDialog`** | A modal dialog component that interrupts user workflow to capture input or confirm actions. |
| **Hoisted Navigation** | Passing navigation callbacks (`onJoinClicked: (Room) -> Unit`) up to parent composables to keep screens decoupled and testable. |

---

## ❓ Q&A

**Q: Why do we use `Modifier.weight(1f)` on the `LazyColumn`?**  
A: Giving `LazyColumn` a weight of `1f` instructs it to expand and fill all remaining vertical space inside the `Column`, pinning the *"Create Room"* button cleanly to the bottom of the screen!

**Q: How does `remember { mutableStateOf(false) }` control the dialog?**  
A: In Compose, UI is declarative. When `showDialog` is `true`, Compose executes the `AlertDialog` composable block; when `false`, the dialog is omitted from the composition tree, causing it to disappear instantly.

---

## ✅ Key Takeaways

1. 📜 **Declarative lists:** `LazyColumn` renders arbitrarily large lists of chatrooms efficiently.
2. 💬 **Modal input:** `AlertDialog` pairs seamlessly with local `mutableStateOf` to prompt for new channel names.
3. 🎯 **Clean UI decoupling:** Screen composables delegate actions to ViewModels and hoist navigation events.
