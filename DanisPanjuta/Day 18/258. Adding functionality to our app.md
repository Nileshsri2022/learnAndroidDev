# Adding functionality to our app

---

## Overview

This lecture adds the **Create Room** dialog: an `OutlinedTextField` + **Create** button that writes a new `Chatroom` document to Firestore.

---

## Write

```kotlin
var roomName by remember { mutableStateOf("") }
Button(onClick = {
    if (roomName.isNotBlank()) {
        Firebase.firestore.collection("chat_rooms")
            .add(mapOf("name" to roomName))
        roomName = ""
        showDialog = false
    }
}) { Text("Create") }
```

*Or typed:* `Chatroom(name = roomName)` → `collection.add(room)`.

Security rules (for development) allow `auth != null`.

---

## Recap / cheat sheet

- **Create:** `firestore.collection("chat_rooms").add(Chatroom(name))`.
