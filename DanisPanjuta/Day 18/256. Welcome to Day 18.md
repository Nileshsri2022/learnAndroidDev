# Welcome to Day 18

---

## Overview

Day 18 — **Firebase Chat App Part 2**. With Auth working, the app adds **chat rooms**: creating rooms, listing rooms, and sending messages inside a room. Data lives in **Firestore** (or Realtime Database in early recordings) under `chat_rooms/{roomId}/messages`.

---

## Roadmap

1. `Chatroom` / `Message` data models.
2. List rooms (`LazyColumn` + `Firestore` `addSnapshotListener`).
3. Create room (dialog → Firestore `add`).
4. Inside a room: list messages, send message (`FieldValue.serverTimestamp`).

---

## Recap / cheat sheet

- **Auth** done → now **chatrooms** collection + **messages** subcollection.
