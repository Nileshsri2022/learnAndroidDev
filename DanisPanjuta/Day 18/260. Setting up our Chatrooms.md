# Setting up our Chatrooms

---

## Overview

This lecture finalizes the Firestore rules, data classes, and `ViewModel` for chatrooms, and fixes the navigation argument passing for `roomId`.

---

## Navigation

```kotlin
composable("chat/{roomId}"){ entry ->
    ChatroomScreen(roomId = entry.arguments?.getString("roomId")?:"")
}
```

`Navigation` passes `navController.navigate("chat/${room.id}")` from the room list.

---

## Summary

With this, auth → room list → chat works end-to-end (in debug rules mode). The download at the next lecture contains the complete source.
