# Chatroom Lists

---

## Overview

This lecture models a `Chatroom` and displays the list of rooms from Firestore.

---

## Model

```kotlin
data class Chatroom(val id: String = "", val name: String = "")
```

Firestore collection `chat_rooms` → each document is a `Chatroom`.

---

## Read

```kotlin
val rooms = remember { mutableStateListOf<Chatroom>() }
Firebase.firestore.collection("chat_rooms")
    .addSnapshotListener { snapshot, _ ->
        if (snapshot != null) {
            rooms.clear()
            rooms.addAll(snapshot.documents.map { it.toObject<Chatroom>()!! })
        }
    }

LazyColumn { items(rooms, key={it.id}) { room -> RoomItem(room){ navController.navigate("chat/${room.id}") } } }
```

`addSnapshotListener` streams updates — new rooms appear without reload.

---

## Recap / cheat sheet

- **Collection:** `chat_rooms` → `Chatroom(id, name)`.
- **List:** `addSnapshotListener` + `LazyColumn`.
