# Chatrooms

---

## Overview

Tapping a room should open its **message list**. This lecture adds `ChatroomScreen(roomId)` that listens to `chat_rooms/{roomId}/messages` ordered by `timestamp`.

---

## Messages

```kotlin
data class Message(val id:String="", val text:String="", val sender:String="", val timestamp: Date? = null)

Firebase.firestore.collection("chat_rooms").document(roomId)
    .collection("messages")
    .orderBy("timestamp")
    .addSnapshotListener { snapshot, _ ->
        messages.clear()
        messages.addAll(snapshot.documents.map { it.toObject<Message>()!! })
    }
```

UI:

```kotlin
LazyColumn { items(messages){ m -> Text("${m.sender}: ${m.text}") } }
Row {
    OutlinedTextField(value=text, onValueChange={text=it})
    IconButton(onClick={
        firestore.collection("chat_rooms").document(roomId).collection("messages")
            .add(Message(text=text, sender=auth.currentUser?.email?:"", timestamp=Date()))
        text=""
    }){ Icon(Send, null) }
}
```

---

## Recap / cheat sheet

- **Subcollection:** `chat_rooms/{roomId}/messages` → `Message`.
- **Listen:** `orderBy("timestamp").addSnapshotListener`.
- **Send:** `add(Message(text, sender, Date()))`.
