# Welcome to Day 17

---

## Overview

Day 17 is the **early-access Firebase Chat App — Part 1**. The goal is a real-time chat app with **Firebase Authentication (Email)** and a project wired to **Android Studio** via the Firebase Assistant / Console. Today is setup, not yet messages.

---

## Why Firebase early?

The course inserts Firebase **before** finishing all UI topics so you see a production BaaS (Backend as a Service) early: Authentication, Firestore/Realtime Database, and `google-services.json` wiring.

---

## Day 17 roadmap

1. Create a **Firebase Project** in the Firebase Console.
2. **Add an Android Project** (package name, SHA-1, `google-services.json`).
3. Enable **Email Authentication** (allow users to register/login).
4. Add Firebase Auth SDK dependency and test registration flow.

---

## Recap / cheat sheet

- **Firebase Project** → **Android App** → `google-services.json` in `app/`.
- **Auth:** Console → Authentication → Sign-in method → Email/Password → Enable.
