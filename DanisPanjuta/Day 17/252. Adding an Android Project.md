# Adding an Android Project

---

## Overview

Link the Android app's package to the Firebase Project so `google-services.json` can be generated.

---

## Steps

1. In the Firebase Project overview, click **Add app** → **Android** (Android icon).
2. **Android package name:** copy from `app/build.gradle.kts` `applicationId` (e.g. `eu.tutorials.chatapp`) — must match exactly.
3. **App nickname:** optional, e.g. *ChatApp Android*.
4. **Debug signing certificate SHA-1:** via Gradle `signingReport` (same method as Day 12 Maps API key) — paste the `SHA1:` line. Optional but required for some Auth flows.
5. Click **Register app**.
6. Download **`google-services.json`** → move it to `app/` (module root, sibling to `build.gradle.kts`). Do not rename, do not commit to public repos if the project is private.
7. Add the classpath/plugins as instructed:

`app/build.gradle.kts`:
```kotlin
plugins {
    id("com.android.application")
    id("org.jetbrains.kotlin.android")
    id("com.google.gms.google-services") // Firebase
}
```

`build.gradle.kts` (project):
```kotlin
plugins { id("com.google.gms.google-services") version "4.4.1" apply false }
```

Sync Gradle.

---

## Recap / cheat sheet

- **Package** must equal `applicationId`.
- **SHA-1** from `signingReport`.
- **`google-services.json`** → `app/google-services.json`.
- Add `google-services` plugin + sync.
