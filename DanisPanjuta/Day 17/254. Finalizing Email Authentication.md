# Finalizing Email Authentication

---

## Overview

This lecture tests registration and sign-in with `FirebaseAuth` and handles `createUserWithEmailAndPassword` / `signInWithEmailAndPassword` results (success → navigate home, failure → snackbar with `exception.message`).

---

## API

```kotlin
val auth = Firebase.auth // FirebaseAuth.getInstance()

auth.createUserWithEmailAndPassword(email, password)
    .addOnCompleteListener { task ->
        if (task.isSuccessful) {
            // navigate to chat list / home
        } else {
            // show task.exception?.message
        }
    }

auth.signInWithEmailAndPassword(email, password)
    .addOnCompleteListener { /* same */ }
```

Email/password validation (non-empty, `password.length >= 6`) is done before the call.

---

## Recap / cheat sheet

- **Register:** `createUserWithEmailAndPassword(email, pwd)`.
- **Login:** `signInWithEmailAndPassword(email, pwd)`.
- Handle `isSuccessful` vs `exception.message`.
