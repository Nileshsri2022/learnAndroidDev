# Create a Firebase Project

---

## Overview

Every Firebase feature lives in a **Firebase Project**, which is a wrapper around a Google Cloud Project. This lecture creates one from the Firebase Console.

---

## Steps

1. Go to **https://console.firebase.google.com**.
2. Click **Add project** (or *Create a project*).
3. Name: e.g. *ChatApp* or *MyChatApp* (ID auto-generated, like `chatapp-12345`).
4. Optionally enable **Google Analytics** (toggle — either is fine for the course; the lecture disables it to keep setup minimal).
5. Click **Create project** → wait for provisioning → **Continue**.

The project now appears on the Firebase Console home.

---

## Recap / cheat sheet

- **Console:** firebase.google.com → Add project → name → Analytics optional → Create.
