# Firebase Email Authentication

---

## Overview

With the Android app registered, **Email/Password** authentication is enabled in the Firebase Console.

---

## Steps

1. Console → **Build** → **Authentication** → **Get started** (if first time).
2. **Sign-in method** tab → **Email/Password** → toggle **Enable** (first switch; second switch *Email link* is optional, left disabled).
3. Click **Save**.

The method now shows as **Enabled** with 0 users.

---

## SDK

`app/build.gradle.kts`:

```kotlin
dependencies {
    implementation(platform("com.google.firebase:firebase-bom:32.7.0"))
    implementation("com.google.firebase:firebase-auth-ktx")
}
```

`firebase-bom` manages versioning — no explicit version on `firebase-auth-ktx`.

---

## Recap / cheat sheet

- **Enable:** Authentication → Sign-in method → Email/Password → Enable → Save.
- **Dep:** `firebase-bom` + `firebase-auth-ktx`.
