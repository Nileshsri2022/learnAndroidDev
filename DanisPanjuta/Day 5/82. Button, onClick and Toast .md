Here is a structured breakdown of everything covered in this lesson on using interactive `Button` composables and displaying `Toast` messages.

---

### 1. The `Button` Composable
`Button` is a Material Design component that users can tap. It is also a `@Composable` function.

```kotlin
Button(
    onClick = { /* Action to run on tap */ }
) {
    // Content inside the button (usually a Text label)
    Text("Click me")
}
```

* **`onClick`:** A mandatory parameter that takes a **lambda (anonymous function)**. This code block executes the moment the user taps the button.
* **Trailing Lambda:** The content inside the curly braces `{ Text(...) }` defines what the button displays. It is a separate content slot from the `onClick`.

> **Note:** Buttons have built-in visual feedback (ripple effects and subtle animations) when pressed.

---

### 2. What is `Context`?
Before displaying system-level pop-ups, Android needs to know **where** in your app the message should appear.

* **`Context`** is an Android object that holds information about the current application environment (the screen, resources, and current activity).

In Jetpack Compose, you retrieve it using:
```kotlin
val context = LocalContext.current
```
* **Import:** `import androidx.compose.ui.platform.LocalContext`

---

### 3. What is a `Toast`?
A `Toast` is a small, non-intrusive pop-up message that appears briefly at the bottom of the screen (over the app). It is used for simple feedback like "Saved!" or "Thanks for clicking."

```kotlin
Toast.makeText(
    context,                    // Where to show it
    "Thanks for clicking",     // The message text
    Toast.LENGTH_LONG          // How long to show it
).show()                       // Actually display it
```

* **Duration Options:**
  * `Toast.LENGTH_SHORT` (~2 seconds)
  * `Toast.LENGTH_LONG` (~3.5 seconds)
* **Two Steps:** You must first *create* the toast with `makeText()`, then *display* it by calling `.show()`.

---

### 4. Putting It Together Inside `onClick`

Because `onClick` expects executable code, we define the `context` outside the button and use it inside the lambda:

```kotlin
@Composable
fun UnitConverter() {
    val context = LocalContext.current // Get the app's current context

    Column {
        // ... other UI ...

        Row {
            Button(onClick = {
                // This anonymous function runs when clicked
                Toast.makeText(
                    context,
                    "Thanks for clicking",
                    Toast.LENGTH_LONG
                ).show()
            }) {
                Text("Click me")
            }
        }
    }
}
```

**Key Concept:** The code inside `{ ... }` for `onClick` is another example of an **anonymous function**—it has no name (`fun clickHandler()`) but executes immediately when the event (the button tap) occurs.

---

### Summary Checklist
1. **Button Structure:** Requires `onClick` (action) and a content block (label/text).
2. **Event Handling:** `onClick = { ... }` is a lambda that executes on user interaction.
3. **`LocalContext.current`:** The Compose way of accessing the Android `Context` needed for Toasts.
4. **Toast Flow:** `Toast.makeText(...).show()` — build it, then trigger it with `.show()`.
5. **Visual Feedback:** Compose buttons handle their own animations (ripple/press effects) automatically.
