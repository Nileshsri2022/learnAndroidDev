## 📝 Summary

Day 5 is a major turning point in the course. Having mastered Kotlin syntax, variables, conditionals, functions, classes, and lists over Days 2–4, students now begin building **real Android applications**. 

Today marks the start of the **Unit Converter** application. The day introduces **Jetpack Compose**—Google's modern, declarative UI toolkit—and walks through composables, buttons, text fields, dropdown menus, and toast notifications. While state management is reserved for Day 6 to avoid overwhelm, Day 5 builds the full interactive layout and structure of our first mobile app.

## 📒 Detailed Notes

### The Transition to Android App Development
- In **Days 2–4**, the focus was entirely on core Kotlin:
  - Variables, types, and operators (Rock, Paper, Scissors)
  - Functions, return values, classes, and objects (Coffee Machine)
  - Lists, mutability, and encapsulation (Bank Account)
- Now, on **Day 5**, that Kotlin knowledge is directly applied to Android development. Kotlin is no longer running in isolation on the terminal—it drives real mobile interfaces.

### What We Build Today: Unit Converter
- The project for Days 5 and 6 is the **Unit Converter** app:
  - An input field where users enter an amount.
  - Two dropdown menus: one for selecting the **input unit** (Centimeters, Meters, Feet, Millimeters) and one for selecting the **output unit**.
  - A conversion engine that computes and displays the converted value in real time.
- On **Day 5**, the focus is on mastering Compose UI building blocks:
  - `Text` and `OutlinedTextField`
  - `Button` and `Toast` messages
  - Layout containers: `Column`, `Row`, `Box`
  - `DropdownMenu` and `DropdownMenuItem`
  - Alignment, arrangement, `Spacer`, and `Modifier.padding`

### Why State is Deferred to Day 6
- Building a UI and handling reactive state are two distinct cognitive hurdles.
- Denis deliberately divides the app across two days:
  - **Day 5:** Mastering the composable widgets, layouts, styling, modifiers, and previews.
  - **Day 6:** Introducing `remember`, `mutableStateOf`, recomposition, and connecting calculation logic to the UI.

## 📌 Important Terms

| Term | Definition |
| :--- | :--- |
| **Jetpack Compose** | Android's modern toolkit for building native UI using declarative Kotlin code. |
| **Composable** | A Kotlin function annotated with `@Composable` that emits UI elements to the screen. |
| **Declarative UI** | A paradigm where you describe *what* the UI should look like for a given state, rather than imperatively mutating views. |
| **Unit Converter** | The first hands-on Android project built in the course, covering measurement conversions. |

## ❓ Q&A

**Q: Why didn't we build Android apps on Day 1?**  
A: Android app architecture requires understanding Kotlin classes, functions, and imports. Without the foundation built in Days 2–4, beginners would be overwhelmed trying to understand the generated boilerplate code.

**Q: Will this app run on real devices?**  
A: Yes! By the end of Day 5 and Day 6, this app can run on both the Android Virtual Device (emulator) and any physical Android phone via USB debugging.
