## 📝 Day 5 Executive Summary

Day 5 moved learners from Kotlin console applications into native Android app development using **Jetpack Compose**. Over the course of the day, we constructed the complete visual user interface for the **Unit Converter** application. We explored how Compose's declarative model differs from legacy XML, how layout containers (`Column`, `Row`, `Box`) position child elements, how `Modifier` controls sizing and alignment, and how interactive widgets like `OutlinedTextField`, `Button`, and `DropdownMenu` are assembled.

## 🧠 Mastered Concepts & Architecture

### 1. Jetpack Compose vs. XML
- **Declarative Paradigm:** In Compose, UI is written as pure Kotlin functions annotated with `@Composable`. 
- **No XML Needed:** No need for `layout.xml` files or `findViewById()` lookups. The UI structure and presentation logic are unified in Kotlin.

### 2. Core Layout Containers
- **`Column`:** Places items vertically from top to bottom.
- **`Row`:** Places items horizontally from left to right.
- **`Box`:** Stacks items on top of each other (used to position dropdown menus relative to trigger buttons).

### 3. Modifiers, Alignment & Arrangement
- **`Modifier.fillMaxSize()` / `Modifier.fillMaxWidth()`:** Expands the composable to occupy all available space.
- **`verticalArrangement = Arrangement.Center`:** Controls how children are distributed along the primary axis (vertical for Columns).
- **`horizontalAlignment = Alignment.CenterHorizontally`:** Centers items along the cross axis (horizontal for Columns).
- **`Spacer(modifier = Modifier.height(16.dp))` vs. `Modifier.padding(16.dp)`:**
  - `Spacer` creates explicit empty gaps between sibling widgets.
  - `padding` adds inset spacing around or inside a specific composable.

### 4. Interactive UI Elements
- **`Text("...")`:** Displays styled text strings.
- **`OutlinedTextField(value = ..., onValueChange = ...)`:** Material design input box with an outline border.
- **`Button(onClick = { ... })`:** Clickable Material button with an action callback.
- **`DropdownMenu` & `DropdownMenuItem`:** Pop-up selection menu anchored to a parent container (`Box`).
- **`Icon(Icons.Default.ArrowDropDown, contentDescription = "...")`:** Material vector icons.
- **`Toast.makeText(context, text, Toast.LENGTH_SHORT).show()`:** Native transient popups for quick alerts.

@Composable
fun UnitConverter() {
    Column(
        modifier = Modifier.fillMaxSize(),
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        // App Title
        Text(
            text = "Unit Converter",
            style = MaterialTheme.typography.headlineMedium
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // Input text field
        OutlinedTextField(
            value = "",
            onValueChange = { /* Will connect in Day 6 */ },
            label = { Text("Enter Value") }
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // Selectors Row
        Row {
            // Input Selection Box
            Box {
                Button(onClick = { /* Open input dropdown */ }) {
                    Text("Select")
                    Icon(Icons.Default.ArrowDropDown, contentDescription = "Arrow Down")
                }
                DropdownMenu(expanded = false, onDismissRequest = { }) {
                    DropdownMenuItem(text = { Text("Centimeters") }, onClick = { })
                    DropdownMenuItem(text = { Text("Meters") }, onClick = { })
                    DropdownMenuItem(text = { Text("Feet") }, onClick = { })
                    DropdownMenuItem(text = { Text("Millimeters") }, onClick = { })
                }
            }
            
            Spacer(modifier = Modifier.width(16.dp))
            
            // Output Selection Box
            Box {
                Button(onClick = { /* Open output dropdown */ }) {
                    Text("Select")
                    Icon(Icons.Default.ArrowDropDown, contentDescription = "Arrow Down")
                }
                DropdownMenu(expanded = false, onDismissRequest = { }) {

        // Result Output

            text = "Result: 0.0",
            style = MaterialTheme.typography.headlineSmall
        )
    }
}

## 📌 Quick Reference Table

| Composable / API | Purpose | Common Syntax |
| :--- | :--- | :--- |
| `@Composable` | Marks a Kotlin function as a UI producer | `@Composable fun MyWidget() { ... }` |
| `@Preview` | Renders a live preview in Android Studio | `@Preview(showBackground = true) @Composable ...` |
| `Column` | Vertical layout container | `Column(verticalArrangement = ..., horizontalAlignment = ...)` |
| `Row` | Horizontal layout container | `Row(horizontalArrangement = ..., verticalAlignment = ...)` |
| `Box` | Stack layout / Menu anchor container | `Box { TriggerButton(); DropdownMenu(...) }` |
| `OutlinedTextField` | Bordered text input field | `OutlinedTextField(value = val, onValueChange = { ... })` |
| `Button` | Material design button | `Button(onClick = { /* action */ }) { Text(...) }` |
| `DropdownMenu` | Floating popup list | `DropdownMenu(expanded = isOpen, onDismissRequest = { ... })` |

| `Toast` | Transient system alert message | `Toast.makeText(context, "Saved", Toast.LENGTH_SHORT).show()` |

## ❓ Self-Check Questions

??? question "Why do we wrap a Button and DropdownMenu inside a Box?"
    A `DropdownMenu` needs an anchor view to determine where it should appear on screen. By wrapping both the trigger `Button` and the `DropdownMenu` inside a `Box`, the dropdown positions itself directly adjacent to the button when expanded.

??? question "What happens if you omit `.show()` on a Toast?"
    The `Toast` object is instantiated in memory, but it will **never be displayed** on the user's screen. Forgetting `.show()` is one of the most common beginner Android bugs!

??? question "What is the difference between `Arrangement` and `Alignment` in a Column?"
    - **`Arrangement`** operates along the **main axis** (vertical for a Column, horizontal for a Row), deciding how items are distributed (e.g. `Center`, `SpaceBetween`, `SpaceEvenly`).
    - **`Alignment`** operates along the **cross axis** (horizontal for a Column, vertical for a Row), deciding how each item is aligned sideways (e.g. `CenterHorizontally`, `Start`, `End`).
