### **What it points to**

* The official Android Studio download page:
  **<https://developer.android.com/studio>**
* The **archive of all past releases**, which is what you actually want if you need to
  match the course version:
  **<https://developer.android.com/studio/archive>**

---

### **Why the archive matters more than the main page**

The main download page only ever offers the **newest** stable build, and it changes every
few weeks. The course was recorded on a specific version
(**Android Studio Hedgehog 2023.1.1 RC1**), and using a different version means:

* menus and panels in **different positions**
* settings that **don't exist** in your build
* generated template code that **looks different**

The archive lets you pick the exact release the instructor is on. The next lecture
(**Downloading Android Studio**) walks through finding it there.

---

### **Key Takeaways**

1. This is a **download shortcut**, not a teaching video.
2. Prefer the **archive page** over the front page so you can match the course version.
3. Version-matching is about the **IDE's UI**, not about Kotlin — the language basics
   taught in this course do not change between Android Studio releases.
