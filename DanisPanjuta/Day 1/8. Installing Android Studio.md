Here is a clear, structured breakdown of the lecture on **installing Android Studio on Windows**.

---

### **1. Overview**

With the download finished, this lecture walks through the actual installation. It is a
standard Windows installer — **every default can be accepted** without consequence.

---

### **2. Step-by-Step Installation**

| Step | What to do | Notes |
| :--- | :--- | :--- |
| **1** | Find the downloaded file | It is an **`.exe`**, e.g. `android-studio-2023.1.1.23-windows.exe` |
| **2** | Double-click it | The **"Welcome to Android Studio Setup"** window appears |
| **3** | Click **Next** | Leave the component defaults checked |
| **4** | Click **Next** again | Choose the **install location** — the default is fine |
| **5** | Optionally rename the Start Menu folder | Purely cosmetic; skip it |
| **6** | Click **Install** | The installer extracts files and writes Android Studio to disk |
| **7** | Click **Next** when it finishes | |
| **8** | Leave **"Start Android Studio"** ticked, click **Finish** | Android Studio launches immediately |

---

### **3. What Happens at First Launch**

Once it opens you are greeted by the **welcome screen**, which has the sidebar options
covered in *Setting up our First Project*:

* **Customize** — theme, font size, keymap
* **Plugins** — marketplace for extensions
* **Learn** — official docs and tutorials
* **New Project** — where you actually start building

The next lecture goes over that welcome screen and the wider interface.

---

### **Key Takeaways**

1. The installer is the **`.exe`** you downloaded in the previous lecture.
2. **Accept every default** — location, components and Start Menu name all work as-is.
3. Ticking **"Start Android Studio"** on the final screen saves a manual launch.
4. First launch shows the **welcome screen**, not an editor — you create a project from
   there before any code appears.
5. If you are on **Linux or macOS**, the flow differs slightly; Linux has its own lecture
   in this day.
