---

### **1. Overview**

Everything so far has been setup. This is the first lecture where you **modify the program
so it does something different** — and the change is deliberately small so the cause and
effect are obvious.

---

### **2. Step 1 — Run the App As-Is**

Press **Run ▶** (the emulator should already be on). Gradle builds, the app installs, and
the screen shows:

```text
Hello Android
```

* The text renders **quite small** — that is normal for a bare `Text` composable.
* Any leftover visual glitch from an earlier run disappears after a fresh install.

---

### **3. Step 2 — Find the Text in the Code**

The instructor asks you to **pause and find it yourself**. The path:

```
Project panel → app → kotlin+java → eu.tutorials.myfirstapp → MainActivity.kt
```

The fast way is **Ctrl + F** (⌘ + F on macOS) and search for `Hello`:

```kotlin
Text(text = "Hello $name!", modifier = modifier)   // around line 32
```

---

### **4. Step 3 — Change `Hello` → `Welcome`**

Edit the string **in the code**, not in the search box:

```kotlin
Text(text = "Welcome $name!", modifier = modifier)
```

Press **Run ▶** again. The emulator now shows:

```text
Welcome Android
```

✅ First successful code change.

---

### **5. Step 4 — Change the Name**

Searching for `Android` finds it in **two places**. Both are worth understanding:

| Location | What it affects |
| :--- | :--- |
| Inside `onCreate` → `Greeting("Android")` | The text shown **on the running app** |
| Inside `GreetingPreview` → `Greeting("Android")` | The text shown in the **preview pane** only |

Double-click the word and change it to your own name:

```kotlin
Greeting("Dennis")
```

Re-run:

```text
Welcome Dennis
```

---

### **6. Why It Works — The Two Pieces Are Connected**

```kotlin
// The value is PASSED IN here...
Greeting("Dennis")

// ...and RECEIVED here as `name`
@Composable
fun Greeting(name: String, modifier: Modifier = Modifier) {
    Text(text = "Welcome $name!", modifier = modifier)
}
```

* **`Greeting`** is a function — a named block of reusable code.
* **`"Dennis"`** is the **argument** you pass in.
* **`name`** is the **parameter** that receives it.
* **`$name`** is a **string template**: Kotlin substitutes the value at runtime, so the
  displayed text becomes `Welcome Dennis`.

Change the string to **anything you like** — paste in a whole sentence. The instructor's

---

### **Key Takeaways**

1. **Run first, change one thing, run again** — the core debugging loop for the whole
   course.
2. **Ctrl/⌘ + F** is the fastest way to locate text in a file.
3. `Android` appears **twice**: once for the **running app**, once for the **preview**.
   Changing only one leaves the other stale.
4. `Greeting("Dennis")` → `name` → `"Welcome $name!"` is the first example of
   **passing data into a function**.
5. Editing a string requires **no new concepts** — just save and re-run.
