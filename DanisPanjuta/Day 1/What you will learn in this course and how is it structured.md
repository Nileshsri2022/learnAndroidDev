## 📌 Important Terms

| Term | Definition |
|------|-----------|
| **Kotlin** | Object-oriented programming language used for Android development |
| **Jetpack Compose** | Google's modern toolkit for building Android UIs declaratively |
| **XML** | Older method of building Android user interfaces (still widely used) |
| **Emulator** | A virtual Android device on your PC for testing apps |
| **MVVM** | Model-View-ViewModel — an architectural pattern for clean code |
| **REST API** | Interface for communicating with web services over HTTP |
| **JSON** | JavaScript Object Notation — data format used in APIs |
| **Retrofit** | Library for making HTTP/network requests in Android |
| **Room Database** | Android's local database solution built on SQLite |
| **CRUD** | Create, Read, Update, Delete — basic database operations |
| **Dao** | Data Access Object — defines database query methods |
| **Dependency Injection** | Design pattern that provides required objects to a class |
| **Geocoding** | Converting GPS coordinates (lat/lng) into a human-readable address |
| **NavHost / NavController** | Jetpack Compose tools for navigating between screens |
| **Serialization** | Converting objects to a storable/transferable format |
| **Firebase** | Google's cloud platform for authentication, storage, and databases |
| **Composable** | A function in Jetpack Compose that defines a piece of UI |
| **Lazy Column** | A Compose UI component that efficiently displays scrollable lists |
| **Context** | An Android object that provides access to system resources and services |
| **State** | Data that drives what is currently displayed in the UI |

## ❓ Q&A

**Q: Why learn Kotlin basics before building Android apps?**
A: Even the simplest Android app requires a significant amount of code. Without understanding Kotlin fundamentals first, the code would be overwhelming and confusing. Days 2–4 build that necessary foundation.

---

**Q: Why is Jetpack Compose taught before XML if XML came first?**
A: Jetpack Compose is now Google's recommended approach (since Android 14). Learning the modern approach first sets the right habits, and XML is then introduced as a secondary, legacy skill.

---

**Q: Why learn XML at all if Jetpack Compose is the future?**
A: The majority of existing companies and apps still use XML. To get hired and work with legacy codebases, developers must understand both approaches. Starting a new app from scratch → use Compose. Working at an existing company → you'll likely need XML.

---

**Q: What is Geocoding and why does it matter?**
A: Geocoding converts raw GPS data (latitude & longitude) into a human-readable address. It matters because displaying "40.7128° N, 74.0060° W" is not useful to users, but "New York, NY" is.

---

**Q: What is the MVVM pattern and why is it important?**
A: MVVM (Model-View-ViewModel) is an architectural pattern that separates UI logic from business logic, making code cleaner, easier to test, and more maintainable. It is a required skill for professional Android development.

---

**Q: Is the Trello Clone necessary to complete?**
A: It is treated as a bonus. By the time students reach it, they will already have the skills to build it independently. However, following along with a guided project can make complex concepts easier to apply.

---

**Q: Can I skip ahead to the XML section directly?**
A: Yes, but you should still complete Days 2–4 (Kotlin basics) before jumping into the XML section, as they are prerequisites for understanding the code in all apps.

## ✅ Key Takeaways

1. 🛠️ **Setup first** — Android Studio and the emulator are configured on Day 1, enabling fast testing without a physical device.
2. 🧱 **Kotlin before Android** — Understanding OOP, functions, lists, and objects in Kotlin is essential before writing any Android UI code.
3. 🎨 **Jetpack Compose is the future** — Google's recommended modern UI toolkit, taught from Day 5 onward.
4. 🏗️ **MVVM is non-negotiable** — Any aspiring Android developer must understand this architecture to work professionally.
5. 🌐 **APIs & networking are core skills** — JSON, Retrofit, and RESTful APIs are introduced early and used throughout the course.
6. 🗄️ **Data persistence matters** — Room Database and Firebase together cover both local and cloud data storage needs.
7. 🗺️ **XML is still relevant** — Legacy codebases are everywhere; understanding both Compose and XML makes you a more employable developer.
8. 🏆 **The Trello Clone is the capstone** — It combines Firebase, drag & drop, user management, and cloud storage into the course's largest project.
9. 💼 **Job-ready goal** — The course is explicitly designed to prepare students for a **junior Android developer** role.
10. 📦 **External libraries save time** — A major theme of the course is learning to leverage packages (Retrofit, Google Maps SDK, Firebase, etc.) rather than building everything from scratch.
