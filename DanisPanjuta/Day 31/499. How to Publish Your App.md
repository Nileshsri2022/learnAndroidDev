# How to Publish Your App

---

## Overview

A resource lecture (no video transcript) on getting an app onto **Google Play**.

---

## Steps

1. **Google Play Console** account (one-time registration fee).
2. Prepare the app:
   - Unique `applicationId`, bump `versionCode` / `versionName`.
   - Remove debug logs, enable **R8/minify** for release.
   - Target the required recent **targetSdk**.
3. **Sign** the app — generate an upload key (Build → Generate Signed Bundle / APK) and enrol in **Play App Signing**.
4. Build an **Android App Bundle (`.aab`)** — Play's required format.
5. Create the app in Play Console and fill in the **store listing**: title, descriptions, icon (512×512), feature graphic, screenshots.
6. Complete **App content**: privacy policy, data safety form, content rating, target audience, ads declaration.
7. Upload to a **testing track** (internal → closed → open); new personal accounts must run a closed test with testers before production.
8. Roll out to **Production** and wait for review.

## Release build config

```groovy
buildTypes {
    release {
        minifyEnabled true
        shrinkResources true
        proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
    }
}
```

---

## Recap / cheat sheet

- Play Console → signed `.aab` → store listing + app content → testing track → production.
- Keep your upload key safe.
