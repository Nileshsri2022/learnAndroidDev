# How To Learn More

---

## Overview

A resource lecture (no video transcript) pointing to ways of continuing your Android learning after the course.

---

## Where to go next

| Resource | Why |
| :--- | :--- |
| **developer.android.com** (guides, codelabs) | Official, always up to date |
| **Android Basics / Modern Android Development** pathways | Jetpack Compose, architecture, testing |
| **Kotlin docs & Kotlin Koans** | Deepen the language (coroutines, Flow, generics) |
| **Official samples (Now in Android)** | Production-grade architecture reference |
| **Stack Overflow / Kotlin Slack / Reddit r/androiddev** | Community help |
| **Open-source apps on GitHub** | Read real code |

---

## Topics worth learning next

- **Jetpack Compose** (declarative UI — the Compose track of this repo).
- **Architecture:** MVVM, ViewModel, StateFlow, Repository, Clean Architecture.
- **Dependency injection:** Hilt / Koin.
- **Coroutines & Flow** instead of `AsyncTask` / callbacks.
- **Testing:** JUnit, Espresso, Compose testing.
- **Jetpack:** Room, DataStore, WorkManager, Navigation, Paging.

---

## Learning habit

Build **your own projects** — cloning apps you use, then adding features — is the fastest way to consolidate knowledge.

---

## Recap / cheat sheet

- Official docs + codelabs, samples, community.
- Next topics: Compose, MVVM, Hilt, coroutines, testing.
