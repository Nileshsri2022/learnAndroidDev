# How to Build Games for Android

---

## Overview

A resource lecture (no video transcript) about options for game development on Android.

---

## Options

| Tool | Language | Best for |
| :--- | :--- | :--- |
| **Unity** | C# | Most popular; 2D/3D, cross-platform |
| **Godot** | GDScript / C# | Free & open source, lightweight |
| **Unreal Engine** | C++ / Blueprints | High-end 3D |
| **libGDX / KorGE** | Java / Kotlin | Code-first 2D games in the JVM world |
| **Android Canvas / Compose Canvas** | Kotlin | Simple 2D games (like the Drawing App techniques) |

---

## Getting started

- Start small: Pong, Flappy-style, puzzle games.
- Learn the **game loop** (update → render at fixed frame rate), input handling, collision detection.
- Play Games Services for achievements/leaderboards.

---

## Recap / cheat sheet

- Engines (Unity/Godot) for serious games; Kotlin + Canvas / libGDX / KorGE for code-first 2D.
