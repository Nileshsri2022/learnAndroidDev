# Adding the required Dependencies to our Shopping List App

---

## Overview

Every new capability in Android starts with **dependencies**. Day 12 reopens the Shopping List app built on Day 7 and adds four groups of libraries at once: the Maps Compose wrapper, the ViewModel Compose integration, Retrofit/Gson for the Geocoding HTTP call, and Navigation Compose.

This lecture is deliberately short — sync once and the rest of the day is unblocked.

---

## Step 1 — open the correct project

Open the **Shopping List** project from Day 7. If it is not available, download the snapshot provided at this point in the course and open it. Wait for the initial Gradle sync to finish before editing anything.

---

## Step 2 — add the dependencies

Open `app/build.gradle.kts` (module `:app`) and scroll to the `dependencies { }` block.

Add the following (use the latest stable versions offered by Android Studio's autocomplete; versions below are the ones current for the Android 14 recording):

```kotlin
dependencies {
    // — already present from Days 5–7 —
    implementation("androidx.core:core-ktx:1.12.0")
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.material3:material3")

    // 1. Google Maps — the Compose wrapper and the underlying Play Services maps
    implementation("com.google.maps.android:maps-compose:2.11.4")
    implementation("com.google.android.gms:play-services-maps:18.2.0")

    // 2. ViewModel for Compose — the viewModel() delegate
    implementation("androidx.lifecycle:lifecycle-viewmodel-compose:2.7.0")

    // 3. Networking — Retrofit + Gson converter (reused from Day 9)
    implementation("com.squareup.retrofit2:retrofit:2.9.0")
    implementation("com.squareup.retrofit2:converter-gson:2.9.0")

    // 4. Navigation for Compose
    implementation("androidx.navigation:navigation-compose:2.7.6")

    // Note: play-services-location is added later when LocationUtils is copied
    // implementation("com.google.android.gms:play-services-location:21.0.1")
}
```

### What each group unlocks

| Dependency | What it provides |
| :--- | :--- |
| `maps-compose` | The `GoogleMap` composable, `Marker`, `MarkerState`, `CameraPositionState` |
| `play-services-maps` | `LatLng`, `CameraPosition`, underlying map engine |
| `lifecycle-viewmodel-compose` | `viewModel()` inside any `@Composable` |
| `retrofit` + `converter-gson` | The `@GET` interface and JSON → data class conversion |
| `navigation-compose` | `NavHost`, `composable`, `dialog`, `rememberNavController` |
| `play-services-location` (later) | `FusedLocationProviderClient`, `LocationCallback`, `Priority` |

> The lecture calls Retrofit *\"the square of retrofit\"* and *\"retrofit to convert to Json\"* — shorthand for the two artifacts above.

---

## Step 3 — sync

Click **Sync Now** in the banner that appears after editing the file. The download may take a minute on first sync. Once it finishes without errors the project is ready:

- The `GoogleMap` composable resolves without a red import.
- `@Composable` can call `viewModel()`.
- `GsonConverterFactory` resolves in the Retrofit builder.

If sync fails, verify that the `google()` Maven repository is present in `settings.gradle.kts` (it is by default in recent templates).

## Recap / cheat sheet

- File: `app/build.gradle.kts` → `dependencies { }` → **Sync Now**.
- Maps: `maps-compose` + `play-services-maps`.
- State: `lifecycle-viewmodel-compose`.
- Network: `retrofit` + `converter-gson`.
- Navigation: `navigation-compose`.
- Location: `play-services-location` (added when `LocationUtils` is copied).
- A missing or misspelled dependency shows as a red import — sync again after correcting it.
