- **Project upgrade:** reopened the Day 7 **Shopping List app** and extended it with location rather than starting from scratch.
- **Dependencies:** added `maps-compose` + `play-services-maps`, `lifecycle-viewmodel-compose`, `retrofit` + `converter-gson`, `navigation-compose` (and later `play-services-location` to support the copied `LocationUtils`).
- **Cloud console:** created project **The Shopper**, enabled **Maps SDK for Android** and **Geocoding API**, generated an **API key**, learned where to find it again under **Credentials → Show key**, and created a budget alert at the $200 free tier.
- **Key security:** restricted the key to **Android apps** (package name + **SHA-1** from `signingReport`), understood that a restricted key fails in a browser (`REQUEST_DENIED`) and that unrestricted use risks **quota theft**.
- **Browser test:** verified the Geocoding JSON shape with `https://maps.googleapis.com/maps/api/geocode/json?latlng=...&key=...` and inspected `results[0].formatted_address` and `status`.
- **Data modelling:** created `LocationData(latitude: Double, longitude: Double)`, `GeocodingResult(formatted_address: String)`, and `GeocodingResponse(results: List<GeocodingResult>, status: String)`.
- **Map UI:** built `LocationSelectionScreen` with `LatLng`, `remember { mutableStateOf }`, `rememberCameraPositionState(CameraPosition.fromLatLngZoom(userLocation.value, 10f))`, `GoogleMap(cameraPositionState, onMapClick = { userLocation.value = it })`, `Marker(state = MarkerState(position))`, and a **Set Location** button that returns `LocationData`.
- **State:** built `LocationViewModel` (`_location: MutableState<LocationData?>` + `location: State` + `_address: MutableState<List<GeocodingResult>>` + `address: State` + `fetchAddress(latlng: String)` with `viewModelScope.launch` and `try/catch`/`Log.e`).
- **Reuse:** copied `LocationUtils` wholesale from Day 11 — `hasLocationPermission`, `requestLocationUpdates` (`FusedLocationProviderClient` + `Priority.PRIORITY_HIGH_ACCURACY` + `Looper.getMainLooper()`), and `reverseGeocodeLocation` (kept, unused).
- **Model & UI update:** added `address: String` to `ShoppingItem` and redesigned `ShoppingListItem` (`Column` with `weight(1f)`, `Row` of `LocationOn` icon + `Text(item.address)`).
- **Permission flow:** copied `rememberLauncherForActivityResult(RequestMultiplePermissions())` into `ShoppingListApp` and added an **address** button inside the `AlertDialog` that either calls `requestLocationUpdates` + `navigate(\"location_screen\") { launchSingleTop = true }` or launches the permission request.
- **Networking:** defined `GeocodingApiService(@GET(\"maps/api/geocode/json\") suspend fun getAddressFromCoordinates(@Query(\"latlng\"), @Query(\"key\")): GeocodingResponse)` and `RetrofitClient(object, BASE_URL = \"https://maps.googleapis.com/\", Builder().baseUrl().addConverterFactory(GsonConverterFactory.create()).build().create(...))`.

## Key architectural takeaway

Day 12 proves that complex features are **assembled**, not written in one file:

| Component | Responsibility |
| :--- | :--- |
| `LocationData` / `Geocoding*` | Pure models — how JSON and coordinates are represented in Kotlin |
| `LocationViewModel` | Holds the chosen coordinate and the fetched address; survives navigation and rotation |
| `LocationUtils` | Platform bridge — permissions, fused location client, local geocoding |
| `GeocodingApiService` / `RetrofitClient` | Remote bridge — builds the Geocoding HTTP call and parses JSON |
| `LocationSelectionScreen` | Visual map shell — translates `LatLng` ↔ `LocationData` via a callback |
| `ShoppingListApp` / `ShoppingListItem` | Business UI — adds an `address` to each item and renders it |
| `Navigation` | Glue — hosts both destinations, shares the ViewModel and LocationUtils, decides which address string to render |

Copy the `LocationViewModel` + `LocationUtils` + `RetrofitClient` triple wholesale into any future app that needs a map picker — only the UI and the model fields change.

## Recap / cheat sheet

- Location + Maps + Geocoding + Retrofit + Navigation + MVVM combine into one app — copy-paste `LocationUtils`, the ViewModel, and the Retrofit client into future projects.
- Restrict every API key immediately after testing; hide it; never expose it in a public repository.
- `dialog` destinations in `NavHost` are the Compose idiom for pop-up map pickers — `popBackStack()` dismisses them.
- `viewModel.address.value.firstOrNull()?.formatted_address ?: \"No Address\"` is the safe projection from network result to UI string.
- Two bug fixes must not be forgotten: forward `address = address` in `ShoppingItemEditor` and in the `AlertDialog`'s `newItem`.
