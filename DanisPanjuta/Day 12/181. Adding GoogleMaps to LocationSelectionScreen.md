# Adding GoogleMaps to LocationSelectionScreen

---

## Overview

The state is ready; now the map is rendered. This lecture adds the **`GoogleMap` composable** from `maps-compose`, a **`Marker`**, and the **`Button`** that commits the chosen point back to the parent. After this, tapping the map moves the marker and pressing **Set Location** returns a `LocationData` via the `onLocationSelected` callback.

---

## Step 1 — the Column layout

`LocationSelectionScreen` shows a map on top and a button below. A `Column` with `fillMaxSize` hosts both:

```kotlin
@Composable
fun LocationSelectionScreen(
    location: LocationData,
    onLocationSelected: (LocationData) -> Unit
) {
    val userLocation = remember {
        mutableStateOf(LatLng(location.latitude, location.longitude))
    }
    val cameraPositionState = rememberCameraPositionState {
        position = CameraPosition.fromLatLngZoom(userLocation.value, 10f)
    }

    var newLocation by remember { mutableStateOf<LocationData?>(null) }

    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        GoogleMap(
            // ...
        )
        Button(
            // ...
        ) {
            Text(\"Set Location\")
        }
    }
}
```

| Element | Modifier / property | Role |
| :--- | :--- | :--- |
| `Column` | `fillMaxSize()` | Takes the whole dialog/scaffold area |
| `GoogleMap` | `weight(1f) + padding(top = 16.dp)` | Takes the majority of vertical space, proportional to weighted siblings |
| `Button` | `onClick { ... }` | Commits the selection |

### Why `weight(1f)`?

`weight` sets size **in proportion to other weighted siblings** inside a `Column` or `Row`. The map has `1f` and the button has no weight → the map expands to fill all remaining space while the button wraps its content at the bottom. Changing the map's weight to `2f` (if the button also had weight) would give the map twice the space.

## Step 2 — the `GoogleMap` composable

Import the **Compose** wrapper, not the view-based one:

```kotlin
import com.google.maps.android.compose.GoogleMap
import com.google.maps.android.compose.Marker
import com.google.maps.android.compose.MarkerState
import com.google.maps.android.compose.rememberCameraPositionState
```

```kotlin
GoogleMap(
    modifier = Modifier
        .weight(1f)
        .padding(top = 16.dp),
    cameraPositionState = cameraPositionState,
    onMapClick = { latLng ->
        userLocation.value = latLng
    }
) {
    Marker(
        state = MarkerState(position = userLocation.value)
    )
}
```

| Property | Value | Meaning |
| :--- | :--- | :--- |
| `cameraPositionState` | `cameraPositionState` | Binds the viewport to the remembered camera state |
| `onMapClick` | `{ userLocation.value = it }` | Every tap yields a `LatLng`; the marker moves because `userLocation` is a `MutableState` |
| `onMapLongClick` | (unused) | Could trigger alternative behaviour, but the lecture uses the plain click path |

The `Marker` is declared **inside** the `GoogleMap` trailing lambda:

```kotlin
Marker(state = MarkerState(position = userLocation.value))
```

`MarkerState(position: LatLng)` holds the red pin's coordinate. Because it reads `userLocation.value`, any tap→state change automatically moves the pin and, through composition, may animate the camera.

## Step 3 — the **Set Location** button

The map selection must be converted back from `LatLng` to the app's own `LocationData` and handed to the parent:

```kotlin
Button(
    onClick = {
        val newLocation = LocationData(
            latitude = userLocation.value.latitude,
            longitude = userLocation.value.longitude
        )
        onLocationSelected(newLocation)
    }
) {
    Text(\"Set Location\")
}
```

- `userLocation.value.latitude / longitude` — the two `Double`s that `LatLng` stores.
- `LocationData(latitude, longitude)` — a plain data class, easy to pass to navigation, ViewModel, or Retrofit.
- `onLocationSelected(newLocation)` — the hoisted callback. What the parent does with it (fetch address, pop the dialog) is decided in `MainActivity`'s `Navigation` composable.

An intermediate `var newLocation: LocationData?` is also declared in the lecture outside the button to illustrate the conversion, but the final button body directly constructs the `LocationData` inline.

## The complete file at this point

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.google.android.gms.maps.model.CameraPosition
import com.google.android.gms.maps.model.LatLng
import com.google.maps.android.compose.*

@Composable
fun LocationSelectionScreen(
    location: LocationData,
    onLocationSelected: (LocationData) -> Unit
) {
    val userLocation = remember { mutableStateOf(LatLng(location.latitude, location.longitude)) }
    val cameraPositionState = rememberCameraPositionState {
        position = CameraPosition.fromLatLngZoom(userLocation.value, 10f)
    }

    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        GoogleMap(
            modifier = Modifier.weight(1f).padding(top = 16.dp),
            cameraPositionState = cameraPositionState,
            onMapClick = { userLocation.value = it }
        ) {
            Marker(state = MarkerState(position = userLocation.value))
        }

        Button(onClick = {
            val newLocation = LocationData(
                latitude = userLocation.value.latitude,
                longitude = userLocation.value.longitude
            )
            onLocationSelected(newLocation)
        }) {
            Text(\"Set Location\")
        }
    }
}
```

Running the app now (once the navigation graph hosts this screen) shows a fully interactive map. Pinch/drag gestures still work; `Ctrl + scroll` (or `⌘ + scroll` on macOS) zooms on the emulator.

## Recap / cheat sheet

- **Layout:** `Column(fillMaxSize)` → `GoogleMap(weight(1f).padding(top=16.dp))` + `Button`.
- **Imports:** `com.google.maps.android.compose.GoogleMap`, `Marker`, `MarkerState`.
- **Camera:** `cameraPositionState = cameraPositionState`.
- **Tap:** `onMapClick = { userLocation.value = it }`.
- **Pin:** `Marker(state = MarkerState(position = userLocation.value))` inside `GoogleMap { }`.
- **Commit:** `onClick { onLocationSelected(LocationData(userLocation.value.latitude, userLocation.value.longitude)) }`.
- **Weight:** `1f` gives the map proportionally all remaining space.
