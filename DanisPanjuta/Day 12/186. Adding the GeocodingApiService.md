# Adding the GeocodingApiService

---

## Overview

The map picker returns a coordinate, but the shopping list needs a **street address**. The Geocoding REST endpoint does the conversion. This lecture adds a tiny **Retrofit interface** — `GeocodingApiService` — whose single `suspend` function builds the URL that was previously typed by hand in the browser and declares the expected `GeocodingResponse` return type.

---

## The browser URL as a template

From the earlier browser test:

```
https://maps.googleapis.com/maps/api/geocode/json?latlng=37.422,-122.084&key=YOUR_KEY
│                         │                    │                │           │
└──── base URL ────────────┘└── endpoint ──────┘└── query ─────┘└── query ─┘
```

| Segment | Belongs to |
| :--- | :--- |
| `https://maps.googleapis.com/` | `Retrofit.Builder().baseUrl(...)` |
| `maps/api/geocode/json` | `@GET(...)` value on the interface method |
| `latlng=37.422,-122.084` | `@Query(\"latlng\") latlng: String` argument |
| `key=AIza...` | `@Query(\"key\") key: String` argument |

Retrofit concatenates `baseUrl + @GET endpoint + @Query(...)` into the final URL and parses the JSON body into `GeocodingResponse` via `GsonConverterFactory`.

---

## Step 1 — create the interface

**Right-click package → New → Kotlin File/Class → Interface → `GeocodingApiService`**.

```kotlin
import retrofit2.http.GET
import retrofit2.http.Query

interface GeocodingApiService {

    @GET(\"maps/api/geocode/json\")
    suspend fun getAddressFromCoordinates(
        @Query(\"latlng\") latlng: String,
        @Query(\"key\") key: String
    ): GeocodingResponse
}
```

| Element | Role |
| :--- | :--- |
| `interface` | Retrofit generates the implementation — no body needed |
| `@GET(\"maps/api/geocode/json\")` | The path appended to the base URL; from the `retrofit2.http.GET` package |
| `@Query(\"latlng\")` | Named `latlng` in the URL; the lecture passes it as a **single** comma-separated string like `\"37.422,-122.084\"` |
| `@Query(\"key\")` | Named `key`; the API key stored in `AndroidManifest.xml` or hard-coded for the exercise |
| `suspend` | Allows the function to be called inside a coroutine (`viewModelScope.launch`) without blocking the UI thread |
| `GeocodingResponse` | Declares that the HTTP body, once converted by Gson, will be that data class (`results` + `status`) |

> The lecture names the parameters `latlng` and `key`. Any Kotlin identifier works as long as the `@Query` string matches the URL parameter name.

## How Retrofit maps the call

```kotlin
// call site will be:
val response: GeocodingResponse = service.getAddressFromCoordinates(
    latlng = \"37.422,-122.084\",
    key    = \"AIza...\"
)

// Retrofit constructs:
// GET https://maps.googleapis.com/maps/api/geocode/json?latlng=37.422,-122.084&key=AIza...
```

The previous browser workflow was:

```text
Browser typed URL → JSON displayed
```

The new workflow is:

```text
App calls suspend fun → Retrofit builds URL → HTTP → Gson parses body → GeocodingResponse
```

No manual URL string building or manual JSON parsing is needed.

## Recap / cheat sheet

- **File:** `GeocodingApiService.kt` (an `interface`).
- **Method:** `@GET(\"maps/api/geocode/json\") suspend fun getAddressFromCoordinates(@Query(\"latlng\") latlng: String, @Query(\"key\") key: String): GeocodingResponse`.
- **Imports:** `retrofit2.http.GET`, `retrofit2.http.Query`.
- **Mapping:** `baseUrl` + `@GET` endpoint + `@Query` args → full URL; JSON body → `GeocodingResponse` via `GsonConverterFactory`.
- **Suspend:** must be called from a coroutine (`viewModelScope.launch`, `lifecycleScope`, etc.).
- **Next:** `RetrofitClient` object to provide the base URL and converter, and `LocationViewModel.fetchAddress` to invoke this suspend function.
