# Restricting your API Key

---

## Overview

An unrestricted API key is a public secret: anyone who finds the string can spend the project's quota. This lecture locks the key so it only works when the request comes from **this Android app** — identified by its **package name** and the **SHA-1 certificate fingerprint** that signs the APK.

---

## What restriction does

| Restriction type | What is checked | Effect of theft |
| :--- | :--- | :--- |
| **None** (unrestricted) | Nothing | Any website, script, or app can use the key — quota theft is trivial |
| **Website** | HTTP referrer | Only listed domains may call |
| **IP address** | Caller IP | Only listed servers may call |
| **Android apps** | `package name` + `SHA-1` | Only an APK signed with the matching certificate and package may call — browsers are rejected with `REQUEST_DENIED` |

For an Android app, **Android apps** is the correct type.

---

## Step 1 — open the credential

1. In the Cloud Console, ensure **The Shopper** project is selected.
2. Go to **APIs & Services → Credentials**.
3. Under **API keys**, click the key created earlier → **Edit API key** (or **Show key → Restrict key**).

---

## Step 2 — collect the two identifiers

### Package name

Open the project in Android Studio. Either:

- Open `app/build.gradle.kts` and copy `applicationId`, or
- Open `MainActivity.kt` and copy the package from the top line:

```kotlin
package eu.tutorials.myshoppinglistapp // ← this string
```

For the Shopping List app it is typically `eu.tutorials.myshoppinglistapp` or similar. The lecture hovers over the package to confirm it.

### SHA-1 certificate fingerprint

The SHA-1 is a hash of the keystore that signs the debug APK. To retrieve it:

1. Open the **Gradle** tool window (elephant icon on the right edge; UI varies by Android Studio version).
2. Click **Execute Gradle Task** (or *Run Anything* with the Gradle icon).
3. Type `signingReport` (written together, no space) and press **Enter**.
4. The **Run** panel appears. Look for the block for the `:app` variant `debug`:

```
Variant: debug
Config: debug
Store: ~/.android/debug.keystore
...
SHA1: 5E:8F:23:...:A9
SHA-256: 3A:...
Valid until: ...
```

5. Copy the entire `SHA1` string **without** the `SHA1:` label and without trailing whitespace.

> Only the SHA-1 is needed. SHA-256 can be ignored for Maps.

---

## Step 3 — apply the restriction

In the **Edit API key** screen:

1. Under **Application restrictions** select **Android apps**.
2. Click **Add package name and fingerprint**.
3. Paste the **package name** from step 2.
4. Paste the **SHA-1** string.
5. Click **Done**.
6. Click **Save**.

The list now shows the key as **Restricted** and the yellow *unrestricted* banner disappears. A confirmation toast appears in the console.

---

## Step 4 — verify

- **Inside the app** (after the manifest `<meta-data>` is set): the map renders and the Geocoding call succeeds.
- **In a browser** with `https://maps.googleapis.com/maps/api/geocode/json?latlng=...&key=...`: the response returns `REQUEST_DENIED` with *\"This IP, site or mobile application is not authorized to use this API key.\"* — proof the restriction is active.

To test the raw JSON shape during development, the restriction can be temporarily set to **None**, the browser URL reloaded to observe `results[0].formatted_address`, and then immediately re-restricted.

---

## Common pitfalls

| Problem | Fix |
| :--- | :--- |
| Copied `SHA-256` instead of `SHA-1` | Re-run `signingReport`, copy the line that starts with `SHA1:` |
| Used `applicationIdSuffix` or build variant package | Use the exact `applicationId` of the `debug` variant being run |
| Map is blank after restricting | The manifest `<meta-data>` value is still the old unrestricted test key — copy the **same** restricted key string |
| `signingReport` shows no output | Ensure the Gradle project is synced and the task is run with `signingReport` exactly (no space) |

---

## Recap / cheat sheet

- **Where:** Cloud Console → **APIs & Services → Credentials → Edit API key**.
- **Type:** **Android apps**.
- **Package:** `MainActivity` package or `build.gradle` `applicationId`.
- **SHA-1:** Gradle → `signingReport` → `SHA1:` line.
- **Save:** **Done → Save** → key shows as **Restricted**.
- **Verify:** browser → `REQUEST_DENIED` is *good*; app → map loads and Geocoding returns `OK`.
- **Hygiene:** re-restrict immediately after any temporary unrestricted test.
