# Welcome to Day 12

---

## Overview

Day 12 revisits the **Shopping List app** from Day 7 and turns it into a location-aware application. Each item can now carry its own **store location** — the place where it should be purchased — selected by tapping a marker on an interactive **Google Map**.

The day combines almost everything learned so far: Jetpack Compose UI, MVVM, permissions, Retrofit/JSON, navigation, and the Google Maps SDK. By the end there is a single, polished app that lets a user add items, pick a location on a map, reverse-geocode that location into a street address, and display it next to the item.

> We are going to become Maps Masters after this day — at least Maps Advanced.

---

## Why maps inside the shopping app?

| Capability | What it adds to the shopping list |
| :--- | :--- |
| Map selection | The user long-presses or taps a map to choose exactly where to buy *Milk* vs. *Shoes* |
| Geocoding | The raw `lat, lng` returned by the map is useless to humans; the **Geocoding API** turns it into *\"Colony St, 12345 City\"* |
| Navigation | The map lives in its own destination (`dialog`) and the shopping list remains the start destination |
| ViewModel + Retrofit | The address survives recomposition and configuration changes and is fetched asynchronously from Google's servers |

This is the most common real-world maps requirement: **let the user choose a point and persist its human-readable address**.

## Day 12 roadmap

1. Add all required **dependencies** to `app/build.gradle.kts` and sync.
2. Create a **Google Cloud project** (*The Shopper*), enable **Maps SDK for Android**, generate an **API key**, and store it as `<meta-data android:name=\"com.google.android.geo.API_KEY\" />` in `AndroidManifest.xml`.
3. Enable the **Geocoding API** and test the key with a raw `https://maps.googleapis.com/maps/api/geocode/json?latlng=...&key=...` URL.
4. **Restrict** the key to an Android app (package name + **SHA-1** from `signingReport`).
5. Map the JSON response to `LocationData`, `GeocodingResponse`, and `GeocodingResult`.
6. Build `LocationSelectionScreen` — `remember { mutableStateOf(LatLng) }`, `rememberCameraPositionState`, `GoogleMap`, `Marker`, `onMapClick`, **Set Location** button.
7. Add `LocationViewModel` to hold `LocationData?` and `List<GeocodingResult>`.
8. Copy `LocationUtils` from Day 11 (adds `play-services-location` if not yet present).
9. Extend `ShoppingItem` with an `address: String` and redesign its row (`Column`, weighted `Row`, `LocationOn` icon).
10. Wire `ShoppingListApp` to take `locationUtils`, `viewModel`, `navController`, `context`, and `address`.
11. Add the `rememberLauncherForActivityResult` permission flow and an **Address** button inside the `AlertDialog`.
12. Create `GeocodingApiService` and `RetrofitClient`.
13. Add `fetchAddress(latlng: String)` to the view model with `viewModelScope.launch` and `try/catch`.
14. Assemble `Navigation` — `NavHost` + `composable(\"shoppingList\")` + `dialog(\"location_screen\")`, `firstOrNull()?.formatted_address ?: \"No Address\"`, `popBackStack()`, and the two bugs that appear while testing.
15. Final verification: permission prompt, map, marker, address resolution, and persisted list.

## A note on billing and quotas

Google Maps does not charge for the first **$200 of monthly usage**. For learning, testing, and even a small production app that traffic is never exceeded unless a loop spams the API. A **billing account** (credit card) is required to create the key, and a **budget alert** is automatically created at that $200 threshold.

> Never commit an unrestricted key to a public repository. Restrict it immediately after testing.

## Recap / cheat sheet

- **Goal:** attach a map-picked address to each shopping item.
- **APIs:** Maps SDK for Android (display) + Geocoding API (reverse-geocode).
- **Key:** create → enable APIs → restrict (package + SHA-1) → `<meta-data>` in manifest.
- **Response:** `GeocodingResponse(results: List<GeocodingResult>, status: String)` → `GeocodingResult(formatted_address: String)`.
- **Map:** `GoogleMap(cameraPositionState, onMapClick)` + `Marker(state = MarkerState(position))`.
- **Flow:** tap map → `mutableStateOf<LatLng>` → **Set Location** → `onLocationSelected(LocationData)` → `viewModel.fetchAddress(\"lat,lng\")` → `address.firstOrNull()?.formatted_address`.
