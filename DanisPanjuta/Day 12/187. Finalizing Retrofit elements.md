# Finalizing Retrofit elements

---

## Overview

The interface exists but nothing materializes an HTTP client. This lecture adds a **singleton retrofit holder** (`RetrofitClient`) that owns the base URL and the Gson converter, and extends the **ViewModel** to call the interface inside a coroutine, capture `List<GeocodingResult>`, and expose it as Compose `State` so the UI recomposes when the address arrives.

---

## Step 1 — create `RetrofitClient` (the singleton)

**Right-click package → New → Kotlin File/Class → Object → `RetrofitClient`**

Use `object` (Kotlin singleton), not `class`:

```kotlin
import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory

object RetrofitClient {
    private const val BASE_URL = \"https://maps.googleapis.com/\"

    fun create(): GeocodingApiService {
        val retrofit = Retrofit.Builder()
            .baseUrl(BASE_URL)
            .addConverterFactory(GsonConverterFactory.create())
            .build()
        return retrofit.create(GeocodingApiService::class.java)
    }
}
```

| Line | Why it exists |
| :--- | :--- |
| `object` | One instance for the whole process — no need to rebuild the converter on every call |
| `BASE_URL = \"https://maps.googleapis.com/\"` | The scheme + host, must end with `/`. The endpoint `maps/api/geocode/json` from `@GET` is appended to it |
| `Retrofit.Builder()` | Builder pattern — constructs an immutable `Retrofit` instance |
| `.baseUrl(BASE_URL)` | Tells every service created from this instance where to send requests |
| `.addConverterFactory(GsonConverterFactory.create())` | Plugs in the Gson converter added to `app/build.gradle.kts` (`retrofit2:converter-gson`). Without it Retrofit cannot deserialize JSON into `GeocodingResponse` |
| `.build()` | Finalizes the configuration |
| `retrofit.create(GeocodingApiService::class.java)` | Reflectively implements the `GeocodingApiService` interface — the returned object has a real `getAddressFromCoordinates` that performs HTTP |

> If `GsonConverterFactory` is red, verify `implementation(\"com.squareup.retrofit2:converter-gson:2.9.0\")` and **Sync Now**.

## Step 2 — extend `LocationViewModel` to fetch the address

Open `LocationViewModel.kt` and add the address state and the network call.

### 2a — address state

```kotlin
class LocationViewModel : ViewModel() {

    private val _location = mutableStateOf<LocationData?>(null)
    val location: State<LocationData?> = _location

    fun updateLocation(newLocation: LocationData) {
        _location.value = newLocation
    }

    // — new —
    private val _address = mutableStateOf<List<GeocodingResult>>(emptyList())
    val address: State<List<GeocodingResult>> = _address

    // — fetch — see below
    fun fetchAddress(latlng: String) {
        // ...
    }
}
```

- Starts as `emptyList()` — at the call site `viewModel.address.value.firstOrNull()?.formatted_address ?: \"No Address\"` cleanly yields the fallback.
- `State<List<GeocodingResult>>` gives automatic recomposition when `_address.value` is assigned.

### 2b — the fetch function

```kotlin
fun fetchAddress(latlng: String) {
    viewModelScope.launch {
        try {
            val result: GeocodingResponse = RetrofitClient.create()
                .getAddressFromCoordinates(
                    latlng = latlng,
                    key = \"YOUR_API_KEY_HERE\"
                )
            _address.value = result.results
        } catch (e: Exception) {
            android.util.Log.e(\"res1\", \"${e.cause}  ${e.message}\")
        }
    }
}
```

| Element | Role |
| :--- | :--- |
| `viewModelScope.launch { }` | Launches a coroutine scoped to the ViewModel's lifecycle — survives rotation, auto-cancelled on clear. `suspend` functions must be called from a coroutine |
| `try / catch (e: Exception)` | Guards against network failures, JSON mismatches, or quota errors; without it the app would crash on any exception |
| `RetrofitClient.create().getAddressFromCoordinates(...)` | The interface's single suspend function. `latlng` is `\"${location.latitude},${location.longitude}\"` built at the call site; `key` is the Maps API key |
| `_address.value = result.results` | The only field kept — `result.status` is ignored (logged if needed). `result.results` is `List<GeocodingResult>` as modelled earlier |
| `Log.e(\"res1\", \"${e.cause}  ${e.message}\")` | Writes to **Logcat** — the bottom panel in Android Studio. Filter by tag `res1` (the lecture names it `res1`; any tag works). `Logcat` shows renderer, system, and app logs in one stream |

#### Where the API key lives at this point

The lecture **hard-codes** the key directly in the string argument for simplicity:

```kotlin
key = \"AIzaSy...CopyFrom Manifest Meta-Data...\"
```

The key is already in the manifest's `<meta-data android:name=\"com.google.android.geo.API_KEY\" />` for the `GoogleMap` widget; hard-coding a second copy for the Retrofit query is redundant but explicit. A more advanced approach would read the manifest meta-data at runtime or centralize the key in `local.properties`.

## The whole data flow

```text
GoogleMap.onMapClick
      │
      ▼
userLocation.value = latLng
      │
      ▼ (Button \"Set Location\")
LocationData(lat, lng)
      │
      ▼ onLocationSelected(LocationData)
Navigation → viewModel.fetchAddress(\"lat,lng\")
      │
      ▼ viewModelScope.launch
RetrofitClient.create().getAddressFromCoordinates(latlng, key)
      │
      ▼ suspend → HTTP GET https://maps.googleapis.com/maps/api/geocode/json?latlng=lat,lng&key=KEY
GeocodingResponse(results, status)
      │
      ▼ _address.value = results
      │         (recomposition)
      ▼
ShoppingListApp renders address: viewModel.address.value.firstOrNull()?.formatted_address ?: \"No Address\"
```

## Recap / cheat sheet

- **`RetrofitClient`:** `object RetrofitClient { private const val BASE_URL = \"https://maps.googleapis.com/\"; fun create(): GeocodingApiService = Retrofit.Builder().baseUrl(BASE_URL).addConverterFactory(GsonConverterFactory.create()).build().create(GeocodingApiService::class.java) }`.
- **ViewModel state:** `private val _address = mutableStateOf<List<GeocodingResult>>(emptyList())` / `val address: State<List<GeocodingResult>> = _address`.
- **Fetch:** `fun fetchAddress(latlng: String) = viewModelScope.launch { try { _address.value = RetrofitClient.create().getAddressFromCoordinates(latlng, KEY).results } catch (e: Exception) { Log.e(\"res1\", \"${e.cause} ${e.message}\") } }`.
- **Logcat:** `Log.e(\"res1\", ...)` → filter by `res1` in Logcat panel.
- **Imports:** `androidx.lifecycle.viewModelScope`, `kotlinx.coroutines.launch`, `retrofit2.Retrofit`, `retrofit2.converter.gson.GsonConverterFactory`, `android.util.Log`.
