# Finalizing the UI of our Age Calculator App

---

## Overview

A mini challenge: replicate the rest of the screen — selected date + label, and the age in minutes + label — then compare with the instructor's XML.

---

## Structure below the button

```xml
<TextView
    android:id="@+id/tvSelectedDate"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:layout_marginTop="16dp"
    android:text="00.00.0000"
    android:textColor="#9C27B0"
    android:textSize="20sp"
    android:textStyle="bold" />

<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Selected Date"
    android:textColor="#A5A5A5"
    android:textSize="16sp" />

<TextView
    android:id="@+id/tvAgeInMinutes"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:layout_marginTop="16dp"
    android:text="0"
    android:textColor="#9C27B0"
    android:textSize="35sp"
    android:textStyle="bold" />

<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Age in minutes"
    android:textColor="#A5A5A5"
    android:textSize="16sp" />
```

---

## Design notes

- Value and label pairs are **grouped** — small/no margin between them, larger `marginTop` between groups.
- Minutes value is **bigger** (35 sp) than the date (20 sp) — visual hierarchy.
- Grey labels (`#A5A5A5`) de-emphasise static text.
- Give an **`android:id`** to every view you'll update from code (`tvSelectedDate`, `tvAgeInMinutes`).

---

## Recap / cheat sheet

- Pair **value + label** TextViews.
- IDs: `@+id/tvSelectedDate`, `@+id/tvAgeInMinutes`, `@+id/btnDatePicker`.
- Hierarchy through `textSize`, `textStyle`, colour.
