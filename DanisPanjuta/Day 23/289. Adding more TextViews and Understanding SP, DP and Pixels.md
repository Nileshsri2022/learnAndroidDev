# Adding more TextViews and Understanding SP, DP and Pixels

---

## Overview

Adds the remaining heading lines and the **Select Date** button, explaining `wrap_content` vs `match_parent`, padding vs margin, and the difference between **px**, **dp** and **sp**.

---

## wrap_content vs match_parent

| Value | Width/height becomes |
| :--- | :--- |
| `wrap_content` | Just big enough to fit the content |
| `match_parent` | As big as the parent allows |

With `match_parent` a `TextView` spans the whole width, so its text starts on the left unless you add `android:gravity="center"`. The **view** is the UI element — the text inside is just its content.

---

## Padding vs margin

- **padding** — space *inside* the view, between its border and content.
- **layout_margin** — space *outside* the view, between it and its neighbours.

```xml
<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="AGE"
    android:padding="10dp"
    android:background="#9C27B0"
    android:textColor="@color/white"
    android:textSize="25sp"
    android:textStyle="bold" />
```

---

## px vs dp vs sp

| Unit | Meaning | Use for |
| :--- | :--- | :--- |
| **px** | Physical screen pixels — varies by device density | Avoid |
| **dp** (density-independent pixels) | 1 dp ≈ 1 px on a 160 dpi screen; scales with density | Sizes, margins, padding |
| **sp** (scale-independent pixels) | Like dp, **plus** respects the user's font-size setting | **Text sizes only** |

> A 100 px square is large on a low-density phone and tiny on a high-density one — `100dp` looks the same physical size on both.

## The Select Date button

```xml
<Button
    android:id="@+id/btnDatePicker"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:layout_marginTop="16dp"
    android:backgroundTint="#DADADA"
    android:text="Select Date"
    android:textColor="#353535"
    android:textSize="20sp" />
```

---

## Recap / cheat sheet

- **dp** for dimensions, **sp** for text, never **px**.
- **padding** inside, **margin** outside.
- `wrap_content` vs `match_parent`.
