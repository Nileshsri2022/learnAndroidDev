# Using the Selected Date to display it and looking into SimpleDateFormat and Date

---

## Overview

Reads the selected year/month/day from the listener, fixes the **zero-based month**, displays the date in a `TextView`, and parses it into a `Date` with **`SimpleDateFormat`**.

---

## Month is zero-based!

```kotlin
Toast.makeText(this,
    "Year was $selectedYear, month was ${selectedMonth + 1}, day of month was $selectedDayOfMonth",
    Toast.LENGTH_LONG).show()
```

`Calendar.MONTH` counts **January = 0 … December = 11** → always add `1` for display. Day-of-month is 1-based.

---

## Holding TextView references

```kotlin
private var tvSelectedDate: TextView? = null

override fun onCreate(savedInstanceState: Bundle?) {
    …
    tvSelectedDate = findViewById(R.id.tvSelectedDate)
}
```

Declared **nullable** at class level (`TextView? = null`) because the view doesn't exist until `setContentView` runs. Access with safe call `?.`.

---

## Displaying the selected date

```kotlin
val selectedDate = "$selectedDayOfMonth/${selectedMonth + 1}/$selectedYear"
tvSelectedDate?.text = selectedDate
```

---

## Parsing with SimpleDateFormat

```kotlin
val sdf = SimpleDateFormat("dd/MM/yyyy", Locale.ENGLISH)
val theDate = sdf.parse(selectedDate)   // java.util.Date?
```

| Pattern | Meaning |
| :--- | :--- |
| `dd` | Day, 2 digits |
| `MM` | Month, 2 digits (capital M! lowercase `mm` = minutes) |
| `yyyy` | 4-digit year |

`Date` internally stores **milliseconds since 1 Jan 1970 00:00 UTC** — accessible via `theDate.time`.

---

## Recap / cheat sheet

- **Month + 1** for display.
- Class-level views: `private var tv: TextView? = null`, then `tv?.text = …`.
- **Format:** `SimpleDateFormat("dd/MM/yyyy", Locale.ENGLISH).parse(str)`.
