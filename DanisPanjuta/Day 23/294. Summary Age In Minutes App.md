# Summary Age In Minutes App

---

## Overview

The first real application of the XML track is done. It can be shared with friends to tell them how many minutes (or days, after the challenge) old they are.

---

## What you learned

| Area | Details |
| :--- | :--- |
| **UI** | `LinearLayout`, `TextView`, `Button`; colours, text sizes, padding/margin, **dp vs sp** |
| **Code ↔ UI** | `findViewById`, nullable view properties, `setOnClickListener` |
| **Built-in classes** | `DatePickerDialog`, `Calendar`, `SimpleDateFormat`, `Date`, `Toast` |
| **Logic** | Milliseconds since 1970 → minutes, date difference |
| **Kotlin** | Lambdas as listeners, `?.let {}`, string templates |

---

## Architecture of the app

```
Button click ──► clickDatePicker()
                   ├─ Calendar → today's y/m/d
                   ├─ DatePickerDialog (maxDate = yesterday)
                   └─ OnDateSetListener
                         ├─ show "dd/MM/yyyy"
                         ├─ parse → minutes
                         └─ now(minutes) − selected(minutes) → TextView
```
