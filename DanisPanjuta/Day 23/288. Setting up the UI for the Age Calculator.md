# Setting up the UI for the Age Calculator

---

## Overview

Creates the project and lays out the first UI elements of the **Age in Minutes** screen in `activity_main.xml` using a vertical **`LinearLayout`**.

---

## Final result (preview)

```
   CALCULATE YOUR
   AGE IN MINUTES          ← white heading on a dark background
   [ SELECT DATE ]         ← button opens a DatePickerDialog
   14/09/2018              ← selected date
   Selected Date
   1579000                 ← minutes
   Age in minutes
```

---

## Project setup

1. **New Project → Empty Activity** (XML "Empty Views Activity" in newer Studio versions).
2. Name: `AgeInMinutes`, language **Kotlin**, min SDK 21+.

---

## Switching the root to LinearLayout

The template uses a `ConstraintLayout`; replace it with a vertical `LinearLayout`:

```xml
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:gravity="center_horizontal"
    android:background="#353535"
    android:padding="16dp"
    tools:context=".MainActivity">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="CALCULATE YOUR"
        android:textColor="#FFFFFF"
        android:textSize="25sp"
        android:textStyle="bold"
        android:layout_marginTop="16dp" />

</LinearLayout>
```

| Attribute | Effect |
| :--- | :--- |
| `orientation="vertical"` | Children stacked top-to-bottom |
| `gravity="center_horizontal"` | Children centred horizontally |
| `background` | Hex colour `#RRGGBB` (or `@color/...`) |
| `padding` | Inner spacing of the layout |

---

## Design vs. Code vs. Split view

- **Design** — drag & drop palette, Attributes panel.
- **Code** — edit XML directly (preferred for precision).
- **Split** — both side by side, live preview.

---

## Recap / cheat sheet

- **Root:** vertical `LinearLayout`, `gravity="center_horizontal"`.
- **TextView attributes:** `text`, `textColor`, `textSize` (sp), `textStyle`.
- Use **Split view** to see XML changes instantly.
