# Intro Age in Minutes Calculator

---

## Overview

Day 23 builds the first real XML app of this track: the **Age in Minutes Calculator**. The user picks their birthday and the app shows how many minutes old they are (precise to the day chosen).

---

## What you will learn

| Skill | Where it's used |
| :--- | :--- |
| Building a UI in **XML** (`LinearLayout`, `TextView`, `Button`) | Whole screen |
| Styling text — colours, `textSize`, `textStyle`, padding, margins | Headings and result views |
| Handling **button clicks** | "Select Date" button |
| Using a built-in **`DatePickerDialog`** | Picking the birthday |
| Working with **`Calendar`**, **`SimpleDateFormat`**, **`Date`** | Parsing & calculating |
| Updating the UI from code | Showing selected date and result |

---

## Philosophy

Lean on **built-in classes** (date picker, calendar, formatter) instead of writing everything from scratch — keep the code as simple as possible.

---

## Recap / cheat sheet

- **App:** birthday → age in minutes.
- **Key classes:** `DatePickerDialog`, `Calendar`, `SimpleDateFormat`, `Date`.
