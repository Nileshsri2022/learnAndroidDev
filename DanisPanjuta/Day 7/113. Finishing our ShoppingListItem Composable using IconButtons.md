## Full row

```kotlin
@Composable
fun ShoppingListItem(
    item: ShoppingItem,
    onEditClick: () -> Unit,
    onDeleteClick: () -> Unit
) {
    Row(
        modifier = Modifier
            .padding(8.dp)
            .fillMaxWidth()
            .border(
                border = BorderStroke(2.dp, Color(0xFF018786)),
                shape = RoundedCornerShape(20)
            )
    ) {
        Text(text = item.name, modifier = Modifier.padding(8.dp))
        Text(text = "Qty: ${item.quantity}", modifier = Modifier.padding(8.dp))
        Row(modifier = Modifier.padding(8.dp)) {
            IconButton(onClick = onEditClick) {
                Icon(
                    imageVector = Icons.Default.Edit,
                    contentDescription = null
                )
            }
            IconButton(onClick = onDeleteClick) {
                Icon(
                    imageVector = Icons.Default.Delete,
                    contentDescription = null
                )
            }
        }
    }
}
```

Later (final lecture) this `Row` also gets `horizontalArrangement = Arrangement.SpaceBetween` so the icons sit on the **right**.

---

## `IconButton` vs `Button`

`IconButton` is a button that **looks like an icon** (no filled pill). It still has `onClick`.

```kotlin
IconButton(onClick = onEditClick) { ... }
```

That is **not** `onClick = { onEditClick }` (that would ignore the click). You pass the lambda itself so the icon **invokes** it.

---

## `Icon` + `ImageVector`

```kotlin
Icon(
    imageVector = Icons.Default.Edit,
    contentDescription = null
)
```

* `Icons.Default.*` — built-in Material icons (`Edit`, `Delete`, `Add`, `Search`, `Send`, `Refresh`, `PlayArrow`, …)
* `ImageVector` is a small vector, not a PNG
* `contentDescription` — accessibility (TalkBack). The course uses `null` for speed; a real app should say `"Edit"` / `"Delete"`

Need the Material icons dependency if `Icons.Default` does not resolve (often `material-icons-extended` or the default icons artifact — Android Studio will hint).
