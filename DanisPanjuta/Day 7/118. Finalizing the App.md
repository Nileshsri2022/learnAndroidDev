# Finalizing the App — Edit, Save, Delete

---

## Overview

All the pieces snap together inside `items(sItems)`.

* If `item.isEditing` → `ShoppingItemEditor`
* Else → `ShoppingListItem`
* Edit icon → set **that** row’s `isEditing` to `true` (`map` + `copy`)
* Save → turn editing off, write new name/qty (`map`, `find`, `let`)
* Delete → `sItems = sItems - item`
* `SpaceBetween` on the row so icons sit on the right

This lecture is dense. The first time through it is normal to feel lost; you will see the same pattern again later in the course.

---

## 1. Rename `it` in `items`

```kotlin
items(sItems) { item ->
    if (item.isEditing) {
        // editor
    } else {
        // normal row
    }
}
```

`{ item ->` names the current element so you are not stuck with `it` (and so inner lambdas can have their own `it`).

---

## 2. Two UIs for one row

```kotlin
if (item.isEditing) {
    ShoppingItemEditor(
        item = item,
        onEditComplete = { editedName, editedQuantity ->
            sItems = sItems.map { it.copy(isEditing = false) }
            val editedItem = sItems.find { it.id == item.id }
            editedItem?.let {
                it.name = editedName
                it.quantity = editedQuantity
            }
        }
    )
} else {
    ShoppingListItem(
        item = item,
        onEditClick = {
            sItems = sItems.map { it.copy(isEditing = it.id == item.id) }
        },
        onDeleteClick = {
            sItems = sItems - item
        }
    )
}
```

---

## 3. Edit click — which pencil was it?

You might have 10 rows. The lambda **closes over** `item` (the row that composed this `ShoppingListItem`).

```kotlin
sItems = sItems.map { it.copy(isEditing = it.id == item.id) }
```

For each element `it` in the list:

* `it.id == item.id` → `true` only for the row whose pencil you tapped
* `copy(isEditing = true/false)` → new objects
* Assigning a **new list** to `sItems` triggers recomposition
* That row now takes the `if (item.isEditing)` branch → editor

Other rows get `isEditing = false`, so only one editor at a time.

---

## 4. Save — `onEditComplete`

The editor calls `onEditComplete(editedName, editedQuantity)`.

```kotlin
sItems = sItems.map { it.copy(isEditing = false) }
val editedItem = sItems.find { it.id == item.id }
editedItem?.let {
    it.name = editedName
    it.quantity = editedQuantity
}
```

| Line | Meaning |
| :--- | :--- |
| `map { copy(isEditing = false) }` | Leave edit mode (all rows). New list → recomposition will show `ShoppingListItem` again |
| `find { it.id == item.id }` | The row we were editing (`ShoppingItem?`) |
| `?.let { ... }` | If found, write the new name and quantity (`var` properties on the data class) |

Mutation happens on the **copied** objects **before** Compose redraws, so the list item shows the new text.

---

## 5. Delete

```kotlin
sItems = sItems - item
```

`-` on a `List` returns a list **without** that element. New list → row disappears.

---

## 6. Icons on the right

On `ShoppingListItem`’s outer `Row`:

```kotlin
horizontalArrangement = Arrangement.SpaceBetween
```

Name/qty stay left; icon cluster goes to the far right.

## Mental model

```
Tap edit
  → map/copy isEditing for matching id
  → recompose → ShoppingItemEditor

Tap Save
  → map/copy isEditing false
  → find + let to write name/qty
  → recompose → ShoppingListItem

Tap delete
  → sItems - item
  → recompose without that row
```
