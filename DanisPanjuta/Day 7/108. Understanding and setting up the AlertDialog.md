# First `AlertDialog` — Show and Hide with State

---

## Overview

The “Add item” popup is an **`AlertDialog`**. The Material dialog is meant for yes/no alerts. You **reuse** it as a form. Compose does not ship every popup you can imagine; you adapt the ones that exist.

This lecture only proves **open / close**. Styling is next.

---

## 1. A boolean for visibility

```kotlin
var showDialog by remember { mutableStateOf(false) }
```

Same pattern as `iExpanded` on Day 6:

* `true` → dialog on screen
* `false` → gone

---

## 2. Open on the button, close on dismiss

```kotlin
Button(
    onClick = { showDialog = true },
    modifier = Modifier.align(Alignment.CenterHorizontally)
) {
    Text("Add Item")
}

if (showDialog) {
    AlertDialog(
        onDismissRequest = { showDialog = false }
    ) {
        Text("I'm an alert dialog beep beep beep")
    }
}
```

| Event | State change |
| :--- | :--- |
| Tap **Add Item** | `showDialog = true` |
| Tap outside / back (`onDismissRequest`) | `showDialog = false` |

The `if (showDialog)` is the whole show/hide logic. When the flag is false, the composable is **not in the tree**. No extra “hide dialog” API.

`onDismissRequest` is the same idea as the dropdown on Day 6.

---

## 3. Two different `AlertDialog`s (important)

There are **several** `AlertDialog` overloads:

1. **Content slot** — `onDismissRequest` + trailing lambda (what this video uses). May need:

   ```kotlin
   @OptIn(ExperimentalMaterial3Api::class)
   ```

   Experimental in Material 3 at the time of recording; that annotation may go away in later libraries.

2. **`title` / `text` / `confirmButton`** — the “full” dialog. **That** is the one used from the next lecture. It does **not** need the experimental opt-in.

If Android Studio offers multiple imports / signatures, pick the one that matches the parameters you want. The instructor accidentally used (1) first, then switched to (2).

---

## 4. What you should see

Tap **Add Item** → a dialog with dummy text, a little enter/exit animation. Tap beside it → it leaves.

No fields, no Add/Cancel yet.

---

## Summary

* Dialog visibility = one `Boolean` state
* `if (showDialog) { AlertDialog(...) }`
* Button sets `true`; `onDismissRequest` sets `false`
