# `ShoppingItemEditor` — Inline Edit UI

---

## Overview

Tapping edit should **replace** that row with:

* Two **basic** text fields (name + quantity) — no outline
* A **Save** button

New composable: `ShoppingItemEditor`. Wiring it into the list (`if (item.isEditing)`) is a few lectures later, after `map` / `copy` / `let`.

---

## 1. Signature

```kotlin
@Composable
fun ShoppingItemEditor(
    item: ShoppingItem,
    onEditComplete: (String, Int) -> Unit
) {
```

| Parameter | Meaning |
| :--- | :--- |
| `item` | Row being edited (starting name / qty / `isEditing`) |
| `onEditComplete: (String, Int) -> Unit` | When Save is tapped, send **new name** + **new quantity** back to the parent. No return |

This lambda **has** inputs, unlike `onEditClick: () -> Unit`.

---

## 2. Local state, seeded from `item`

```kotlin
var editedName by remember { mutableStateOf(item.name) }
var editedQuantity by remember { mutableStateOf(item.quantity.toString()) }
var isEditing by remember { mutableStateOf(item.isEditing) }
```

* Fields need **strings** → `quantity.toString()`
* Typing updates `editedName` / `editedQuantity` only. The list item is updated when Save calls `onEditComplete`
* `isEditing` local flag is set `false` on Save (the parent will also clear it on the data class)

---

## 3. Layout: `Row` → `Column` of fields + Save

```kotlin
Row(
    modifier = Modifier
        .fillMaxWidth()
        .background(Color.White)
        .padding(8.dp),
    horizontalArrangement = Arrangement.SpaceEvenly
) {
    Column {
        BasicTextField(
            value = editedName,
            onValueChange = { editedName = it },
            singleLine = true,
            modifier = Modifier
                .wrapContentSize()
                .padding(8.dp)
        )
        BasicTextField(
            value = editedQuantity,
            onValueChange = { editedQuantity = it },
            singleLine = true,
            modifier = Modifier
                .wrapContentSize()
                .padding(8.dp)
        )
    }
    Button(onClick = {
        isEditing = false
        onEditComplete(editedName, editedQuantity.toIntOrNull() ?: 1)
    }) {
        Text("Save")
    }
}
```

| Choice | Why |
| :--- | :--- |
| `BasicTextField` not `OutlinedTextField` | Demo has no box around the text |
| `wrapContentSize()` | Width follows the text, not the whole screen |
| `Arrangement.SpaceEvenly` | Equal gaps (unlike `SpaceBetween`, which shoves items to the edges) |
| `background(Color.White)` | `Color` from `androidx.compose.ui.graphics.Color` |
| `toIntOrNull() ?: 1` | Garbage quantity → **1**, no crash (Elvis, Day 6) |

Save:

1. `isEditing = false`
2. `onEditComplete(name, qty)` — parent updates `sItems`

The parent call is the next block of lectures (`map`, `copy`, `let`), then **Finalizing the App**.

* Safe parse: `toIntOrNull() ?: 1`
