## Theme

Build a shopping list with Compose: dialog to add, `LazyColumn` to show, custom rows to edit/delete. State is a **list of data-class objects**.

---

## Data

```kotlin
data class ShoppingItem(
    val id: Int,
    var name: String,
    var quantity: Int,
    var isEditing: Boolean = false
)
```

```kotlin
var sItems by remember { mutableStateOf(listOf<ShoppingItem>()) }
var showDialog by remember { mutableStateOf(false) }
var itemName by remember { mutableStateOf("") }
var itemQuantity by remember { mutableStateOf("") }
```

---

## Add

```kotlin
if (itemName.isNotBlank()) {
    val newItem = ShoppingItem(
        id = sItems.size + 1,
        name = itemName,
        quantity = itemQuantity.toInt()
    )
    sItems = sItems + newItem
    showDialog = false
    itemName = ""
}
```

Always **replace** the list (`+`, `-`, `map`). Do not mutate `listOf` in place.

---

## Show / edit / delete

```kotlin
items(sItems) { item ->
    if (item.isEditing) {
        ShoppingItemEditor(item) { editedName, editedQuantity ->
            sItems = sItems.map { it.copy(isEditing = false) }
            sItems.find { it.id == item.id }?.let {
                it.name = editedName
                it.quantity = editedQuantity
            }
        }
    } else {
        ShoppingListItem(
            item = item,
            onEditClick = {
                sItems = sItems.map { it.copy(isEditing = it.id == item.id) }
            },
            onDeleteClick = { sItems = sItems - item }
        )
    }
}
```

## Kotlin cheat sheet

| Tool | One-liner |
| :--- | :--- |
| Lambda | `val doubleNumber: (Int) -> Int = { it * 2 }` |
| Callback param | `onEditClick: () -> Unit` |
| `map` | `list.map { it * 2 }` → new list |
| `copy` | `item.copy(isEditing = true)` |
| Nullable | `String?` |
| `let` | `editedItem?.let { it.name = "x" }` |
| Elvis | `toIntOrNull() ?: 1` |

## Compose cheat sheet

| API | Use |
| :--- | :--- |
| `LazyColumn` + `items(list)` | Long lists; only visible rows composed |
| `AlertDialog(title, text, confirmButton)` | Popup form (`text` can be a `Column`) |
| `IconButton` + `Icons.Default.Edit` | Icon-only click |
| `BasicTextField` | Text input without outline |
| `BorderStroke` + `RoundedCornerShape` | Card-like row |
| `Arrangement.SpaceBetween` / `SpaceEvenly` | Horizontal distribution |
