# The `map` Keyword — Transform Every Element

---

## Overview

To edit one shopping row you will walk the **whole list** and build a new list. Kotlin’s `map` does that. Story + tiny example; used for real in Finalizing the App.

---

## Story (Coulterville)

Myra’s enchanted paintbrush turns **every** painting gold: blue bird → gold, red apple → gold. Same operation on each item.

`map` is that brush for lists.

---

## Code

```kotlin
val numbers = listOf(1, 2, 3)
val doubled = numbers.map { it * 2 }
println(doubled)  // [2, 4, 6]
```

`map` walks an `Iterable`:

| Index | Before | After `{ it * 2 }` |
| :--- | :--- | :--- |
| 0 | 1 | 2 |
| 1 | 2 | 4 |
| 2 | 3 | 6 |

* Original `numbers` is unchanged
* Result is a **new** list
* `it` is the current element

You can use a named parameter: `numbers.map { n -> n * 2 }`.

---

## Why the shopping list needs it

`sItems` is a list of `ShoppingItem`. To turn **one** row’s `isEditing` on (and the others off):

```kotlin
sItems = sItems.map { it.copy(isEditing = it.id == item.id) }
```

That line shows up after `copy` is explained. For now: **`map` = new list, one result per old element.**
