# Designing the AlertDialog — Title and Two Text Fields

---

## Overview

Target look: rounded card, title **Add shopping item**, two outlined fields (name, quantity), later two buttons. This lecture builds title + fields. Buttons are next.

Also: **use the other `AlertDialog` overload** — the one with `confirmButton`, `title`, and `text`. The experimental content-slot dialog from last time is removed. No `@OptIn(ExperimentalMaterial3Api::class)` needed.

---

## 1. Extra state for the form

```kotlin
var itemName by remember { mutableStateOf("") }
var itemQuantity by remember { mutableStateOf("") }
```

Quantity is a **`String`**, not `Int`, because `OutlinedTextField` works with strings. You convert with `.toInt()` when saving.

---

## 2. The “full” `AlertDialog`

```kotlin
if (showDialog) {
    AlertDialog(
        onDismissRequest = { showDialog = false },
        confirmButton = { /* buttons next lecture */ },
        title = { Text("Add shopping item") },
        text = {
            Column {
                OutlinedTextField(
                    value = itemName,
                    onValueChange = { itemName = it },
                    singleLine = true,
                    modifier = Modifier
                        .fillMaxWidth()
                        .padding(8.dp)
                )
                OutlinedTextField(
                    value = itemQuantity,
                    onValueChange = { itemQuantity = it },
                    singleLine = true,
                    modifier = Modifier
                        .fillMaxWidth()
                        .padding(8.dp)
                )
            }
        }
    )
}
```

`confirmButton` is required on this overload — leave a stub if the compiler complains; fill it next.

---

## 3. `text` is a composable slot, not only `Text`

The parameter is named `text`, but its type is `@Composable () -> Unit`. You can put a **`Column`**, fields, spacers — not just a sentence. That is how a “yes/no alert” becomes a small form.

Same idea as Day 6: `value` + `onValueChange = { itemName = it }`. `it` is the new string on every keystroke.

| Parameter | Meaning |
| :--- | :--- |
| `singleLine = true` | No multi-line names |
| `fillMaxWidth()` | Field uses the dialog width |
| `padding(8.dp)` | Breathing room (8dp grid) |

Default Material 3 dialog: colored container, large title. Fine for now.

Tap outside still dismisses via `onDismissRequest`.

---

## Summary

* Switch to `AlertDialog(confirmButton, title, text)`
* `itemName` / `itemQuantity` as `String` state
* `text = { Column { two OutlinedTextFields } }`
