# The Shopping List App — What You Are Building

---

## Overview

Jamie keeps forgetting paper grocery notes, shows up at the store empty-handed, and ends up buying milk she does not need. The app is a phone list she cannot leave on the kitchen table.

(The lecture uses a slightly chaotic DALL·E story. The useful part is the **feature list**.)

---

## Finished app (demo)

1. **Add Item** button at the top
2. Tap it → a **popup** (“Add shopping item”)
3. Two fields: **name** and **quantity**
4. **Add** saves a row; **Cancel** (or tap outside) closes the popup
5. Each row shows `name` + quantity, plus **edit** and **delete** icons
6. Edit swaps that row for inline text fields + **Save**
7. Delete removes the row

Examples from the video: 5 apples, 3 Ferraris, the moon — then delete Ferrari, edit the moon.

---

## Features you will implement

| Feature | Compose / Kotlin piece |
| :--- | :--- |
| Add popup | `AlertDialog` + `OutlinedTextField` |
| Scrollable list | `LazyColumn` + `items(...)` |
| One row | custom `ShoppingListItem` composable |
| Edit mode | custom `ShoppingItemEditor` + `isEditing` |
| Update one row | `map` + `copy` + `find` + `let` |
| Delete a row | `sItems = sItems - item` |

---

## Important limitation

If you kill the app and open it again, **the list is empty**. Nothing is written to disk. Room (persistent storage) is next week. Today is about lists on screen.

You could restyle the dialog (align text, colors). The course builds a working version first.
