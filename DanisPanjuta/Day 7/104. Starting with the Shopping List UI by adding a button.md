## 2. A full-screen centered column

```kotlin
Column(
    modifier = Modifier.fillMaxSize(),
    verticalArrangement = Arrangement.Center
) {
    // button goes here
}
```

* `fillMaxSize()` — use the whole screen
* `verticalArrangement = Arrangement.Center` — stack from the middle (top to bottom)

Imports: hover the red name → **Alt+Enter** (Windows/Linux) to add `Column`, `fillMaxSize`, etc. Prefer the **Compose** packages, not old View ones.

---

## 3. The button

```kotlin
Button(
    onClick = { /* nothing yet */ },
    modifier = Modifier.align(Alignment.CenterHorizontally)
) {
    Text("Add Item")
}
```

| Piece | Why |
| :--- | :--- |
| `onClick = { }` | Required. Empty for now — dialog comes later |
| `Modifier.align(Alignment.CenterHorizontally)` | Center in the `Column` (only works as a child of `Column`) |
| `Text("Add Item")` | Button **must** have content or Compose errors |

Use **Material 3** `Button` (`androidx.compose.material3.Button`).

Run it: a centered **Add Item** button. In the finished app it sits at the **top** — `LazyColumn` with `fillMaxSize()` will push it up in a later lecture.
