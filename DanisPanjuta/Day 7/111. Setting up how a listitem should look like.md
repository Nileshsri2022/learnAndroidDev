# Designing `ShoppingListItem` — Your Own Row Composable

---

## Overview

Each grocery row: name, quantity, edit icon, delete icon. This lecture extracts a **custom composable** and shows the **name** only. Quantity and icons come after a lambda detour.

You also write your **own** `onClick`-style parameters: lambdas.

---

## 1. Signature — data + two callbacks

Outside `ShoppingListApp()`:

```kotlin
@Composable
fun ShoppingListItem(
    item: ShoppingItem,
    onEditClick: () -> Unit,
    onDeleteClick: () -> Unit
) {
    // UI
}
```

| Parameter | Meaning |
| :--- | :--- |
| `item` | The row’s data (`name`, `quantity`, …) |
| `onEditClick: () -> Unit` | Code to run when edit is tapped. **No args, no return** |
| `onDeleteClick: () -> Unit` | Same for delete |

`()` = no input. `Unit` = no useful return (like `void`).

You have been **passing** lambdas since Day 5 (`onClick = { ... }`). This is the first time you **declare** a parameter that accepts one. The parent decides *what* edit/delete mean; the child only *when*.

---

## 2. A bordered `Row`

Rows go **horizontal**. The finished item is one horizontal strip:

```kotlin
@Composable
fun ShoppingListItem(
    item: ShoppingItem,
    onEditClick: () -> Unit,
    onDeleteClick: () -> Unit
) {
    Row(
        modifier = Modifier
            .padding(8.dp)
            .fillMaxWidth()
            .border(
                border = BorderStroke(2.dp, Color(0xFF018786)),
                shape = RoundedCornerShape(20)
            )
    ) {
        Text(
            text = item.name,
            modifier = Modifier.padding(8.dp)
        )
    }
}
```

| Modifier | Role |
| :--- | :--- |
| `padding(8.dp)` | Space around the card (8dp grid again) |
| `fillMaxWidth()` | Full list width |
| `BorderStroke(2.dp, Color(0xFF018786))` | 2dp cyan/teal stroke. Hex `0xFF018786` (the video says “F018786”) |
| `RoundedCornerShape(20)` | 20% rounded corners (there is also a `dp` overload) |

You could use `Color.Black` etc.; hex is how you pick a custom teal.

## 3. Call it from `LazyColumn`

```kotlin
items(sItems) {
    ShoppingListItem(
        item = it,
        onEditClick = { },
        onDeleteClick = { }
    )
}
```

`it` is the current `ShoppingItem`. Empty lambdas `{ }` mean the icons (once added) do nothing yet.

Add “keyboard” / “mouse” in the dialog → names appear in the list. No qty, no buttons yet.
