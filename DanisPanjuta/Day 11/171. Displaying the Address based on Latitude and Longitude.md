# Displaying the Address based on Latitude and Longitude

---

## Overview

Displaying raw GPS numbers like `50.9413, 6.9583` is helpful for debugging, but useless to most end
users. People understand street names, postal codes, and city names.

**Reverse Geocoding** is the process of converting numerical geographic coordinates (latitude and
longitude) into a human-readable street address. Android provides the `Geocoder` class for this
purpose.

---

## Step 1 — add Google Play Services Maps dependency

In `app/build.gradle.kts`:

```kotlin
dependencies {
    implementation("com.google.android.gms:play-services-maps:18.2.0")
}
```

This brings in `LatLng` and related mapping classes.

---

## Step 2 — reverse geocoding in `LocationUtils`

Add the `reverseGeocodeLocation` function to `LocationUtils`:

```kotlin
fun reverseGeocodeLocation(location: LocationData): String {
    val geocoder = Geocoder(context, Locale.getDefault())
    val coordinate = LatLng(location.latitude, location.longitude)

    val addresses: MutableList<Address>? =
        geocoder.getFromLocation(coordinate.latitude, coordinate.longitude, 1)

    return if (addresses?.isNotEmpty() == true) {
        addresses[0].getAddressLine(0)
    } else {
        "Address not found"
    }
}
```

Key points:

### 1. `Geocoder(context, Locale.getDefault())`

- `context`: Required by system services to access Android resources.
- `Locale.getDefault()`: Formats the address according to the device's current locale (e.g., German
  formatting in Germany, US formatting in the United States). You can also force a specific locale if
  desired.

### 2. `geocoder.getFromLocation(lat, lng, maxResults)`

- `maxResults = 1`: We only want the most accurate, best-matching address.
- Notice that in newer Android versions, `getFromLocation(double, double, int)` has a strike-through
  indicating deprecation in favor of an asynchronous listener API. However, for synchronous/simple
  usage, this method still works reliably as demonstrated in the course.

### 3. Safe unpack of nullable list

```kotlin
val addresses: MutableList<Address>?
```

- A coordinate in the open ocean or middle of the desert may yield zero addresses or `null`.
- Checking `addresses?.isNotEmpty() == true` safely confirms that at least one address was returned.
- `addresses[0].getAddressLine(0)` retrieves the full formatted single-line street address (e.g.,
  *"Universitätsstraße 3, 50931 Köln, Germany"*).

## Step 3 — update `LocationDisplay` UI

In `MainActivity`:

```kotlin
@Composable
fun LocationDisplay(
    locationUtils: LocationUtils,
    viewModel: LocationViewModel,
    context: Context
) {
    val location = viewModel.location.value
    val address = location?.let {
        locationUtils.reverseGeocodeLocation(it)
    }

    // ... launcher and column setup ...

    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        if (location != null) {
            Text(text = "Address: ${location.latitude} ${location.longitude} \n $address")
        } else {
            Text(text = "Location not available")
        }

        Button(onClick = {
            if (locationUtils.hasLocationPermission(context)) {
                locationUtils.requestLocationUpdates(viewModel = viewModel)
            } else {
                requestPermissionLauncher.launch(
                    arrayOf(
                        Manifest.permission.ACCESS_FINE_LOCATION,
                        Manifest.permission.ACCESS_COARSE_LOCATION
                    )
                )
            }
        }) {
            Text(text = "Get Location")
        }
    }
}
```

## Testing in the emulator

1. Run the app and tap **Get Location**.
2. If location was set to Cologne:
   - Latitude and Longitude appear.
   - The address string resolves to: `Universitätsstraße 3, Köln, Germany`.
3. Set the emulator position to Cape Point, Australia or another landmark:
   - The coordinates change immediately.
   - The reverse-geocoded address updates to reflect the new landmark and country.

## Summary of the location conversion flow

```text
GPS Receiver / Emulator
         │ (lat, lng)
         ▼
LocationData(latitude, longitude)
         │
         ▼
Geocoder.getFromLocation(lat, lng, 1)
         │ (List<Address>?)
         ▼
address[0].getAddressLine(0)
         │ (formatted String)
         ▼
Rendered in Text Composable:
"Address: 50.9413 6.9583
 Universitätsstraße 3, Köln, Germany"
```

---

## Recap / cheat sheet

- **Reverse Geocoding:** coordinates `(lat, lng)` → readable address.
- `Geocoder(context, Locale.getDefault())` handles the translation.
- `geocoder.getFromLocation(lat, lng, maxResults)` queries the address provider.
- `addresses[0].getAddressLine(0)` gives the complete formatted street line.
- Always handle null or empty results gracefully with `"Address not found"`.
