Here is a clear, structured breakdown of the lecture on **`while` loops with a counter** —
your first loop, and the concept the Rock, Paper, Scissors exercises depend on.

---

### **1. What Is a Loop?**

> A **loop** executes a block of code **again and again, as long as its condition is true.**

```kotlin
while (condition) {
    // runs repeatedly while the condition holds
}
```

---

### **2. The Danger: Infinite Loops**

```kotlin
while (true) {
    println("forever")
}
```

The condition never becomes false, so the loop **never ends** — it prints until memory runs
out and the application crashes. **Never do this.**

The rule:

> Every loop needs a condition that **can eventually become false**, and something inside the
> loop that **makes it become false**.

---

### **3. The Counter Pattern**

```kotlin
var count = 0

while (count < 3) {
    println("Count is $count")
    count++
}
println("Loop is done")
```

Output:

```text
Count is 0
Count is 1
Count is 2
Loop is done
```

#### Step by step

| Iteration | `count` at check | `count < 3`? | Action |
| :--- | :--- | :--- | :--- |
| 1 | 0 | ✅ true | print 0, increment → 1 |
| 2 | 1 | ✅ true | print 1, increment → 2 |
| 3 | 2 | ✅ true | print 2, increment → 3 |
| — | 3 | ❌ **false** (3 is *equal*, not less) | **exit the loop** |

That is why the last printed value is **2**, not 3.

---

### **4. Three Identical Ways to Increment**

```kotlin
count = count + 1
count += 1
count++
```

All three do exactly the same thing. **`count++`** is the idiomatic choice.

---

### **5. The Condition Is a Boolean**

This connects straight back to the Booleans lecture:

```kotlin
count < 3      // evaluates to true or false
```

`while` doesn't care *how* you produce the boolean — a numeric comparison, a boolean
variable, or a compound `&&` expression all work identically.

---

### **6. String Templates Work With Numbers**

```kotlin
println("Count is $count")
```

You needed `.toInt()` to go **string → number**, but **number → string is automatic** inside
a string template. No conversion required.

---

### **7. Other Loop Types**

Kotlin also has `for` loops (used with lists on Day 4) and `do-while`. The instructor defers
them until they're needed — for now, `while` is enough.

---

### **Key Takeaways**

1. **`while (condition) { }`** repeats a block while the condition is true.
2. A condition that **can never become false** creates an **infinite loop** and crashes the
   app.
3. The standard fix is a **counter variable** that you increment inside the loop.
4. **`count++`**, **`count += 1`** and **`count = count + 1`** are equivalent.
5. `count < 3` stops at **2** — the loop exits as soon as the check fails.
6. The condition is just a **boolean**, so anything that produces one will drive a loop.
