Here is a clear, structured breakdown of the lecture on **Booleans** and the three logical
operations — the foundation of every condition you will write, including the whole Rock,
Paper, Scissors game.

---

### **1. What Is a Boolean?**

A `Boolean` holds exactly one of two values:

```kotlin
val myTrue: Boolean = true
val myFalse: Boolean = false
```

There is **nothing in between**. (A nullable `Boolean?` can also be `null` — "empty" — but
the instructor deliberately skips that as too advanced for now.)

---

### **2. Reading the Colour Coding**

Android Studio colours Kotlin keywords differently, and it's worth learning to read:

| Colour | Meaning | Examples |
| :--- | :--- | :--- |
| **Orange** | Kotlin keyword | `true`, `false`, `val`, `var` |
| **Blue** | Special function | `main` |
| **White** | Your own names | `myTrue`, `println` |

`true` and `false` are **keywords**, not strings — never wrap them in quotes.

---

### **3. The Three Logical Operations**

| Name | Operator | Kotlin | Rule |
| :--- | :--- | :--- | :--- |
| **Disjunction** (OR) | `\|\|` | `a \|\| b` | `true` if **either** side is true |
| **Conjunction** (AND) | `&&` | `a && b` | `true` only if **both** sides are true |
| **Negation** (NOT) | `!` | `!a` | Flips the value |

---

### **4. Worked Example**

```kotlin
val myTrue: Boolean = true
val myFalse: Boolean = false

println(myTrue || myFalse)   // true   ← one side is true
println(myTrue && myFalse)   // false  ← not BOTH true
println(!myTrue)             // false  ← negation of true
```

Actual console output:

```text
true
false
false
```

---

### **5. Side Topic: Inline Comments**

Introduced here because the instructor annotates the examples as he writes them:

```kotlin
println(myTrue || myFalse)   // this will be true
```

Everything after **`//`** on a line is **ignored by the compiler**. Comments exist purely for
humans — to explain intent to your future self or a teammate.

---

### **6. Why This Lecture Matters**

The Rock, Paper, Scissors logic is entirely boolean:

```kotlin
playerChoice == "Rock" && computerChoice == "Scissors"   // → true means the player wins
```

Equality comparisons (`==`) produce booleans, and `&&` / `||` combine them. Without this
lecture the game's winning conditions make no sense.

---

### **Key Takeaways**

1. **`Boolean`** = `true` or `false`, nothing else. They are **keywords**, not strings.
2. **`||`** = OR (either), **`&&`** = AND (both), **`!`** = NOT (flip).
3. `myTrue || myFalse` → `true`; `myTrue && myFalse` → `false`; `!myTrue` → `false`.
4. **`//`** starts an inline comment; the compiler ignores the rest of that line.
5. Booleans are what **conditions are made of** — every `if` and every `when` branch in this
   course reduces to them.
