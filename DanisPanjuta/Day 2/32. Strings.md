Here is a clear, structured breakdown of the lecture on **Strings** — the last data type
before the Rock, Paper, Scissors build begins.

---

### **1. What Is a String?**

A `String` stores **a sequence of characters** — a word, a sentence, or paragraphs of text.

```kotlin
val name = "Dennis"
```

**Double quotes** are what make it a string. Even an empty pair creates one:

```kotlin
var name = ""      // a String — empty, but NOT null
```

Printing it outputs nothing visible, yet it is a real value. (`null` — meaning genuinely
absent — is a separate concept covered much later.)

---

### **2. A String Is a Collection of Chars**

The documentation's point: you can index into a string like a list, because a string is
fundamentally a **sequence of `Char`s**. (The docs demonstrate this with a `for` loop — a
concept you haven't met yet, which the instructor cites as another example of why the
official docs are a poor beginner guide.)

---

### **3. `var` vs `val` — The IDE Tells You**

```kotlin
var name = "Dennis"        // ⚠️ IDE: "you never change this — use val"
name = "Frank"             // now the warning disappears
```

Android Studio actively nudges you toward **`val`** whenever a variable is never reassigned.
Listen to it.

---

### **4. Strings Are Objects — So They Have Methods**

Everything in Kotlin behaves like an object, and objects expose **functions** (called
**methods** when invoked on an object):

```kotlin
println(name.lowercase())   // everything → lowercase
println(name.uppercase())   // everything → UPPERCASE
```

Type a variable followed by **`.`** and Android Studio autocompletes every available method.
`uppercase()`, `lowercase()` and `println()` are all the same kind of thing — **executable
functions**.

---

### **5. Concatenation — Joining Strings With `+`**

```kotlin
val firstName = "Dennis"
val lastName = "Panjuta"

println(firstName + lastName)      // DennisPanjuta   ← no space!
println(firstName + " " + lastName) // Dennis Panjuta  ← add the space yourself
```

The `+` operator **does not insert a space**. You must add one explicitly.

---

### **6. Escape Sequences in Strings**

| Escape | Effect |
| :--- | :--- |
| **`\n`** | **New line** — everything after it prints on the next line |
| **`\t`** | **Tab** |

```kotlin
println("Dennis\nPanjuta")
// Dennis
// Panjuta
```

---

### **7. Commenting Out Code (Recap)**

```kotlin
// name = "Frank"     ← greyed out, ignored by the compiler
```

Everything after **`//`** on a line is not code. Useful for temporarily disabling a line
while testing.

---

### **Key Takeaways**

1. **`String`** = characters in sequence, written in **double quotes**. `""` is a valid
   empty string, not `null`.
2. Kotlin **warns you to use `val`** when a `var` is never reassigned.
3. Strings are **objects**, so they have methods: `.uppercase()`, `.lowercase()`, and many
   more via autocomplete.
4. **`+` concatenates** but adds **no space** — supply it yourself.
5. **`\n`** = new line, **`\t`** = tab.
6. **`//`** comments out the rest of a line.
7. With strings done, the remaining prerequisites are **conditions** and **user input**.
