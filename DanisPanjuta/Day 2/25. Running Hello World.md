Here is a clear, structured breakdown of the lecture on **running Kotlin code** — both inside
Android Studio and in a browser.

---

### **1. Overview**

Days 2–4 need a fast way to execute small snippets without building an Android app. This
lecture sets that up.

---

### **2. Option A (Recommended): A Bare Kotlin Project in Android Studio**

#### Creating the project

```
File → Close Project  →  New Project  →  No Activity  →  Next
```

| Setting | Value | Why |
| :--- | :--- | :--- |
| **Template** | **No Activity** | No UI, no `MainActivity`, no Compose boilerplate — nothing to distract you |
| **Name** | `Kotlin Basics` | |
| **Package** | `eu.tutorials.kotlinbasics` | Same reverse-domain format as before |

#### Adding the file

In the Project panel, make sure **`Android`** is selected in the view dropdown, then:

```
app → kotlin+java → eu.tutorials.kotlinbasics → right-click → New → Kotlin Class/File
```

Choose **File** (not Class) and name it `Basics`. It contains only:

```kotlin
package eu.tutorials.kotlinbasics
```

#### The entry point

```kotlin
fun main() {
    println("Hello, World!")
}
```

| Piece | Meaning |
| :--- | :--- |
| **`fun`** | The Kotlin keyword for **function** |
| **`main`** | The special name Kotlin looks for as the **program's entry point** |
| **`()`** | The parameter list — empty, because `main` takes nothing |
| **`{ }`** | The body — code runs top to bottom inside here |
| **`println(...)`** | Built-in function that prints a line to the **console** |

Press **Run ▶**. The output appears in the console at the bottom:

```text
Hello, World!
```

### **3. Option B: Kotlin Playground (Browser)**

**`play.kotlinlang.org`** — or search *"run Kotlin code online"*.

It opens with the same `fun main()` / `println("Hello, World!")` starter and a **Run**
button. No install, no Gradle, instant.

#### Why the instructor doesn't use it in the course

| Downside | Detail |
| :--- | :--- |
| **Needs internet** | Android Studio works offline |
| **Not under his control** | If the site shuts down, every recorded video breaks. He has had to **re-record courses** before because of exactly this |
| **Slight differences** | Behaviour may not match Android Studio precisely |

Use it freely for quick experiments — just know the course itself uses Android Studio.

---

### **4. Sequential Execution**

Both environments run your code **line by line, top to bottom**. That simple fact becomes
important in the next lecture, when reassigning a variable produces different output
depending on *where* the `println` sits.

---

### **Key Takeaways**

1. Create a **No Activity** project for pure-Kotlin practice — it has no Android clutter.
2. **`fun main() { }`** is the entry point; without it nothing runs.
3. **`println()`** prints to the console — your main feedback loop for the next three days.
4. Code executes **sequentially**, top to bottom.
5. **Kotlin Playground** is a fine scratchpad, but the course standard is Android Studio so
   that results always match the videos.
