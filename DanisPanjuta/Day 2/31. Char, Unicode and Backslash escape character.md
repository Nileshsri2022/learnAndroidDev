Here is a clear, structured breakdown of the lecture on the **`Char` type**, Unicode, and the
backslash escape character.

---

### **1. What Is a `Char`?**

A `Char` stores **exactly one character** — not a word, not a sentence. Use it when you need
a single symbol (a grade, a yes/no flag, a separator).

```kotlin
val myChar = 'a'
println(myChar)      // a
```

---

### **2. Single Quotes, Not Double**

This is the one syntax rule that matters:

| Quotes | Type | Holds |
| :--- | :--- | :--- |
| **`'a'`** | `Char` | **one** character |
| **`"a"`** | `String` | any number of characters |

Trying to put two characters in a `Char` is an immediate error:

```kotlin
val myChar = 'ad'    // ❌ too many characters
```

---

### **3. Unicode**

`Char` isn't limited to the Latin alphabet — it can hold **any Unicode character**, including
emoji and scripts from any language. Unicode 15.1 contains **149,874 characters**, because it
must account for every Chinese, Arabic, Cyrillic and Latin glyph in existence.

---

### **4. Escape Sequences — Typing What Isn't on Your Keyboard**

A **backslash `\`** is the **escape character**: it tells Kotlin *"something special follows."*

#### The Unicode escape

To type the copyright sign © (which has no key), look up its code point — **U+00AE** — and
write:

```kotlin
val copyright = '\u00AE'
println(copyright)      // ©
```

Search **"Unicode table"** to find any character's code point.

#### Other common escapes

| Escape | Produces |
| :--- | :--- |
| `\t` | a **tab** |
| `\b` | a **backspace** |
| `\\` | a literal **backslash** |

---

### **5. Printing an Actual Backslash**

Because `\` is the escape marker, a lone backslash is ambiguous. You must **escape the
escape**:

```kotlin
println('\\')      // prints: \
```

The first `\` says "special character coming"; the second is the character itself. Only one
appears in the output.

Escape characters come up properly again later in the course — the Day 4 BankAccountApp uses
`$$amount` to print a dollar sign followed by a variable.

---

### **Key Takeaways**

1. **`Char`** holds **exactly one** character, written in **single quotes**.
2. **Double quotes make a `String`** — the two are not interchangeable.
3. `Char` supports **all of Unicode** (~150,000 characters), not just ASCII.
4. **`\u00AE`** is a Unicode escape — the way to write characters absent from your keyboard.
5. **`\` is the escape character.** To print a real backslash, write `\\`.
6. Other useful escapes: **`\t`** (tab) and **`\b`** (backspace).
