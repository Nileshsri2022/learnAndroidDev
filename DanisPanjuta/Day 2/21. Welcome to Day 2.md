### **1. What You Build Today**

A **Rock, Paper, Scissors** game. It runs on your PC as a plain Kotlin program — no Android
UI, no emulator.

---

### **2. Why Three Days of Kotlin First?**

The instructor's reasoning:

> It is **too complex to teach language basics inside a full Android app.**

Even a trivial Android screen contains imports, composables, lifecycle methods and Gradle
config. Learning what a *variable* is while all of that is on screen means fighting two
problems at once. So Days 2–4 strip everything away and teach Kotlin in isolation:

| Day | Topic | Project |
| :--- | :--- | :--- |
| **Day 2** | Variables, data types, `if`, `when` | Rock, Paper, Scissors |
| **Day 3** | Functions, classes, objects | Coffee machine |
| **Day 4** | Lists, for loops | Bank account |

---

### **3. Today's Syllabus**

1. **Variables** — storing data
2. **Data types** — numbers, text, booleans
3. **`if` statements and conditions**
4. **`when` statements**
5. **Exercises** in between — the instructor strongly recommends doing them
6. **Rock, Paper, Scissors** at the end

---

### **Key Takeaways**

1. Today is **Kotlin only** — you'll run code in a console, not on an emulator.
2. The day ends with a **working game**, so every concept has an immediate purpose.
3. **Do the exercises.** They are the difference between recognising syntax and being able
   to write it.
4. Day 1 was UI and setup; **Day 2 is where the actual coding starts.**
