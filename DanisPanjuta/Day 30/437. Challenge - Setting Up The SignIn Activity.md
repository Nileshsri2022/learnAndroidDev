# Challenge - Setting Up The SignIn Activity

---

## Overview

Challenge: build **SignInActivity** yourself — it's almost identical to Sign Up, minus the Name field.

---

## Differences from Sign Up

| | Sign Up | Sign In |
| :--- | :--- | :--- |
| Toolbar id | `toolbar_sign_up_activity` | `toolbar_sign_in_activity` |
| Description | "Enter name, email and password to register" | "Enter email and password to login" |
| Fields | Name, Email, Password | Email, Password |
| Button | SIGN UP | SIGN IN |

---

## Code

```kotlin
class SignInActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_sign_in)
        window.setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN,
                        WindowManager.LayoutParams.FLAG_FULLSCREEN)
        setupActionBar()
    }

    private fun setupActionBar() {
        setSupportActionBar(toolbar_sign_in_activity)
        supportActionBar?.setDisplayHomeAsUpEnabled(true)
        supportActionBar?.setHomeAsUpIndicator(R.drawable.ic_black_color_back_24dp)
        toolbar_sign_in_activity.setNavigationOnClickListener { onBackPressed() }
    }
}
```

Intro: `btn_sign_in_intro.setOnClickListener { startActivity(Intent(this, SignInActivity::class.java)) }`.
