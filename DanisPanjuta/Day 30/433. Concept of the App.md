# Concept of the App

---

## Overview

A demo of the finished **Projemanag** app and its data model.

---

## Screens

```
SplashActivity ──(2.5 s)──► IntroActivity (SIGN IN / SIGN UP)
                              │
             SignUpActivity ◄─┴─► SignInActivity
                                        │ (auto login if already signed in)
                                        ▼
MainActivity  ── Drawer: My Profile, Sign Out
  ├─ RecyclerView of boards (image, name, created by)
  ├─ FAB ──► CreateBoardActivity (image + name)
  └─ tap board ──► TaskListActivity
                     ├─ horizontal lists ("To Do", "In Progress"…) with cards
                     ├─ add / edit / delete lists, add cards, drag & drop cards
                     ├─ menu: Members ──► MembersActivity (add by email → push notification)
                     └─ tap card ──► CardDetailsActivity (name, colour label, members, due date, delete)
MyProfileActivity (image, name, email, mobile — update)
```

---

## Firestore data model

```
users (collection)
 └─ {uid}: { id, name, email, image, mobile, fcmToken }

boards (collection)
 └─ {documentId}: {
       name, image, createdBy,
       assignedTo: [uid, uid…],
       taskList: [
         { title, createdBy,
           cards: [ { name, createdBy, assignedTo: [uid…], labelColor, dueDate } ] }
       ]
    }
```

A whole board (lists + cards) is one document — updating a card rewrites `taskList`.

---

## Recap / cheat sheet

- Boards → task lists → cards; users assigned at board and card level.
