# Designing The SignUp Activity

---

## Overview

Builds **SignUpActivity**: a custom toolbar with back arrow, a description, and a **CardView** containing Name, Email, Password fields and a SIGN UP button.

---

---

## Toolbar code

```kotlin
private fun setupActionBar() {
    setSupportActionBar(toolbar_sign_up_activity)
    val actionBar = supportActionBar
    if (actionBar != null) {
        actionBar.setDisplayHomeAsUpEnabled(true)
        actionBar.setHomeAsUpIndicator(R.drawable.ic_black_color_back_24dp)
    }
    toolbar_sign_up_activity.setNavigationOnClickListener { onBackPressed() }
}
```

`setHomeAsUpIndicator` — custom back icon (black instead of white).

Intro buttons: `btn_sign_up_intro.setOnClickListener { startActivity(Intent(this, SignUpActivity::class.java)) }`.

---

## Recap / cheat sheet

- `inputType` sets the keyboard: `textEmailAddress`, `textPassword`.
- Custom back icon via `setHomeAsUpIndicator`.
