# Adding A Detail Screen For Cards

---

## Overview

Tapping a card opens **CardDetailsActivity**. The click travels from the **inner** card adapter through the **outer** task list adapter to the activity, carrying both the **task list position** and the **card position**.

---

## CardListItemsAdapter — click interface

```kotlin
private var onClickListener: OnClickListener? = null

holder.itemView.setOnClickListener {
    onClickListener?.onClick(position)
}

interface OnClickListener { fun onClick(cardPosition: Int) }
fun setOnClickListener(onClickListener: OnClickListener) { this.onClickListener = onClickListener }
```

---

## TaskListItemsAdapter — forward to activity

```kotlin
adapter.setOnClickListener(object : CardListItemsAdapter.OnClickListener {
    override fun onClick(cardPosition: Int) {
        if (context is TaskListActivity) {
            context.cardDetails(position, cardPosition)
        }
    }
})
```

---

## TaskListActivity

```kotlin
// Constants
const val TASK_LIST_ITEM_POSITION: String = "task_list_item_position"
const val CARD_LIST_ITEM_POSITION: String = "card_list_item_position"

fun cardDetails(taskListPosition: Int, cardPosition: Int) {
    val intent = Intent(this, CardDetailsActivity::class.java)
    intent.putExtra(Constants.BOARD_DETAIL, mBoardDetails)
    intent.putExtra(Constants.TASK_LIST_ITEM_POSITION, taskListPosition)
    intent.putExtra(Constants.CARD_LIST_ITEM_POSITION, cardPosition)
    startActivityForResult(intent, CARD_DETAILS_REQUEST_CODE)
}
```

## Recap / cheat sheet

- Nested click: inner adapter → outer adapter → activity.
- Pass board + list position + card position.
