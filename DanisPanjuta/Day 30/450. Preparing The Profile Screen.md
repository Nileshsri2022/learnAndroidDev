# Preparing The Profile Screen

---

## Overview

Creates **MyProfileActivity**: toolbar, a large circular profile image, and Name, Email (read-only) and Mobile fields plus an UPDATE button. The drawer's **My Profile** opens it.

---

## Layout highlights

```xml
<de.hdodenhof.circleimageview.CircleImageView
    android:id="@+id/iv_profile_user_image"
    android:layout_width="@dimen/my_profile_user_image_size"
    android:layout_height="@dimen/my_profile_user_image_size"
    android:src="@drawable/ic_user_place_holder"
    app:civ_border_color="@android:color/white"
    app:civ_border_width="@dimen/my_profile_user_image_circular_border_width" />

<!-- TextInputLayouts -->
<AppCompatEditText android:id="@+id/et_name" android:hint="@string/name" … />
<AppCompatEditText android:id="@+id/et_email" android:hint="@string/email"
    android:focusable="false" android:focusableInTouchMode="false" … />
<AppCompatEditText android:id="@+id/et_mobile" android:hint="@string/mobile"
    android:inputType="phone" … />

<Button android:id="@+id/btn_update" android:text="@string/update"
    android:background="@drawable/shape_button_rounded" … />
```

Email is **not editable** — it's the login identity in Firebase Auth.

---

## Navigation

```kotlin
R.id.nav_my_profile -> {
    startActivityForResult(Intent(this, MyProfileActivity::class.java), MY_PROFILE_REQUEST_CODE)
}
```

Toolbar title: `actionBar.title = resources.getString(R.string.my_profile)` with a white back arrow.

---

## Recap / cheat sheet

- Profile screen: image + name + (read-only) email + mobile + UPDATE.
