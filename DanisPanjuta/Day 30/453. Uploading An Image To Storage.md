# Uploading An Image To Storage

---

## Overview

Uploads the selected image to **Firebase Storage** and retrieves its public **download URL**.

---

## Setup

- Console → **Storage → Get started** (test-mode rules).
- `implementation 'com.google.firebase:firebase-storage-ktx'`

---

## Code

```kotlin
private var mProfileImageURL: String = ""

private fun uploadUserImage() {
    showProgressDialog(resources.getString(R.string.please_wait))

    if (mSelectedImageFileUri != null) {
        val sRef: StorageReference = FirebaseStorage.getInstance().reference.child(
            "USER_IMAGE" + System.currentTimeMillis() + "." +
            Constants.getFileExtension(this, mSelectedImageFileUri))

        sRef.putFile(mSelectedImageFileUri!!)
            .addOnSuccessListener { taskSnapshot ->
                Log.e("Firebase Image URL",
                    taskSnapshot.metadata!!.reference!!.downloadUrl.toString())

                taskSnapshot.metadata!!.reference!!.downloadUrl
                    .addOnSuccessListener { uri ->
                        Log.e("Downloadable Image URL", uri.toString())
                        mProfileImageURL = uri.toString()
                        updateUserProfileData()
                    }
            }
            .addOnFailureListener { exception ->
                Toast.makeText(this, exception.message, Toast.LENGTH_LONG).show()
                hideProgressDialog()
            }
    }
}

btn_update.setOnClickListener {
    if (mSelectedImageFileUri != null) {
        uploadUserImage()
    } else {
        showProgressDialog(resources.getString(R.string.please_wait))
        updateUserProfileData()
    }
}
```

| Step | API |
| :--- | :--- |
| Unique path | `reference.child("USER_IMAGE<millis>.<ext>")` |
| Upload | `putFile(uri)` |
| URL | `metadata.reference.downloadUrl` (another async task) |

Uploaded files appear in the Storage section of the console.

---

## Recap / cheat sheet

- `FirebaseStorage.getInstance().reference.child(name).putFile(uri)`.
- Then `downloadUrl` → store the URL string in Firestore.
