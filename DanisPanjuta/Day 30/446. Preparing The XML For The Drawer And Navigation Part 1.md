# Preparing The XML For The Drawer And Navigation Part 1

---

## Overview

Converts `activity_main.xml` into a **`DrawerLayout`** with a **`NavigationView`** (side menu), and includes a separate `app_bar_main` layout containing the toolbar.

---

## activity_main.xml

```xml
<androidx.drawerlayout.widget.DrawerLayout
    android:id="@+id/drawer_layout"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:openDrawer="start">

    <include
        layout="@layout/app_bar_main"
        android:layout_width="match_parent"
        android:layout_height="match_parent" />

    <com.google.android.material.navigation.NavigationView
        android:id="@+id/nav_view"
        android:layout_width="wrap_content"
        android:layout_height="match_parent"
        android:layout_gravity="start"
        android:fitsSystemWindows="true"
        app:headerLayout="@layout/nav_header_main"
        app:menu="@menu/activity_main_drawer" />
</androidx.drawerlayout.widget.DrawerLayout>
```

| Element | Role |
| :--- | :--- |
| `DrawerLayout` | Container that slides a drawer over the content |
| First child | Main content |
| `NavigationView` with `layout_gravity="start"` | The drawer (left in LTR) |
| `app:headerLayout` | Top part (avatar + name) |
| `app:menu` | Menu items |

---

## Drawer menu — `menu/activity_main_drawer.xml`

```xml
<menu>
    <group android:checkableBehavior="single">
        <item android:id="@+id/nav_my_profile" android:icon="@drawable/ic_nav_user"
              android:title="@string/nav_my_profile" />
        <item android:id="@+id/nav_sign_out" android:icon="@drawable/ic_nav_sign_out"
              android:title="@string/nav_sign_out" />
    </group>
</menu>
```

---

## Recap / cheat sheet

- `DrawerLayout` → content (`<include>`) + `NavigationView` (header + menu).
