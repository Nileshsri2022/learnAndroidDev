# Creating The Board In The Firestore Database

---

## Overview

Stores the board in a **`boards`** collection with an **auto-generated document ID**.

---

## Code

```kotlin
// Constants
const val BOARDS: String = "boards"

// FirestoreClass
fun createBoard(activity: CreateBoardActivity, board: Board) {
    mFireStore.collection(Constants.BOARDS)
        .document()                            // auto ID
        .set(board, SetOptions.merge())
        .addOnSuccessListener {
            Log.e(activity.javaClass.simpleName, "Board created successfully.")
            Toast.makeText(activity, "Board created successfully.", Toast.LENGTH_SHORT).show()
            activity.boardCreatedSuccessfully()
        }
        .addOnFailureListener { e ->
            activity.hideProgressDialog()
            Log.e(activity.javaClass.simpleName, "Error while creating a board.", e)
        }
}
```

- `document()` with no argument → Firestore generates a unique ID.
- Check the new document in the console: `name`, `image`, `createdBy`, `assignedTo`, `taskList`.

---

## Recap / cheat sheet

- `collection(BOARDS).document().set(board)`.
