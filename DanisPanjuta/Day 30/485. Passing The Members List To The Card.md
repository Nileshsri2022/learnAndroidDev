# Passing The Members List To The Card

---

## Overview

To assign members to a card, CardDetailsActivity needs the **full `User` objects** of the board's members. TaskListActivity loads them once and passes them along.

---

## TaskListActivity

```kotlin
// Constants
const val BOARD_MEMBERS_LIST: String = "board_members_list"

lateinit var mAssignedMembersDetailList: ArrayList<User>

fun boardDetails(board: Board) {
    mBoardDetails = board
    hideProgressDialog()
    setupActionBar()

    showProgressDialog(resources.getString(R.string.please_wait))
    FirestoreClass().getAssignedMembersListDetails(this, mBoardDetails.assignedTo)
}

fun boardMembersDetailList(list: ArrayList<User>) {
    mAssignedMembersDetailList = list
    hideProgressDialog()

    val addTaskList = Task(resources.getString(R.string.add_list))
    mBoardDetails.taskList.add(addTaskList)
    rv_task_list.layoutManager = LinearLayoutManager(this, LinearLayoutManager.HORIZONTAL, false)
    rv_task_list.setHasFixedSize(true)
    rv_task_list.adapter = TaskListItemsAdapter(this, mBoardDetails.taskList)
}

fun cardDetails(taskListPosition: Int, cardPosition: Int) {
    val intent = Intent(this, CardDetailsActivity::class.java)
    …
    intent.putExtra(Constants.BOARD_MEMBERS_LIST, mAssignedMembersDetailList)
    startActivityForResult(intent, CARD_DETAILS_REQUEST_CODE)
}
```

The RecyclerView setup moved into `boardMembersDetailList` so members are available before cards render (needed to show member avatars on cards).

---

## CardDetailsActivity

```kotlin
private lateinit var mMembersDetailList: ArrayList<User>

if (intent.hasExtra(Constants.BOARD_MEMBERS_LIST)) {
    mMembersDetailList = intent.getParcelableArrayListExtra(Constants.BOARD_MEMBERS_LIST)!!
}
```

`User` is Parcelable → `ArrayList<User>` can travel via `putExtra`.

---

## Recap / cheat sheet

- Load board members once; pass `ArrayList<User>` with `getParcelableArrayListExtra`.
