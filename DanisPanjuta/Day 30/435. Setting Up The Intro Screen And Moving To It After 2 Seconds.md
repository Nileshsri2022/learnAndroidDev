# Setting Up The Intro Screen And Moving To It After 2 Second

---

## Overview

After ~2.5 seconds the splash navigates to **IntroActivity** — logo, "Let's get started", a description, and **SIGN IN** / **SIGN UP** buttons.

---

## Delayed navigation

```kotlin
Handler(Looper.getMainLooper()).postDelayed({
    startActivity(Intent(this@SplashActivity, IntroActivity::class.java))
    finish()
}, 2500)
```

- `postDelayed(runnable, ms)` runs code later on the main thread.
- `finish()` so Back doesn't return to the splash.

(Android 12+ also offers the official **SplashScreen API**.)

## Intro layout highlights

```xml
<LinearLayout android:background="@drawable/ic_background" android:orientation="vertical" …>
    <ImageView android:src="@drawable/app_logo" … />
    <TextView android:id="@+id/tv_app_name_intro" android:text="@string/app_name" … />
    <TextView android:text="@string/intro_screen_description"
        android:gravity="center" android:textColor="@color/secondary_text_color" … />

    <Button
        android:id="@+id/btn_sign_in_intro"
        android:background="@drawable/white_border_shape_button_rounded"
        android:text="@string/sign_in"
        android:textColor="@color/white" … />

    <Button
        android:id="@+id/btn_sign_up_intro"
        android:background="@drawable/shape_button_rounded"
        android:text="@string/sign_up"
        android:foreground="?attr/selectableItemBackground" … />
</LinearLayout>
```

`shape_button_rounded.xml` — a rectangle with `corners android:radius="20dp"` and solid colour; the white-border variant uses `stroke`.

Apply the same custom font and full-screen flags.
