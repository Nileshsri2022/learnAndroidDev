# Setting Up The Splashscreen, Using Custom Fonts And How To Find Them

---

## Overview

Creates the project, packages (`activities`, `adapters`, `firebase`, `models`, `utils`), and a full-screen **SplashActivity** with a background image and the app name in a **custom font**.

---

## Project structure

```
com.projemanag
 ├─ activities   (SplashActivity, IntroActivity, …)
 ├─ adapters
 ├─ firebase     (FirestoreClass)
 ├─ models       (User, Board, Task, Card)
 └─ utils        (Constants)
```

Move `MainActivity` into `activities` and fix the manifest path. Set `SplashActivity` as the **launcher**.

---

## Finding fonts

- **Google Fonts** / **dafont.com** / **fontsquirrel.com** — check the license (free for commercial use?).
- Put `.ttf` files in **`app/src/main/assets/`** (New → Folder → Assets Folder).

---

## Code

```kotlin
class SplashActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_splash)

        window.setFlags(
            WindowManager.LayoutParams.FLAG_FULLSCREEN,
            WindowManager.LayoutParams.FLAG_FULLSCREEN
        )

        val typeFace: Typeface = Typeface.createFromAsset(assets, "carbon bl.ttf")
        tv_app_name.typeface = typeFace
    }
}
```

Alternative: `res/font/` folder + `android:fontFamily="@font/carbon"` in XML.

---

## Recap / cheat sheet

- Custom font: `assets/*.ttf` → `Typeface.createFromAsset(assets, "file.ttf")`.
- `FLAG_FULLSCREEN` for an immersive splash.
