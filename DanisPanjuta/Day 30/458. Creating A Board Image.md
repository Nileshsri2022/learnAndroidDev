# Creating A Board Image

---

## Overview

On CREATE, upload the board image to **Firebase Storage** (if chosen), then create the board with its URL.

---

## Code

```kotlin
private var mBoardImageURL: String = ""

btn_create.setOnClickListener {
    if (mSelectedImageFileUri != null) {
        uploadBoardImage()
    } else {
        showProgressDialog(resources.getString(R.string.please_wait))
        createBoard()
    }
}

private fun uploadBoardImage() {
    showProgressDialog(resources.getString(R.string.please_wait))

    val sRef: StorageReference = FirebaseStorage.getInstance().reference.child(
        "BOARD_IMAGE" + System.currentTimeMillis() + "." +
        Constants.getFileExtension(this, mSelectedImageFileUri))

    sRef.putFile(mSelectedImageFileUri!!)
        .addOnSuccessListener { taskSnapshot ->
            taskSnapshot.metadata!!.reference!!.downloadUrl
                .addOnSuccessListener { uri ->
                    mBoardImageURL = uri.toString()
                    createBoard()
                }
        }
        .addOnFailureListener { exception ->
            Toast.makeText(this, exception.message, Toast.LENGTH_LONG).show()
            hideProgressDialog()
        }
}
```

A board without an image is allowed — `mBoardImageURL` stays empty and a placeholder is shown.

---

## Recap / cheat sheet

- Prefix `BOARD_IMAGE` distinguishes board files from `USER_IMAGE`s.
- Upload → download URL → `createBoard()`.
