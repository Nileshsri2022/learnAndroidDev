# Using The FireStore Database to Store The User Details Part 2

---

## Overview

Creates **`FirestoreClass`** — the single place for all Firestore calls — and stores the new `User` document right after registration.

---

## Constants

```kotlin
object Constants {
    const val USERS: String = "users"
}
```

---

## FirestoreClass.registerUser

```kotlin
class FirestoreClass {

    private val mFireStore = FirebaseFirestore.getInstance()

    fun registerUser(activity: SignUpActivity, userInfo: User) {
        mFireStore.collection(Constants.USERS)
            .document(getCurrentUserId())
            .set(userInfo, SetOptions.merge())
            .addOnSuccessListener {
                activity.userRegisteredSuccess()
            }
            .addOnFailureListener { e ->
                Log.e(activity.javaClass.simpleName, "Error writing document", e)
            }
    }

    fun getCurrentUserId(): String {
        val currentUser = FirebaseAuth.getInstance().currentUser
        var currentUserID = ""
        if (currentUser != null) currentUserID = currentUser.uid
        return currentUserID
    }
}
```

- Document ID = Firebase Auth **UID** → easy lookup of the user's profile.
- `SetOptions.merge()` — merge fields rather than overwrite the whole document.

## SignUpActivity

```kotlin
if (task.isSuccessful) {
    val firebaseUser: FirebaseUser = task.result!!.user!!
    val registeredEmail = firebaseUser.email!!
    val user = User(firebaseUser.uid, name, registeredEmail)
    FirestoreClass().registerUser(this@SignUpActivity, user)
}

fun userRegisteredSuccess() {
    Toast.makeText(this, "You have successfully registered.", Toast.LENGTH_SHORT).show()
    hideProgressDialog()
    FirebaseAuth.getInstance().signOut()
    finish()
}
```

Pattern: FirestoreClass receives the **activity** and calls back a public method on success.

---

## Recap / cheat sheet

- `collection(USERS).document(uid).set(user, SetOptions.merge())`.
- Callback into the activity on success.
