# Reloading The Board Details On Change

---

## Overview

When members changed, `TaskListActivity` should reload the board on return — via `setResult` in **`onBackPressed`**.

---

## MembersActivity

```kotlin
private var anyChangesMade: Boolean = false

override fun onBackPressed() {
    if (anyChangesMade) {
        setResult(Activity.RESULT_OK)
    }
    super.onBackPressed()
}
```

---

## TaskListActivity

```kotlin
companion object {
    const val MEMBERS_REQUEST_CODE: Int = 13
    const val CARD_DETAILS_REQUEST_CODE: Int = 14
}

override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    if (resultCode == Activity.RESULT_OK &&
        (requestCode == MEMBERS_REQUEST_CODE || requestCode == CARD_DETAILS_REQUEST_CODE)) {
        showProgressDialog(resources.getString(R.string.please_wait))
        FirestoreClass().getBoardDetails(this, mBoardDocumentId)
    } else {
        Log.e("Cancelled", "Cancelled")
    }
}
```

Reload only if something changed — saves network calls.

---

## Recap / cheat sheet

- Callee: `setResult(RESULT_OK)` in `onBackPressed` when changed.
- Caller: reload board on result.
