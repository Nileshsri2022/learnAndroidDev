# Using The FireStore Database to Store The User Details Part 1

---

## Overview

Authentication only stores email/password. Additional profile data (name, image, mobile…) goes into **Cloud Firestore**. Part 1: enable Firestore and create the **`User`** model.

---

## Enable Firestore

1. Firebase console → **Firestore Database → Create database**.
2. Start in **test mode** (open read/write for 30 days) — tighten **rules** later.
3. Choose a region.

```groovy
implementation 'com.google.firebase:firebase-firestore-ktx'
```

---

## Firestore concepts

| Concept | Like |
| :--- | :--- |
| **Collection** | A folder / table (`users`) |
| **Document** | A record identified by an ID (`{uid}`) |
| **Field** | Key-value inside a document |

NoSQL — documents in a collection don't need identical fields.

---

## User model (Parcelable)

```kotlin
data class User(
    val id: String = "",
    val name: String = "",
    val email: String = "",
    val image: String = "",
    val mobile: Long = 0,
    val fcmToken: String = "",
    var selected: Boolean = false
) : Parcelable {
    constructor(source: Parcel) : this(
        source.readString()!!, source.readString()!!, source.readString()!!,
        source.readString()!!, source.readLong(), source.readString()!!
    )
    override fun describeContents() = 0
    override fun writeToParcel(dest: Parcel, flags: Int) = with(dest) {
        writeString(id); writeString(name); writeString(email)
        writeString(image); writeLong(mobile); writeString(fcmToken)
    }
    companion object {
        @JvmField
        val CREATOR: Parcelable.Creator<User> = object : Parcelable.Creator<User> {
            override fun createFromParcel(source: Parcel): User = User(source)
            override fun newArray(size: Int): Array<User?> = arrayOfNulls(size)
        }
    }
}
```

**Default values are required** — Firestore needs a no-argument constructor to deserialize with `toObject()`.

## Recap / cheat sheet

- Firestore: collections → documents → fields.
- Model with defaults for every property.
