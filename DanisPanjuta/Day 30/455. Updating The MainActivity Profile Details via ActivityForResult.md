# Updating The MainActivity Profile Details via ActivityForResult

---

## Overview

When returning from the profile screen after an update, the drawer header should reflect the new name/image — using **`startActivityForResult`**.

---

## MainActivity

```kotlin
companion object {
    const val MY_PROFILE_REQUEST_CODE: Int = 11
}

R.id.nav_my_profile -> {
    startActivityForResult(
        Intent(this@MainActivity, MyProfileActivity::class.java),
        MY_PROFILE_REQUEST_CODE)
}

override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    if (resultCode == Activity.RESULT_OK && requestCode == MY_PROFILE_REQUEST_CODE) {
        FirestoreClass().loadUserData(this@MainActivity)
    } else {
        Log.e("Cancelled", "Cancelled")
    }
}
```

`MyProfileActivity.profileUpdateSuccess()` calls `setResult(Activity.RESULT_OK)` before `finish()`.

---

## Recap / cheat sheet

- Refresh the caller only when the callee reports `RESULT_OK`.
