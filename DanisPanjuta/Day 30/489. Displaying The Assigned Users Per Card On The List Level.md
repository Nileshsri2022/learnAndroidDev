# Displaying The Assigned Users Per Card On The List Level

---

## Overview

Cards in the task list show **small avatars** of their assigned members — but only if someone **other than the creator alone** is assigned.

---

## CardListItemsAdapter

```kotlin
if ((context as TaskListActivity).mAssignedMembersDetailList.size > 0) {
    val selectedMembersList: ArrayList<SelectedMembers> = ArrayList()

    for (i in context.mAssignedMembersDetailList.indices) {
        for (j in model.assignedTo) {
            if (context.mAssignedMembersDetailList[i].id == j) {
                selectedMembersList.add(SelectedMembers(
                    context.mAssignedMembersDetailList[i].id,
                    context.mAssignedMembersDetailList[i].image))
            }
        }
    }

    if (selectedMembersList.size > 0) {
        if (selectedMembersList.size == 1 && selectedMembersList[0].id == model.createdBy) {
            holder.itemView.rv_card_selected_members_list.visibility = View.GONE
        } else {
            holder.itemView.rv_card_selected_members_list.visibility = View.VISIBLE
            holder.itemView.rv_card_selected_members_list.layoutManager =
                GridLayoutManager(context, 4)
            val adapter = CardMemberListItemsAdapter(context, selectedMembersList, false)
            holder.itemView.rv_card_selected_members_list.adapter = adapter
            adapter.setOnClickListener(object : CardMemberListItemsAdapter.OnClickListener {
                override fun onClick() { onClickListener?.onClick(position) }
            })
        }
    } else {
        holder.itemView.rv_card_selected_members_list.visibility = View.GONE
    }
}
```

- `mAssignedMembersDetailList` made **public** (no `private`) in TaskListActivity so the adapter can read it.
- Tapping the avatar strip opens the card, same as tapping the card.

Now **three levels** of nested RecyclerViews: task lists → cards → member avatars.

---

## Recap / cheat sheet

- Hide avatars if only the creator is assigned.
- `assignMembers = false` → no "+" item on list level.
