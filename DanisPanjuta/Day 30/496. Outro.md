## Overview

The **most complex application of the course** is done — as much content as another entire course. It grew feature by feature because each addition seemed too valuable to leave out.

---

## What the Trello clone covered

| Area | Features |
| :--- | :--- |
| **Auth** | Sign up / in / out, auto login |
| **Firestore** | Users, boards, lists, cards; `set`, `update`, `whereArrayContains`, `whereIn`, `whereEqualTo` |
| **Storage** | Profile and board images |
| **UI** | Splash, intro, drawer, nested RecyclerViews (3 levels), custom dialogs |
| **Collaboration** | Members per board and per card |
| **Card details** | Name, colour label, members, due date, delete |
| **UX** | Drag & drop, progress dialogs, snackbars |
| **Push** | FCM tokens and notifications |

---

## Ideas to extend

- Remove members from a board.
- Drag cards **between** lists.
- Sort/filter by due date, overdue highlighting.
- Replace `AsyncTask` with coroutines; migrate to View Binding / Compose.
- Secure Firestore **rules**; send notifications from Cloud Functions.
