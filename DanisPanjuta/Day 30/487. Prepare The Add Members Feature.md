# Prepare The Add Members Feature

---

## Overview

Handles **select/unselect** from the members dialog by adding/removing the user ID in the card's `assignedTo`, and adds a horizontal **RecyclerView** of selected member avatars in the card detail screen.

---

## Selected member model

```kotlin
data class SelectedMembers(
    val id: String = "",
    val image: String = ""
) : Parcelable { … }
```

---

## Dialog callback

```kotlin
override fun onItemSelected(user: User, action: String) {
    if (action == Constants.SELECT) {
        if (!mBoardDetails.taskList[mTaskListPosition].cards[mCardPosition]
                .assignedTo.contains(user.id)) {
            mBoardDetails.taskList[mTaskListPosition].cards[mCardPosition]
                .assignedTo.add(user.id)
        }
    } else {
        mBoardDetails.taskList[mTaskListPosition].cards[mCardPosition]
            .assignedTo.remove(user.id)
        for (i in mMembersDetailList.indices) {
            if (mMembersDetailList[i].id == user.id) mMembersDetailList[i].selected = false
        }
    }
    setupSelectedMembersList()
}
```

---

## Recap / cheat sheet

- SELECT → `assignedTo.add(id)`; UN_SELECT → `remove(id)`.
- `SelectedMembers(id, image)` feeds the avatar row.
