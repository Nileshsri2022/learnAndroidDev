# Introduction to the Chapter - Trello Clone

---

## Overview

Day 30 is the **largest project of the course**: a **Trello clone** (app name *Projemanag*) — a project-management app with boards, task lists and cards, shared between users in real time via **Firebase**.

---

## What you will learn

| Topic | Details |
| :--- | :--- |
| **Splash & intro screens** | Custom fonts, delayed navigation |
| **Firebase Authentication** | Email/password sign up, sign in, auto login, sign out |
| **Cloud Firestore** | Storing users, boards, task lists, cards; queries |
| **Firebase Storage** | Uploading profile and board images |
| **Navigation Drawer** | `DrawerLayout` + `NavigationView` |
| **BaseActivity** | Reusable progress dialog, snackbar, double-back-to-exit |
| **Glide** | Loading remote images |
| **Nested RecyclerViews** | Horizontal task lists containing vertical card lists |
| **Members** | Adding users to boards and cards |
| **Dialogs** | Colour label dialog, members dialog, date picker |
| **Drag & drop** | Reordering cards with `ItemTouchHelper` |
| **Push notifications** | Firebase Cloud Messaging (FCM) tokens and messages |

---

## Recap / cheat sheet

- **65 lectures** — a complete, production-style app backed by Firebase.
