# Creating Lists Inside A Board

---

## Overview

Tapping **Add List** reveals an inline input card (name + ✕ / ✓). Confirming creates a new `Task` in the board.

---

## Toggling the input (adapter)

```kotlin
holder.itemView.tv_add_task_list.setOnClickListener {
    holder.itemView.tv_add_task_list.visibility = View.GONE
    holder.itemView.cv_add_task_list_name.visibility = View.VISIBLE
}

holder.itemView.ib_close_list_name.setOnClickListener {
    holder.itemView.tv_add_task_list.visibility = View.VISIBLE
    holder.itemView.cv_add_task_list_name.visibility = View.GONE
}

holder.itemView.ib_done_list_name.setOnClickListener {
    val listName = holder.itemView.et_task_list_name.text.toString()
    if (listName.isNotEmpty()) {
        if (context is TaskListActivity) {
            context.createTaskList(listName)
        }
    } else {
        Toast.makeText(context, "Please Enter List Name.", Toast.LENGTH_SHORT).show()
    }
}
```

`context is TaskListActivity` — the adapter calls back into its hosting activity (smart cast).

---

## Activity — createTaskList

```kotlin
fun createTaskList(taskListName: String) {
    val task = Task(taskListName, FirestoreClass().getCurrentUserId())
    mBoardDetails.taskList.add(0, task)                                // add at the front
    mBoardDetails.taskList.removeAt(mBoardDetails.taskList.size - 1)   // drop "Add List" placeholder

    showProgressDialog(resources.getString(R.string.please_wait))
    FirestoreClass().addUpdateTaskList(this, mBoardDetails)
}
```

The placeholder must be removed before saving — it's UI only, not data.

---

## Recap / cheat sheet

- Inline add card with visibility toggles.
- Adapter → `(context as TaskListActivity).createTaskList(name)`.
- Remove the "Add List" placeholder before persisting.
