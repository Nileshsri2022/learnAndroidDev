### **4. The Bigger Point: These Skills Transfer**

The instructor emphasises that what you've learned is **not Kotlin-specific**:

> *"You have learned the basics of any given programming language."*

| Concept | Present in |
| :--- | :--- |
| Variables, types | Every language |
| Functions | Every language |
| Loops, conditions | Every language |
| Classes and objects | Most languages — Java, C#, Python, and more |

Syntax differs in the details; the mental model is the same. Learning Kotlin has effectively
taught you the shape of Java, C# and Python too.
