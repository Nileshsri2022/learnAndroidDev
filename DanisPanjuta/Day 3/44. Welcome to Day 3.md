This video is the **intro to Day 3** — a short preview of functions and classes.

---

### **1. What Changes Today**

Until now every function you've used was **written by someone else**:

* `main()` — Kotlin's entry point
* `println()` — output
* `readln()` — input
* `toInt()` — parsing
* `random()` — random numbers

**Today you write your own.**

---

### **2. The Two Concepts**

| Concept | What it does |
| :--- | :--- |
| **Functions** | Bundle code into a named, reusable block — write it once, call it anywhere |
| **Classes** | Group related functions *and* data together — the next level of organisation |

---

### **3. Why This Matters**

Classes are the entry point to **object-oriented programming (OOP)**, which is how Kotlin —
and therefore Android — is structured. Every screen, model and repository you build later in
the course is a class.

---

### **Key Takeaways**

1. Day 3 moves you from **calling** functions to **creating** them.
2. Functions give you **reusable code**; classes let you **cluster** functions and data.
3. This is the start of the **OOP** trail that runs through the entire course.
4. The running example all day is a **coffee machine** — small enough to follow, expressive
   enough to demonstrate every concept.
