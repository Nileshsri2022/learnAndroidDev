### **What it is**

A PDF/reference sheet attached to the lecture, summarising Day 3's syntax so you can check

### **What it covers**

The same ground as the [Day 3 summary](60-summary-of-day-3.md):

* **Functions** — `fun name(params): ReturnType { }`, defining vs calling
* **Parameters** — `name: Type`, multiple and mixed types, argument order
* **Return types** — declaring one, the `return` keyword, `Unit`
* **Integer division** — why `5 / 3` is `1`, and using `Double` to fix it
* **Classes** — `class`, primary constructor, `init`, member functions
* **Properties** — `val` vs `var`, dot notation, default values
* **Data classes** — `data class`, `.toString()`, `.equals()`, `.copy()`
* **String templates** — `${object.property}` requires braces
